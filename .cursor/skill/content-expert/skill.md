```
用户提出选题需求（行业+场景）
    ↓
📅 获取当前时间 + 判断淡旺季
    ↓
📊 调用市场分析接口（行业特征、消费趋势）
    ↓
🔍 调用社交舆论接口（舆情热点、用户需求）
    ↓
📋 生成选题报告：
    - 当前时间 & 淡旺季判断

```

## 指令

### 第一部分：脚本撰写

#### 1.1 脚本结构模板

**通用脚本结构**：
```markdown
# [标题]

## 开场（黄金3秒）
【口播+字幕】
[核心关键词] + 心理钩子（三选一）
- 打断预测/奖励期待/损失厌恶

## 引入（10秒）
【口播+字幕】
痛点引入 + 共鸣建立
[长尾关键词]自然融入

## 主体（60-90秒）
【口播+字幕】
解决方案/产品介绍/案例展示
[产品关键词]出现 ≥1次
[核心关键词]出现 2-3次

## 结尾（15秒）
【口播+字幕】
价值总结 + 行动号召
[核心关键词]再次出现

## 评论区引导
[利益点]？[核心关键词变体]评论区[指令]

## Hashtag矩阵
#[核心关键词] + #[产品关键词] + #[长尾关键词] + #[行业词] + #[品牌词]
```

#### 1.2 脚本类型

| 脚本类型 | 适用场景 | 结构特点 |
|----------|----------|----------|
| **问题解决型** | 选购指南、避坑 | 痛点→分析→方案→行动 |
| **案例拆解型** | 成功案例、效果展示 | 背景→数据→关键动作→复制 |
| **清单合集型** | 工具推荐、资源整理 | 核心推荐→分类清单→建议 |
| **对比评测型** | 产品对比、方案对比 | 维度→A分析→B分析→结论 |
| **故事叙述型** | 人设打造、客户案例 | 背景→冲突→转折→收获 |

#### 1.3 脚本撰写示例

**示例：奶粉选购问题解决型**

```markdown
# 奶粉怎么选？90%的人都踩了这3个坑

## 开场（黄金3秒）
【口播+字幕】
"别再随便买奶粉了！90%的妈妈都踩过这个坑。"
核心词：奶粉

## 引入（10秒）
【口播+字幕】
"每次去母婴店，店员推荐的总是最贵的那款。
但贵的真的好吗？到底怎么选才对？"
长尾词：奶粉怎么选

## 主体（60-90秒）
【口播+字幕】

### 第一招：看奶源
"奶源是奶粉的灵魂。
全球黄金奶源地在哪里？新西兰、荷兰、澳大利亚...
记住这个口诀：南纬45度以北，品质差不了。"
产品词：婴儿奶粉、有机奶粉

### 第二招：看配方
"配方怎么看？关键看这三个：
OPO结构脂、乳铁蛋白、DHA...
不是越全越好，而是适合宝宝最重要。"
核心词：婴儿奶粉

### 第三招：看渠道
"渠道不正规，再好的奶粉也是假的。
教你看清授权书、辨真伪..."
产品词：奶粉推荐

## 结尾（15秒）
【口播+字幕】
"选奶粉记住三句话：
看奶源、看配方、看渠道。
觉得有用，记得收藏+关注。"
核心词：奶粉

## 评论区引导
"怕选错奶粉被骗？奶粉选购问题评论区问我"

## Hashtag
#奶粉 #婴儿奶粉 #奶粉怎么选 #母婴 #[品牌名]
```

### 第二部分：封面设计指南

#### 2.1 封面三原则

```
✅ 少即是多 - 每屏不超过2个重点
✅ 对比明显 - 颜色、文字大小区分层次
✅ 留白舒适 - 呼吸感提升阅读体验
```

#### 2.2 封面模板

| 类型 | 排版 | 文字内容 | 示例 |
|------|------|----------|------|
| **数字冲击型** | 数字+大标题 | 7天/10个/3招 | "7天学会选奶粉" |
| **痛点直击型** | 问题+问号 | 你是否...？ | "你的宝宝上火了吗？" |
| **对比型** | 前后对比 | Before→After | "选错奶粉=害了宝宝" |
| **清单型** | 列表展示 | 1/2/3/4... | "10款奶粉大测评" |
| **警示型** | 感叹号+警示 | 千万别/注意 | "千万别买这5款" |
| **人设型** | 真人+标签 | 身份+观点 | "营养师：别再乱补了" |

#### 2.3 封面配色建议

| 内容类型 | 推荐配色 | 适用场景 |
|----------|----------|----------|
| 干货教程 | 蓝色系、专业感 | 知识类 |
| 测评对比 | 黄色/橙色、醒目 | 选购类 |
| 避坑警示 | 红色系、警示感 | 提醒类 |
| 好物推荐 | 粉色系、温暖感 | 种草类 |
| 人设打造 | 品牌色、统一感 | IP类 |

#### 4.7 ⭐ 豆包AI绘图避坑指南（重要！）

> ⚠️ 发送给豆包生成图片时特别注意，以下符号和emoji容易出现乱码

**❌ 容易乱码的符号（避免使用）**：
| 类别 | 乱码符号 | 稳定替代方案 |
|------|----------|--------------|
| ✅❌ | ❌ ✅ | 用 `✓` `✗` 替代 |
| 🏆💰 | 🏆 💰 | 用 `第1名` `￥` 替代 |
| 🎯📌 | 🎯 📌 | 用 `重点` `必看` 替代 |
| 📊📋 | 📊 📋 | 用 `数据` `清单` 替代 |
| ⚡🔥 | ⚡ 🔥 | 用 `速看` `爆款` 替代 |

**⚠️ 慎用的emoji**：
- 部分特殊emoji在AI绘图中渲染不稳定
- 推荐使用：👍 ❤️ ⭐ 🌟 ✨ 💡
- 避免使用：组合emoji、肤色emoji、复杂表情

**✅ 推荐的中文符号**：
```

＋ － × ÷ ＝ ≠ ≤ ≥
「」『』【】《》〈〉『'
```

### 第六部分：内容优化

#### 6.1 数据反馈优化

| 指标 | 问题 | 优化方向 |
|------|------|----------|
| **点击率低** | 封面不吸引/标题无亮点 | 参考高点击封面优化 |
| **完播率低** | 内容太枯燥/节奏慢 | 增加钩子/精简内容 |
| **互动率低** | 没有引导/内容无槽点 | 增加互动话术 |
| **涨粉率低** | 价值感不足/不连贯 | 提供系列内容 |

#### 6.2 A/B测试建议

- **标题测试**：同一内容，不同标题
- **封面测试**：同一标题，不同封面
- **开头测试**：同一内容，不同开头
- **时长测试**：同一内容，不同时长
