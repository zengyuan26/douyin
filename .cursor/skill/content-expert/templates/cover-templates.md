# Content Expert - 封面设计模板库

## 一、封面设计原则

### 1.1 封面三原则

```
✅ 少即是多 - 每屏不超过2个重点
✅ 对比明显 - 颜色、文字大小区分层次
✅ 留白舒适 - 呼吸感提升阅读体验
```

### 1.2 封面尺寸规范

```
抖音尺寸：9:16 竖屏（1080×1920）
文字区域：居中或上下1/3处
核心文案：不超过15字
```

```

│   奶粉选购必知要点          │
│                             │
│  ┌─────────────────────┐    │

│  └─────────────────────┘    │
```

## 四、字体规范

| 层级 | 字大小 | 字重 | 用途 |
|------|--------|------|------|
| H1 | 80-100px | 加粗 | 核心数字/关键词 |
| H2 | 50-60px | 加粗 | 核心卖点 |
| H3 | 32-40px | 常规 | 辅助说明 |

## 五、封面元素位置

### 竖屏封面布局

```
┌─────────────────────────────┐
│          H1（标题）          │  ← 顶部1/4
├─────────────────────────────┤
│                             │
│         主体视觉             │  ← 中部1/2
│                             │
├─────────────────────────────┤
│          H3（说明）          │  ← 底部1/4
├─────────────────────────────┤
│    #话题标签 #品牌标签       │  ← 最底部
└─────────────────────────────┘
```

---

## 六、封面检查清单

```
✅ 封面检查

□ 是否有核心数字/关键词？（H1）
□ 是否有明确的价值承诺？（H2）
□ 颜色是否与内容类型匹配？
□ 字体大小是否清晰可读？
□ 是否有话题标签？
□ 是否有人设/品牌标识？
□ 整体是否有视觉冲击力？
□ 是否与竞品有差异化？
```
