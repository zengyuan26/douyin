# Track C · 身份定位线

> 不打"你想错了"，打"你在哪一层"。不是拆穿幻觉——是让观众逐段自我归位。归完发现自己站在低层，焦虑驱动往上走。走到最后，带一个具体动作离开。

---

## 一、信任路径

| 维度 | Track A 朱莉娅 | Track C 身份定位 |
|------|------|------|
| 信任靠什么 | 跨域连接——"三个不相干领域指向同一结论" | 在场经验——"我亲眼见过的 + 你身上也正在发生" |
| 观众心里那句 | "这人能把不相干的东西连起来——他看问题比我深" | "他说的就是我——他走过这条路" |
| 权威建立 | 外部弹药交叉验证 | 第一人称在场 + 见过的样本量 |
| 壁垒 | 跨域连接能力，不可复制 | 在场经验天然独占——你见过就是你见过 |

---

## 二、路由判据

| 判断条件 | 走 Track C | 走 Track A |
|------|------|------|
| 话题是日常场景？ | ✅ 窗口办事/逛超市/做抖音/选工作 | 否——是概念/机制层 |
| 观众拿走的是 | 一个明天就能做的动作 | 一个换角度看问题的新框架 |
| 开场是 | 一个画面（"你去窗口..."） | 一个判断（"拥挤的不只是编制"） |
| 弹药是 | 在场经验 + 见过的样本 | 跨域连接——金融/科学/商业 |
| 结尾是 | "评论区说说你有没有踩过这个坑" | "画地图的人自己走地图上的路吗" |

**一句话路由：** 观众看完第一反应是"这就是我"→ Track C。观众看完第一反应是"原来可以这样看"→ Track A。

## 三、结构骨架

### 3.1 清单体（主骨架）

**论文先行，不是场景先行。场景是证明，不是钩子。**

v1-v7 踩过的坑：用场景开篇（"你去工厂找个人"）→ 观众在画面外面隔着玻璃看别人。变强起点用论文开篇（"穷人的孩子混社会"）→ 观众第1个字就被装进身份里。

```
┌──────────────────────────────────────────────────┐
│ 1. 论文（身份 + 断言）                              │
│    "普通人家出来的孩子，必须学会看工资以外的另一个数"    │
│    一句话定身份 + 给结论。不铺垫。                     │
├──────────────────────────────────────────────────┤
│ 2. 禁忌感                                         │
│    "学校不教。父母不懂。你爸教你的那套是真心的——       │
│     但那张地图是三十年前的。"                         │
│    三短句。让观众觉得在学别人不知道的东西。              │
├──────────────────────────────────────────────────┤
│ 3. 代价 + 命名                                     │
│    "你要想30岁不一抬头发现前面没路了，这堂课必须补上。    │
│     这堂课叫：五年后你在哪。"                         │
│    具体后果 + 给概念起名字。                          │
├──────────────────────────────────────────────────┤
│ 4. 隐藏劣势                                        │
│    "普通人家孩子选工作最大的坑——不是不努力，是太会算了。  │
│     算得太精了，精到只算了一个月。"                     │
│    推翻常识。观众以为自己缺努力，其实缺的是另一个量法。    │
├──────────────────────────────────────────────────┤
│ 5. 对话转折                                        │
│    "兄弟，你那条路已经窄到只能侧身挤了。"               │
│    从讲道理切换到跟观众说话。                          │
├──────────────────────────────────────────────────┤
│ 6. 场景（证明）                                     │
│    "来。我给你看一条路。这条路地图上没有。"              │
│    "你去任何一家制造业工厂。找一个30岁出头、自己开厂的   │
│     人。问他22岁在干什么。"                           │
│    论文是子弹，场景是弹孔。让观众看见弹孔在哪。          │
├──────────────────────────────────────────────────┤
│ 7. N条逐层展开（N=5最佳）                            │
│    每条 = 你在X / 他在Y / 结果                       │
│    定位句是观察，不是纠正。不说"你错了"——两条路摆出来，   │
│    观众自己归位。                                    │
├──────────────────────────────────────────────────┤
│ 8. 算账时刻                                        │
│    "来，帮你算笔账。不是讲道理——就按计算器。"           │
│    用手替观众算。具体金额。A vs B 两边都算。            │
├──────────────────────────────────────────────────┤
│ 9. 评论区归位                                       │
│    零知识门槛 + 回答自带叙事                          │
│    "你第一份工作看工资还是看谁带你？那条路走对了吗？"     │
└──────────────────────────────────────────────────┘
```

### 3.2 案例体（变体）

```
论文 → 禁忌 → 代价+命名 → 隐藏劣势 → 对话转折 → 案例1（你在X/他在Y/结果）
→ 案例2 → 案例3 → 原理提炼 → 怎么做（4条左右）
→ 算账时刻 → 评论区归位
```

**判断用清单体还是案例体：** 话题有5层递进逻辑 → 清单体。话题是"一个领域里你不知道的秘密" → 案例体。

## 四、句式弹药库

### 弹药 A · 定位句 "你在X，他在Y"

全篇最高频句式。每条至少出现一次。**全篇≥8次。**

```
你在 [做低维动作] ，他在 [做高维动作]

"你在用时间换钱，他在用系统放大结果"
"你在卖货，他在卖情绪"
"你拿的是确定性收入，他拿的是系统性利润"
"你以为这叫认真，这叫头铁"
"你在表达自我，他在设计流量路径"
"你觉得自己在省钱，其实你在用身体硬刚一个可以绕过去的坑"
```

**写作规则：**
- X 必须是具体动作（用时间换钱/卖货/讲道理/省钱）——不能说"你能力差"
- Y 必须是 X 的高维版本——不能说"他运气好"
- 不用"而"字连接——用逗号顿开。"你在X，他在Y"
- 每条定位句既是判断也是钩子——让观众停下来：我在哪边？
- **定位句 ≠ 纠正句。** "你在用月薪选路，他在用师傅选未来"——这是观察，观众自己归位。**不能说**"你不知道""你以为""你这不叫"——那是纠正，观众防御。把纠正全砍掉。结论留给观众自己推。

### 弹药 B · 定义权 "这不叫X，这叫Y"

每条展开后的收尾。给老词一个新名字。**全篇≥3个。**

```
"这不叫生意，这叫出卖劳动力"
"这不叫行贿，这叫人情润滑剂"
"这不叫圆滑，这是智慧"
"值钱是别人愿意给你开价，有钱是你拥有规则和分配权"
"运气就是踩对了算法、抓对了痛点"
"信息本身不值钱，你对信息做出的判断才值钱"
```

**写作规则：**
- X 必须是被社会污名化或被误解的词——"行贿""圆滑""清高"
- Y 必须是新的、反常识的、但一听就对的词——"润滑剂""智慧"
- 定义不是解释——是**命名权**。观众看了说"哦——"
- 每个定义独立成行，不塞在长句里

### 弹药 C · 算账体 "你算过账吗"

把抽象认知翻译成具体数字。位置：清单结束后、收束前。

```
"你省了15块，搭进去的是一整天 + 来回车费 + 重新打印 + 憋着的气"
"第一份工资最高 = 五年后你最穷"
"你现在不做，一年后还是现在的你"
```

**写作规则：**
- 必须有具体数字——金额/时间/年份。不能是"代价很大"
- 两边都要算：选了A亏什么，选了B得什么

### 弹药 D · 在场锚点 "我在XX干了X年，见过..."

权威不靠引用。靠在场的样本量。**全篇≥3次。**

```
"我在深圳干了这么多年，见过太多人技术牛逼——最后活成了高级打工仔"
"我在抖音干了这么多年，见过太多人产品不错服务业行，就是卖不动"
```

**写作规则：**
- "我见过太多人"后面必须接一个具体画像
- 样本量暗示：不是"我见过一个人"——是"我见过太多人"
- 隐含信息：我不是在讲理论——这条路我走过

### 弹药 E · 场景代入 "你XX，但你没想过XX"

每一段开头，先把观众拽进一个具体画面。

```
"你去窗口办审批，材料被退回——"
"你逛超市看到一瓶饮料，只会想贵不贵——"
"你刚进公司，想跟老员工学东西，干等着——"
```

**写作规则：**
- 必须用"你"开头
- 必须是日常画面——每个人做过的事
- 不能用"有一种人""很多人"——必须是"你"

## 五、钩子后三段式过渡

钩子刺中后，不直接进入内容。做三个动作——顺序可变，但三个都在。

### 动作1：扩大共鸣面——从"你"到"很多人"

```
"学校不教，父母不懂，甚至很多人听了会皱眉头"
"很多人一辈子搞不清楚一个问题——为什么自己比老板更能干、更辛苦，却永远赚不到老板的钱？"
"很多人活了大半辈子才发现自己一直在害怕——怕别人看不起、怕做错事、怕被拒绝、怕失败、怕丢脸"
```

**作用：** 钩子已经刺中你了。过渡句让你确认——"不止是我，很多人都有这个问题"。这个确认卸掉羞耻——你更愿意往下听了。

**写作规则：** "很多人"后面接的不是笼统描述——是具体感受/动作。"很多人听了会皱眉头"=具体动作。"很多人一辈子搞不清楚一个问题"→后面立刻接那个问题。

### 动作2：在场锚点——"我不是在讲理论"

```
"我在深圳干了这么多年，见过太多人技术牛逼——最后活成了高级打工仔"
"我见过太多这样的人，做抖音的时候有人问我——我想做账号但我怕别人笑话我"
"我最近在逛闲鱼，发现了一个特别有意思的现象"
```

**作用：** 在观点落地之前，先落一个人。"我不是读了几本书来给你讲课。我亲眼见过。"这个锚点打下去之后——后面的结论你不太会反驳了。

**写作规则：** 必须落在具体地点/时间/人物。"在深圳做电商"比"在行业里"强。"最近在逛闲鱼"比"据我观察"强。

### 动作3：画面/案例——让你看见

```
"来，我给你描述一个场景，你看像不像你？你去某个部门办一个审批——"
"我给你举几个例子，第一个改PDF文件里的字——"
"普通人逛超市看到一瓶饮料卖6块钱，只会想贵不贵——"
```

**作用：** 过渡段制造的共鸣还是抽象的。"很多人都有这个问题"——但你还没"看见"自己。画面让你看见自己在里面。一旦看见了——后面的道理不是你听进去的，是你自己推出来的。

### 三段式过渡模板

```
钩子                          ← 刺中
  ↓
"很多人都有这个问题"           ← 卸掉羞耻（不是只有你）
  ↓
"我在XX干了X年，见过太多人"    ← 落信任锚（我不是在讲理论）
  ↓
"给你看一个画面/案例"          ← 让你看见自己在里面
  ↓
进入清单/弹药                  ← 开始推
```

**和 Track A 的区别：** Track A 钩子后直接进概念（"拥挤交易"）。没有过渡。观众还在"这是什么意思"，就开始推弹药了。门槛高——需要观众自己跟上来。Track C 的三段式过渡在降低这个门槛——先卸羞耻、再落信任、再让你看见。然后才推。

## 六、声线：路边大哥的对话感

### 核心原则：说的不是写的

v1-v7 共 7 版稿子反复犯同一个错——结构对了、内容对了、但味不对。根因：**语言是"写完的"，不是"说出来的"。**

变强起点的稿子读起来像一个人在跟你聊天。v7 读起来像一个人在念稿子。差距在这里。

### 对话感四要素

| # | 要素 | 不是这样 | 是这样 |
|---|------|------|------|
| 1 | **称呼** | 没有称呼，直接说 | "兄弟""你想一下""你看像不像你" |
| 2 | **邀请** | "你去工厂找个人"（指令） | "来。我给你看一条路。"（拉你一起看） |
| 3 | **算账** | "选A——每月多拿2000。五年多12万。"（表格感） | "来，帮你算笔账。不是讲道理——就按计算器。你算过这笔账吗？"（用手指替你算） |
| 4 | **句号密度** | 中等。句子有长有短 | 极高。短句。说完就断。"两条路。同一个起点。中间只差了一件事。" |

### 定位句 vs 纠正句（重申）

这是声线走形的第一原因。详细规则见 Section 四-A。

```
✅ 观察："你在量工资。他在量师傅。"
❌ 纠正："你不知道这条路。""敌人在你自己脑子里。"

✅ 让观众自己推："两条路。两个结果。"
❌ 替观众下结论："你这不叫务实。这叫只算了一个月。"
```

### 对话检查点

写完稿子后，朗读一遍。问自己：
- 这篇稿子说出来——旁边的人会觉得我在跟他聊天，还是我在念稿？
- 有没有连续 3 句以上"你"后面接纠正？（有 → 声线污染）
- "兄弟""来""你想一下"出现没有？（至少各 1 次）

### 和 Track A 声音的区别

| | Track A（朱莉娅） | Track C（路边大哥） |
|------|------|------|
| 关系 | 我给你看几个事。你自己想。 | 兄弟，你看像不像你？ |
| 弹药驱动 | 六类权威交叉扫射 | 画面 + 在场样本 |
| "兄弟" | **禁止。** 弹药密度已经站高处，别假装蹲路边 | **必须。** 至少 3 次。这是对话感的核心 |
| 结论谁推 | 弹药推。观众接收后自行判断 | **画面推。** 两个结果摆出来，观众自己算 |

## 七、钱锚铁律

### 不是技巧——是选题决策

变强起点五篇——不管入口是什么话题，出口永远是钱。连#43精神内耗都落钱（"不给我钱也不对我好的人一概不在乎""我只在乎我的情绪、我的钱、我的健康"）。

**Track C 铁律：钩子必须含具体金额或金钱逻辑。观众3秒内能算出一笔账。**

| 篇 | 表面话题 | 钩子里的钱 | 为什么能停 |
|------|------|------|------|
| 5件事 | 商业思维 | "为什么赚不到老板的钱" | 直接问钱 |
| 60天 | 思维训练 | "月入5万的故事" | 具体金额 |
| 闲鱼 | 副业/小生意 | "月入过万""20-50一单" | 具体金额贯穿全文 |
| 小钱开路 | 社交/人情 | "小钱开路""15块两瓶水" | 金额+金钱逻辑 |
| 不害怕 | 精神内耗 | "我只在乎我的情绪、我的钱、我的健康" | 钱是过滤标准 |

### 钩子自检

```
钩子读一遍。问自己：观众3秒内能在心里算出一笔账吗？
算不出来 → 钩子是认知入口，不是钱入口 → 重写。

❌ "你脑子里有一颗炸弹。定时器设在30岁" → 零金钱。认知隐喻。
✅ "你每个月多拿2000块。五年多拿12万。你以为赚了。你亏了。" → 3秒算出12万。
```

### 为什么有效

钱是唯一通用的焦虑语言。你说"精神内耗""社交恐惧""认知框架"——不同的人有不同的焦虑。你说"你在亏钱"——每个人都停下来。

### 翻译规则

| 原始概念 | 钱锚翻译 |
|------|------|
| 清高/要面子 | "你这不叫清高叫傻，你的目标是把事办成"——事办不成=亏钱 |
| 恐惧/犹豫 | "你现在不做，一年后还是现在的你"——一年后=收入没变 |
| 不会经商/没商业思维 | "你逛超市只看到贵不贵，有人在看利润怎么分配"——你看不到的钱=别人在赚 |
| 精神内耗 | "不给我钱也不对我好的人——我一概不在乎"——用一个钱标准过滤掉所有内耗 |

### 强制闸门

- **C2 定位隐藏劣势：** 强制问"这个错让他亏了多少钱？"算不出→退回重选
- **Step 7.66 #5 钱锚：** 钩子带钱了吗？观众3秒内能算出一笔账吗？不过→钩子重写
- **全篇出口：** 算账时刻必须落一个具体数字。不是"代价很大"——是"多拿12万，亏的是五年后的跳变"

## 八、评论区设计

### 四种评论引导类型

| 类型 | 例子 | 为什么能爆 |
|------|------|------|
| **归位型** | "你现在在哪一层？" | 每个人都想表达自己站在哪一级——自我定位=社交货币 |
| **动作型** | "就这一个动作先做起来" → 做完的人回来报道 | 做完的人回来打卡——评论区变成进度条 |
| **需求暴露型** | "如果你脑子里已经有了一个方向，打到评论区，我们一起来看看值不值得做" | 你在评论区暴露需求→博主免费帮你看→别人也在围观 |
| **故事型** | "你有没有因为死要面子把自己坑了的经历？评论区聊聊" | 人人都有——被坑过的记忆是最好挖的。每个回答都是一个微型故事 |
| **承诺型** | "你打算从哪件让你害怕的事开始突破？我会看每一条留言" | 公开承诺=自我绑定。说出来=有人盯着。兑现的人会回来汇报 |

### 四个设计规律

**1. 零知识门槛。** 不需要懂任何东西。只需要你是个人。

```
❌ "你怎么看这个框架？"        → 需要理解框架
❌ "你觉得哪一步最重要？"       → 需要看完+理解+比较
✅ "你有没有被坑过？"           → 只需要活过
```

**2. 回答自带叙事。** 不是"是/否"——每个回答都是一个微型故事。

```
"你有没有因为死要面子把自己坑了的经历？"
→ "有。2019年我..." ← 每个回答都是完整的故事
→ 故事驱动互动，互动驱动算法
```

**3. 回答让回答者受益。** 不是"帮博主"——是"帮自己"。

| 类型 | 回答者的收益 |
|------|------|
| 归位型 | 被看见——"我在第3层"=我有自我认知 |
| 动作型 | 被认可——"我今天开始练了"=我是行动者 |
| 需求暴露型 | 被帮助——"帮我看这个方向"=博主免费帮我看 |
| 故事型 | 被共情——"我也被坑过"=评论区形成互助团 |
| 承诺型 | 被绑定——"我说了要开始健身"=有人盯着我更可能做 |

**4. 不制造争论——制造分享。**

争论型：你站哪边？→ 少数人吵，多数人沉默。
分享型：你经历过吗？→ 人人都能讲自己的故事。故事比争论多10倍参与。

### 和 Track A 评论区的区别

| | Track A 朱莉娅 | Track C 变强起点 |
|------|------|------|
| 典型评论引导 | "画地图的人自己走地图上的路吗？" | "你有没有因为死要面子把自己坑了的经历？" |
| 需要的能力 | 理解框架+反思+抽象表达 | 回忆+讲一个自己的故事 |
| 谁在回答 | 思考型观众（少数） | 每个人（大多数） |
| 回答长度 | 短。一句话观点 | 长。一个微型故事 |
| 互动率 | 低——有门槛 | 高——零门槛 |

## 九、内容飞轮

```
钱锚钩子（"你在亏"）→ 三段式过渡（卸羞耻+落锚+画面）→ 清单/案例（你在X，他在Y × N）
→ 算账时刻（翻译成具体金额）→ 评论区归位（零门槛讲故事）

评论区讲故事 → 故事越多 → 算法推越多 → 更多人看到 → 更多人评论区讲故事
```

**五个飞轮节点——少了任何一个，评论量就会降：**

| # | 节点 | 少了会怎样 |
|---|------|------|
| 1 | 钩子不带钱 | 停下来的人少 |
| 2 | 过渡不卸羞耻 | 停在"看到了"但没往下 |
| 3 | 没有在场锚点 | 觉得你在说教，不信 |
| 4 | 收束不落评论区 | 看完就走 |
| 5 | 评论引导有门槛 | 想评论但不知道说什么 |

## 十、选题公式

```
[普通人] + [一个隐藏劣势] + [反常识低成本解法]
```

| 公式元素 | 例子 |
|------|------|
| 普通人 | "穷人家的孩子""不会经商的你""只会干活的你" |
| 隐藏劣势 | "太爱省""没人教过商人的眼睛""只会执行不会设计" |
| 低成本解法 | "小钱开路""60天练5件事""闲鱼改PDF" |

**选题自检三问：**

| # | 问 | 通过标准 |
|---|------|------|
| 1 | 这是"普通人"的痛点吗？ | 不是老板/高管/投资人——是工位上的人、窗口前的人、刷招聘网站的人 |
| 2 | 劣势是他自己没意识到的吗？ | 不是"我太穷了"，是"我不知道我的清高在害我" |
| 3 | 解法是低成本的吗？ | 不需要钱/人脉/背景。一瓶水、60天练习、一个思维动作 |

## 十一、质量自检清单

**结构层：**
```
□ 场景钩子：10秒内能看见自己吗？（不是"有一种人"）
□ 定义重命名：有没有一个词被重新定义了？
□ 清单 = 5条？少了观众觉得不完整，多了记不住
□ 每条有"你在X，他在Y"定位句？
□ 算账时刻：有具体数字吗？（不是"代价很大"）
□ 评论区是归位型提问？不是争论型？
```

**句式层：**
```
□ "你在X，他在Y"全篇≥8次？
□ 定义句"这不叫X，这叫Y"全篇≥3个？
□ "我见过太多人"≥3次？
□ 每个弹药段的开头是"你XX"的场景吗？
□ 没有"在当今""随着...""众所周知"？
```

**信任层：**
```
□ 在场锚点够不够具体？（"在深圳做电商"不是"在行业里"）
□ 案例是真实细节不是笼统概括？
□ 观众看完会觉得"他在说我"而不是"他在教我"？
```

## 十三、Track C vs Track A 对比

| | Track A 朱莉娅 | Track C 身份定位 |
|------|------|------|
| **打什么** | 认知幻觉——"你想错了" | 身份焦虑——"你在这一层" |
| **结构** | 反常识阶梯——每层推翻上一层 | 清单骨架——每层让你归位一次 |
| **弹药** | 四域交叉（金融/科学/商业/认知） | 单域直拳（在场经验+见过的样本） |
| **权威** | 外部引用——风投数据/于东来/幸存者偏差 | 第一人称——"我在XX干了X年+我见过X种人" |
| **开场** | 概念开火（"拥挤交易"） | 场景代入（"你去窗口..."） |
| **每段收尾** | 反常识过渡——推翻上一个结论 | 定位句——"你在X，他在Y" |
| **观众感受** | "原来可以这样看" | "他在说我，我得往上走" |
| **分享动机** | 金句/框架/概念（"这个角度好牛"） | 清单/自我定位（"你在哪一层？"） |
| **评论驱动** | 争议型（方法论分歧） | 归位型（自我暴露+讲故事） |
| **时间抗衰** | 强——机制层，十年后成立 | 中——方法层，部分有时效 |
| **人设壁垒** | 强——跨域连接能力独占 | 中——在场经验天然独占 |
| **顶层传播** | "我在思考深刻的东西" | "他在说我" |
| **高净值信任** | 强——判断力打动 | 弱——会被觉得"肤浅" |
| **学习成本** | 高——需要跨领域知识储备 | 中——需要真实的在场经验 |

## 十四、融合使用

Track A 的弹药可以用 Track C 的句式收尾。幂律分布验证了这一点——它本质是 Track A，但 P2"你习惯的世界 vs 真实的世界"本质上就是"你在X，他在Y"。这种融合不改变轨道归属——但提升传播力。

**Track A 可偷 Track C 的句式：**
- 每个弹药段结尾加一行动位句——"你看到的X，他看到的Y"
- 收束前加一个算账体——把抽象框架翻译成具体代价

**Track C 不能偷 Track A 的弹药：**
- Track C 的场景代入不能被概念开火替换
- Track C 的在场锚点不能被外部权威替换
