# 产业对标型图文

> 类型：投行分析型图文子类 | 状态：已验证（比亚迪vs宁德爆款） | 更新：2026-07-16

---

## 一、定义

产业对标型图文：**没有新闻事件触发，基于结构性认知差，用SOTP/对标框架同时分析两个可交易标的，让评论区自动分裂成两派。**

跟事件驱动型的本质区别：

| | 事件驱动型 | 产业对标型 |
|------|----------|----------|
| 触发 | 新闻/政策/数据 | 结构性认知差 |
| 时效 | 48h窗口，过期衰减 | 无过期，可反复迭代 |
| 叙事起点 | "刚发生了一件事" | "市场一直看错了一件事" |
| 核心框架 | 事件→信号→拆解→判断 | 对标→拆解→两套标签→重估 |
| 评论驱动 | 观点认同/反对 | 身份站队（A派 vs B派） |
| 制作周期 | 快（一天，抢窗口） | 慢（需研究两家，数据密度更高） |
| 代表篇 | 钠电CVC / 绿证暴涨 / 六张网 | 比亚迪vs宁德 |

## 二、黄金结构（6页）

```
P1 封面   = 两个对标数字 + 反常识判断 + 标签行
           例：比亚迪营收8000亿。宁德4200亿。赚更多的那家，市值更低。

P2 拆解   = SOTP/四宫格。每格=业务板块+规模+对标+问题
           目的：让读者自己算出"加起来不止这个价"

P3 价值链  = 一张表展示产业链能力差异。三玩家的✓/✗。
           中间夹一个反转故事（如中东订单）。
           收尾：Punchline句号断开。"全链都做的那家。市场叫她'车企'。"

P4 争议   = 同一赛道两套标签的对比。
           左边全是溢美词，右边全是贬义词。
           全文只放一个争议点。"尺子歪了。不是一天的歪法。"
           以"你怎么看？"把话筒递给读者。

P5 预期差  = 两边都算一遍（公平感）。
           三种情形用中文标签：修复/重估/悲观。
           机构背书放在个人判断之后。

P6 二选一  = 一个词开头。"最后。"
           不给答案给选择。两个名字并列。
           "留个言。到时候回来翻。"
```

## 三、写作铁律

### 句号密度
- 逗号少用，句号大胆用
- 连接词（但是/然而/因此）全部删掉
- 两个短句并列，让读者自己比

### 数字规则
- 每个数字必须带对比参照
- 不能"比亚迪8000亿"——必须"比亚迪8000亿。宁德4200亿。"
- 数字不是装饰，是武器

### 争议设计
- 全文只放一个争议点（P4）
- 争议必须是结构性的（"尺子歪了"），不是具体数据对错
- 不给结论，给问题

### 收尾
- P6不是总结，不是CTA，是填空
- 两个选项并列，读者必须选一个
- "到时候回来翻"制造时间约定

### 标签框架
- 核心概念用日常词汇："标签"不是"估值"，"尺子"不是"估值体系"
- 让普通人觉得自己也能判断，不需要专业背景

## 四、选题条件

同时满足四个条件才能用产业对标型：

1. **两个可交易标的** — 都是上市公司或知名品牌，散户能搜到股票代码
2. **同一赛道** — 做同一个生意，但市场给不同待遇
3. **争议空间** — 不能一边倒。两边都能列论据
4. **认知标签差** — 不只是"A比B便宜"，是"市场为什么给A和B不同标签"

## 五、选题池

| 选题 | 标的A | 标的B | 标签差 |
|------|------|------|--------|
| AI+能源谁在第二档谁在第三档 | 协鑫能科（25x PE） | 林洋能源（15x PE） | 一个跟蚂蚁合资，一个自己跑 |
| 逆变器两条路线 | 阳光电源 | 华为LUTERRA | 纯逆变器 vs 自研SiC+AI+构网闭环 |

## 六、跟事件驱动型的分工

```
投资向图文
├── 事件驱动型（钠电/绿证/六张网）
│   → 事件→信号→拆解→判断。48h窗口。每月1-2篇。
│   → 优势：蹭热点流量，拉新快
│   → 劣势：过期就凉，评论区深度不够
│
└── 产业对标型（比亚迪vs宁德）
    → 对标→拆解→标签差→重估。无过期。每月1篇。
    → 优势：评论区炸裂，信任锚最深，可反复迭代
    → 劣势：研究量大，需积累两家公司的完整数据
```
