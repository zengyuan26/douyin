## 核心概念

每个人在接触任何信息之前，脑子里已经选好了一个默认值：**世界是友善的，还是敌意的。** 这个默认值决定了接下来一切行为。

| | 友善默认 | 敌意默认 |
|---|---|---|
| 外部信号 | 信息。接收→处理→决定 | 威胁。识别→防御→反击 |
| 行为模式 | 不设防。观察。借力 | 戒备。压制。树敌 |
| 长期结果 | 越来越大（信息接收最大化） | 越来越小（制造了本不存在的敌人） |
| 底层心理 | 信自己不会被一击就碎 | 觉得自己随时会掉下去 |

## 弹药三连

### 1. 华为竹知了（敌意默认代价）

10块钱竹子玩具→发出类似发布会观众声音→华为投诉171次要求下架→结果：卖了50万个，64%负面。

组织病灶：法务KPI✅+外包指标✅+平台风控✅=品牌承担全部反感。每步都对，加起来全错。

### 2. Levi's世界杯白布（友善默认复利）

冠名体育场Logo被FIFA白布遮住→回应：把头像换成被遮Logo+"没人会知道的"→135万赞，史上最强免费广告。

同一类事。两个方向。不是公关差距——底层默认设定反了。

### 3. 李小龙"我眼里没有敌人"（升维）

不设防的前提是知道自己是谁。不靠"打败谁"确认位置。

### 4. 郭德纲收束（文化层）

"一个不能开玩笑调侃的民族，是可悲的。" → 玩不起的那一刻，已经输了。
