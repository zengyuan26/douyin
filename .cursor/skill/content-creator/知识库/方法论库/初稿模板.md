> 导演分析通过后出。30 秒扫完的蓝图，确认方向再动笔。

```
层层追问 → 导演分析 → 初稿（本模板）→ 确认 → 完整内容制作
```

## 二、分支观点（2-4 个）

> 核心观点的拆解。每个分支观点 = 内容的一个章节。用逻辑链串联。

```
分支①
分支②
分支③
分支④
```

**逻辑链检查：** 抽掉任何一个分支，整体逻辑会不会断？

---

类型标注：事实 / 数据 / 历史规律 / 案例 / 个人经历 / 框架

## 四、目标观众

> 不是"所有人"。具体到一个人。

## 六、利益点设计

> 逐段标注类型 + 获得感。密度前密后疏。

```
P1 ██  类型：               获得感：
P2 ███ 类型：               获得感：
P3 ██  类型：               获得感：
P4 ██  类型：               获得感：
P5 █   类型：               获得感：
P6 █   类型：               获得感：
P7 █   类型：               获得感：
```

**密度检查：** 曲线是 3→2→2→1→1→1 吗？P2 叠了三个不同类型吗？有没有空洞段？

---

## 七、情绪节奏设计

> 一条线画出来。不能是平的。

```
P1
P2
P3
P4
P5
P6
P7
```

**节奏检查：** 有起伏吗？有高点吗？有张力吗？有出路吗？（不能停在焦虑）

---

## 自检（确认前先过）

```
□ 核心观点能一句话说出来吗？
□ 分支观点之间有逻辑链吗？
□ 目标观众在第几段觉得"这跟我有关"？（≤3）
□ 利益点密度是前密后疏吗？P2 是生死页吗？
□ 情绪线有起伏吗？
□ 有没有空洞段——有追问没利益点？
□ 认知差够不够？（AI 能不能给？能的换角度）
□ 封面只放锚点+悬念了吗？（没给结论？）
```
