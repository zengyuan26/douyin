# 新闻分析类图文模式

> 基于钠电CVC（60GWh）和比亚迪储能大单（11.275GWh）两篇爆款图文拆解提炼。两篇数据验证了同一套模式——不是巧合，是可复用的公式。

---

## 一、模式总公式

```
新闻分析类爆款 = 一个最新事件（带具体数字）
               × 一个反常识判断（打破观众已有认知）
               × CVC投行视角（读信号→拆架构→下判断→押位置）
               × 黄金六页结构（钩子→结论→认知→逻辑→终局→收尾）
               × 个人判断贯穿（每页至少1句判断）
               × 一个争议钩子（放在P4，不在P6）
```

**这个模式跟其他分析类图文的本质区别：**

其他图文在"解释一个概念"。这两篇在"走一遍分析流程"。

- 解释概念 → 观众被动接收 → "知道了" → 划走
- 走分析流程 → 观众跟着想 → "原来是这样判断的" → 收藏+关注

**CVC投行人设不是点缀，是这个模式的核心引擎。** 观众不是来学知识的，是来看"专业的人怎么分析这件事"。

---

## 二、标题公式

```
具体数字 + 反常识判断 + 身份/场景标签
```

| 要素 | 钠电篇 | 比亚迪篇 | 作用 |
|------|--------|----------|------|
| 数字锚点 | 60GWh | 11.275GWh | 让人停下来 |
| 反常识判断 | "不是在讲PPT是在签合同" | "宁德时代被踢了" | 让人点进去 |
| 标签行 | 成本-30% · -40℃ · 不靠锂矿 | 2710Ah · IP66 · -30~55°C | 建立公信力 |

**铁律：**
- 标题第一行必须有一个带单位的数字。不要形容词（"大单"不如"60GWh"）。
- 反常识判断必须是观众已有的普遍认知的反面。不是制造未知，是打破已知。
- 标签行覆盖成本+场景+壁垒至少两个维度，不堆无关联参数。

## 三、P1 封面：三层结构

```
第1层  谁 + 做了什么 + 具体数字（带单位）
       例：宁德签了60GWh钠电大单。
       作用：1秒之内告诉观众"这是什么事"

第2层  反常识判断（打破观众的已有认知）
       例：不是在讲PPT。是在签合同。
       作用：制造认知落差 → "等等，什么？！" → 翻页

第3层  数据标签行（≥2个维度：成本/场景/壁垒）
       例：成本-30% · -40℃ · 不靠锂矿
       作用：三个具体参数 = "这个人做了功课" → 信任
```

### 每层的心理学机制

| 层 | 观众视线 | 心理反应 | 如果缺失 |
|------|------|------|------|
| 第1层 数字 | "什么事？" | 锚定注意力 | 扫过去不停 |
| 第2层 反转 | "为什么我该在乎？" | 惊讶→翻页动力 | 无情绪冲击 |
| 第3层 标签 | "凭什么信你？" | 公信力建立 | 有判断无证据 |

### 第2层的关键：反转 > 悬念

反转和悬念的区别：

| | 反转 | 悬念 |
|------|------|------|
| 触发机制 | 打破已有认知 → 惊讶 | 制造未知 → 好奇 |
| 需要什么 | 观众已经有预期 | 观众不需要背景 |
| 情绪强度 | 强（"什么？！"） | 中（"然后呢？"） |
| 翻页动力 | "凭什么？"（验证驱动） | "是什么？"（好奇驱动） |

反转比悬念强，因为反转挑战的是观众**已经相信的东西**。

但反转有条件：必须挑一个**观众已有的普遍认知**来打破。钠电篇打"钠电还在实验室"，比亚迪篇打"宁德时代无敌"。这两个认知不挑人——关心这个领域的人都有。

### 第3层的结构

标签行不是随便挑三个参数。每组覆盖成本+场景+壁垒：

| 维度 | 钠电 | 比亚迪 |
|------|------|--------|
| 成本 | -30% | （2710Ah大电芯=BMS复杂度降） |
| 场景 | -40℃能用 | -30~55°C + IP66 |
| 壁垒 | 不靠锂矿 | 2710Ah（全球最大储能电芯） |

### P1 禁止项

- 不给最终判断（那是P5的事）。如果封面已经给了核心观点，观众为什么要翻页？
- 不设悬念提问。设问不如反转有力。
- 不用形容词代替数字。"大单"不如"60GWh"。
- 不堆无维度关联的参数。三个参数之间要有逻辑关系。

### 失败案例：国常会篇

```
AI吃掉的电，从你电费里出。
运营商和国常会，同一天释放重点信号。
算力铁塔，又是什么东西？
```

| 层 | 问题 |
|------|------|
| 第1层 | "AI吃掉的电从你电费里出"——是一句观点，不是具体事件。没有数字。 |
| 第2层 | "同一天释放信号"——是阴谋论暗示，不是反转。观众没有预期可以打破。 |
| 第3层 | "算力铁塔又是什么东西"——是提问，不是数据标签。没有公信力建立。 |

**致命伤：三层功能全部缺失。** 而且"AI吃掉的电从你电费里出"已经把核心判断给了——这是P5的金句，不是P1的钩子。

### 国常会篇 P1 应按此公式改写

```
第1层  7月10号，国常会定调新型储能入选六大新兴支柱。
       跟集成电路同级。

第2层  同一天。联通副总在台上讲Token。国常会在会上定储能。
       不是巧合。

第3层  通信网 · 算力网 · 新型储能 —— 三网同步
```

## 四、P2 核心结论：四宫格 + 一句收束

P2 是全文信息密度最高的页面。用四宫格控制阅读节奏，让密集信息不压人。

### 结构

```
主标题：一句话概括这页在讲什么
        例："钠电到底强在哪？4个数据，讲人话。"

┌──────────────┬──────────────┐
│ 数字/参数      │ 数字/参数      │
│ 翻译成人话     │ 翻译成人话     │
│ 证据锚点       │ 证据锚点       │
├──────────────┼──────────────┤
│ 数字/参数      │ 数字/参数      │
│ 翻译成人话     │ 翻译成人话     │
│ 证据锚点       │ 证据锚点       │
└──────────────┴──────────────┘

底部收束：一句判断句，把四张卡片拼成一个完整结论
```

### 每张卡片的三行结构

```
第1行  数字/参数          ← 眼睛最先看到（-30%、11.275 GWh）
第2行  翻译成人话          ← 扫一眼就理解（"比锂电便宜三成"）
第3行  一个证据锚点        ← 为什么重要（"原料是食盐不是锂矿"）
```

四张卡片是四个自包含的信息单元。观众在手机上扫视，不管先看哪张，都能独立理解——不需要上下文。

### 为什么四宫格比列表强

列表：四个条目，看完第四个忘了第一个。无层次。观众在"浏览"。

四宫格：2×2 布局给了空间分区。每个卡片视觉独立。视线自然形成两次水平扫视。底部横跨全屏的结论行形成视觉收束。

**P2 的四宫格不是信息容器，是阅读节奏控制器。**

### 铁律
- 每个数据必须配人话翻译。不能只写"-30%"不加"比锂电便宜三成"。
- 底部收束句必须是一个判断，不是一个事实罗列。
- 四张卡片的维度之间要有逻辑关系（成本+寿命+场景+供应链 = 四条全占）。

### 失败案例：国常会篇 P2

```
他们在做什么？

三大运营商算力规模，超200 EFLOPS。
全国占比前列，跟阿里云华为一个量级。

推5G-A。建万卡GPU。搞差异化套餐。
上海移动220多万户已经付费升级。

西部算力中心，一个接一个开工。
```

| 问题 | 说明 |
|------|------|
| 无数字卡片格式 | 200 EFLOPS、万卡GPU、220万户——全是好数字，散在段落里 |
| 无"翻译成人话" | "200 EFLOPS"什么概念？没翻 |
| 收束句缺失 | "西部算力中心一个接一个开工"是在列行动，不是在给判断 |
| 信息层级扁平 | 所有内容同一层级，不知道先看哪个 |

## 五、P3 关键认知：打破一个常识

P3 的任务不是"介绍一个事实"，是"纠正一个错误认知"。

### 两篇的 P3 动作

```
钠电：   认知① 钠电的赛道不是"替代锂电"
         → 打破"钠电来了锂电就完了"

比亚迪： 认知① CATL 为什么被踢？
         → 打破"宁德技术最强所以通吃"
```

### 为什么"纠正认知"比"介绍知识"强

```
"应用场景有三个"     → 你在教我新东西 → "哦" → 划走
"不是替代锂电"       → 你在纠正我以为对的东西 → "等等，那是什么" → 翻页
```

**认知纠正制造轻微不适感。这种不适感就是完播动力。**

### 结构

```
主标题：认知① [打破什么常识]

对比（可选）：
  你以为的 → 实际上的

具体展开（2-3个点）：
  ● 场景一
  ● 场景二
  ● 场景三

一句话收束判断
```

### 铁律
- P3 必须否定一个普遍存在的认知。不能是"原来如此"的揭晓——那是P2的事。
- 对比句式优先于罗列句式。"不是 X，是 Y" > "有以下三个特点"。
- 收束句是全文第一个金句位——对仗、有力、可截图。

## 六、P4 逻辑框架：排序 + 判断 + 争议

两篇 P4 是这个模式最值钱的一页。它同时做了三件事。

### 结构

```
主标题：[排序型问题]
        例："产业链上谁最受益？" / "出海到底拼什么？"

┌─────────────────────┐
│ ① [第一名]           │
│ [一个事实]           │
│ [一个判断]           │
├─────────────────────┤
│ ② [第二名]           │
│ [一个事实]           │
│ [一个判断]           │
├─────────────────────┤
│ ③ [第三名]           │
│ [一个事实]           │
│ [一个判断]           │
└─────────────────────┘

个人判断：我倾向 / 我个人认为 [明确排序]

争议钩子：一个开放性争议 + "你怎么看？"
```

### P4 同时发生的三件事

**1. 排序 = 判断 = 价值**

不是"A好B好C好"，是"我倾向 A > B > C"。

观众的潜意识反应不是"我要记住这三条"，是"他排的对不对？我觉得B好像更优先"。**这已经是评论区的内容了。**

清单让人收藏。排序让人评论。

**2. 每条一个事实 + 一个判断**

```
钠电：   谁先跑通量产=钠电版当升科技       ← 类比判断
        懂调度的集成商才是利润中心          ← 排序判断
        偏早期，需要等政策                 ← 时机判断

比亚迪： 碾压级领先                        ← 程度判断
        场景牌最硬                        ← 排序判断
        场景经验追不了                     ← 壁垒判断
```

**3. 争议钩子放在这一页，不在 P6**

```
钠电：   宁德一家独大，窗口期有限。你怎么看？
比亚迪： CATL慢半拍，技术路线问题还是判断慢了？你怎么看？
```

争议放 P4 的原因：
- 观众认知最密集的时刻，争议嵌入框架里
- P6 是收束页，观众已经累了
- P4 放争议 = 观众带着争议进入 P5

### 铁律
- 必须是排序型框架（①②③），不是并列型（ABC）。
- 每一条必须有一个判断词（"更硬""才是""偏早期""追不了"）。
- 争议钩子必须跟框架内容直接相关，不能凭空出一个争议。

## 七、P5 终局判断：损失厌恶 + 窗口描述

P5 只做一件事：制造紧迫但不给答案。

### 结构

```
主标题：终局③ [一个预测/一个趋势]

展开（可选）：场景描绘或时间窗口

个人体验（可选）："刚入行就看到..." / "说实话..."

一句话收束：门票价格，还没开始涨。
```

### 两篇的收束句几乎一样

```
钠电：   这个赛道的门票价格，还没开始涨。
比亚迪： 中东储能这张门票，价格还没开始涨。
```

这不是巧合。是同一套机制：

- "门票还没涨" → 现在还有机会 → 但快没了 → 损失厌恶
- "这个行业很有前景" → 好消息 → 无紧迫感 → 不收藏
- "现在进场已经晚了" → 观众划走 → 不评论

**"还没来得及涨"是一个精确定位的窗口**——不是"已经起飞"，不是"还没起飞"。制造的是"你刚好站在起跑线前"的感觉。

### 铁律
- P5 的收束句必须指向一个具体行动信号（关注/进场/盯住）。
- 不能只确认概念不翻译成行动关联。"算力铁塔在铺路"——所以呢？
- 数字要有。600GW、中东后续市场——没有数字的预测是空话。

## 八、P6 收尾：二选一对线

P6 不给确定性答案。给一个问题。而且这个问题必须是二选一的。

### 两篇的 P6 对比

```
钠电：   钠电赛道，你觉得能投吗？
         → 能投 / 不能投

比亚迪： 是王炸，还是包袱？评论区见。
         → 王炸 / 包袱
```

### 为什么二选一 > 开放提问

| | 二选一 | 开放提问 |
|------|------|------|
| 观众心理 | 已经知道"我站哪边" | 要想"我该说什么" |
| 评论门槛 | 低（只需要说出来） | 高（需要想出来） |
| 示例 | "能投/不能投" | "你怎么看？" |

### 二选一的两个类型

```
类型A  判断型（比亚迪篇）
       用两个对立判断让评论区站队
       例："是王炸，还是包袱？"
       适用：事件有争议空间

类型B  选择型（钠电篇）
       给一个决策问题
       例："能投吗？"
       适用：有明确的行动关联
```

### 失败案例：国常会篇

```
你坐在电费账单这边，还是算力中心那边？
```

看起来是二选一。但不是真的二选一。这是**角色扮演式的二选一**——观众不知道"坐在算力中心那边"是什么意思，不知道怎么选。

**真正的二选一不需要任何专业知识。直觉就能选。人人都能站队。**

### 铁律
- 二选一的选项必须是人人都能直觉判断的。不需要背景知识。
- 选项之间是对立的（能/不能、好/坏、赢/输）。
- 不搞角色扮演。不搞概念性二选一。

## 九、全篇情绪节奏

```
        钠电篇                    比亚迪篇                 观众心理状态
─────────────────────────────────────────────────────────────────────
P1  数字+反转                   数字+反转                  "什么？！"
    "不是在讲PPT是在签合同"       "CATL被踢了"

P2  四宫格+一句结论              四宫格+一句结论            "原来这么硬"
    "四条全占"                   "沙漠不再是禁区"

P3  打破常识                    打破常识                  "等等，我之前想错了"
    "不是替代锂电"               "比的是谁设备能不坏"

P4  排序+判断+争议               排序+判断+争议             "他排的对不对？我觉得..."
    "正极①>集成②>高寒③"         "场景>集成>电芯"

P5  终局数字+门票                终局场景+门票              "还来得及，要关注"
    "600GW·门票没涨"             "中东第一枪·门票没涨"

P6  二选一对线                   二选一对线                 "我站这边"
    "能投吗"                     "王炸还是包袱"
```

### 情绪线

```
震惊 → 信服 → 纠正 → 对线 → 紧迫 → 站队
```

每一页的情绪是设计好的。前页的情绪是后页的燃料：
- P1 的震惊让观众翻到 P2
- P2 的信服让观众信任你的判断
- P3 的纠正打破舒适区，制造翻页动力
- P4 的对线触发"我要评论"的冲动
- P5 的紧迫制造收藏动机
- P6 的站队把冲动变成行动

## 十、常见错误对照表

| 错误 | 出现位置 | 正确做法 |
|------|------|------|
| P1 用观点代替事件 | 国常会篇 | 第1层必须是具体事件 + 数字 |
| P1 用悬念代替反转 | 国常会篇 | 反转打破已知 > 悬念制造未知 |
| P1 给最终判断 | 国常会篇"AI吃掉的电从你电费里出" | P5 才能给最终判断 |
| P2 不用卡片格式 | 国常会篇 | 四宫格 + 每格三行（数字+人话+证据） |
| P2 没有收束判断句 | 国常会篇"西部算力中心一个接一个开工" | 必须有一句判断收束 |
| P3 介绍知识而不是纠正认知 | 国常会篇"这些动作有了答案" | 必须是"不是X，是Y" |
| P3 信息太多，提前高潮 | 国常会篇P3内容实际是P4/P5 | P3只做一个认知转折 |
| P4 不给排序给清单 | — | 必须①②③排序 |
| P4 每条没判断词 | — | 每条必须有一个判断 |
| P4 争议放P6 | — | 争议必须放P4，嵌入框架 |
| P5 收束不指向行动 | 国常会篇"铺路铺到哪一步了" | 必须翻译成"所以呢？" |
| P5 没有"门票"机制 | 国常会篇 | 必须制造窗口期紧迫感 |
| P6 角色扮演式二选一 | 国常会篇"电费账单这边还是算力中心那边" | 必须是直觉型二选一 |
| P6 开放式提问 | — | 必须是二选一 |

## 十一、快速套用清单

制作新闻分析类图文前，逐项核对：

```
□ 1. 有一个最新事件 + 具体数字？（没有=不是新闻分析类）
□ 2. 能挑出一个观众已有的普遍认知来打破？（没有=没有反转）
□ 3. 标题：数字 + 反常识判断 + 标签行 三要素俱全？
□ 4. P1 三层结构（数字→反转→标签）各司其职？
□ 5. P2 四宫格每格有数字+人话+证据？
□ 6. P2 底部有收束判断句？
□ 7. P3 是"纠正一个认知"还是"介绍一个知识"？
□ 8. P4 是排序（①②③）还是清单（ABC）？
□ 9. P4 每条有判断词？
□ 10. P4 有争议钩子？
□ 11. P5 有"门票"机制？
□ 12. P6 是直觉型二选一？
□ 13. 全篇情绪线：震惊→信服→纠正→对线→紧迫→站队？
□ 14. 每页都有一句个人判断？
□ 15. CVC投行视角贯穿？（不是客观研报）
```

## 十二、与图文创作方法论的关系

本文件是 [图文创作方法论](图文创作方法论.md) 的子集深化。图文创作方法论是总纲（覆盖分析型+教程型+视觉设计+image prompt）。本文是分析型中的一个特定子类型的深度拆解——**基于新闻事件、通过CVC投行视角、走完整分析流程的六页图文**。

当选题满足以下条件时，用本文的逐页公式：
- 有一个具体的新闻事件（带数字）
- 事件涉及行业格局变化或认知反转
- 你有明确的个人判断和排序
- 可以用CVC投行视角（读信号→拆架构→下判断→押位置）

当选题是纯认知科普（无热点事件）或教程型时，回到图文创作方法论主文件。
