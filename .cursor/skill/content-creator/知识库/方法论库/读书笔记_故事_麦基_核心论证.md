# 读书笔记：《故事》— 材质、结构、风格和银幕剧作的原理

> 原书：Story: Substance, Structure, Style, and the Principles of Screenwriting (1997)
> 作者：Robert McKee（罗伯特·麦基） | 译者：周铁东 | 2014 天津人民出版社
> 笔记日期：2026-07-31

---

## 一、全书核心命题

**一句话：故事是生活的比喻。原理不是规则，原始模型不是陈规俗套。好故事通过冲突制造鸿沟，逼迫人物做出选择，从而揭示人性。**

作者的核心主张：

1. **故事论述的是原理，不是规则**——规则说"你必须这样做"，原理说"这样做有效……而且经过了时间的验证"
2. **故事论述的是原始模型，不是陈规俗套**——原始模型挖掘普遍性人生体验，以独一无二的文化手法装饰。陈规俗套固步自封，原始模型不胫而走
3. **故事是生活的比喻**——不是照搬生活（刻板故事），不是脱离生活（奇观故事），而是提取精华后的再创造
4. **故事天才 > 文学天才**——文学天才是对语言的驾驭，很普通。故事天才是对生活本身的创造性组织，很罕见
5. **观众不仅聪明，而且比大多数电影更聪明**——作家必须使出浑身解数，力图超越观众敏锐的感知力

## 三、逐章核心观点 × 关键框架

### 序言：原理、形式、原始模型

**核心观点**：六句话概括全书的哲学立场。

| 论述的是 | 而不是 |
|----------|--------|
| 原理（这样有效，经过了时间验证） | 规则（你必须这样做） |
| 永恒、普遍的形式 | 公式（成功范本和速成模式） |
| 原始模型（普遍人生体验 + 独特文化装饰） | 陈规俗套（狭隘文化体验 + 陈腐形式） |
| 一丝不苟（简约是關鍵，简明扼要需要时间） | 旁门捷径 |
| 写作的现实（银幕之上没有藏拙之地） | 写作的秘诀（秘密一直是公开的） |
| 对观众的尊重（观众集体智商在黑暗中飞跃 25 点） | 对观众的鄙薄 |

**一个洞察**：急于求成、缺少经验的作家往往遵从规则；离经叛道、非科班的作家破除规则；艺术家则精通形式。

### 第一章：故事问题 — 故事是人生必需的设备

**核心观点**：人类对故事的胃口不可餍足。哲学、科学、宗教相继退场后，故事艺术成为人类灵感的首要来源。但故事讲述的总体质量在每况愈下。

**两种典型的失败剧本**：

| 类型 | 特征 | 病因 |
|------|------|------|
| "个人故事"坏剧本 | 对生活片断的呆板刻画，误将表象逼真当成生活真实 | 只看到可见的事实，对生活的真实茫然无视 |
| "保证商业成功"坏剧本 | 结构性过强、感官刺激堆砌，用奇观取代实质 | 把动作误以为娱乐，模拟现实取代了想象 |

**文学天才 vs 故事天才**：

```
文学天才：日常语言 → 更具表现力的更高形式
          很普通。每个识字人群都有成百上千人能做到

故事天才：生活本身 → 更有力度、更富意味的体验
          很罕见。材料是生活本身，不是话语
```

**一个洞察**：如果要在讲得精彩的琐碎素材和讲得拙劣的深奥素材之间选择，听众总是选择前者。故事大师懂得从最少的事件中挤出生命力。

### 第二章：结构图谱 — 故事三角

**核心观点**：结构是对人物生活故事中一系列事件的选择，将事件组合成具有战略意义的序列，以激发特定情感，表达特定人生观。

**结构的五个层级（从小到大）**：

```
节拍（beat）
  └── 动作/反应中行为的交替。场景内最小的结构成分

场景（scene）
  └── 在连续时空中，通过冲突表现的动作
  └── 让至少一个价值层面发生转折（正→负 或 负→正）
  └── 没有转折的场景 = 非事件 = 只有解说 → 砍掉

序列（sequence）
  └── 2-5 个场景，冲击力递增，最后到达顶峰

幕（act）
  └── 一系列序列的组合，导致价值的重大转折

故事（story）
  └── 一系列幕构成最大的结构
  └── 最后一幕高潮：绝对而不可逆转的变化
```

**事件 ≠ 发生了什么事**。故事事件创造出人物生活情境中富有意味的变化，通过冲突来完成。纯粹偶然的事件（如天降大雨），无论价值负荷多大，都不能构成故事事件。

**故事三角**：

```
              大情节（经典设计）
              /\
             /  \
            /    \
           /      \
          /        \
    小情节          反情节
  （极简主义）    （反结构）
```

| 维度 | 大情节 | 小情节 | 反情节 |
|------|--------|--------|--------|
| 结局 | 闭合式 | 开放式 | 开放式 |
| 冲突 | 外在冲突 | 内在冲突 | 内在 |
| 主人公 | 单一、主动 | 多重/被动 | 被动 |
| 时间 | 线性时间 | 线性 | 非线性 |
| 因果 | 因果关系 | 因果 | 巧合驱动 |
| 现实 | 连贯现实 | 连贯 | 非连贯现实 |

**一个洞察**：大情节是世界电影的主食，过去一百年滋养着绝大多数备受世界观众欢迎的影片。但作家必须了解这三个角，才能知道自己站在哪里。

### 第七章：故事材质 — 鸿沟

**核心观点**：故事产生于主观领域和客观领域的交接之地。主人公采取行动期望某种反应，世界的实际反应与期望不同——鸿沟裂开。这就是故事的温床。

**主人公的五条标志性特质**：

1. **具有意志力**——必须足以在冲突中支撑欲望，最后采取行动创造不可逆转的变化
2. **具有自觉的欲望**——知道自己想要什么。可以加上一个**不自觉的欲望**（与自觉欲望矛盾），创造复杂人物
3. **有能力令人信服地追求欲望对象**——人物塑造必须与他追求的欲望构成适当平衡
4. **至少有一次机会达成欲望**——观众不会奉陪一个毫无希望的主人公
5. **具有移情作用**（同情可有可无）——移情是指"像我"。观众在人物内心深处发现某种共通的人性

**移情 ≠ 同情**。麦克白是杀人凶手，但莎士比亚给了他一颗良心——"我为什么要这样做？我到底是什么样的人？"观众听到后想："心怀负罪感……就像我一样。"

**冲突的三个层面**：

```
          个人外冲突
         （社会/环境）
            /\
           /  \
          /    \
    个人冲突    内心冲突
  （家人/朋友）（头脑/身体/情绪）
```

**鸿沟 — 全书最核心的机制**：

```
主人公采取行动
  └── 期望世界做出某种有益反应
      └── 世界的实际反应与期望不同（更强烈/完全相反）
          └── 期望和结果之间裂开一道鸿沟
              └── 主人公重整旗鼓，采取第二个行动（更大风险）
                  └── 第二道鸿沟裂开
                      └── 循环往复 → 直到线索终点
```

**风险定理**：人物欲望的价值尺度与他愿意承担的风险成正比。价值越大，风险便越大。如果答案是"失败后生活回到正常状态"，这个故事不值得讲。

**从里写到外面**：问"如果我是这个人物，在这种情况下，我会怎么做？"——不是问"一个人应该如何做"（导致陈词滥调），不是问"一个人可能会怎么做"（导致花边文章），不是问"我的人物会怎么做"（导致距离感）。你必须进入人物的主观视点，从里面体验。

**一个洞察**：故事和生活之间的重大差异——生活中 99% 的情况下我们采取行动都能得到预期反应，但在故事中，那些时刻被扬弃。故事只关注预期被打破的那一瞬间。

### 第八章：激励事件 — 打破平衡的那一下

**核心观点**：激励事件彻底打破主人公的生活平衡，激起恢复平衡的欲望，把他送上求索之路。

**激励事件必须做到**：

1. 打破主人公生活中各种力量的平衡（变好或变坏）
2. 激起主人公恢复平衡的**自觉欲望**（+ 可选：激活矛盾的**不自觉欲望**）
3. 把主人公送上追求欲望对象的**求索之路**
4. 在观众脑中提出**戏剧大问题**（"这件事的结果将会如何？"）
5. 投射出**必备场景**（危机）的影像——观众知道在故事结束前必定会看到什么

**激励事件的质量**：可以小到一个女人把手放在桌子上，以"那种特别的方式"看着你。在适当的上下文中，仅一个手势和一个眼神就可能意味着"我再也不想见到你了"或"我将永远爱你"。

**定位规则**：主情节激励事件必须在讲述过程的前四分之一时段内发生。必须发生在银幕上——不能发生在幕后故事之中。观众必须亲身经历。

**设计问题**：

> 可能发生在主人公身上最坏的事情是什么？那一事件如何才能最终成为可能发生在主人公身上最好的事情？

> 可能发生在我主人公身上最好的事情是什么？它如何能变成最坏的事情？

**故事脊椎**：主人公欲望的能量形成的贯穿线。如果只有自觉欲望→自觉目标成为脊椎。如果有不自觉欲望→不自觉欲望成为脊椎（更强烈、更持久）。

**求索 — 所有故事的根本形式**：

```
一个事件打破平衡 → 激起欲望 → 送上求索之路
  → 与各种对抗力量（内心/个人/个人外）抗衡
  → 也许能也许不能达成欲望
```

**一个洞察**：即如音乐只有十二个音符却构成了我们称为音乐的一切，求索的根本要素也就是这十二个音符。看似简单，实际操作时却发现不可思议的复杂。

### 第九章：幕设计 — 进展纠葛与冲突法则

**核心观点**：若无冲突，故事中的一切都不可能向前进展。冲突之于故事，犹如声音之于音乐。

**不归点**：当鸿沟裂开时，观众意识到这是一个不归之点——最小的努力无济于事。类似力度和性质的所有行动都必须从故事中排除。作者由此构建出一个循序渐进的进展过程。

**故事绝不能退隐于轻量级行动，必须循序渐进地朝着观众无从想象出更好替代的一个最后行动向前运行。**

**冲突法则**：冲突是故事的灵魂。生活就是冲突——萨特说现实的精华就是匮乏，海德格尔说时间是存在的基本范畴。如果冲突停顿太久，观众的眼睛就会离开银幕。

**纠葛型 vs 复杂型**：

```
纠葛型：只在一个冲突层面上展开
复杂型：同时在内心/个人/个人外三个层面展开
```

**一个洞察**：如此之多的影片在第二幕中间出现疲软——作者未能构建进展过程，给人物设计那种已经在第一幕尝试过的微小行动。观众直觉知道这些行动不可能成功。故事在循环，观众在踩水。

### 第十三章：危机、高潮和结局

**核心观点**：危机是真正的两难之境。高潮必须同时是"不可避免而又出乎意料"的。

**危机 = 危险 + 机会**：

- 危机是故事的必备场景，是主人公用尽了所有行动后只剩最后一个尚未完成的时刻
- 危机必须是**真正的两难之境**——两善取一或两恶择轻，或两者同时
- 主人公在此如何选择，揭示了其深层性格和人性
- 危机决定必须是一个**有意而为的静态时刻**——不要让它在画外发生

**高潮**：

- 绝对而不可逆转的价值摇摆——当价值处于最大负荷时的剧变
- 意义创造情感："意生情"——不是金钱，不是特技，不是明星
- 最后一幕的高潮是想象力的大跃进。没有它，就没有故事
- 从尾到头逆向工作：高潮的想法先出现，然后为它在虚构现实中找到支撑

**高潮的关键**：给予观众他们想要的东西，但不是通过他们所期望的方式。这就是区别艺术家和业余者的试金石。

**结局**：必须同时是"不可避免而又出乎意料"的——回溯时，讲述过程所采取的路径似乎是唯一的路径；但在发生时，是观众不可能预期的方式。

**一个洞察**：如果一个场景剪掉后并不影响结局的冲击力，那么它就必须剪掉。所有场景都必须比照高潮确立其存在的理由。

### 第十四章：反面人物塑造原理

**核心观点**：主人公及其故事的智慧魅力和情感魄力，必须与对抗力量相适应。对抗力量越强大越复杂，人物和故事必定发展得越充分。

**对抗力量 ≠ 反面人物**。对抗力量是对抗人物意志和欲望的各种力量的总和。

**负面的四个层次**（以"正义"为例）：

```
正面价值：正义
    ↓
相反价值：不公平（裙带关系、官僚拖延、偏见）
  └── 负面但未违法
    ↓
矛盾价值：非正义（有人犯了法）
  └── 正面的直接对立
    ↓
否定之否定：专制（"强权即真理"）
  └── 复合否定——法律本身成了犯罪工具
  └── 已达于人性黑暗势力的极限
```

大多数犯罪剧的对抗力量绝少超越矛盾价值（非正义）。真正抵达极限的故事（如《失踪》）会到达否定之否定——专制。

**一条检验原则**：如果在激励事件发生的当刻研究主人公，将其意志力总和与来自各个层面的对抗力量总和比较——他应该看起来是一条战败狗。他只有一次机会。

**一个洞察**：我们将能量注入故事的负面，不仅是为了使人物得到完全实现，还是为了将故事本身带到线索的终点，带入一个辉煌而令人满足的高潮。

```
  +

  ├── 激励事件：打破平衡 → 激起欲望 → 投射必备场景

  ├── 进展纠葛：不归点循序渐进，力度只增不减

  +

  终点（CHAPTER 13-14）
  ├── 危机：真正的两难之境（两善择一 / 两恶择轻）
  ├── 高潮：绝对不可逆转 + 不可避免而出乎意料
  ├── 反面人物原理：对抗力量越强，故事越充分
  └── 否定之否定：将负面推到人性极限
```

## 五、可以带走的方法论

1. **每个场景都要有价值转折**。如果一场戏开始和结束时人物的价值状态没变——不管中间说了多少话做了多少事——这场戏只有解说，没有事件。删掉。

2. **鸿沟是故事的发动机**。不是让人物一路顺风地达成目标，而是每次行动都激起意料之外的反应。每次反应都逼他冒更大的风险。鸿沟逐次加深，故事逐次推进。

3. **从里往外写**。不要站在人物外面猜测"他应该怎么做"，进入他的主观视点问"如果我是他，在这种情况下，我会怎么做"。情感真理的唯一可靠来源是你自己。

4. **反面人物原理 = 你的内容力度的上限**。你设定的对抗力量有多强，你的故事就有多强。如果对抗力量只是"不公平"，你的故事只能到那儿。推到"否定之否定"，才能到达人性极限。

5. **激励事件必须让观众亲眼目睹**。不能放在幕后、不能靠旁白交代。观众必须在银幕上经历那个打破平衡的瞬间，否则戏剧大问题不会在他们脑中涌现。

6. **风险必须有分量**。问：如果主人公失败，可能发生在他身上的最坏的事是什么？如果答案是"生活回到正常状态"，这个故事不值得讲。

7. **高潮从尾往头写**。先有高潮的想法，然后逆向工作，为它找到因果支撑。所有场景都必须比照高潮确立存在理由。

8. **移情不是同情**。观众不需要"喜欢"你的主人公。他们需要在主人公身上看到自己。麦克白是杀人犯，但他有良心——"就像我一样"。

---

## 六、可复用的叙事技巧（来自此书）

- **"故事是生活的比喻"** —— 不是照搬，不是脱离。提取精华，以事件作为韵律
- **鸿沟递进** —— 不是一次反转到头，是一道鸿沟接一道鸿沟，逐级加深（= 幂律的四级反常识楼梯）
- **从里往外写** —— 代入人物主观视点，不是站在外面分析人物
- **"给予观众想要的东西，但不是通过他们期望的方式"** —— 满足情感承诺，但用出人意料的方式达成
- **危机必须是真正的两难** —— 两善取一或两恶择轻。不是"要不要做"，是"两个都要不了"
- **反面人物的四个层次** —— 从相反价值到否定之否定，逐级推到人性极限
- **"不可避免而又出乎意料"** —— 回溯时唯一路径，发生时无法预见
