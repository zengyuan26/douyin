# 图文创作方法论

> 基于备电（分析型）和南漳黄姐（教程型）11篇图文拆解提炼。每次创作图文前必加载。

---

## 一、类型决策树

```
选题来了 → 核心问题是"为什么"还是"怎么做"？

"为什么" → 分析型（备电模式）
  ├─ 有热点事件 → 事件分析型 → 6页 | 深色+数据卡片
  ├─ 无热点/纯认知 → 认知反转型 → 5页 | 对比分屏+证据链
  └─ 集体痛点 → 痛点驱动型 → 5页 | 实拍/场景感

"怎么做" → 教程型（南漳黄姐模式）
  ├─ 预防翻车 → 诊断处方型 → 4页 | 四宫格+checklist
  ├─ 已经翻了 → 损失救援型 → 4-5页 | 前后对比+分级方案
  └─ 条件判断 → 三栏科普型 → 4页 | 三栏信息图+记好按钮

A/B决策：需要逐层展开逻辑链 → A型轮播。一张图讲清关系/流程 → B型单张。
```

---

## 二、页数铁律

**基于实际数据，不是感觉：**

| 类型 | 最优页数 | 数据依据 |
|------|---------|---------|
| 教程型（翻车救援） | **4张** | 72.7万（4张）> 16.7万（4张）> 4.8万（5张） |
| 教程型（条件科普） | **4-5张** | 三栏结构天然限制 |
| 分析型（事件驱动） | **5-6张** | 钠电6张爆款 > 六张网7张 > 长时储能7张（翻车） |
| 认知反转型 | **5张** | 冷水下锅5张17.7万 |

**铁律：**
- 教程型超过5张 = 完播率断崖下跌
- 分析型超过7张 = 读者疲劳，最后一页基本看不到
- **默认4张，确认有必要再加。不要上来就7张。**

## 三、逐页设计规范

### 分析型图文（备电）

```
P1 封面    — 钩子页
           任务：让读者停下来
           手法：事件+数字 / 论点宣言 / 认知反转
           反面：公司名做钩子（除非是宁德/字节这种全民认识的公司）
           视觉：单物体+光束，标题≤15字，超大字体

P2 灵魂页  — 直接给答案
           任务：不铺垫，核心结论砸出来
           手法：数据卡片 / 三组对照表 / 一句话判断
           铁律：P2必须有判断句，不能只列事实
           视觉：卡片式/对照表式，强调色标注关键数字
            对比权力关系：如果本页做对比（旧vs新/A vs B），
              你有判断的那一侧必须视觉占优——更大卡片、更亮光源、更暖色调。
              禁止左右等分。"两边一样大"=你没有判断。

P3-P4 拆解 — 逐条展开
           任务：每页一个分论点+一个判断句
           手法：信号链证据级联 / 东西对照双线 / 缩放结构
           铁律：每页≤3个信息模块，每页有"所以呢？"
           视觉：保持母题一致（桌面/文件/仪表——选一个做到底）

P5 落地    — 从大到小
           任务：宏观→具体到"你"能做什么
           手法：三张牌/三个指标/两条路
           铁律：必须有可操作的具体动作（数字/指标/省份）
           视觉：仪表盘/清单/对比表

P6 收尾    — 争议+CTA
           任务：保持诚实+驱动行动
           手法：一个争议点+私信/评论CTA
           反面："等等看""等下一张牌"——主动弃权
           视觉：回到P1的视觉锚点（首尾闭合）
           反模板：禁止每期收尾用同一构图。金句块格式、CTA位置、
             光源角度——每期至少换一个。观众看得出重复。
```

### 教程型图文（南漳黄姐）

```
P1 封面    — 翻车现场
           任务：让正在翻车的人停下来
           手法：对仗痛点（一晒就酸，一切就散）
               / 损失厌恶（别扔！救回你的肉钱）
               / 常识挑战（原来一直做错了）
           视觉：失败状态实拍+对仗大字+数字徽章（红圈）

P2 灵魂页  — 直接给方案
           任务：一张图讲清全部答案
           手法：三栏信息图（温度/风力/光照）
               / 四宫格步骤（加蛋+七分满+扎孔+80°C）
               / Why+How双栏（好处+步骤）
           铁律：每个建议必须带数字，"适量""适当"=零收藏
           视觉：三栏/四宫格/左右分栏——结构可视化，截图即收藏

P3-P4 延伸 — 细节+证据
           任务：补充P2没讲完的+给证据感
           手法：实拍温湿度计/温度计/操作特写
           视觉：实拍照片+箭头标注+配角标数字

P5 收尾    — checklist+CTA（教程型最多5张）
           任务：收藏理由+评论驱动
           手法：numbered list总结+填空式评论CTA
           视觉：checklist格式+评论关键词浮层
```

## 四、视觉设计方法论

### 4.1 两种视觉路线

| | 生成图路线（备电） | 实拍路线（南漳黄姐） |
|---|---|---|
| 适合 | 抽象概念/数据/政策 | 实物操作/场景/工具 |
| 信任感 | 专业/距离感 | 亲切/老师傅感 |
| 成本 | 每页生成1张图 | 拍照+后期标注 |
| 模板复用 | 换文字可套 | 每次重新拍 |

### 4.2 生成图设计规则（备电用）

```
母题统一：
  选一个视觉母题贯穿全篇。不能P1办公桌 P2战略墙 P3电费单 P4画廊 P5卡片 P6仪表盘——7页7个世界=散架。
  正确示范：AI视频耗电→全篇咖啡桌/手机/便利贴/电表（都是"个人桌面上的东西"）
  正确示范：长时储能→全篇木桌/黄铜/玻璃展板/蓝图（工业质感的同一张工作台）

配色系统：
  底色：深炭黑 #121212（分析型）/ 亮白 #FAFAFA（痛点/生活型）
  强调：琥珀 #C89050（数据/判断）/ 冷青 #4D8F8F（对比/注释）
  文字：暖白 #f0ead6（标题）/ 冷灰 #888（辅助信息）
  铁律：全篇只用1个强调色。超过1个=没重点。

每页安全区：
  顶部 120px：摄像头禁区——不放核心文字
  底部 170px：抖音描述区——不放核心文字
  核心内容：120px ~ 1750px

每页信息密度：
  ≤3个信息模块。超过3个=读者不读了。
  模块 = 一个卡片/一组对比/一个判断句+数据

文字层级：
  标题：暖白，大字号，≤15字
  判断句：琥珀，中字号，1句
  数据/注释：冷灰，小字号，≤30字

视线流量（每页构图必须设计 eye path）：
  进入：视线从画面哪个位置进入？（左上/中央/由人物视线引导）
  慢下来：在哪个元素上减速？（大数字/对比数据/人脸/手写标注）
  落点：最终视线落在哪里？这是本页的信息核心。如果落点不明确=构图失败。
  出口：从哪个位置离开准备翻页？右下/由箭头指向引出下一页。
  
  自检：写一句视线流量句子——"视线从X进入→在Y慢下来→落在Z→从W出去"。写不清=构图只是元素堆叠。

  应用示例：
    P1封面：进入=大标题→慢下来=琥珀判断句→落点=判断句→出口=右下（想翻页）
    P2灵魂页：进入=数据卡片的主数字→慢下来=对比差异→落点=判断句→出口=右下（想看拆解）
    P3-P4拆解：进入=上一页延续的母题元素→慢下来=新增数据→落点=本页判断→出口=箭头/视线引导至下一页
    P5落地：进入=清单第一项→慢下来=具体数字→落点=可操作的最后一项→出口=右下
    P6收尾：进入=P1同款视觉锚点→慢下来=金句/CTA→落点=CTA按钮→出口=评论区/私信
```

### 4.3 image prompt 写作规范

```
每条prompt自包含：比例+安全区+配色+物理场景+光源

必须包含的要素：
  1. 9:16 vertical photograph (1080x1920px) —— 比例
  2. 物理材质 —— 桌面/纸张/玻璃/金属/布料（不是抽象渐变）
  3. 光源方向+色温 —— 颜色必须来自画面内部实物光源（台灯/窗外自然光/屏幕光/仪表指示灯），不凭空加色调滤镜。
     如："warm amber desk lamp from upper left, 2700K" / "cool overcast window light from right, 5500K"
  4. 实物道具 —— 文件/笔/仪表/便利贴/温湿度计（不是排版元素）
  5. 配色声明 —— "dark charcoal background #121212, amber accents #C89050"
  6. 文字位置 —— "handwritten on a cream sticky note" / "etched on a brass nameplate"

反面示例：
  ✗ "A dark background with text about energy policy"
  ✓ "A 9:16 vertical photograph. Dark charcoal desk surface. A red-header government 
     document lies open, amber lamp beam across it. Handwritten annotation in black ink 
     on the margin: '它从不说投储能。它只说让什么变贵。' Beside it: black fountain pen, 
     uncapped. Warm light, deep shadows. 1080x1920px."

禁止：
  ✗ 抽象渐变背景 + 纯文字排版（不是image2的强项，出来像PPT截图）
  ✗ 多个不相关的物体散落（AI会混乱）
  ✗ 中文Logo/品牌名（AI渲染中文不准，出来像乱码）
  ✗ 视觉风格名称（财新/Caixin/白皮书）写进prompt——这是内部标签
```

### 4.4 实拍+标注规则（教程型用）

```
拍照规范：
  - 自然光/厨房灯，不追求专业布光
  - 手机拍摄即可，老师傅现场感 > 精致摄影
  - 特写为主（切香肠/温湿度计/扎孔细节）

标注规范：
  - 红X标记错误，绿✓标记正确
  - 箭头+数字标注关键参数（5cm间距、80°C）
  - 数字用红/黄高亮圈出
  - 大字报文字用白色粗体+深色半透明底
```

## 五、钩子公式库

### 分析型钩子（备电）

```
公式1：事件+数字+判断
  "宁德刚签了60GWh大单。钠电能不能投？"
  适用：有热点事件时

公式2：论点宣言
  "政策文件里，从来没有写过'建议你投储能'。"
  适用：打破默认假设

公式3：认知反转
  "1块钱涨到5块8。你以为这是环保情怀？错了。"
  适用：有价格/数据变化

公式4：集体痛点+归因反转
  "每次用即梦卡在99%。不是服务器不够。是电。"
  适用：无热点、靠集体记忆驱动
```

### 教程型钩子（南漳黄姐）

```
公式5：对仗痛点
  "一晒就酸，一切就散"
  适用：预防翻车

公式6：损失厌恶
  "别扔！2个方法救回你的肉钱"
  适用：已经翻车

公式7：常识挑战
  "香肠冷水下锅还是热水下锅？原来一直做错了！"
  适用：人人都这么做但做错了

公式8：具体失误+因果链
  "香油放多了不干怎么办？香油放多=晾不干=一切就散"
  适用：长尾搜索型
```

## 六、CTA模板

### 评论驱动（比私信互动量高10倍）

```
✗ "评论区聊聊" —— 太开放，没人知道聊什么
✗ "你怎么看" —— 太空，不知道看什么

✓ 填空式："你所在省的峰谷价差，现在是多少？"
✓ 诊断式："评论区说你的城市气温，帮你判断能不能做"
✓ 关键词式："评论区打'香肠避坑'"
```

### 私信驱动（适合工具/算账型）

```
✓ "私信「电价表」· 各省峰谷电价按月更新"
✓ "私信「算账」· 帮你算工厂储能回本周期"
```

## 七、制作前自检清单

```
□ 1. 这篇图文只服务一类人吗？（两类人=分裂=两类都不满足）
□ 2. 页数≤6？（教程型≤5）
□ 3. P1钩子是读者的痛点/好奇，还是我的信息？（前者才有效）
□ 4. P2直接给答案了吗？（禁止概念铺垫/背景介绍）
□ 5. 每页有判断句吗？（不只是罗列事实）
□ 6. 每个建议/数据带数字了吗？（"适量"=零收藏）
□ 7. 视觉母题统一了吗？（全篇同一个世界）
□ 8. 有1个争议点吗？（全说好话=AI味）
□ 9. 有"谁在讲"的身份锚点吗？（没有身份=防御心态=划走）
□ 10. 收尾有行动驱动吗？（"等等看"=弃权）
□ 11. CTA是填空式/诊断式，还是开放提问？（前者有效）
□ 12. image prompt自包含比例+安全区+配色+物理场景+光源了吗？
□ 13. 合规检查：无禁用词/公司名≤5次/无CTA违禁词
□ 14. 每页视线流量是否清晰？（进入→慢→落→出写得清吗？写不清=构图失败）
□ 15. 每页颜色是否来自画面内部实物光源？（不是外部强加色调滤镜）
□ 16. 对比页（如有）是否有判断的一侧视觉占优？（不是左右等分）
□ 17. 收尾页构图是否跟上一期不同？（金句块/CTA位置/光源角度至少换一个）
```
