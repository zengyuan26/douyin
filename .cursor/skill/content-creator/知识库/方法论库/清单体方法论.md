# 清单体方法论

> 16:9横屏 | PPT画面+素材混剪 | AI录音 | 无人出镜
> 投研清单体的备电迁移版。降低投研内容消费门槛的高频轻量格式。

---

## 定位：什么时候用清单体

| 场景 | 用清单体 | 用A型图文 |
|------|---------|----------|
| 有天然品类/排序/分组 | ✅ | — |
| 信息密度为王，不需要情绪弧 | ✅ | — |
| 需要深度拆解一个事件 | — | ✅ |
| 追求传播效率+高频更新 | ✅ | — |
| 追求品牌厚度+观点输出 | — | ✅ |

**一句话**：清单体是「轻量信息快餐」，A型图文是「深度行业正餐」。互补不互斥。

## 三种结构模板

### A. 扁平清单（无排序）

```
标题：N个/种 [主题]
每项：名称 → 一句话定义 → 1-2句展开 → 关键标的
适用：品类多、无天然排序。如"储能行业5种温控方案"
项数：6-12
```

### B. 分组清单（有分类）

```
标题：[主题]：[角度]
结构：M组 × N家/组（3-4家/组为佳）
组序：按产业链/逻辑线排列
适用：跨环节覆盖。如"储能产业链各环节龙头"
项数：3-5组 × 3-4家
```

### C. 排名清单（有量化排序）

```
标题：[领域][指标]TOP N
结构：N→1倒计时，指标逐级攀升
适用：有公开量化数据。如"储能中标量TOP10"
项数：8-10
前置条件：数据必须可验证，不能自编排名
```

## Hook 三种开场

| # | 公式 | 示例 | 适用 |
|---|------|------|------|
| A | "别只盯着X" | "别只盯着宁德。储能行业真正赚钱的环节藏在这8家公司里" | 纠正认知 |
| B | "你真的知道吗？" | "工商业储能回本最快的方案，你真的知道吗？" | 挑战知识 |
| C | "X就是把……现在……" | "现货电交易就是把电像股票一样买卖。现在各省价差拉大……" | 解释概念 |

**选Hook原则**：选题知名度高→用A（纠正认知）。选题冷门→用C（先科普）。选题有反差→用B。

## 单项信息模板

每项统一5字段，全篇严格一致：

```
[标识] [名称] [核心数据]
→ [定位/差异化一句话]
→ [关键客户/应用场景]
→ [时间锚点（如有）]
```

**铁律**：
- 每项2-3句封顶。超过3句就啰嗦了
- 字段顺序全篇不变。观众第3项开始就进入自动驾驶模式
- 数据必须具体（"35亿"不是"数十亿"）
- 企业名只列不评（"绑定特斯拉"可以，"最值得买"绝对不行）

## 收尾三种

| # | 做法 | 适用 |
|---|------|------|
| A | **选择题CTA**：开放式问题，降低评论门槛 | 内容有争议性或观点分歧时 |
| B | **情绪金句**：1-2句价值观升维，不给问题 | 信息量+情绪已饱和时 |
| C | **无收尾**：最后一项讲完即止 | 排名清单、信息密度极高时 |

**收尾纪律**：信息量爆了就别加CTA。观众需要消化，不是被追问。

## 视觉规格

```
画幅：16:9 横屏（1920×1080）
画面：PPT图表/文字 + 少量实拍素材混剪
录音：AI语音（抖音合规范围内）
人物：无出镜
时长：2-4分钟（每项约20-30秒）
```

**为什么横屏**：清单体信息量大，横屏天然适合展示表格、产业链图、数据对比。牺牲一部分推荐流效率，换取信息容量。

## 合规注意事项

- 企业名可列不可评（"市占率第一"可，"值得买"不可）
- "仅为行业分析不构成投资建议"——开头或结尾出现一次
- 数据注明来源性质（"公开中标数据""业绩预告"）
- 不用"暴涨""翻倍""暴增"等平台敏感词
- AI录音需确认抖音当前对AI配音的政策

## 跟A型图文的分工

| | 清单体口播 | A型图文 |
|---|----------|---------|
| 目的 | 传播+扩圈 | 深度+品牌 |
| 频率 | 可日更 | 周2-3篇 |
| 生产成本 | 低（AI录音+PPT） | 高（GPT生图+人工精调） |
| 情绪设计 | 无情绪弧，靠节奏 | 7页情绪弧 |
| 人设 | 教导者为主 | 陪伴者+教导者 |
| 温度 | 有用>有趣>共鸣 | 有用+共鸣为主 |
