# 学习笔记模板

> 日更系列。一个概念 + 一张图 + 一段字。固定格式，可重复。

---

## 图片规格

```
比例：1:1 正方形 1080×1080px（信息流友好）
或 4:5 竖版 1080×1350px（占据更多屏幕）
```

## 画面结构（三层）

```
┌──────────────────────┐
│                      │
│    📋 学习笔记        │  ← 顶部标签，小字
│                      │
│                      │
│     一阶导            │  ← 概念名，超大居中
│     /                │
│     二阶导            │
│                      │
│                      │
│   市场不看你好不好     │  ← 底部钩子，小字一行
│   看你在不在加速变好   │
│                      │
└──────────────────────┘
```

## 视觉风格：白皮书 light

> 复用已有 [[白皮书]] 风格。暖白底+深蓝黑标题+干净理性。

| 要素 | 规则 |
|------|------|
| 底色 | 暖白 #F8F6F0 |
| 主文字体 | 深蓝黑，粗体，干净无衬线 |
| 标签行 | 小字，浅灰，左上角 |
| 强调色 | 深蓝黑为主，不额外加色 |
| 画面元素 | 公式、箭头、简笔图示 > 纯文字排版 |
| 禁止 | emoji、渐变、多色、装饰、照片 |

## 画面结构（两种）

> 顶部统一标注：`📋 学习笔记 · {系列名}`。系列名做母题，每期一个子概念。

**类型A：公式/图示型** — 概念适合用数学、逻辑、流程图表达
```
┌──────────────────────┐
│  📋 学习笔记 · 边际思维 │
│                      │
│        y             │
│        │             │
│        ▼             │
│      dy/dx           │
│     一阶导：增速       │
│        │             │
│        ▼             │
│     d²y/dx²          │
│    二阶导：加速度      │
│                      │
│  绝对值 → 增速 → 加速度 │
└──────────────────────┘
```

**类型B：纯文字型** — 概念只能文字传达
```
┌──────────────────────┐
│  📋 学习笔记 · 宏观    │
│                      │
│    流动性             │
│    虹吸               │
│                      │
│  不是你的资产变差了    │
│  是钱走了             │
└──────────────────────┘
```

两种类型共用同一套底色/字体/强调色。一眼认出是同一个系列。

## 配套正文结构

```
🔋 学习笔记 | #标签

一句话解释：...

今天学了这个概念 → 想到以前...（个人经历，跨界锚点）

给工厂老板一个判断：...（落点，可操作）

#学习笔记 #CVC投行 #新能源
```

## 文件命名

```
学习笔记_{YYYYMMDD}_{概念名}.md
例：学习笔记_20260717_一阶导二阶导.md
```

## 规则

- 每期只讲一个概念。但可以通过 [[层层推导法]] 把一个概念推到更远——从个股推到宏观、从道理推到判断。
- 正文 100-200 字
- 跨界锚点必须是真实经历（电商/投行/看项目）
- 落点面向工厂老板/创业者，让他拿去就能用
- 配图只放概念名+钩子，正文放评论区/文案区
- 第一步提问，最后一步抛问题。不画句号。

## 系列话题 & 延伸学习

每篇底部固定两个区段：

```
## 📂 系列话题：{系列名}

- [x] 本篇概念 ← 本篇
- [ ] 子概念2 — 一句话描述
- [ ] 子概念3 — 一句话描述

## 🔗 延伸学习

- [ ] 关联概念1 — 一句话描述
- [ ] 关联概念2 — 一句话描述
```

- 系列话题：同一母题下有哪些子概念。已写的打 `[x]`，待写的打 `[ ]`
- 延伸学习：跨系列但有关联的概念。形成知识图谱
