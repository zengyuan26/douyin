# 导演分析方法论

> 从 zimeiti-creator 分镜系统迁移。两阶段流水线：先导演分析→确认→再逐页生成。

---

## 核心理念

**一次生成全文 = 黑箱。拆成两阶段 = 可控。**

当前问题：AI 一步出 P1-P7，用户只能看结果，无法干预中间决策。主线歪了、情绪不对、钩子没力——只能整篇重来。

两阶段方案：Phase 1 只出导演分析（一屏 JSON），用户确认核心创意/情绪曲线/视觉风格后再进入 Phase 2 逐页生成。每次只做一个决策，错了只回退一步。

---

## Phase 1：导演分析

### 输入

选题 + 目标人群 + 内容类型（A型图文/B型图文/口播脚本/清单体口播）

### 输出格式

```json
{
  "directorAnalysis": {
    "title": "吸引人的标题",
    "contentType": "A型图文",
    "totalPages": 7,

    "directorBrief": {
      "coreIdea": "一句话核心创意：这篇讲什么、为什么观众会看完（必填）",
      "mainThread": "一个词主线。如：调度/自循环/溯源/信息差。整篇只讲这一件事（必填）",
      "hookDesign": "封面钩子设计：观众停下滑动的理由。用利益/恐惧/数字，不用概念/政策编号（必填）",
      "emotionalTone": "情绪基调：整体色彩倾向/节奏感/语气风格（必填）",
      "visualStyle": "视觉风格：A财新周刊dark / B白皮书light / C深夜对话dark（必填）",
      "visualMetaphor": "贯穿全篇的视觉比喻，如 信息差=沙漏上半满下半空、关系=不放复利的天平（必填）",
      "colorMotivation": "色彩动机：每一页/每镜的颜色从哪个实物光源来？不允许凭空加色调。如：琥珀光来自桌角台灯、冷白来自窗外阴天、绿来自仪表盘指示灯（必填）"
    },

    "audienceMap": [
      {
        "page": "P1",
        "sees": "观众眼睛看到什么画面",
        "thinks": "观众脑子里想什么",
        "feels": "🤔 好奇",
        "intensity": 8
      }
    ],

    "rhythmMap": [
      {
        "page": "P1",
        "label": "钩子",
        "tempo": "快速扫",
        "purpose": "抓住注意力·制造悬念"
      }
    ],

    "emotionCurve": [
      {
        "page": "P1",
        "emotion": "好奇",
        "intensity": 8,
        "trigger": "反问打破固有认知"
      }
    ],

    "keyFrames": [
      "P1: 封面画面——观众停下滑动时看到的",
      "P4: 转折画面——情绪从乐观到清醒的拐点",
      "P7: 收尾画面——最后的情绪落点"
    ],

    "prePageHints": {
      "suggestedVisualElements": "建议视觉元素（如：合同纸撕开/沙漏/天平）",
      "suggestedColorEmphasis": "建议强调色使用节奏（哪些页用琥珀/哪些用绿/哪些用红）",
      "suggestedPages": 7
    }
  }
}
```

### 输出后暂停

Phase 1 输出导演分析 JSON + 一段人话摘要。**禁止直接进入 Phase 2**。等用户说"确认"/"继续"/"改XX"后再进入 Phase 2。

### 确认项清单

用户确认前检查：
- [ ] 主线是否一句话说清？
- [ ] 钩子是否用利益锚点（不是概念/政策编号）？
- [ ] 情绪曲线是否有起伏（不能一路乐观或一路悲观）？
- [ ] audienceMap 的每一拍，观众"看什么"和"想什么"是否对得上？
- [ ] 视觉比喻是否贯穿全篇（不是 P1 出现一次就丢了）？
- [ ] 视觉风格是否匹配内容类型（硬核分析→A，知识整理→B，个人表达→C）？
- [ ] 色彩动机是否来自画面内部实物光源（不是外部强加色调）？
- [ ] 反模板：这一期的构图/配色/元素跟上一期同一位置有没有太像？像了就换构图策略

## Phase 2：逐页生成

### 输入

Phase 1 确认后的 directorAnalysis JSON

### 生成要求

逐页生成时，每页必须遵守：

1. **连续性约束**：每页（P2起）标注与上一页的衔接关系
2. **观众追踪**：每页参考 audienceMap 的 sees/thinks/feels
3. **视觉风格**：每页继承 directorBrief.visualStyle 的色板/光影
4. **视觉比喻**：核心比喻在至少 3 页中出现（P1/P4/P7 至少各一次）
5. **情绪→颜色映射**：乐观页用绿、警示页用红、结论页用琥珀

### 连续性字段（P2 起每页必填）

```
P1→P2:
  transition: 翻页衔接方式（硬切/叠化/色块过渡/意象延续）
  carryOver: 上一页哪个元素保留（颜色/图形/意象/关键词）
  newElements: 这一页新增什么信息
  emotionLink: 情绪变化（如：好奇→恍然）

P2→P3: ...
```

### 输出后自检

- [ ] 每页的 audienceMap 对应关系正确？
- [ ] 连续性是否每页都有（P2-P7）？
- [ ] 视觉比喻贯穿了吗（≥3页）？
- [ ] 情绪线是否跟 Phase 1 的 emotionCurve 一致？
- [ ] 合规检查通过？
- [ ] 反模板：金句页/收尾页的构图是否跟上一期重复？重复就换

## 两阶段 vs 一步生成 对比

| 维度 | 一步生成（旧） | 两阶段（新） |
|------|--------------|-------------|
| 主线控制 | AI 自己决定，可能跑偏 | Phase 1 锁定主线，Phase 2 只执行 |
| 修改成本 | 整篇重来 | 只改 Phase 1 的某个字段，重新 Phase 2 |
| 情绪曲线 | 隐含在文字里，不可检查 | Phase 1 显式输出，可逐个节拍确认 |
| 视觉一致性 | 每页独立描述，可能风格跳跃 | Phase 1 锁定风格 token，Phase 2 全部继承 |
| 观众追踪 | 没有 | audienceMap 逐页追踪 sees/thinks/feels |

---

## 适用内容类型

| 内容类型 | 导演分析 | 逐页生成 |
|---------|---------|---------|
| A型图文 (7页) | ✅ 完整输出 | ✅ 逐页+连续性 |
| B型图文 (1页) | 精简版（只出 coreIdea + visualStyle + keyFrame） | 一步生成 |
| 口播脚本 | ✅ 完整输出 | ✅ 逐段生成 |
| 清单体口播 | ✅ 完整输出 | ✅ 逐条生成 |
