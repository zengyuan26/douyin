# 读书笔记：《薛兆丰经济学讲义》— 核心观点与论证

> 原书：薛兆丰经济学讲义 (2018)
> 作者：薛兆丰
> 出版社：中信出版社
> 笔记日期：2026-08-03

---

## 一、全书核心命题

**一句话：经济学研究的是陌生人之间如何协作的规律。稀缺是基本事实，成本是放弃的最大代价，价格是唯一不浪费的分配方式。人的所有经济行为，都在为克服信息不对称、应对未来的不确定性而展开。**

作者用 10 章 118 讲，从稀缺出发，经成本、需求、价格、权利、耐心、供应、信息不对称、合作，到宏观协调，回答了一个根本问题：由亿万陌生人组成的社会，为什么没有崩溃，反而越来越繁荣？答案是一套自发的制度安排——产权、价格、市场、货币、企业——让分散的知识得以协调，让陌生人得以协作。

---

## 二、全书架构（十大模块递进）

```
第一部分：经济学基础（第1-2章）
  稀缺 → 选择 → 歧视 → 成本

第二部分：市场如何运行（第3-4章）
  需求定律 → 价格机制 → 竞争规则

第三部分：权利与耐心（第5-6章）
  产权保护 → 时间偏好 → 利息 → 保险期货

第四部分：生产与组织（第7-9章）
  比较优势 → 价格歧视 → 信息不对称 → 企业理论

第五部分：宏观与公共选择（第10章 + 后记）
  货币通胀 → 经济周期 → 选举 → 再分配 → 经济学思维
```

## 三、逐章核心观点 × 关键论证

### 第1章 稀缺 — 为何商业是最大的慈善

**核心观点**：稀缺是经济学的基础。因为稀缺，选择不可避免；选择必有标准，标准就是歧视。商业是最大的慈善——市场比行善更高效地改善了陌生人的生活。

**八讲论证逻辑**：

| 讲次 | 核心论证 | 关键例子 |
|------|----------|----------|
| 001 战俘营里的经济组织 | 经济规律在哪里都起作用，哪怕在最不市场化的环境里 | 战俘营中的香烟货币、价格波动、通胀通缩、跨境贸易 |
| 002 马粪争夺案 | 公正背后是效率考量——保护产权的规则降低社会总消耗 | 18堆马粪判给堆粪者→鼓励创造财富；判给拿走者→人人花功夫看管财产 |
| 003 看得见的和看不见的 | 好经济学家能同时看见直接后果和隐形后果 | 破窗理论三变种：国家发展、工人就业、节省物资；巴斯夏蜡烛商请愿书 |
| 004 区分愿望与结果 | 经济学研究"事与愿违"的规律，不是"事与愿符"的愿望 | 最低工资保护穷人→穷人更糟；同工同酬保护弱势群→损害他们利益 |
| 005 不确定性、进化与经济理论 | 经济学关心存活条件，和人是否理性无关 | 阿尔钦：加油站开在路边就能存活；树叶朝阳光就茂盛 |
| 006 亚当·斯密的人性观 | 人是自私的，也有同情心；小圈子靠爱心，大世界靠市场 | 伦敦绅士对中国地震只发两根蜡烛；屠户、酿酒商和面包师不是靠恩惠 |
| 007 铅笔的故事 | 市场让成千上万陌生人协作，没有一个人掌握铅笔的全部知识 | 铅笔原料来自全球、工序涉及上万人的代际努力，一支只卖几毛钱 |
| 008 商业是最大的慈善 | 行善扶贫缺反馈机制，市场有天然反馈 | 世界银行 50 年 2.3 兆美元援助没让儿童打上 12 美分疫苗；哈利·波特 900 万册一天到读者手里 |

**一个洞察**：弗里德曼说，好多人只记得术语图表，从没听过经济学的音乐。薛兆丰用战俘营、马粪案、铅笔把音乐放出来了——这四个例子的共同指向是：哪怕在极端环境里，不靠爱心不靠命令，陌生人自发的交易也能创造秩序和财富。

### 第2章 成本 — 不要只盯着钱

**核心观点**：成本是放弃了的最大代价。成本由别人决定，不由自己决定。盈利和亏损都是意外——盈利提高资源未来使用成本，亏损降低之。供需决定价格，价格反过来决定成本，不是成本决定价格。

**十三讲论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 013 一句话给成本下定义 | 成本是放弃了的最大代价 | 采石场主买空地让它空着——不是自私，是消费者最终买单；沉没成本不是成本 |
| 014 你的成本由别人决定 | 负面感受不是成本，放弃的最大代价才是 | 长安街祖传铺位卖茶叶蛋——成本是别人愿意出的铺租，和产权归属无关 |
| 015 别只盯着钱 | 货币成本只是全部成本的一部分 | 淘旧货省了钱但花了时间+买到假货的风险；中间商赚差价让商品更便宜；腐败也得精打细算 |
| 016 从成本角度理解盈利与亏损 | 凡是盈利都是意外，亏损也是意外 | 10 元买的碗是乾隆用过的值 10 万→盈利瞬间发生，此后使用成本按 10 万算 |
| 017 供需决定成本 | 不是原材料成本决定售价，是售价反过来决定成本 | 王菲酬劳高不是因为成本高→是因为歌迷愿意出高价推高了她的劳动力资源 |
| 018 租 | 租是对资产的付费，是旱涝保收白赚的收入 | 猫王当卡车司机 10 万 vs 歌星 1000 万→990 万是租；你在上班时刷朋友圈赚了半小时的租 |
| 019 寻租 | 向政府争取优惠导致社会总资源耗散的行为 | 乞丐比惨自残的竞争消耗资源；政府 100 元优惠政策，争夺成本远超 100 元 |
| 020 社会成本问题 | 所有的伤害都是相互的，都是对稀缺资源的争用 | 科斯：牛吃小麦、酒店副楼挡泳池阳光、火车火星烧亚麻——不是谁伤害谁，是争夺同一资源 |
| 021 谁用得好就归谁 | 科斯定律：交易费用为零时，资源流到价值最高的用途上 | 钻石归白富美不归矿工；Kindle 笔记数据归亚马逊≈归读者；隐私权与公共安全需平衡 |
| 022 环境保护 | 必须用持平的眼光看待污染，在发展与环保之间找平衡 | 马车→汽车解决了马粪污染；黄石公园科斯对价解决狼群之争；布餐巾 vs 纸餐巾 |
| 023 交易费用 | 凡在一个人社会里不存在、多人社会里存在的成本 | 居民凑 50 元装过滤器的扯皮成本高到交易无法完成；风俗习惯是为减少重复商议成本 |
| 024 征地的权衡 | 私有产权和政府征地权之间必须取得平衡 | 基洛诉新伦敦市政府（辉瑞征地案 5:4 败诉）；芝加哥机场拆迁 160 年墓地 |
| 025 寻求合作解 | 不讲理要讲数，找平衡点 | 大学宿舍派对 vs 复习：出价在 100-300 之间成交；张五常蜜蜂寓言；瑞格利球场居民按门票 17% 分成 |

**一个洞察**：成本章是全书最深的硬核。薛兆丰用一个采石场的故事串起全部概念——那块空地之所以值钱，是因为消费者最终愿意为石头买单。成本不是企业家算出来的，是整个社会所有人共同决定的。所谓"不忘初心"之所以难，不是你不坚定，是放弃的代价被社会抬高了。

### 第3章 需求 — 好东西运到远方去

**核心观点**：个人估值为一切价值的起点。需求三定律是经济学最底层的规律：价格上升需求量下降（需求第一定律），时间越长弹性越大（需求第二定律），附加费固定时好东西显得更便宜（需求第三定律）。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 026 个人主义主观价值论 | 价值是个人主观的，不是商品固有的 | 明星拍 2 秒广告值天价，普通人拍不值钱——只有主观价值论能解释 |
| 027 边际革命 | 边际效用递减，边际平衡最大化总效用 | 罗斯福第四个三明治吃不下去；经济学考 100 分不如考 90 分把时间分给别的科 |
| 028 需求第一定律 | 价格下降，需求量上升；消费者剩余=交易剩余 | 停电时冰箱 300 元食物快坏了，你愿付 300 元来电实际只付 2 元，298 元是剩余 |
| 029 需求第二定律 | 时间越长替代方案越多，弹性越大 | 突然暴雨付 3 倍打车费；连下几天雨→你住学校附近酒店或取消课 |
| 030 需求第三定律 | 好东西运到远方去——固定附加费让优质品相对便宜 | 普通苹果 1 元精选 2 元，加 10 元运费→精选只贵 10%；进口澳洲牛肉去骨 |

**一个洞察**：需求第三定律最有反直觉张力。"好东西运到远方去"——不是因为远方人更富，是因为运费一加，高端货和低端货的价差缩小了。同理，你的简历为什么得用 A4 纸认真排版？花在写简历上的时间是固定附加成本，简历水平越低，这时间越不值。

### 第4章 价格 — 如何减少竞争的无谓损失

**核心观点**：价格不是数字，是三合一工具——传递稀缺信息、指导生产方式、决定分配（奖惩）。分配规则反过来决定饼能做多大。价格管制必然导致资源价值耗散，人会用越来越迂回的方式绕开管制。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 031 经济计算问题 | 计划经济有三个不可逾越的障碍 | 人际效用不可比较（张三家的老大≠李四家的老二）；数据不可得（人会故意误导）；奖惩无法恰如其分 |
| 032 知识在社会中的运用 | 哈耶克：价格让分散的局部知识得以协调 | 狗窝涨价→只有买狗窝的人收到信号，其他人不用知道你为什么爱你的狗 |
| 033 如何分饼决定饼做多大 | 价格的第三作用最关键——奖惩机制驱动人行动 | 农村土改"交够国家留足集体剩下是自己的"→同样土地产出翻倍；拜杜法案→美国科技爆发 |
| 034 乘人之危发财 | 利用别人困境发财的人增加了供给和选择 | 卡特里娜飓风发电机商被逮捕、发电机被没收→灾民反过来要发电机；弗里德曼：他们该得奖章 |
| 035-036 竞争的规则 | 所有规则都有赢家，按出价竞争浪费最小 | 暴力→练武，先到先得→排队，按需分配→装穷——只有按出价竞争，竞争过程中的努力为别人创造价值 |
| 037 短缺与过剩 | 稀缺是永久的，短缺和过剩是价格被压制或抬高的结果 | 北京 6 万辆出租车非短缺是价格太低；总统套房从不短缺因价格够高；美国牛奶倒掉=过剩=价格被抬高 |
| 038 价格管制 | 张五常理论：价格管制必然导致资源价值耗散，人追求损失最小化 | 房租管制→钥匙金、鞋金、捆绑销售；把民宅改商用规避管制 |
| 039 春运火车票 | 票价不够高导致更迂回的非价格竞争 | 实名制后黄牛从 30 元→200 元逼黄牛陪过安检；电话追拨器→刷票软件依次升级 |
| 040 美国的房租管制 | 房租管制毁了房子，伤害它想帮助的穷人 | 旧金山 1906 地震无短缺，1946 房租管制后求租者是出租者的 300+ 倍 |
| 041 解除价格管制 | 西德一夜取消全部价格管制→经济奇迹 | 艾哈德 1948 年广播解除管制→第二天消失十年的商品重回橱窗 |
| 042 实物补贴 vs 货币补贴 | 经济学家罕见共识：给穷人现金最好 | 教育券（弗里德曼）：补贴学生不补贴学校；公交补贴给乘客不给公司 |
| 043-045 房价专题 | 房价上涨正因素=集聚效应，负因素=制度摩擦 | "重要的不是你是谁，而是你跟谁在一起"；空置税催生"遛房"职业；消灭投资需求=消灭未来供给 |

**一个洞察**：薛兆丰用整章搭建"价格不可替代"的脚手架。最锋利的一句："控制温度计，是调节不了温度的。枪毙信使，并不能把坏消息变成好消息。"价格只是信使——涨价不是贪婪的人在搞鬼，是稀缺程度变了。

### 第5章 权利 — 自由不等于免费

**核心观点**：权利是文明的产物，通过社会强制实现。产权保护有财产原则、责任原则、不可转让原则三种模式，选择标准是交易费用高低。公共服务的关键不在物理属性，在产权缺位导致拥堵。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 051-053 产权保护三原则 | 财产原则（交易费用低）、责任原则（交易费用高）、不可转让原则（禁止交易） | 交通事故手臂不能事前议价→责任原则；摩尔诉加州大学——医生取走独特脾脏细胞开发 30 亿美元→不可转让原则 |
| 054-055 拥堵费 | 拥堵根因是路没有主人，收费不是筛选贫富是筛选需求 | 奈特 1924 年已指出：路若有主，主人定拥堵费保持"适当拥堵"；华盛顿 495 公路实时路权拍卖 |
| 056-057 公用品私用品 | 公用品≠政府提供，看物理属性：一人用后别人还能不能用 | 鸡蛋=私用品，旋律=公用品；科斯灯塔——英国灯塔自古由私人建造靠码头收费运营 |

**一个洞察**：器官买卖之所以被禁止，不是因为经济学家认为它邪恶，而是"不可转让原则"背后的父爱主义——政府替你做的决定。但如果器官合法化，死者将是最大的供给来源，这比禁止更能挽救生命。这是经济学分析在道德禁区里仍保持冷静的例子。

### 第6章 耐心 — 想象力决定生产力

**核心观点**：费雪《利息理论》串起了时间、耐心、利息、投资、保险和期货。利息是对推迟消费的补偿。投资是时间维度上的平衡消费。保险重新分摊风险，期货是正和游戏。

**十三讲核心链条**：

| 概念 | 论证 | 关键例子 |
|------|------|----------|
| 不耐产生交易 | 人对早消费有确定性偏好，现货期货比价=利率 | 战乱文物便宜和平贵；殖民者修百年石头洋房——文化影响不耐程度 |
| 利率管制 | 低息令穷人更难借钱，因为利率歧视被替换为身份歧视 | 民间借贷利率上限→黑社会地下借贷→迂回付息，交易费用更高 |
| 贴现率 | 未来越不确定，贴现率越高 | 100 年后 100 元在 6% 贴现率下=今天 0.3 元；贪腐"老寒腿"=自律=低贴现率 |
| 投资=时间平衡消费 | 追求终身幸福总和最大化 | 为什么不停吃三天再饿三天？→边际效用递减；度假是对记忆力的投资 |
| 有效市场假说 | 资产价格已反映可得信息，只随意外消息变化 | 阿尔钦仅靠查股票推断出氢弹原料是锂——秘密早已泄露到价格里 |
| 肥猪丸与回报率 | 竞争使所有资产回报率趋同 | 肥猪丸本身涨价吸收了回报，养猪场回报率不增；出租车份子钱同理 |
| 保险 | 购买"未来收入一致性"服务 | 细分越细保费越低（按年龄/婚否/邮编）；病毒基因细分在美国非法因被视为歧视 |
| 期货 | 重新分配不可避免的风险，是正和游戏 | 咖啡厅买咖啡期货→涨跌都高兴因为买的是确定性；预测气温比气象局还准 |

**一个洞察**：费雪一句话把整个人生重新定义——"投资是时间维度上的平衡消费"。你今天健身、学习、度假、陪家人，每一个决策都是在不同时点之间做消费的套利。自律不是因为道德高尚，是你的贴现率低，看得见 30 年后的自己。

### 第7章 供应 — 好钢用在刀刃上

**核心观点**：比较优势原理是经济学里最反直觉又最坚固的规律。价格歧视不是剥削，是觅价者把无谓损失消化的办法。衡量市场竞争程度不看企业个数，看行业入口有没有行政障碍。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 071 比较优势 | 自己跟自己比，总能找到机会成本最小的项目 | 中国造袜子机会成本<造飞机；孪生兄弟禀赋相同→随机选一行天天干也比样样干好 |
| 072-074 贸易 | 顺差逆差不重要，全局收支平衡就行；贸易报复是自残 | 中国对美顺差、意大利对中顺差、美国对意顺差→三角互抵；"愈让步愈进步" |
| 075 受价者觅价者 | 完全竞争是静止僵化的，不完全竞争才是常态 | 小区小卖部卖的是"水+位置的综合服务"，涨价五毛你还买；不完全竞争根本不值得批评 |
| 076-077 价格歧视 | 允许价格歧视→无谓损失消失，觅价者无罪 | 航空公司几乎没人票价相同；精装书先出向热心读者收高价 |
| 078 竞争不看个数 | 关键看入口有没有人为设障 | 苹果微软是开放市场的觅价者（靠消费者投票）；唯一例外是专利制度 |

**一个洞察**："一个社会的每种职业、每种生产，你往细里看，都可以找到本身独有的特色。"经济学家曾批评垄断者产量低价格高造成无谓损失，但允许价格歧视后，这个罪名消失了。垄断者（觅价者）在努力摸清消费者的每一条支付意愿曲线——这本身就是竞争。

### 第8章 信息不对称 — 谁的话语权更大

**核心观点**：人与人之间本来不存在互信。社会衍生了大量精妙制度来克服信息不对称——重复交易、第三方背书、沉没成本信号、质保延保、合同设计、垂直整合、监管竞争。高质量不意味着"最好"，而是匀质和性价比相当。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 079 柠檬市场 | 信息不对称会让市场崩溃：买家只知平均质量→高质品退出→平均质量继续下降→循环 | 阿克罗夫这篇被三家大刊拒稿，31 年后拿诺贝尔奖 |
| 080 何谓优质 | 优质=匀质+性价比相当，不是"质量越高越好" | 弗里德曼：汽车加 16 元挡板减少死亡→"如果你承认这个事实，就是在成本和生命之间权衡" |
| 081 重复交易与第三方背书 | 信任起源于重逢；附加成本发信号 | CarMax 买卖二手车做中间人；美国医学院面试一身行头几万美元 |
| 082 担保延保共享合同 | 信息不对称是双向的，供需双方都要珍惜信誉 | 苹果延保是甄别重度用户，不用把键盘做成绝对防水；按篇付费文章最普通 |
| 083 沉没成本人质抵押 | 故意付出不可收回的成本来取信对方 | 银行总部买下繁华地段不租；中国酒文化"我干三杯你随意"是自残式信任 |
| 084 广告代言形象打扮 | 巨额广告是把主动权交给消费者，自我削弱操纵地位 | 矿泉水厂花 1 亿请明星：想收回只能老老实实出 10 亿瓶好水 |
| 085 特许经营合同 | 表面不平等的合约恰恰在纠正另一种不公平 | 加盟店拥有砸总店牌子的能力——"termination at will"条款是总店自保 |
| 086 食品药品质量 | 管道产品难追溯→垂直整合；零部件产品可追溯→分工 | 三聚氰胺来自奶农；托牛所+试管留样解决追溯问题 |
| 087 婚姻经济学 | 婚姻是内容极复杂无法写条款的合约 | 一夫一妻制是对成功男人的限购政策，效果是财富转移；男女价值高峰不同期→嫁年长者婚姻更稳 |
| 088 汉德公式 | B<P×L 时承担注意义务，让防范成本最小的人负责 | Anna C 驳船沉没：船主派个人定期查看成本极低，损失极大→船主也负有责任 |
| 089 监管看边际 | 追求极致安全本身有成本，药物滞后让病人吃苦 | 艾滋病人到 FDA 门口抗议"我们不需要那么安全的药" |
| 090 监管引入竞争 | 强制披露令失败，让专家之间竞争 | iTunes 协议最小号字打出来 30 多页；医生列出副作用反而更被信赖 |

**一个洞察**：信息不对称贯穿一切人际关系。薛兆丰最精彩的洞察是——"表面上的强者（被称上帝的顾客）其实是弱者，表面上的弱者（殷勤的厨师）其实是强者。"所以豪华装修、制服笑脸、巨额广告，都是强者在交"保证金"，把钱先烧掉以换取弱者的信任。酒桌上喝吐的人不是在炫耀酒量，是在交抵押品。

### 第9章 合作 — 为何同工不同酬

**核心观点**：企业不是剥削场所——是专用资源者承担更大风险所以当老板，是难监督者拿剩余索取权所以自己监督自己。同工同酬法和最低工资法事与愿违，剥夺了弱者跟强者竞争的武器。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 091 企业的团队本质 | 企业能产生团队成员产出之和的超额效用→无中生有 | 柏林爱乐+卡拉扬 vs 无人指挥→收入差=指挥的边际贡献 |
| 092-094 谁来当老板 | 三条标准：谁容易被滥用（资本）、谁是专用资源（企业垮了贬值大）、谁难被监督（拿剩余索取权） | 资本一投入就没退路（弱者），劳动者随时可撤退（强者）；杰克逊说了算因为他不可替代 |
| 095 收入高低与节奏 | 工资由在别处的机会+边际贡献决定；节奏由品质鉴别难度决定 | 演员品质几天知道→收入短期支付；教授等 19-40 年→签终身合约摊平到漫长时间 |
| 096 同工同酬法 | 剥夺弱者的竞争武器：要求 80 元的女工只能索要 100 元→老板雇更合算的 100 元男工 | 哪里存在同工不同酬，哪里就存在"廉价优质员工"→贪心的老板会雇她们 |
| 097 最低工资法 | 最低工资导致失业，被用来提高竞争对手的成本 | 南非白人工会章程"致力于支持政府针对黑人的最低工资法"——不是爱黑人是提高对手成本 |
| 098 基尼系数 | 收入不平均≠收入不公，基尼系数忽略终身收入维度 | 年轻人穷是正常的；今天中产以上十年前也是穷人 |
| 099-101 工人违约与罢工 | 罢工=关键时刻敲竹杠+阻止别人干活=集体违约 | 阿拉斯加捕鱼案—渔民到现场提价；执业许可制度由内部人定标准→电工资格越难考触电死亡率越高 |
| 102 最富裕的穷人在今天 | 穷人搭社会进步的顺风车 | 美国七成贫困家庭有车 27% 有两辆以上；发明家收入只占社会价值的 2% |

**一个洞察**：全章用量子力学级的精度瓦解"资本家剥削工人"的直觉。企业不是比谁的嗓门大，是比谁承担的风险重——资本投进去跑不掉，所以资本当老板；专用资源企业倒闭就贬值，所以专用者做决策；经理关在办公室里做的事永远没人说得清，所以经理拿剩余利润自己监督自己。

### 第10章 协调 — 众人如何彼此影响

**核心观点**：宏观经济学没有标准答案——各学派在争论同一个问题的不同侧面。但共识清晰：货币发多了会通胀，长期菲利普斯曲线是垂直的，政府微调经济做不到。公共选择领域——一人一票的结果由中位数决定，财富再分配真正得益的是中产阶级。中国做对了四件事：确权、引入竞争、鼓励民企、加入 WTO。

**论证逻辑**：

| 讲次 | 核心概念 | 关键例子 |
|------|----------|----------|
| 103-104 货币 | 货币是自发秩序，商业银行通过存贷循环创造货币 | 双重偶然性（要找到既卖奶又买面包的人）；挤兑不是经营不善是机制性流动性困难 |
| 105-106 通胀 | MV=PY，通胀永远是一种货币现象；坎蒂隆效应——货币像蜜不均匀流淌 | 餐厅生意好分不清是相对优势还是通胀→错误决策；通胀是无形的税收 |
| 107 通胀与失业 | 长期菲利普斯曲线垂直，滞胀证明了它 | 弗里德曼&菲尔普斯 1968 年预言→1970 年代滞胀出现 |
| 108 奥地利学派 | 经济周期起源于政府过度发钞→低利率误导投资→泡沫破裂 | 资本是异质的，错误投资修改成本巨大；自由发钞制度让滥发银行被淘汰 |
| 109 凯恩斯学派 | 动物精神导致消费骤降，价格工资刚性令市场无法自行调整 | 菜单成本、效率工资；政府花钱替私人花钱的后果是债台高筑 |
| 110 货币主义理性预期 | 永久收入假说，政府政策被预期抵消 | 发 1 万元不会买 1 万红酒而是摊平到每顿饭；"大家不要吵"本身就增加噪声 |
| 111 真实经济周期 | 冲击是常态，经济周期是自然现象，政府连管都不该管 | 投资加速器：家里每天都有客人吗？衰退是过去错误决策的休整，阻止住院于事无补 |
| 112 聪明人为何不同意 | 变量太多、预期对策、不确定性无法用科学方法应对 | 盲人摸象；风险（掷骰子）vs 不确定性（AI 互联网）——后者根本不可预知 |
| 113-116 选举与再分配 | 中位数投票人原理；阿罗不可能定律；戴雷科特定律（中产受益） | 选举结果由中间派决定；投钞票可反映偏好强度投选票不能；高速公路/教育/医疗的再分配都是中产受益 |
| 117 脱贫致富 | 让穷人发挥能动性最重要 | 中国收费公路（用者自付）vs 美国汽油税大锅饭——制度小差别结果大不同 |
| 118 中国做对了什么 | 确权、引入竞争、鼓励民企、加入 WTO | 家庭联产承包→农民变剩余索取者→积极性大增；从认人→认钱→竞争成本最低 |

**一个洞察**：凯恩斯"从长远而言我们都将一命呜呼"，卡普兰"理性胡闹"——人在市场里为自己淘便宜货时会做出精明选择，在政治里不需要为选票承担后果时就会支持无效政策。这就是为什么懂经济学的人往往同时更相信市场、更不信任政府的干预能力。

### 后记 何为地道的经济学思维

**八点心得**：

1. **可证伪的才是地道的**——有可能错的理论才是科学理论；公平公正属于价值偏好不是科学
2. **与生活相关的才是地道的**——批评黑板经济学；麦克洛斯基：真正推动增长的是创新、企业家精神、商人守约的美德
3. **看见看不见的才是地道的**——从时间维度看成本；从竞争维度看浪费；区分成功者与失败者、潜在竞争者、潜在供给
4. **能分辨原因和结果的才是地道的**——相关性≠因果性；供求决定售价→售价决定生产要素成本
5. **能分辨事实和语言的才是地道的**——"消费者剩余"应称"交易剩余"；学区房把对学位的追逐变成对住房的追逐，家长付给学校的钱变成付给开发商
6. **能分辨愿望与结果的才是地道的**——买方找最便宜苹果令苹果涨价、卖方找最高房价令房价下跌；税负由弹性小的一方承担
7. **能分辨个体与全体的才是地道的**——剧场效应；戴雷科特定律；合成谬误
8. **牢记基本事实的才是地道的**——罐头刀笑话："假设我们有一把罐头刀"；不能假设信息对称、合同完备、交易费用为零、调整不需要时间

## 四、全书方法论骨架

```
薛兆丰的经济学推理方法：

1. 起点必是真实世界的故事
   → 战俘营 / 马粪案 / 铅笔厂 / 春节火车票 / 阿拉斯加捕鱼

2. 引入一对对立概念
   → 看得见的 vs 看不见的 / 愿望 vs 结果 / 成本决定论 vs 供需决定论

3. 用边际分析替代总量思维
   → 不是"要不要保护环境"而是"保护到什么程度"
   → 不是"要不要安全"而是"安全到什么代价"

4. 指出人的能动性和对策
   → 不管规则怎么定，人都会找到最优应对
   → 绕过管制的迂回成本才是真正的损失

5. 回到效率标准——谁避免意外的成本最低
   → 科斯的"相互伤害" + 汉德公式 B<P×L
```

## 五、可以带走的方法论

### 1. 任何问题先问"放弃了什么"
- 做 A 的成本不是 A 的辛苦，而是放弃的 B 里价值最高的那个
- 成本由别人决定——你开一家茶馆的成本是别人愿意出的租金，不是你的装修费

### 2. 看到价格先问"是不是被人扭曲了"
- 短缺永远不是供给问题，是价格被压低了
- 过剩永远不是消费问题，是价格被抬高了
- 价格管制不会消灭竞争，只会把竞争从"出价"变成"排队/攀附/自残"

### 3. 看到合约先问"在解决什么信息不对称问题"
- 表面不平等的条款（加盟可随时终止、婚前财产公证）恰恰在纠正另一种不公平
- 强者示弱（装修、广告、制服）= 交沉没成本 = 向弱者交信任抵押

### 4. 看到政策先想到"人的对策"
- 法律画上的不是句号，是冒号
- 实名制逼出了黄牛陪过安检；空置税催生了"遛房"职业
- "不管你怎么切，有人就有对策"

### 5. 判断争议用科斯眼光
- 不是谁伤害谁，是双方在争用同一种没界定清楚的稀缺资源
- 问：假设两者同属一人会怎么做？
- 不讲理，要讲数

### 6. 判断宏观政策用理性预期
- 政府发的钱不是白给的——人们知道迟早要还
- 反复用通胀刺激就业只会得到滞胀
