# 平行世界叙事法

> 寓教于乐。观众不是来听课的——是来看故事的。让他先在熟悉的世界里走一遍，最后告诉他"这就是XX"。

---

## 核心公式

```
建一个平行世界 → 给规则让人物自己跑 → 翻译只做一次 → 结论一句就够了
```

观众记住的不是知识，是他住过的那个世界。

---

## 底层原理：每次只拆一个概念

### 不是框架，是概念

四个视频，每个只讲一个概念。不是一个框架、不是一个方法论、不是"三个条件"或"五步法"。

| 视频 | 概念 | 观众原以为 |
|------|------|-----------|
| 巴萨效应 | 汇率为什么是这个数 | "国家规定的吧" |
| 汽油标号 | 为什么不同车加不同油 | "厂家骗钱吧" |
| 化学键 | 原子怎么粘在一起 | "反正有吸引力" |
| 做空 | 做空到底怎么赚钱 | "赌它跌" |

每个概念都是**观众以为自己懂、其实不懂**的东西。他做的事情不是"教知识"——是让观众发现自己其实不懂，然后在故事里自己搞懂。

**辨别标准**：如果你要讲的东西能用一句话说清楚概念（不是标题），那是一个概念。如果需要"第一…第二…第三…"才能说清，那是框架，不是概念。

### 平行世界选址三条件

四个平行世界全选在**观众不需要任何专业知识就能判断对错**的场景：

1. **日常生活场景** — 工人找活、马厩喂马、邻居拼车位、跟老王借东西。不是"用简单的东西比喻复杂的东西"，是选一个观众本来就活在里面的世界。
2. **有明确的社会规则** — 银行换钱、借东西要还、邻居会议论。社会规则观众不用学，肌肉记忆。
3. **观众自己当裁判** — 不需要被告知"这是对的"。老六工资涨了但东西也贵了→观众自己就能判断"好像没变富"。壮马吃镇静剂不撂蹶子了→观众自己就能理解"多花钱买安稳"。

**选址铁律**：如果平行世界里还需要"专家"来解释发生了什么，选址就错了。对的门槛是——把故事讲给一个初中生，他能在翻译之前就说"这不就是XX吗"。

### 人物驱动，不是逻辑驱动

观众记住的是人，不是道理。

- 记住"老六去银行换钱"，不是"购买力平价公式"
- 记住"壮马吃了镇静剂不撂蹶子了"，不是"辛烷值定义"
- 记住"老王借黄金给你"，不是"做空机制"

**他把概念变成了人的命运。** 每一步推进不是"因为A所以B"的逻辑链，而是"这个人在这个规则下会怎么做"的行为链。观众关心的是人物，概念是附带的。

### 开场公式（关键）

四个视频，开场结构完全一样：

```
为什么 [真实困惑A]，而不是 [真实困惑B]？
答案是 [概念名]。
啥是 [概念名] 呀？
[进入平行世界第一句]
```

逐段拆解：

| 拍 | 原文示例 | 作用 |
|----|---------|------|
| 真实困惑 | "为什么水分子是一个氧原子配两个氢原子，而不是3个或4个氢原子呢？" | 每个上过化学课的人都想过。不是"今天讲化学键"。是观众心里本来就有的问题 |
| 概念名 | "答案是化学键。" | **概念在前5秒就说了。** 概念不是悬念——概念是锚点。观众听到"化学键"但不知道它到底是什么。故事负责让他懂 |
| 替观众问 | "啥是化学键啊？" | 替观众说出正在想的话。然后一秒不停，直接进入平行世界 |
| 进入世界 | "这是一个原子核——" | 不讲定义。不列公式。直接画一个原子核。故事开始 |

**铁律**：
- ❌ 不要"今天讲XX"、不要"你猜怎么着"、不要"你知道吗"
- ❌ 不要把概念名藏到最后。概念名是开场锚点，不是结尾彩蛋
- ✅ 困惑必须是真实具体的——"为什么92/95/98号汽油价格不一样"强过"你知道汽油标号吗"
- ✅ 观众心里的问题被你说出来了——"啥是XX呀"——然后立刻进入世界

这和"80%篇幅不讲术语"不矛盾。**术语（杠杆/做空/化学键）在开场就说，但它的含义——那种真正让你"啊原来如此"的理解——要到故事最后才落地。** 观众听了一个词，追着一个故事，最后真正懂了。

### 结构精度

```
前 5s    真实困惑 → 概念名 → "啥是XX呀"
前 80%   只在平行世界里跑。除了开场的概念名，一个术语都不出现
80-90%   翻译一次。"这就是XX"。呼应开场的概念名
90-100%  结尾反问。不给答案
```

不是"先打比方、再讲理论、再总结"——理论部分根本不存在。故事本身就是全部内容，概念名是锚点，翻译是闭环。

## 六步法

### 1. 建一个平行世界

不用原领域任何一个术语。用观众日常熟悉的东西——马厩、小区车位、邻居家、六个打工的人。

| 原领域 | 平行世界 |
|--------|---------|
| 发动机爆震 | 壮马撂蹶子 |
| 化学键 | 邻居拼车位 |
| 汇率/购买力平价 | 六个工人，太平洋两岸 |
| 做空 | 跟邻居老王借黄金 |

**铁律**：前50%篇幅里，一个专业词都不能出现。

### 2. 给这个世界一条社会规则

物理定律太远。社会规则才是人能代入的——"邻居会议论""车位不能空""银行只有1万美元""借一天给10万利息"。

规则不是外部强加的。是这个世界里的人**自己会遵守的**。

### 3. 让人物在规则里自己跑

不是你在解释。是老六、老七、老八在银行大厅竞价，是小B失业后去小C的工厂打工。观众看到的是人，记住的是人。

**每推进一步，让观众自己先感受到矛盾——再翻下一页。**

```
"只开放服装 → 没啥变化 → 嗯合理"
"开放手机 → 汇率跳1:7 → 卧槽"
"打电话问 → 体感没变 → 等等，这是为什么？"
```

不是讲道理。是让观众自己发现矛盾。

### 4. 翻译只做一次，在最后

80-90%篇幅在平行世界走完。翻译只占最后两段。

观众的反应不是"学到了新知识"。是"啊原来我刚才已经懂了"。

```
"这种拼车合同，叫化学键。"
"这叫巴萨效应。"
"你现在叫私募基金。"
```

### 5. 上电梯（可选）

同一公式，换规模。不变的是逻辑，变的是量级。

```
黄金 → 股票 → 泰铢 → 美元
私募基金 → 量化机构 → 索罗斯 → 华尔街资本
```

每一层都是上一层的放大。观众不是学了五个知识，是跟着同一条逻辑坐了五层楼。

### 6. 结尾不解释。反问。

不给答案。让观众坐在那个问题里。

> "为什么那些可爱的散户朋友们却依然排队入场，一点都不怕你呢？"

真正的力量不在前面的解释，在最后这句话制造的不适感。

## 直播类变体（父亲给孩子讲知识）

场景本身就是钩子。给两岁孩子讲"巴萨效应"——观众第一反应"这人疯了吧"。然后发现孩子听没听懂不重要，**自己能听懂**。

白板 + 边画边讲 + 虚拟人物（小甲小乙小丙小A小B小C）。核心手法跟前面完全一致，只是加了**场景反差**作为额外钩子。

## 格式适配

### 短视频（原生格式）

这是平行世界叙事法的原生格式。四个案例全部是短视频——一个人坐在桌前，边画边讲。镜头控制节奏、停顿制造转折、沉默比语言更有力。

**叙事骨架（镜头弧线）：**

```
镜1  真实困惑 → 概念名 → "啥是XX？"→ 进入平行世界（开场，概念锚点）
镜2  世界的规则 + 人物开始行动（观众在心里比较）
镜3  人物继续行动。矛盾开始暴露（观众先于结论感到不适）
镜4  矛盾升级。时间拉开（观众自己在心里问出"为什么"）
镜5  翻译——"这就是XX"。呼应镜1的概念名，但这次真正懂了
镜6  反问。不给答案。黑屏
```

**短视频独有优势：**
- 创作者控制节奏——哪里停、哪里快、哪里让沉默说话
- 观众不能翻页——叙事弧线不能被跳过
- 画的过程本身就是视觉钩子——观众看着画从无到有，跟着走

### 图文（降级适配）

图文没有镜头语言和口播节奏，观众控制翻页速度，叙事弧线容易被破坏。能勉强承载平行世界叙事，但效果打折扣。

**图文骨架（7页）：**

```
P1  真实困惑 → 概念名 → "啥是XX？"→ 进入平行世界
P2  世界的规则
P3  人物在规则里行动
P4  矛盾暴露
P5  矛盾升级
P6  翻译——"这就是XX"
P7  反问。不给答案
```

**图文限制：**

```
❌ 禁止：P1 就是专业术语
❌ 禁止：用"三条件""五步法"等清单式拆解
❌ 禁止：结尾给标准答案

✅ 必须：前3页让观众待在一个他熟悉的世界里
✅ 必须：术语只在最后1-2页出现
✅ 必须：结尾反问或留白
```

### 格式选择规则

```
概念拆解型选题（讲一个概念是什么）→ 短视频优先。镜头节奏是叙事的一部分
个人经历型选题（讲一段真实经历）→ 图文可用。来时路的页面停顿反而有力量
框架/知识型选题（产业链拆解等）→ 图文优先。不需要叙事弧线，需要信息密度
```

---

## 与"来时路"叙事的关系

两者是兼容的。来时路解决"信任从哪来"，平行世界解决"知识怎么讲"。

```
来时路（个人经历） → 让观众认识你、信任你
平行世界（熟悉场景） → 让观众自己先走一遍、再翻译
```

可以交替使用。个人故事型内容用来时路。知识拆解型内容用平行世界。两者都遵循同一个底层逻辑：**先体验，后结论**。
