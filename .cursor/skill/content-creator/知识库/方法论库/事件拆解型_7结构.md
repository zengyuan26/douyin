# 事件拆解型内容 · 7 种结构模板

> 来源：反无人机「安全规则变了」案例拆解时整理。适用于「根据真实事件/案例拆解出的爆款内容」这一类。
> 位置：属于「图文创作方法论」类型决策树中「分析型」下的细分结构库。跟 [[开场方法论]]、[[新闻分析类图文模式]] 互补。

---

## 一、核心洞察（先记这个，比 7 种本身更重要）

**7 种结构共享同一个内核骨架：**

```
事件/案例 → 痛点放大 → 原因拆解 → 认知升级 / 方案
```

**它们唯一的区别是第一屏（P1）用什么钩子让观众停下来。**

所以「选结构」本质上 = 「选钩子」。钩子选对了，后面 4 屏是同一套拆解逻辑；钩子选错了，观众第一屏就划走。

**判断选哪个钩子，用钩子三问 + 焦虑距离：**

- 谁会睡不着觉想这个？（焦虑主体）
- 反应是「有意思」还是「这就是我」？（代入深度）
- 落钱 / 关系 / 认知了吗？（价值锚点）
- 切入事件离观众的焦虑 ≤1 步吗？（≤1 步放钩子，>1 步降级为弹药）

## 二、7 种结构速查表

| 结构 | 第一屏钩子 | 钩子本质 | 适用场景 | 适配度 |
|------|-----------|---------|---------|--------|
| 损失前置型 | 损失金额/时间 | **痛觉** | 有明确损失数字 | ⭐⭐⭐⭐⭐ |
| 数字冲击型 | 大数字 vs 小数字 | **反差** | 数字反差大 | ⭐⭐⭐⭐⭐ |
| 认知升级型 | 旧认知 vs 新认知 | **迭代** | 有认知刷新点 | ⭐⭐⭐⭐⭐ |
| 反差对比型 | 你以为 A 其实是 B | **打破常识** | 认知反差大 | ⭐⭐⭐⭐ |
| 身份代入型 | 你是 X | **自我代入** | 观众身份明确 | ⭐⭐⭐⭐ |
| 战场类比型 | 强符号借力 | **降低理解成本** | 有大众熟知类比 | ⭐⭐⭐⭐ |
| 时间线叙事型 | 追剧式揭秘 | **悬念** | 事件有时间线 | ⭐⭐⭐ |

## 三、7 种结构详解（含反无人机案例对照）

### 1. 损失前置型（案例驱动的主力结构）

**结构**：封面讲损失 → 案例细节 → 痛点放大 → 原因拆解 → 方案/认知升级

**反无人机案例**：
- P1：研发两年，两个月被抄
- P2：苏州厂镜片被抄，定价更低
- P3：索赔 3000 万，补不回市场
- P4：秘密是被拼出来的，不是被偷的
- P5：安全规则变了——先抬头看天

**爆款逻辑**：观众先感受到「痛」，才会想听「为什么」和「怎么办」。

---

### 2. 反差对比型

**结构**：你以为 A → 其实是 B → 案例证明 → 认知升级 → 行动建议

**反无人机案例**：
- P1：你以为秘密是被内鬼偷的
- P2：其实是对手用无人机拼出来的
- P3：苏州厂查遍内部没泄密，围墙外每周被拍
- P4：四碎片拼出工艺路线（设备/专利/招聘/采购）
- P5：你防的是人，漏的是天

**爆款逻辑**：打破常识，制造「原来如此」的顿悟感。

---

### 3. 时间线叙事型

**结构**：T0 事件发生 → T1 发现异常 → T2 追查原因 → T3 真相大白 → T4 认知升级

**反无人机案例**：
- P1：第 1 周：对手新品上市，价格低 30%
- P2：第 2 周：我们查内部，没泄密
- P3：第 3 周：发现围墙外有无人机每周来
- P4：第 4 周：四碎片拼出工艺路线
- P5：第 8 周：安全规则变了——先抬头看天

**爆款逻辑**：观众像看侦探片，跟着一步步揭开真相。

---

### 4. 数字冲击型

**结构**：大数字（损失）→ 小数字（成本）→ 反差放大 → 原因拆解 → 方案

**反无人机案例**：
- P1：几千万研发 vs 几百块无人机
- P2：两年时间 vs 两个月被抄
- P3：索赔 3000 万 vs 市场全丢
- P4：四碎片拼出工艺路线
- P5：安全规则变了

**爆款逻辑**：数字是最直观的冲击，观众秒懂「不值」。

---

### 5. 身份代入型

**结构**：你是 X → 你遇到 Y → 你怎么办 → 案例证明 → 方案

**反无人机案例**：
- P1：你是工厂老板，研发两年，对手两个月抄走
- P2：你索赔 3000 万，市场没了
- P3：你查遍内部，没泄密
- P4：真相是无人机每周在围墙外偷拍
- P5：你该怎么办？先抬头看天

**爆款逻辑**：观众直接代入「这就是我」，完播率高。

---

### 6. 认知升级型

**结构**：旧认知 → 新认知 → 案例证明 → 底层逻辑 → 行动建议

**反无人机案例**：
- P1：旧认知：秘密是被偷的
- P2：新认知：秘密是被拼出来的
- P3：苏州厂案例：四碎片拼出工艺路线
- P4：底层逻辑：信息碎片化时代，没有绝对秘密
- P5：行动建议：先抬头看天，再谈安保

**爆款逻辑**：观众觉得「学到了」，容易点赞收藏。

---

### 7. 战场类比型

**结构**：战场案例 → 工厂案例 → 类比逻辑 → 认知升级 → 方案

**反无人机案例**：
- P1：俄乌战场：几亿的坦克被几千块无人机点名
- P2：你的工厂：几千万研发被几百块无人机抄走
- P3：类比逻辑：都是降维打击
- P4：认知升级：安全规则变了
- P5：方案：先抬头看天

**爆款逻辑**：借大众认知里的「强符号」（坦克/无人机），降低理解成本。

## 四、怎么选（决策顺序）

1. **先定内核**：这个事件有没有清晰的「案例 → 痛 → 原因 → 方案」拆解链？没有就不属于事件拆解型，回到类型决策树。
2. **再看钩子素材**：你手上最强的是哪个钩子？
   - 有明确损失金额/时间 → **损失前置型**
   - 有强烈数字反差 → **数字冲击型**
   - 有认知刷新点 → **认知升级型**
   - 观众身份极明确（老板/家长）→ **身份代入型**
   - 有大众熟知的类比符号 → **战场类比型**
3. **一稿多钩**：同一个内核可以换壳复用——反无人机这 7 种就是同一素材的 7 个变体，适合做成系列或 A/B 测试。
