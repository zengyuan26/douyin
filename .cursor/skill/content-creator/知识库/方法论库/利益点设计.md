# 利益点设计

> 层层追问是"拉"——制造缺口。利益点是"推"——填上缺口。两股力配合才能从头拉到尾。
> 核心理念：观众每翻一页都在问自己"还值得往下看吗？"每页必须有获得感。

---

## 四种利益点类型

| 类型 | 观众心里话 | 判断标准 | 示例 |
|------|-----------|---------|------|
| **信息差** | "原来是这样，第一次听说" | 这个数据/事实，大多数目标观众不知道 | 联通副总原话、137 EFLOPS |
| **认知差** | "这个角度我没想过" | AI 搜不到这个判断，是你推出来的 | 管道工→工厂主、算力铁塔 |
| **实用价值** | "这个我能用上" | 观众看完能做一个具体动作 | 岗位表、EMC 零投入装光伏 |
| **情绪价值** | "说到我心坎里了" | 恐惧/共鸣/愤怒/被理解 | 你多花的电费替AI买了单 |

认知差 > 信息差 > 实用价值 > 情绪价值，按稀缺性排序。认知差最难复制，是差异化核心。

## 密度分布：前密后疏

```
P1 封面  ██        2个利益点  （锚点+悬念同时给，停住人）
P2 灵魂  ███       3个利益点  （最密。决定留下还是划走）
P3 定价  ██        2个利益点
P4 关系  ██        2个利益点
P5 普人  █         1个利益点  （开始变疏，已投入的观众不需要密）
P6 工厂  █         1个利益点
P7 投资  █         1个利益点 + 争议钩子
```

**曲线：3 → 2 → 2 → 1 → 1 → 1**

前 3 页随时划走，每页必须有多个利益点叠在一起，用获得感砸到他不走。后面他已投入沉没成本，一个深度利益点足够。

---

## P2 是生死页

P2 决定"留下还是划走"。必须叠三个不同类型的利益点：

- 信息差（数据/事实，证明你不是在吹）
- 认知差（框架/判断，证明你的视角不一样）
- 情绪价值（格局/共鸣，让他觉得"这人有东西"）

三个少一个，观众可能觉得"还行吧"然后划走。

---

## 与层层追问的配合

```
追问（拉）              利益点（推）
  ↓                        ↓
"百倍价值密度？"    →   管道工vs工厂主（认知差）
"凭什么？垄断？"    →   算力铁塔（认知差）
"电费涨不涨？"      →   结构性涨价挡不住（信息差+情绪）
"普通人机会？"      →   证比学历重要（实用价值）
"工厂做什么？"      →   峰谷4毛就值得装（实用价值）
"钱往哪放？"        →   盯第二波运营（实用价值）
```

追问制造"我想知道"，利益点给"幸好我知道了"。两个力交替——不能只有追问（空洞），不能只有利益点（说教）。

---

## 类型交替原则

不能连续两页给同一种利益点。认知差连续两页可以（P2+P3），但实用价值连三页就是枯燥。交替节奏：

- P2 认知 → P3 认知（允许连续，核心判断层）
- P4 情绪（打破认知连续，拉回"跟我有关"）
- P5 实用 → P6 实用 → P7 实用（后段实用可连续，观众在对号入座）

---

## 每页生成前自检

```
□ 这一页的"获得感时刻"是什么？（一句话说出来）
□ 利益点属于哪个类型？（信息差/认知差/实用/情绪）
□ 这个利益点，AI 能不能给？（能 → 换角度。你的判断才有认知差）
□ 观众会不会因为这个利益点，愿意翻下一页？
□ 跟前一页的利益点类型重复了吗？（P2+P3 认知连续可以，其他要交替）
```

第三个问题是关键。利益点的作用不是"让这一页好看"——是 **让观众愿意翻到下一页**。

---

## 常见反模式

- **封面给结论**：利益点不是答案。P1 给锚点+悬念，不给判断。给了判断观众就不用翻了
- **空洞页**：整页没有"获得感时刻"，观众看完觉得"所以呢？"
- **数据堆砌**：全是信息差，没有认知差。AI 也能给。观众会想"我搜一下就知道了"
- **密度倒挂**：前面稀后面密。前 3 页每页一个利益点，P6 反而给三个。观众已经走了
- **连续同类型**：P4-P7 全是实用价值，没有情绪调剂。变成说明书
