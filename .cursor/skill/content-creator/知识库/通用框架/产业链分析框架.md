# 产业链分析框架

> 不是用来写行业报告的。是用来快速摸清一个行业，找到问题在哪个环节、谁在吃亏、谁在卡脖子、哪里藏着选题。

---

## 一、为什么需要这个框架

直接看新闻容易只看到表面事件。产业链框架让你看到：
- 这条链上钱在往哪流、谁在赚谁在亏
- 瓶颈在哪——哪个环节掐着所有人的脖子
- 哪个环节的人最焦虑、最脆弱、最容易被收割

**任何一个行业都可以拆成四层。拆完，问题自己会浮出来。**

---

## 二、四层结构

```
上游（原料/设备/投入品）
  → 中游（加工/制造/集成）
    → 下游（产品/渠道/终端用户）
      ← 横向（技术/金融/物流/监管 — 贯穿所有层）
```

| 层 | 含义 | 判断标准 |
|----|------|---------|
| **上游** | 原料、零部件、设备、技术授权 | 中游必须买它的东西才能开工 |
| **中游** | 加工、制造、组装、平台运营 | 把上游的东西变成下游要的东西 |
| **下游** | 品牌、渠道、终端用户 | 谁最后付钱、谁把东西递到付钱的人手里 |
| **横向** | 装备、软件、金融、物流、检测、监管 | 不直接参与生产，但没有它链条转不起来 |

---

## 三、核心操作：画链条映射表

### 步骤

1. **定边界** — 从哪到哪。比如"动力电池产业链"的边界：采矿 → 电芯 → 新能源车。不延伸到充电桩运营商。
2. **分层** — 把每个环节归到上/中/下游。
3. **找代表** — 每个环节 2-5 家代表公司（上市/知名/你能查到数据的）。
4. **标特征** — 集中度、毛利率区间、定价权方向。

### 空白模板

```
行业：_______________
边界：从 _______________ 到 _______________

| # | 环节 | 层 | 代表公司 | 集中度 | 毛利率 | 定价权 | 谁依赖它 | 它依赖谁 |
|----|------|---|---------|--------|--------|--------|---------|---------|
| 1 |     | 上游 |        |        |        |        |         |         |
| 2 |     | 上游 |        |        |        |        |         |         |
| 3 |     | 中游 |        |        |        |        |         |         |
| 4 |     | 中游 |        |        |        |        |         |         |
| 5 |     | 下游 |        |        |        |        |         |         |
| 6 |     | 下游 |        |        |        |        |         |         |
| - |     | 横向 |        |        |        |        |         |         |
```

**集中度**：一家独大 / 寡头(2-3家) / 分散
**定价权**：强（敢涨价） / 弱（被压价） / 夹心（上下游同时挤压）
**毛利率**：高(>40%) / 中(20-40%) / 薄(<20%)

### 怎么填

不需要精确数据。初次画图，估算区间就够了。关键是理清**谁在价值链的什么位置**。

填表时问三个问题：
1. 这个环节要是没了，下游还能转吗？（不能 = 瓶颈）
2. 这个环节的毛利率比上下游高还是低？（高 = 有议价权）
3. 这个环节是只有两三家做，还是谁都能做？（寡头 = 有壁垒）

## 四、三步定位瓶颈和问题

### 第一步：找毛利率断层

毛利率断崖式跳高的地方 = 瓶颈。上下游差超过 15 个点就要注意。

```
例：隔膜毛利率45%，电芯25%，正极材料15%
→ 隔膜是瓶颈。电芯厂想降价，隔膜厂不跟。
→ 问题方向：为什么隔膜能卡住电池厂的脖子？
```

### 第二步：找夹心层

被上下游同时挤压的环节 = 最脆弱 = 最有故事。

```
例：电芯厂。
上游碳酸锂涨价 → 成本涨。下游车企压价 → 售价降。两头挤。
→ 问题方向：电芯厂怎么活下来的？谁先死？
```

### 第三步：找依赖陷阱

某个环节严重依赖单一上游或单一下游 = 风险点。

```
例：一家正极材料厂80%的货卖给宁德时代。
→ 宁德一砍单，直接归零。
→ 问题方向：把命交给一家大客户的人，现在怎么想的？
```

### 三步走完的画布

```
瓶颈（高毛利+寡头+不可替代）：___________
夹心层（两头受挤压）：___________
依赖陷阱（单一客户/供应商）：___________
```

三个框填完 → 这条产业链上最大的三个问题全出来了。

## 五、从链条到选题：双轨输出

三步定位走完，同一条链可以长出两类完全不同的内容。

---

### Track B：说给产业经营者听

你的观众是这个行业里的人。他们天天在里面，反而看不见结构性问题。你替他们看见。

**一句话**：我看到了一个你自己没发现的问题。

| 挖掘方向 | 问什么 | 选题信号 |
|---------|--------|---------|
| **谁在吃亏** | 这个环节的人，赚不到钱还在干，为什么？ | 有苦说不出的群体 → 替他们说出来 |
| **谁在卡脖子** | 这个环节涨价，下游所有人跟着涨，凭什么？ | 一个你离不开的东西 → 拆解它的权力来源 |
| **谁在悄悄赚钱** | 不起眼的环节，毛利率最高？ | 反直觉——"最赚钱的不是你以为的那个" |
| **谁要被淘汰** | 什么变化会让这个环节消失？ | 技术替代/政策一刀切/上游一体化 → 末日时钟 |
| **谁在互害** | 上游涨价 → 下游压价 → 中游怎么活？ | 结构性的两难 → "两条路都在输" |
| **钱去哪了** | 消费者付的钱，产业链上谁分走了最大块？ | 一张利润分配表 → "我的钱被谁赚了" |
| **谁最焦虑** | 政策/技术/贸易一变，谁先睡不着觉？ | 最脆弱环节的人的决策困境 |
| **行业暗账** | 公开说法跟实际数据对不上？ | 一个外行看不到的真实数字 → 信息差揭穿 |

---

### Track C：帮产业经营者做内容给他们的客户

你用这张表帮行业里的人做内容。你不经营这个行业，但你可以帮他们触达他们的客户。

**一句话**：我帮你的客户看懂你做的事。

| 内容类型 | 链条给你什么 | 选题方向 |
|---------|------------|---------|
| **透明工厂** | 上游到中游的每一步 | "你花100块买的XX。材料多少钱、人工多少钱、谁赚走了大头" |
| **好坏鉴别** | 相邻环节的品质差异 | "超市XX和菜市场XX，差的不只是价格——差在这三步" |
| **信任建立** | 中游加工过程 | "王大姐灌香肠，你在旁边看着。这三步，工厂永远不敢让你看" |
| **避坑指南** | 下游端的价格/品质乱象 | "买XX别只看价格。问这三个问题，老板知道你是内行" |
| **行业科普** | 任何一个有信息差的环节 | "为什么冬天灌的香肠比夏天香？不是心理作用。是温度和菌" |
| **溢价合理性** | 毛利率断崖处 | "这个东西比别家贵一倍。贵在哪？拆开给你看" |
| **季节/时令** | 季节性依赖的环节 | "一年只做三个月的东西。为什么值得等九个月" |

## 六、完整示例：动力电池

### 链条映射表

| # | 环节 | 层 | 代表公司 | 集中度 | 毛利率 | 定价权 |
|---|------|---|---------|--------|--------|--------|
| 1 | 锂矿/钴矿/镍矿 | 上游 | 天齐/赣锋/华友 | 寡头 | 中-高(周期) | 强(涨价周期) |
| 2 | 正极材料 | 上游 | 容百/当升/德方纳米 | 分散 | 薄(10-15%) | 弱 |
| 3 | 负极材料 | 上游 | 贝特瑞/杉杉 | 寡头 | 中(20-30%) | 中 |
| 4 | 隔膜 | 上游 | 恩捷/星源 | **一家独大** | **高(40-50%)** | **强** ← 瓶颈 |
| 5 | 电解液 | 上游 | 天赐/新宙邦 | 寡头 | 中(25-35%) | 中 |
| 6 | 电芯/Pack | 中游 | 宁德/比亚迪/中创新航 | 寡头 | 中(20-25%) | 被挤压 |
| 7 | 新能源车 | 下游 | 比亚迪/特斯拉/蔚小理 | 寡头竞争 | 薄-中(10-25%) | 弱(价格战) |
| 8 | 储能系统 | 下游 | 海博思创/阳光电源 | 分散 | 中(20-30%) | 中 |
| — | 设备(涂布/卷绕) | 横向 | 先导/赢合 | 寡头 | 中-高 | 中 |

### 三步定位

- **瓶颈**：隔膜。恩捷一家占40%+市场份额，毛利率40%+。下游电芯厂敢降我价？不存在的。
- **夹心层**：电芯/Pack。上游矿涨价 + 下游车企价格战 = 两头挨打。
- **依赖陷阱**：正极材料。技术路线一变（三元→铁锂→钠电），直接清零。

### Track B：说给产业经营者听

| 问题来源 | 选题 | 目标观众 |
|---------|------|---------|
| 瓶颈（隔膜） | "电池降价的路上，有一关怎么都过不去——隔膜厂不跟" | 电芯厂老板/采购 |
| 夹心层（电芯） | "碳酸锂涨，车价降。做电池的在给两边打工" | 电池厂/投资者 |
| 依赖陷阱（正极） | "钠电池如果成了。这些公司就没了" | 正极材料厂 |
| 谁在悄悄赚钱 | "电池厂都在哭穷。有一家公司从来不哭" | 行业从业者 |
| 钱去哪了 | "你买一辆20万的车。电池厂只赚了8000" | 整车厂/经销商 |

### Track C：帮产业经营者做内容给他们的客户

帮储能/光伏/微电网企业做内容，触达工厂老板客户。

| 内容类型 | 链条给的素材 | 选题方向 |
|---------|------------|---------|
| 透明算账 | 电芯成本→Pack成本→系统成本→售价 | "你工厂装的这套储能。电芯多少钱、集成多少钱、我赚了多少" |
| 好坏鉴别 | 一线电芯 vs 二三线电芯的品质差 | "A类电芯和B类电芯。看起来一样。用到第三年你就知道了" |
| 避坑指南 | 下游集成商乱象 | "装储能别只比价格。问这三句，方案商知道你是懂行的" |
| 溢价合理性 | 隔膜/设备等高毛利环节 | "为什么恩捷的东西比同行贵20%。拆开给你看" |
| 趋势判断 | 钠电替锂电的技术替代风险 | "现在上储能，选锂电还是等钠电？一张表告诉你" |

## 七、完整示例：手工灌香肠

用同一个框架，小生意也拆得开。

### 链条映射表

| # | 环节 | 层 | 代表 | 集中度 | 毛利率 | 定价权 |
|---|------|---|------|--------|--------|--------|
| 1 | 生猪养殖/屠宰 | 上游 | 牧原(工业)/散户(手工) | 工业寡头+散户分散 | 工业周期暴利/散户5% | 强(周期) |
| 2 | 天然肠衣 | 上游 | 肠衣加工厂 | 分散 | 中(20-25%) | 中 |
| 3 | 调料/香料 | 上游 | 批发市场调料商 | 分散 | 中(20-30%) | 中 |
| 4 | 切肉调味 | 中游 | 菜市场肉摊/作坊 | **极度分散** | — | 弱 |
| 5 | 灌制分段 | 中游 | 同上(一体) | 极度分散 | — | 弱 |
| 6 | 晾晒/熏制 | 中游 | 同上/专业熏房 | 分散 | 加工费3-5元/斤 | 弱 |
| 7 | 菜市场代售 | 下游 | 肉摊老板 | 极度分散 | 薄(10-15%) | 弱 |
| 8 | 熟食店/社区 | 下游 | 个体户 | 极度分散 | 中(25-35%) | 弱 |
| 9 | 直播/短视频 | 下游 | 作坊+快递 | 新渠道 | 高(直销) | 中-强 |
| 10 | 终端消费者 | 下游 | 家庭/个人 | — | — | — |
| — | 食品监管 | 横向 | 市场监管局 | 政府 | — | 一票否决 |
| — | 冷链快递 | 横向 | 顺丰/京东冷链 | 寡头 | 中 | 强 |

### 三步定位

- **瓶颈**：没有传统意义上的瓶颈。整条链极度分散。但猪肉价格是一个**自然瓶颈**——没人能控制它，但所有人都被它控制。猪肉占成品成本60-70%，3-4年一个周期。
- **夹心层**：加工作坊。猪肉涨 → 成本涨。消费者嫌贵 → 售价涨不动。同时两面受敌——上面工厂香肠成本是你1/3，下面邻居大妈零加工费纯帮忙。
- **依赖陷阱**：三个。猪肉周期（不可控成本）、季节性（70%销量在冬天）、本地信任（换个小区从零开始）。

### Track B：说给产业经营者听

说给灌香肠的人、肉摊老板、想入行的人。

| 选题 | 问题根源 | 方向 |
|------|---------|------|
| **"灌香肠的人，在给猪打工"** | 夹心层 + 自然瓶颈 | 一斤香肠成本拆开。猪肉占六成。三年猪价波动 vs 利润曲线，两条线反向。三种抗周期方法都不完美。落点：原材料占成本60%以上的生意，你永远在赌上游。 |
| **"只做三个月生意，怎么活一年"** | 季节性依赖 | 为什么灌香肠只在冬天——温度/湿度/传统习惯三重锁定。三种解法：冷库控温全年做、夏天换品类（腊排骨/酱肉）、冬天灌真空冻全年卖。最聪明的人在用第三种——抖音=打破季节性的武器。 |
| **"工厂香肠比你便宜一半。为什么你还在？"** | 工业化替代 | 工厂怎么做：猪碎肉+淀粉+磷酸盐保水+烟熏液(不是真熏)+防腐剂。出肉率120%。手工怎么做：前腿肉+肥瘦3:7+真熏+风干。出肉率65%。落点：工厂卖的是价格，你卖的是"知道这肉哪头猪的、谁灌的、怎么熏的"。 |
| **"超市香肠和你的香肠。肉眼看不出来。但你的贵一倍"** | 信任是怎么变成溢价的 | 三层信任：看见（在旁边看你灌）→ 被告诉（肥瘦3:7、今早宰的前腿）→ 验证过（上次买了小孩说好吃）。三层叠满，溢价一倍是便宜的。落点：小生意的护城河不是技术不是产能，是一个人的名字。王大姐三个字比ISO值钱。 |
| **"猪肉明年什么价？灌香肠的人每年都在想这个问题"** | 猪肉周期 | 猪周期的机制。今年肉贵→大家都养猪→明年肉贱→大家都不养→后年又贵。灌香肠的人怎么应对：囤肉赌方向（资金压死）、锁定客户预付款（客户不干）、随行就市定价（客户嫌贵）。三种都不对。有没有第四种？ |

### Track C：帮灌香肠的人做内容给他们的客户

你帮王大姐做抖音。让她的客户排队。

| 选题 | 链条素材 | 怎么讲 |
|------|---------|--------|
| **"超市香肠18块。王大姐灌的45。差在哪？"** | 中游加工过程透明化 | 一镜到底：去肉摊拍王大姐选肉→切肉→调味→灌制→扎孔→上架。每一步跟工厂做法对比。不评价。让观众自己看。结尾：王大姐说"你买哪家的都行。但看完你知道差在哪了。" |
| **"一斤香肠。肉占几两。水占几两。"** | 上游→中游的成本拆解 | 画面：一斤前腿肉上秤（650g出肉率65%→成品425g）。对面放工厂香肠（120%出肉率→一斤肉出一斤二两）。字幕："多出来的半斤，是水和淀粉。"不攻击工厂。只展示差异。 |
| **"为什么冬天灌的香肠比夏天香？不是心理作用"** | 中游晾晒/熏制环节 | 三个原因：低温风干（菌群温和发酵 vs 高温腐败）、烟熏渗透时间（冷天肉紧实、烟慢慢渗进去）、阳光角度（冬天太阳角度低、斜晒更均匀）。夏天控温冷库也可以做，但成本翻倍。落点：等一年等的不只是味道。是三个自然条件同时到位。 |
| **"买香肠别只问价格。问这三句。老板知道你是内行"** | 下游采购指南 | 第一句"肥瘦比多少"——手工3:7，工厂随便调。第二句"熏了几天"——真的三天以上，工厂喷烟熏液10分钟。第三句"猪肉是哪天的"——当天宰的出油少、肉紧。不会问的人只比价，会问的人比的是"吃进去的是什么"。 |
| **"你吃火锅点的香肠。大概率是三个月前灌的"** | 季节性+冷链 | 香肠是冬天灌的，真空冻起来全年卖。冷链快递让王大姐的香肠从菜市场半径变成全国。落点：好东西不怕冻。怕的是你不知道它冻了多久——问日期。 |

### 跟电池的对比 — 同一个框架，两种世界

| 维度 | 动力电池 | 手工灌香肠 |
|------|---------|-----------|
| 集中度 | 多环节寡头 | 全链分散 |
| 瓶颈 | 有（隔膜） | 有，但不是人——是**猪周期** |
| 毛利率差距 | 大（15%→50%，断崖明显） | 小（5%→35%，谁都不暴利） |
| 技术替代风险 | 高（钠电替锂电，路线赌错清零） | 低（香肠还是香肠，但工厂在替代手艺人） |
| **Track B 选题性质** | 结构性卡脖子——"谁能掐死谁" | 全面微利+周期性——"谁在苟着，谁能做大" |
| **Track C 选题性质** | 行业太远，普通人用不上 | 每个家庭都买香肠——天然的大众内容 |

同一个框架跑两个行业，跑出来的问题性质完全不同。电池是权力的游戏。香肠是生存的游戏。

这个对比本身就是一个 Track B 选题：「电池和灌香肠。到底哪个更难做？」

## 八、自检清单

画完链条映射表后，过一遍：

```
□ 上游/中游/下游/横向 四层都填了至少一行？
□ 每行有至少一家代表公司/玩家？
□ 有三列能看出梯度吗？（毛利率必须有断崖）
□ 瓶颈找到了吗？（不一定是某个环节，也可能是"自然瓶颈"如猪周期/政策/气候）
□ 夹心层找到了吗？（上下同时挤压）
□ 依赖陷阱至少一个？（严重依赖单一上游或下游）
□ Track B 至少三个选题？（说给行业里的人听。一个瓶颈/一个夹心/一个反直觉）
□ Track C 至少三个选题？（帮行业里的人做内容给他们的客户。一个信任/一个鉴别/一个科普）
```

两条轨各缺一条 → 回去继续挖。

## 九、跟其他分析的区别

| | 这个框架 | 波特五力 | SWOT | PESTEL |
|---|---------|---------|------|--------|
| 看什么 | 一条链上谁在干什么 | 一个行业的竞争强度 | 一家公司的优劣势 | 宏观环境 |
| 粒度 | 环节级（隔膜、电芯） | 行业级（电池行业） | 公司级（宁德时代） | 国家/区域级 |
| 产出 | 瓶颈在哪、问题在哪 | 行业值不值得进 | 公司哪里强哪里弱 | 宏观顺风还是逆风 |
| 用于内容 | ✅ 直接出选题 | ⚠️ 背景框架，难直接出钩子 | ❌ 太窄 | ❌ 太宽 |

波特五力告诉你「电池行业竞争激烈」。这个框架告诉你「隔膜环节掐着所有人的脖子」。
