# 合规规则

> 抖音广告检测规避。图文/口播全类型强制。生成内容后必须逐项检查。
> **v6.0：通用平台框架。项目专属敏感词表、免责声明句、自检清单在 `项目/<项目名>/config.md` 定义。**

---

## 通用规则（所有项目适用）

### 一、公司/品牌名密度控制

- 全篇 ≤ 项目 config 定义的上限（默认 5 次）
- 首次用全名，后续用"该公司""这家公司"
- 股票代码绝对禁止

### 二、CTA 禁止项

- 禁用：收藏、关注、点赞、转发、点击、扫码
- 禁用：任何行动指令
- 末尾放 config 定义的免责声明句

### 三、发布前自检流程

```
□ 公司全名 ≤ config 上限？
□ 无 config 敏感词表内的禁用词？
□ 无收藏/关注/点赞/转发/点击/扫码？
□ 无公司名+财务数据紧挨的句子？
□ 有 config 定义的免责声明句？
□ P1 封面无结论行（封面只制造悬念）？
□ 配文也过了以上所有检查？
□ 首评无诱导词？
```

---

## 强制规则

**每个项目必须在 `config.md` 定义自己的：**
- 敏感词替代表（禁用 → 替换）
- 全类型敏感词库
- 免责声明句
- 公司/品牌名密度上限
- CTA 限制细则

示例见 `项目/备电/config.md` 合规章节。
