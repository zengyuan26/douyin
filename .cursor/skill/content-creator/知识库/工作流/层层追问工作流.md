# 层层追问工作流

> 内容价值不是生成出来的，是追问出来的。此流程在用户选择选题之后、Step 2.1（判断内容类型）之前强制执行。

---

## 一、什么时候触发

**所有分析/判断/科普型内容强制触发。** 教程型（步骤清单/操作指南）可选触发。

触发条件：选题涉及"解释一个概念 / 分析一个事件 / 下一个判断"。

---

## 二、追问环节（Step 1.6）

### 会话格式

```
用户：抛出选题 + 第一轮真实疑问（"我看到XXX，但我不太懂YYY"）
AI：  探索性回答 + 指出可能的认知差在哪里
用户：追问（"那如果是ZZZ情况呢？"）
AI：  回答 + 引出下一层
... （循环直到用户说"我懂了"）
```

### 追问深度要求

至少到达 **机制层**，不能停在表面层。**强制要求至少一问跳到社会机制层。**

```
层级1 表面层：发生了什么
层级2 归因层：为什么发生
层级3 事实机制层：背后的制度/市场/技术机制是什么 ← 最少到这里
层级4 社会机制层：这个事件暴露了什么社会/心理/群体行为模式？ ← 必须至少一问
层级5 影响层：对谁有影响、怎么影响
层级6 行动层：受影响的现在能做什么
```

**社会机制层 vs 事实机制层的区别：**

| | 事实机制层（层级3） | 社会机制层（层级4） |
|---|---|---|
| 问什么 | 这个事件内部是怎么运转的 | 人们为什么只看到事件的这一面 |
| 方向 | 往事件里面挖 | 往事件上方跳 |
| 产出 | "讲清楚"的内容 | "讲穿了"的内容 |
| 例子 | 中联油脂把热损率从0.5%放宽到5% | 为什么"10 vs 2"传遍全网而"0.5%→5%"没人在传 |

**自检：** 如果追问链全是"这个数字是什么意思/这个流程怎么走/这个人做了什么"→ 全在事实层，必须加一问"为什么人们只看到X没看到Y"或"这件事暴露了什么群体行为规律"。

### AI 在追问环节的职责

1. **记录** — 完整记录每一轮 Q&A，这是内容骨架
2. **引导深度** — 如果用户停在表面层，主动提示"要不要往机制层挖？"
3. **补充数据** — 提供相关数据点，帮助用户理解
4. **标记认知差** — 指出"这一点大部分人不知道"的地方，这些是金矿

### 停止条件

- 用户明确说"我懂了""我明白了"
- 用户开始用自己的话解释给别人听（这是真正理解的信号）
- 如果 3 轮追问后还在表面 → 选题可能认知差不够，建议换题

## 三、不懂不发闸门（Step 1.7）

追问结束后，用户确认以下三项，缺一不可：

```
□ 我能用自己的话把这个概念讲给一个外行听吗？
□ 如果有人追问"为什么"，我能再往下讲一层吗？
□ 别人问到的具体场景/变体，我能回答吗？

三项全 ✓ → 通过闸门 → 进入 Step 2.1 生成
任一项 ✗ → 回到 Step 1.6 继续追问
```

**如果反复追问仍无法通过闸门** → 这个选题先搁置。不是每个选题都适合现在做。标记到选题池，等理解到位再做。

---

## 四、追问链 → 内容骨架

追问结束后，AI 将 Q&A 链整理为内容骨架：

### 追问链示例 → 内容结构

```
追问链：
Q: 虚拟电厂到底是什么？跟储能有什么关系？
A: 虚拟电厂是把分散的储能/光伏/负荷聚合成一个整体参与电力市场
Q: 那工厂装了储能就算虚拟电厂了吗？
A: 不算。虚拟电厂需要聚合平台，单个储能只是"待聚合的资源"
Q: 聚合平台谁来运营？电网还是第三方？
A: 售电公司、负荷聚合商都可以。电网也做，但第三方更灵活
Q: 那对工厂来说，被聚合有什么好处？
A: 多一条收入线。储能原本只有峰谷套利，被聚合后还有辅助服务收入

提取的内容骨架（口播/图文）：
P1 钩子 → "你以为装储能就是省钱。少了另一条收入线。"
P2 概念 → 虚拟电厂=把分散的资源聚合成一个整体
P3 关键 → 单个储能≠虚拟电厂，缺的是"聚合平台"
P4 玩家 → 谁在干聚合？售电公司 vs 电网
P5 落地 → 工厂储能被聚合后，多一条辅助服务收入
P6 CTA → "查你所在省需求响应招募"
```

**提取规则：**
- 每一轮追问 ≈ 一个内容段落
- 追问链中的"反常识点" = 钩子候选
- 追问链中的"关键区分" = 核心论点
- 追问链中的"落地场景" = 收尾CTA

## 五、跟小周出镜的整合

二人出镜时，追问链直接转化为对话：

```
你的追问 → 你的台词
小周的问题 → 追问链中"观众可能问的问题"
```

**小周的台词来源：**
1. 你在追问环节中自己问过的问题（最自然）
2. AI 标注的"大部分人不知道/会误解的地方"
3. 评论区高频问题（过往内容的评论数据）

小周不需要表演。他的问题是你真实问过的→他问出来的语气就是真实的。

---

## 六、跟 Step 2.4 独家价值的衔接

层层追问天然产生独家素材。追问中你自己想通的东西、你自己困惑然后搞明白的过程——AI 搜不到。

追问结束后，对照 Step 2.4 四层独家价值：
- L1 一手对话/个人经历 → 追问中你脑子里的思考过程就是 L1
- L2 判断框架/工具 → 追问链本身就是判断框架
- L3 跨领域类比 → 追问中自然会联想到
- L4 行动清单 → 追问落到"能做什么"就是 L4

**如果追问后填不满 7.5 三问 → 追问不够深，继续。**
