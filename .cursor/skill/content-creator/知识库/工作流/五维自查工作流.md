# 五维自查工作流

> 触发词："五维自查"。内容定稿后执行。逐维诊断，标状态 + 缺什么 + 怎么补。
> 每次自查必须覆盖全部五个维度，不允许跳过。

---

## 五个维度

### 1. 情绪弧线

**定义**：观众从头到尾的情绪变化曲线。不能全程匀速，必须有起伏。

**检测方法**：
- 逐段标注观众此刻的感受（好奇/恍然/共鸣/温暖/不适/扎心/释然/被理解/确信/带走）
- 检查有没有"谷底"——观众感到不适、自我审视的那一刻
- 如果全程正向（共鸣→共鸣→共鸣），标记为"平"，需要加谷底

**常见问题**：
- 全程正向，没有低谷 → 在中间靠后位置插入一个"你也这么干过"的不适时刻
- 谷底太浅，一闪就过 → 多停留一句，让观众真的不舒服
- 谷底之后没有出路 → 接一个被理解的时刻（个人故事/共情），然后给工具

**标准弧线**：
```
好奇 → 恍然 → 共鸣 → [谷底：不适/自我审视] → 被理解 → 带走
```

---

### 2. 共鸣选题

**定义**：观众能不能在内容里看到自己。不是"他讲得对"，是"他讲的是我"。

**检测方法**：
- 前 30 秒有没有让观众对号入座的句子？
- 每个案例/场景，观众看到时的第一反应是"别人家的事"还是"这就是我"？
- 有没有一个场景深挖到让观众觉得被看见了？

**常见问题**：
- 前 30 秒无认可 → 开场故事是别人的事，观众旁观 → 加一句"你肯定经历过"
- 案例广但浅，每个只跑一笔 → 挑一个案例停下来多写一句："你是不是也…你当时以为…"
- 全篇没有一句"你"开头的话 → 逐段检查，至少每两段出现一次"你"

**标准配置**：
```
前30秒：1次认可（"你经历过"）
中间段：每个案例至少1次"你是不是也..." 
收尾前：1次深挖认可（"你可能已经开始不舒服了，因为你意识到..."）
```

---

### 3. 认可句

**定义**：观众听到会点头、会说"对""就是这样""我也经历过"的句子。是共鸣的载体。

**检测方法**：
- 扫描全文，标出所有能让观众"点头"的句子
- 检查密度：每 200 字至少 1 句？
- 检查分布：集中在中后段？前 30 秒有没有？

**四类认可句**：
| 类型 | 示例 | 触发机制 |
|------|------|----------|
| 经历认可 | "你肯定经历过。你定过一个规则想让事情变好，结果反而更差了。" | 唤起记忆 |
| 行为认可 | "你是不是也定过这样的指标？你当时以为自己在优化效率。" | 对号入座 |
| 情绪认可 | "你可能已经开始不舒服了。" | 命名感受 |
| 自我认知认可 | "当时我以为是我懒。现在回头看——" | 替他说出心里话 |

**常见问题**：
- 后置：认可句全在中后段 → 前 30 秒加一句经历认可
- 太概括："每个人都经历过"不如"你定过一个规则想让事情变好"
- 缺情绪认可 → 观众有感受但没人帮他说出来

---

### 4. 槽点

**定义**：故意设计出来让观众想评论的位置。位置 × 门槛 × 争议性三维度。每篇 ≥ 2 个。

**安全争议区原则**：争议方法论，不争议价值观。

**三种槽点类型**：

| 类型 | 格式 | 门槛 | 示例 |
|------|------|------|------|
| 填空式 | 开放式问题，让观众讲故事 | 最低 | "你们公司用哪个指标把人玩坏的？" |
| 站队式 | 二选一，扣1扣2 | 低 | "给过孩子奖励的，扣个1。没给过的扣2。" |
| 争议式 | 抛出一个可辩论的判断 | 中 | "KPI 是管理者懒惰的产物。你同意吗？" |

**检测方法**：
- 全文有没有故意留出的"评论入口"？
- 每个槽点的门槛够不够低？（门槛太高 = 没人评论）
- 争议式槽点有没有踩价值观线？

**常见问题**：
- 0 个 → 必须加。填空式 1 个 + 站队式 1 个打底
- 只有争议式没有填空式 → 门槛太高，补一个低门槛的
- 槽点位置太近 → 分散在不同的内容段落后

**标准配置**：至少 1 个填空式（低门槛）+ 1 个站队式或争议式。

---

### 5. 转发金句

**定义**：观众愿意截图、复制、发朋友圈、写在评论区的一句话。独立于上下文仍然有力。

**检测方法**：
- 全文有没有一句话，单独拿出来仍然成立？
- 这句话在全文最后三句之内吗？（不在 → 被埋了）
- 念一遍。够短吗？（超过 20 字 → 太长，截图放不下）

**金句公式**：
| 公式 | 示例 |
|------|------|
| 不要用 X，杀死 Y | "不要用价格，杀死一个人的'我应该'。" |
| 不是 X。是 Y | "不是我的道德有问题。是数学替我做了选择。" |
| X 可以 Y。但 Z。 | "价格标签可以杀死内疚。" |
| 最 X 的不是 Y，是 Z | "最危险的激励不是设计错了。是加在了一件本来不需要激励的事上。" |

**常见问题**：
- 有但被埋 → 被前面的例子/论证压住了 → 提到全文最后一句或倒数第二句
- 太长 → 砍到 20 字以内
- 像标题不像金句 → 标题是钩子，金句是结论。金句要让你想截图，标题要让你想点开
- 没有独立的画面感 → 金句必须能在纯色背景上单独存在

**标准位置**：全文最后一句。或倒数第二句，最后一句做收束。

## 执行模板

每次收到"五维自查"，按以下格式输出：

```
### 五维自查

| 维度 | 状态 | 缺什么 |
|------|------|--------|
| 情绪弧线 | ✅/⚠️/❌ | [一句话] |
| 共鸣选题 | ✅/⚠️/❌ | [一句话] |
| 认可句 | ✅/⚠️/❌ | [一句话] |
| 槽点 | ✅/⚠️/❌ | [一句话] |
| 转发金句 | ✅/⚠️/❌ | [一句话] |

[各维度详细诊断，每条≤3行]
```

**状态标记**：
- ✅ 合格，不需要改
- ⚠️ 有但不够，需要补强
- ❌ 空缺，必须加

---

## 注意

- 五维自查是**诊断工具**，不是写作指南。先写完内容，再跑自查。
- 如果五个维度都 ✅，不用为了改而改。
- 朱莉娅风格内容：槽点替换为诊断工具，认可句替换为学术权威，其他维度不变。
