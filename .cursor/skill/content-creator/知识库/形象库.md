# 形象库

> 仿 zimeiti-creator 形象管理系统。每个形象定义服装/体型/姿势，即梦分身出镜时锁定服装一致性。AI 可协助生成新形象。

---

## 使用方式

1. 分镜预设时 → 用户选择哪些形象出镜（可多选）
2. 脚本中写入形象锁定 → 复制对应条目的"即梦 prompt 分身描述"
3. 即梦使用"分身出镜"功能 → 面部一致性由分身系统保证，此处只锁服装
4. 新形象 → AI 按模板生成，入库

## AI 生成新形象

仿 zimeiti-creator 形象 AI 生成功能。用户给形象名称 + 风格方向（可选），AI 输出：

```
请为"_____"形象生成外观细节。风格方向：_____。
输出纯JSON：
{
  "name": "形象名称",
  "clothing": "服装描述（具体到款式、颜色、面料，不描述面部/发型/眼镜——这些由即梦分身系统管理）",
  "build": "体型身高",
  "pose": "出镜姿态和范围",
  "expression": "表情基调",
  "suitableFor": "适用内容类型"
}
```

生成后按上述模板入库。
