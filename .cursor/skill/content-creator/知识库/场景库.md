# 场景库

> 仿 zimeiti-creator 场景管理系统。每个场景定义环境/氛围/光影，即梦 prompt 直接引用。AI 可协助生成新场景。

---

## 使用方式

1. 判断内容情绪 → 匹配默认场景
2. 脚本中写入场景锁定（复制对应条目的"即梦 prompt 场景描述"）
3. 用户想换 → 说一声，从库重选
4. 新场景 → AI 按模板生成，入库

## 场景列表

### 场景 1：深夜书房

| 维度 | 内容 |
|------|------|
| 场景名 | 深夜书房 |
| 环境 | 深灰色墙面，右侧木质书架虚化。画面简洁无装饰物 |
| 氛围 | 安静·专注·深夜独自思考 |
| 光影 | 单束暖色主光从右上方45°打脸，辅光微弱补左侧阴影。背景自然暗下去，不做额外补光 |
| 适用内容 | 硬核拆解、观点输出、行业分析、避坑警示 |
| 情绪匹配 | 严肃、冷静、犀利 |

**即梦 prompt 场景描述（直接复制）：**

```
场景：深灰色墙面背景，右侧木质书架虚化。单束暖光从右上方45°照到人物面部，背景自然暗下去。安静专注氛围。
```

### 场景 6：茶台对谈

| 维度 | 内容 |
|------|------|
| 场景名 | 茶台对谈 |
| 环境 | 木质茶台，两人对坐。白瓷茶具（茶壶+两个茶杯）居中。背景简洁，可有绿植或木质格栅虚化 |
| 氛围 | 轻松·对谈·朋友间聊天。像两个朋友喝茶聊正事 |
| 光影 | 暖色顶灯+柔和的侧补光。面部均匀明亮，茶具表面有温润反光。无明显戏剧性阴影 |
| 适用内容 | 一问一答、概念拆解、对话类内容 |
| 情绪匹配 | 轻松、亲近、好奇心 |

**即梦 prompt 场景描述（直接复制）：**

```
场景：木质茶台，两人对坐。白瓷茶具居中，茶壶冒着热气。暖色顶灯+柔和侧光，面部均匀明亮。背景简洁，绿植或木质格栅虚化。轻松对谈氛围，像两个朋友喝茶聊正事。
```

## AI 生成新场景

仿 zimeiti-creator 场景 AI 生成功能。用户给场景名 + 参考图（可选），AI 输出：

```
请为"_____"场景生成拍摄环境描述。输出纯JSON：
{
  "environment": "环境描述（1-2句话，空间特征+关键物品）",
  "atmosphere": "氛围（2-4字+感受）",
  "lighting": "光影特点（光源类型+方向+效果）",
  "suitableFor": "适用内容类型",
  "promptText": "即梦 prompt 场景描述（一句话，可直接复制）"
}
```

生成后按上述模板入库。
