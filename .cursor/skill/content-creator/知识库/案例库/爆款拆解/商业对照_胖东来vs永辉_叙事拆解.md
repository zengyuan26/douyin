## 文章骨架

```
L1 [起跑线+反常识钩子]
    永辉学胖东来21个月，亏损21亿，连续五年亏超116亿。
    胖东来13家店、零负债、坪效全国第一。抄作业为什么越抄越穷？

L2 [面子vs里子]
    永辉：货架降到1.6米、休息区、试吃台、商品结构与胖东来九成相似。首日销售暴增14倍。
    胖东来：95%利润分员工、保洁月薪9000、年休145天、离职率0.33%。
    差距：学了装修和试吃，没学到"先对员工好"。

L3 [员工待遇]
    永辉：最低工资涨到5600，但实际到手变化不大、工作量翻倍、加班常态、严苛考核扣钱。
    胖东来：店长月薪7.8万、基层9886（当地3.9倍）、损耗率0.3%（行业1/8）。
    差距：员工带着生计焦虑工作，再好的装修也传递不出真诚服务。

L4 [供应链]
    永辉：第三方物流+中间商，损耗率8%-10%。全国30多省市，无法区域集约。
    胖东来：自建冷链+直采基地，损耗≤3%。"四方联采"压缩采购成本30%-50%。
    差距：供应链效率决定了价格和品质的下限。

L5 [战略定力]
    永辉：5年追3个风口全踩空（mini店/到家/仓储会员）。超九成门店租赁，租金压顶。
    胖东来：30年只做许昌新乡，拒绝上市、不追风口、大量自有物业。
    差距：一个做减法做到极致，一个做加法做到崩溃。

L6 [信任经济]
    永辉：未打破"压价赚通道费"的传统盈利模式。顾客新鲜感过后流失。
    胖东来：公开进货价和毛利率（服装标签写"赚2.5元"），95%复购率，5%净利率（行业3倍）。
    差距：信任是最便宜的获客成本，也是最难抄的东西。

L7 [收束]
    "表面做法好抄，骨子里的东西难学。" "学我者生，似我者死。"
    不是抄错了，是试图用"表面改良"解决"系统性衰败"。
```

## 对照手法拆解

### 1. 反常识钩子 + 对照型叠加（本篇独有手法）

普通对照型：A赢了B输了，对比差距。本篇多了一层——**B在抄A的作业，抄了21个月，反而亏了21亿。** "抄作业"是观众默认有效的行为（"学最好的那个总没错吧"），结果是越抄越穷。这个反常识直接把对照的张力拉满——不是A vs B的静态对比，是"B追着A跑但越跑越远"的动态讽刺。

### 2. 六层对照的递进逻辑

对照型的层级顺序不是随便排的。本篇从最表面到最底层：

```
面子（装修/货架）→ 员工（待遇/忠诚）→ 供应链（效率/成本）→
战略（定力/扩张）→ 信任（透明/复购）→ 系统（不可复制的生态）
```

观众跟着从"这不难学啊"走到"这根本学不了"。层级递进本身就是论证——越往下挖，差距越不是"做法"层面的，而是"信仰"层面的。

### 3. 数据并置的密度

本篇数据密度比韩束篇更高——对照型天然需要数字支撑，但本篇在每一层都放了双方的直接对比数字：

- 永辉亏损21.4亿 vs 胖东来营收180亿
- 永辉损耗8%-10% vs 胖东来≤3%
- 永辉资产负债88.96% vs 胖东来零负债
- 永辉离职率高 vs 胖东来离职率0.33%
- 永辉坪效6万/㎡ vs 胖东来15万/㎡

每一组数字放一起，不需要任何形容词。这是对照型最强的武器——数字并置 = 无声的结论。

### 4. 于东来的原话收束

"表面做法好抄，骨子里的东西难学"——这是胖东来创始人自己的话。用对照对象之一的原话做全文收束，比作者自己总结更有力。观众读到最后感受到的不是"作者说胖东来牛"，而是"胖东来自己知道别人抄不了"。

## 对照型写作铁律（两篇共同提炼）

1. **起跑线必须对齐。** 先证明A和B站在同一起点，差距才是选择造成的。
2. **每层不换维度。** 同一层里对比的东西必须是可以直接对照的，不能A讲产品B讲管理。
3. **数字并置代替形容词。** "A的损耗3%，B的损耗10%"——不需要说"差距巨大"，数字自己在喊。
4. **层级递进有方向。** 要么从表到根（永辉篇），要么从外到内（韩束篇）。不能随机跳。
5. **收束不重复前文。** 结尾不是"综上所述"，是一句新的、更深的、可以脱离全文传播的判断。

## 适用场景

- 同行业两个天然对照物的深度分析，尤其适合"一个成功一个失败"的反差选题
- 需要数据密度支撑的长文/报告体
- 反常识钩子叠加——不只是"A赢了B输了"，而是"B在学A，越学越糟"
- 可迁移到口播：压缩为3-4层对照，保留"从表到根"的递进方向，每层用一对数字并置
