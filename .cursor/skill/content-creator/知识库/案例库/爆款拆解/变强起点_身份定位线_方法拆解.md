# 变强起点 · 身份定位线 · 完整方法拆解

> 账号：抖音「变强起点」（潘哥）
> 形式：9:16竖屏，混剪视频+配音，无真人出镜
> 风格：身份定位驱动。场景代入→逐层归位→算账时刻→评论区归位
> 代表作品：赚大钱的5件事（#39）、60天商人视角（#40）、闲鱼暗网（#41）、小钱开路（#42）、不害怕任何人（#43）

---

## 一、账号定位

不打认知幻觉（"你想错了"）——打身份焦虑（"你在这一层"）。每一段让观众做一次自我归位。归完发现自己站在低层，焦虑驱动往上走。

信任来源不是外部权威引用——是第一人称在场经验。"我在深圳/抖音干了这么多年，见过太多人"。

---

## 二、结构模板（两种变体）

### 清单体

```
场景钩子 → 定义重命名 → N条逐层展开（N=5最佳） → 算账时刻 → 评论区归位
```

适用：话题有5层递进逻辑。观众跟着往上爬。

### 案例体

```
场景钩子 → 定义重命名 → 案例1 → 案例2 → 案例3 → 原理提炼 → 怎么做 → 算账时刻 → 评论区归位
```

适用：话题是"一个领域里你不知道的秘密"——用具体案例让观众"看见"。

---

## 三、核心手法矩阵

### 手法1 · 定位句 "你在X，他在Y"

全篇最高频句式。每篇≥10次。不是教你怎么做——是让你先看见自己站在哪。

```
"你在用时间换钱，他在用系统放大结果"
"你在卖货，他在卖情绪"
"你在讲道理，他在造氛围"
"你拿的是确定性收入，他拿的是系统性利润"
"你在表达自我，他在设计流量路径"
"你在创作，他在计算转化"
"你以为这叫认真，这叫头铁"
```

每读一句，观众在心里把自己归到一边。制造焦虑→制造"我要到Y那边"的动机。

**公式：** 你在 [具体低维动作] ，他在 [同场景高维动作]。不用"而"——用逗号。

### 手法2 · 定义权 "这不叫X，这叫Y"

每条展开后的收尾。给老词一个新名字。定义本身就是截图金句。

```
"这不叫生意，这叫出卖劳动力"
"这不叫行贿，这叫人情润滑剂"
"这不叫圆滑，这是智慧"
"值钱是别人愿意开价，有钱是你拥有规则和分配权"
"运气就是踩对了算法、抓对了痛点"
"信息本身不值钱，你对信息做出的判断才值钱"
```

**公式：** 这不叫 [社会污名化词] ，这叫 [新定义词]。观众看了说"哦——"。

### 手法3 · 在场锚点 "我见过太多人"

权威不靠引用。靠在场的样本量。

```
"我在深圳干了这么多年，见过太多人技术牛逼——最后活成了高级打工仔"
"我在抖音干了这么多年，见过太多人产品不错服务也行，就是卖不动"
"我自己做了7年抖音，见过太多人想做副业但总觉得自己没资源"
```

**公式：** 我在 [具体地点/领域] 干了 [具体年数] ，见过太多人 [具体画像] ——最后 [具体代价]。

### 手法4 · 算账体

把抽象认知翻译成具体数字。

```
"你省了这15块，搭进去的是一整天 + 来回车费 + 重新打印 + 憋着的气"
"你现在不做，一年后还是现在的你"
```

**公式：** 你省了 [具体金额] ，搭进去的是 [列举具体代价]。不用讲道理——替观众算一遍。

### 手法5 · 场景代入

每一段开头，先用"你"拽进具体画面。

```
"你去窗口办审批，材料被退回——"
"你逛超市看到一瓶饮料，只会想贵不贵——"
"你刚进公司，想跟老员工学东西，干等着——"
"你刷到别人月入5万，第一反应是运气好——"
```

## 四、选题公式

```
[普通人] + [一个隐藏劣势] + [反常识低成本解法]
```

| 篇 | 普通人 | 隐藏劣势 | 低成本解法 |

## 五、钩子公式

```
[反常识判断] + [不是X，是Y]
```

| 篇 | 钩子 |
|------|------|
| 5件事 | "真正赚大钱的人，靠的不是手艺不是知识——靠这5件事" |
| 60天 | "你不懂商业不是笨——是没人教过你用商人的眼睛看世界" |
| 闲鱼 | "闲鱼不是二手平台——是中国暗网的另一张面孔" |
| 小钱开路 | "穷人家孩子最大的死穴不是没钱——是太爱省了" |
| 不害怕 | "你害怕的不是别人——是你自己脑子里演的一场戏" |

**公式内核：** 推翻一个默认假设。观众进门以为是A，第一句话告诉他是B。

## 六、评论区设计

不是争论型提问——是**归位型**引导。让观众自我定位+讲故事。

| 篇 | 评论区引导 |
|------|------|
| 5件事 | 隐含归位——"你现在在哪一层？" |
| 60天 | "从今天的第一件事开始——你下次消费问自己：成本多少，谁赚了钱？" |
| 闲鱼 | "如果你脑子里已经有了一个方向，打到评论区，我们一起来看看值不值得做" |
| 小钱开路 | "你有没有因为死要面子把自己坑了的经历？评论区聊聊" |
| 不害怕 | "你打算从哪件让你害怕的事开始突破？" |

**公式：** 你有没有因为 [隐藏劣势] 而 [具体代价] 的经历？

## 九、与 Track A 的互补关系

| | Track A | Track C |
|------|------|------|
| 什么时候用 | 需要观众换一个角度看世界 | 需要观众看见自己站在哪一层 |
| 信任 | 跨域连接——越不相干越有说服力 | 在场经验——越具体越有说服力 |
| 天花板 | 顶层受众觉得"深刻" | 顶层受众觉得"他在说我" |
| 地板 | 需要观众有思考习惯 | 门槛极低——谁都能对号入座 |
| 创作成本 | 高——需要跨领域知识储备 | 中——需要真实的在场经验 |
| 人设风险 | — | 在场经验必须真实——假的一眼穿 |

**不融合。** 两条轨道独立创作。但 Track A 的每段弹药可以用 Track C 的定位句收尾（幂律分布验证了这一点）。
