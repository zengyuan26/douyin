## 账号画像

- 定位：科技/半导体投研
- 形式：PPT画面 + 少量视频素材混剪，无人出镜
- 画幅：16:9 横屏（非抖音主流9:16，偏B站/西瓜）
- 语调：客观理性，数据密度高，不煽动

---

## 内容结构

```
Hook（挑战主流认知）
  → 12种材料逐一拆解（统一模板）
    → CTA互动收尾
```

### Hook 拆解

"真正卡住中国科技命脉的，是这12种看不见的材料，别再只盯着光刻机"

- **反常识锚**：「光刻机」是大众已知→「材料」才是关键→制造认知落差
- **数字锚**：12种→给观众明确的预期，暗示「这篇很全，值得看完」
- **价值锚**：千亿市场空间+国产替代→利益相关，不是纯科普

### 单项信息模板（每项严格一致）

```
[序号] [材料名] → [一句话定义] → [紧缺程度/缺口] → [核心企业×3]
```

每项4-5句，信息密度极高，无废话。企业名只列不评（合规安全）。

### 收尾 CTA

"你觉得这12种材料里，哪一类最有可能率先实现全面国产突破？欢迎在评论区留下你的看法"

- 开放式问题，降低评论门槛
- 暗示「你也能参与判断」，不是单向输出

## 手法提炼

| 维度 | 做法 | 可复用点 |
|------|------|---------|
| **Hook** | 挑战主流认知（"别再只盯着X"） | 备电可用："别再只盯着光伏组件。真正的瓶颈在____" |
| **结构** | 统一信息模板循环12次 | 循环制造节奏，观众预期明确，完播率高 |
| **密度** | 每项4-5句，无过渡无废话 | 信息量本身即吸引力。不需要故事线 |
| **合规** | "仅为行业分析不构成投资建议"一句带过 | 轻合规，不破坏节奏 |
| **CTA** | 开放式选择题 | 比"你怎么看"更具体，评论门槛更低 |
| **素材** | PPT为主+少量视频 | 生产成本低，适合高频更新 |
| **画幅** | 16:9横屏 | 投研类横屏信息容量更大，表格/图表友好 |

## 对备电的迁移可能

1. **储能技术路线清单体**："别再只盯着锂电池。这8种储能技术，正在悄悄改写格局"
2. **售电政策清单体**："2026年电力市场。这5个省的政策，藏着最大的差价机会"
3. **工厂储能方案清单体**："工厂上储能。这6种方案，回本周期差3倍"

核心逻辑：**把行业知识压缩成可滑动的清单，降低消费门槛，提高完播率**。

---

## 注意事项

- 投研账号可以做「12种」，因为半导体材料天然有细分品类。备电选题要确保能拆出 ≥6 项，否则撑不起清单体节奏
- 企业名只列不评，避免合规风险
- 适合作「泛人群扩圈」内容，深度不如A型图文但传播效率更高
