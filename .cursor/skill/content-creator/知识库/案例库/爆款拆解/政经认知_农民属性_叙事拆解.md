## 完整文案

大多数的中国人，包括我自己，都是穿着西装的农民，还活在种地系统里，守着自己的农民属性。

所以尤瓦尔·赫拉利在《人类简史》中说——"大多数人终其一生只是在复制祖先的生活。"

什么是农民属性？把风险交给天命，不相信系统，只相信经验。把勤劳当作信仰，不理解杠杆，更排斥非线性增长。把能摸到的才算安全，执着于土地、房产和现金。把人情当规则，眼里没有契约，心里没有长期结构。

福山在《政治秩序的起源》中写道——"一个民族真正的制度不在于写在纸上的宪法，而在写进每个人脑子里的心理结构。"

为什么中国人很难剥离农民属性？因为我们的文明是财政制度驯化下的结果。

托克维尔说——"人民的性格来自他被征税的方式。"

郭建龙在《财政密码》中指出，在明清时代，国家财政的主要来源并不是富人官僚，而是底层商人。一个商人可能要缴纳十成利润中的七到九成作为税收和摊派。普通农户却享有粮食自留权，负担相对可控。这就是中国历史上的抑商财政。

明朝规定重农抑商，商人要额外承担差役、摊派。清代养兵靠盐税、关税，商人被当做提款机。在长期亏损的状态下，商人越富越危险——或者抄家征税，或者被摊派——而土地越多越安全，朝代更替都不轻易动耕地。

这导致一个深远的后果：商人无法代代成为精英，商业无法形成阶层，财商无法系统传承。"富不过三代"并不是迷信，而是制度使然。在这种制度下，做生意也就只是谋生。

所以我们就形成了一个千年一贯的认知模型——敬祖宗不信契约，信人情不信规则，信积攒不信配置，信稳定不信波动。这不是个人问题，是制度刻进了民族基因的心理结构。

结果是什么呢？商人是政府财政的汲取对象，是可宰可割的肥羊。这是一种税制驯化——你无法通过市场成功，而只能通过回避风险来扛下去。久而久之，一个社会便失去了商人阶层的系统性冒险精神。

---

为什么西方能够完成从农民到商人的文明跃迁？根源在于西方的税制从中世纪开始就与资产性收益深度绑定。

亚当·斯密在《国富论》中有句话——"法律不是为了限制商业，而是让商业得以代代延续。"

1215年英国的《大宪章》第一次约束国王——未经贵族与商人同意不得加税。这是后来的议会制度与资产保护机制的开端。

17世纪的荷兰，商会参与立法，税收来源于股份利润，风险有制度兜底。这才诞生了现代金融中心、东印度公司以及后来的罗斯柴尔德家族。犹太商人不种地，却通过金融、保险、航运搭建了横跨欧洲的金融网络，甚至反哺国家战争财政，最后拥有政治权利。

对比之下，当时的中国商人靠交保护费求苟活，西方的商人则买国家的股权换自由。这才有了商业文明的两条路径——中国重农抑商，税于商，轻产权，社会形成短线思维；西方重商保产，税于利，重契约，社会形成长期博弈。

山西的太谷票号一度风靡全国，拥有完整的金融转账系统和审计制度。它的崩塌不是因为管理不善，而是清末改朝换制——洋银加税、征兵战乱，国家每一次财政的赤字都直接传导到了票号头上。票号不败于市场，却败于不可预期的国家财政对商人的收割。

而英国1720年南海公司泡沫破灭后，政府迅速修订《股份公司法》，并明确设立有限责任与公共金融监督。这一制度让商人敢于再投资、敢于跨代、敢于融资，不用担心破产即灭门。

结果——英美企业一代一代做系统，中国商人一代一代扛风险。

中国徽商鼎盛时期控制了全国的盐业、茶叶、典当业，但他们依然买田建祠堂，不肯建工厂搞研发。因为他们知道——生意可以做，但不能做大。做大就要被摊派、被连坐。所以徽商是富而不强——只把商业当成求财手段，不当社会结构工程。

---

今天的我们还活在这个种地逻辑中。不是不努力，是你努力的方向仍然是种地模式。

房子是一辈子的土地信仰。储蓄是你对来年收成不稳的焦虑。创业失败一次就退场，是你无法承受风险内化的心智。

农民属性的人看见的永远是收成，商业属性的人设计的是系统本身。

郭建龙说——"国家的财政制度决定了人民的性格结构。"

查理·芒格说——"你告诉我激励机制，我就能预测你的行为。"

如果你还在用农民的思维做商人，永远只能守着那块土地，被动等待天命。唯有拥抱风险，突破束缚，重塑思维，你才可能打破命运的枷锁，成为真正掌握未来的商业主体。跳出种地思维的桎梏，你才能成为真正意义上的第一代创业者。

## 叙事手法拆解

### 1. 开场：身份炸弹 + 自我包含

"大多数的中国人，包括我自己，都是穿着西装的农民。"

**"包括我自己"是这句话最关键的部分。** 如果只说"大多数中国人是农民"，观众会防备——"你凭什么说我？""你自以为自己不是吗？"但加上"包括我自己"，说话人先站进了被批评的阵营。你不是在被一个人居高临下地批评，你是在听一个跟你同病的人分析病因。

**"穿着西装的农民"** ——六个字，一个完整的人格画像。西装=现代外表，农民=底层操作系统。观众听到这六个字，已经在脑子里看见了自己。

### 2. 定义式枚举（四种农民属性）

"把风险交给天命，不相信系统，只相信经验。把勤劳当作信仰，不理解杠杆。把能摸到的才算安全，执着于土地、房产和现金。把人情当规则，眼里没有契约。"

**四种属性的对仗结构：** 每种属性都是"把X当Y"的句式——天命/勤劳/实物/人情。四种属性的递进关系：
- 风险交给天命（面对未知的态度）→ 
- 勤劳当信仰（面对努力的态度）→ 
- 实物才安全（面对资产的态度）→ 
- 人情当规则（面对关系的态度）

从天到地，从外到内，四个方面覆盖了人类行为的全部领域。

### 3. 税制归因（全篇的知识核心）

这是全篇最根本的论点——**"我们的文明是财政制度驯化下的结果。"**

不是讲心理学，不是讲文化传统，不是讲国民性格——是讲税制。这个归因方式非常"投行人"——把所有人都归因到文化/心态的时候，投行人归因到制度设计。这是朱莉亚跟深度进化Theo的核心差异——Theo归因到个体心理（确定性需求、大脑机制），朱莉亚归因到制度结构（税制、财政汲取方式）。

**引用链：** 托克维尔（"人民的性格来自被征税的方式"）→ 郭建龙（明清商税70%-90%）→ 制度结论（富不过三代不是迷信，是制度使然）。每一环都是学者原话+一手数据。

### 4. 东西对照（同时代双线叙事）

| 维度 | 中国 | 西方 |
|------|------|------|
| 税收对象 | 商人（70%-90%利润被抽） | 与资产性收益绑定 |
| 制度开端 | 重农抑商 | 大宪章1215（国王不得擅自加税） |
| 商人地位 | 可宰可割的肥羊 | 买国家股权换自由 |
| 金融案例 | 太谷票号（败于财政收割） | 南海泡沫→股份公司法（败了反而保护更强） |
| 商人行为 | 买田建祠堂（徽商富而不强） | 建工厂搞研发（英美企业做系统） |
| 代际结果 | 一代一代扛风险 | 一代一代做系统 |

**太谷票号 vs 南海泡沫的对比尤其精妙：** 两个案例都是金融系统崩溃。但中国的是"票号没做错什么，被外部收割了"——英国的是"泡沫破了，政府修法让以后不再破"。同一个事件（金融失败），不同的制度响应，导致了完全不同的商业文明路径。

### 5. 学术三角引证 + 现代权威落地

全篇引用了7位学者/思想家：

| 引用 | 功能 |
|------|------|
| 尤瓦尔·赫拉利 | 开场——"复制祖先生活"建立人类学框架 |
| 福山 | 过渡——"写在脑子里的心理结构"从行为转到深层原因 |
| 托克维尔 | 发动机——"性格来自被征税的方式"开启制度归因 |
| 郭建龙 | 数据——明清商税70%-90%，财政密码的具体内容 |
| 亚当·斯密 | 东西对照——"法律让商业代代延续" |
| 郭建龙（第二次） | 收束——"财政制度决定性格结构" |
| 查理·芒格 | 落地——"告诉我激励机制，我就能预测行为" |

**七个人从人类学到政治学到历史学到经济学到投资学，各自从自己的角度说了同一句话：制度决定了人的行为模式。** 这是朱莉亚标志性的跨学科围剿式论证。

### 6. 三阶段叙事弧线

```
过去：千年税制驯化 → 农民属性形成
现在：穿着西装的农民 → 种地模式的现代形态
未来：跳出种地思维 → 成为第一代创业者
```

**收尾的"第一代创业者"是精心选择的词：** 不是"成功人士"，不是"富人"，是"第一代"。呼应了全篇的核心论点——因为前几代人受制于制度没有完成从农民到商人的跃迁，所以你现在要做的是"第一代"。

### 7. 收尾：从根源分析到行动宣言

"如果你还在用农民的思维做商人，永远只能守着那块土地，被动等待天命。"——回到开场的"把风险交给天命"。

收尾不是"所以你要改变"，而是点出具体的跃迁方向——"跳出种地思维的桎梏，你才能成为真正意义上的第一代创业者"。给观众的不仅是认知，是一个新的身份标签——"第一代创业者"。

## 适用场景

- 政经/历史/社会类深度思辨选题
- 需要解释"为什么我们是这个样子"的根源性话题
- 投行/金融人设的差异化表达——把一切归因到制度设计而非个人品德
- 东西方比较类选题的标准骨架：同时代案例对照→不同制度响应→不同文明路径
