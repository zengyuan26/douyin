### 一二三周爸爸（金融/认知/科普）

- 账号：抖音「一二三周爸爸」
- 形式：9:16竖屏，真人出镜。会议桌前对双胞胎儿子（1岁，不会说话）提问引入→白板讲解→结尾回到孩子面前问"懂了没/听到了没"
- 风格：平行世界叙事法 + 隐喻翻译法。用具体人物/故事让观众自己推导，不讲课不定义
- 代表作品：做空（#3）、巴萨效应（#4）、汽油标号（#5）、化学键（#6）

**叙事手法谱系：**

| 手法 | 代表篇 | 核心 |
|------|--------|------|
| 平行世界叙事 | 做空、巴萨效应 | 直接在目标领域建角色，观众自己在故事里推导 |
| 隐喻翻译法·纯翻译型 | 汽油标号 | 先在类比世界建完整故事，再逐词翻译回真实世界 |
| 隐喻翻译法·拟人世界观型 | 化学键 | 构建有社会规则的微型世界，用社交动机替代物理/化学动机 |

**差异化设计：不可能听众机制**

对1岁双胞胎讲金融/经济/化学——孩子根本听不懂也不会说话。这不是 bug，是刻意设计的 engagement 引擎：

```
孩子听不懂 → 弹幕刷"过分了！孩子一脸懵" → 冲突产生 → 互动飙升
```

三层效果：

| 层 | 效果 |
|----|------|
| 弹幕驱动 | 观众忍不住要替孩子"喊冤"，弹幕活跃度天然高 → 算法加权 |
| 记忆锚点 | "那个对着婴儿讲做空的博主"——一句话就能让人记住，比任何内容标签都强 |
| 观众代入 | 孩子=听不懂的观众自己。博主对孩子的耐心讲解，就是观众希望被对待的方式 |

**对备电的启发：** 不一定要用婴儿。核心公式是「严肃内容 × 不匹配的听众 × 坚持讲完」。备电可以探索「对工厂老板的猫讲储能」「对着设备讲给路过的大爷听」等变体。

- 对备电的参考价值：抽象概念用故事讲，不讲课不定义，让观众自己算出来。不可能听众机制可迁移

### 小德momo（经济/社会/认知）

- 账号：抖音「小德momo」
- 形象：20出头女孩，偶尔真人出镜。主体内容是虚拟形象在动物之森风格小岛上讲述，角色都是岛民
- 形式：9:16竖屏，虚拟形象出镜 + 动物之森游戏画面。架空世界叙事——核战后小岛，岛民角色演绎概念
- 风格：经济/社会概念的故事化讲解。双主角对比骨架+四声部交替（场景描写/角色对话/内心独白/主播点评）+名字即讽刺
- 标志手法：生活观察钩子→"用一个故事讲清楚"→架空世界建角色→具体数字让观众自己算→落回现实→系列钩子收尾
- 代表作品：GDP分配（#10）、方向大于努力（#11）、长期持有的前提（#12）、什么样的人值得投资（#13）
- 叙事双模式：
  - **架空故事型**（GDP分配/长期持有）：虚构角色+世界观，间接讲概念。可融入真实人物案例作为证据锚
  - **个人经历型**（方向大于努力）：自身低谷→权威启发→认知反转。低谷透明化建立信任+权威引用升维+自身数据验证
- 对备电的参考价值：用架空角色替代真人出镜，降低制作门槛。双角色对比天然适合"两种储能路线/两种商业模式"类选题

### 爆米花企业赋能（商业/企业实操）

- 账号：抖音「爆米花企业赋能」
- 形式：9:16竖屏，配音+PPT/素材，无真人出镜
- 风格：接地气商业口播。货币化框架命名（三层皮/防弹衣/输液管）+ 翻车故事钩子 + 借假修真收尾
- 标志手法：翻车反例开场→正反对比立论→递进式实操框架→情绪刹车转折→金句对仗收尾
- 代表作品：科技贴牌（#14）、负债（#15）、债务滚动（#16）
- 双重语调：
  - **老江湖靠谱型**（科技贴牌）：翻车故事→三层实操框架→借假修真→金句对仗
  - **老江湖狂放型**（负债/债务滚动）：挑衅断言→身份羞辱筛选→概念翻转/机制演示→悖论金句
- 对备电的参考价值：政策/补贴类内容翻译成"对你钱包有什么影响"的表达方式

### 哎呀朱莉亚（投行/思辨/认知/财富/文明）

- 账号：抖音「哎呀朱莉亚」
- 形象：投行人，真人出镜 · 单人口播（独白式讲述，非对谈非表演）
- 风格：知识分子型思辨口播。从头到尾不用"我认为""我觉得"，只用事实、案例、数字当论据。把抽象概念拆成多个维度。给日常词赋予新含义（怕=敬畏、赚钱=美德）。
- 标志手法：证据饱和攻击（量本身就是论据）+ 归因升级（每层只推一层）+ 变量切换（不反驳，换维度）+ 三分法递进 + 闭环收尾
- 代表作品：失控与伟大（#17）、门当户对（#18）、农民属性（#19）、"靠"文化（#20）、管钱的底层逻辑（#22）、东西方科学路径（#23）、反智与独立思考（#24）、AI时代的哲学复兴（#25）、修行与量子（#26）、嫉妒（#27）、入世与出世（#28）、解释权（#29）、孙雨晨四重思维（#30）、感情阶级（#31）
- 切入方式：
  - **论点宣言**（失控/反智）：直接甩出反常识判断
  - **数据震撼**（门当户对）：一个数字推翻一个观念
  - **身份炸弹**（农民属性）：给观众一个不愿认但无法否认的标签
  - **影视切入**（"靠"文化）：借一个已在观众脑中的故事，用一句台词导出概念
  - **反常识问题**（管钱/科学路径）：先问一个日常困惑，再剥开
  - **具体翻转**（AI+哲学）：用一个人人皆知的人（张雪峰）+ 一个翻转当钩子
- 对备电的参考价值：目前案例库里最完整的一套可复用模板。财富/框架判断类写法标杆——用事实论证替代主观判断，用归因升级把一个概念推到系统级判断。四条不同赛道，同一套骨架。

### 朱莉亚的智汇圈（投资/认知/宏观）

- 账号：抖音「朱莉亚的智汇圈」
- 形式：9:16竖屏，真人出镜·单人口播
- 风格：层层推导法。不解释概念，推导概念。从一个小概念出发，一步一步推到宏观判断。画面代替术语（锅盖>虹吸），问题开头问题结尾。
- 代表作品：边际思维推导（#21）
- 对备电的参考价值：学习笔记系列的写法标杆。单一概念卡到处都有，但把一个概念推到系统级判断的能力是壁垒。

### 深度进化Theo（认知/成长/方法论）

- 账号：抖音「深度进化Theo」
- 形式：9:16竖屏，配音+素材/文字动画，无真人出镜
- 风格：中长认知口播，三段式/四步法框架，高信息密度+强逻辑链
- 标志手法：认知缺口钩子→跨来源印证→框架化→示范式拆解→画面化收尾
- 代表作品：无常（#7）、信息环境设计（#8）、自我拆解重构（#9）
- 对备电的参考价值：框架化表达+示范式拆解，可迁移到储能知识的方法论输出

## 案例性质标注

每个案例必须在文件头部和本索引中标注两个维度：

**维度一：性质**

| 标记 | 含义 | 适用 |
|------|------|------|
| ✅ 正向 | 爆款/可复用手法 | 外部对标账号的成功案例 |
| ❌ 反面 | 翻车/避免踩坑 | 自己的失败案例、常见错误示范 |
| 待标记 | 尚未评估 | 新入库未分类 |

**维度二：出镜形式**

| 标记 | 画面特点 | 文案影响 |
|------|---------|---------|
| 真人出镜 | 人物在画面中，面部表情+手势传递情绪 | 文案可稍松弛，表演分担注意力 |
| 无真人·PPT/素材 | 配音+画面素材/文字动画，无人物 | 文案必须更密、信息量更高、转折更频繁 |
| 无真人·素材混剪 | 配音+视频素材混剪，画面节奏快 | 文案需配合画面切换节奏 |
| 无真人·轻出镜 | 以配音为主，偶有出镜或不露脸出镜 | 介于两者之间 |
