# 经济概念·巴萨效应·叙事拆解

> 来源：抖音「一二三周爸爸」| 保存：2026-07-11
> 性质：✅ 正向案例
> 出镜形式：真人出镜 · 场景叙事（会议桌前对双胞胎儿子提问→白板讲解→结尾问"懂了没有"）
> 类型：口播。平行世界叙事法。六角色+进出口贸易模拟+汇率推演。

---

## 完整文案

美国外卖小哥跑一单赚5美元，中国外卖小哥跑一单赚5人民币。干同样的活儿，凭啥美国外卖小哥可以多赚7倍的钱呢？答案是巴萨效应。

啥是巴萨效应啊？

这是美丽的太平洋，太平洋左边是中国，右边是美国。中国用人民币，美国用美元。

这是中国外卖员小蒋，他跑一单外卖赚5块钱，每天跑20单，一天的收入是100人民币。这是美国外卖员小A，他跑一单赚5美元，每天跑20单，一天的收入是100美元。

这是中国服装厂的小乙，他做一件衣服赚5块钱，每天做20件，一天的收入也是100人民币。这是美国服装厂的小毕，他做一件衣服赚5美元，每天做20件，一天的收入也是100美元。

这是中国手机厂的小丙，他组装一台手机赚5块钱，每天组装20台，一天的收入还是100人民币。这是美国手机厂的小C，他组装一台手机赚5美元，每天组装20台，一天的收入还是100美元。

在中国，一天的房租是50块，一份外卖10块，一件衣服100块，一台手机1000块。在美国，一天的房租是50美元，一份外卖10美元，一件衣服100美元，一台手机1000美元。

所以你看这六个人，他们虽然国籍不同、职业不同，但是互相之间谁都不羡慕谁。因为每个人的收入和生活水平都一样——房租都是收入的50%，外卖10%，买一件衣服都需要工作一天，买一台手机都需要工作10天。

但是，这种平衡状态是建立在两国市场彼此隔绝的前提下。一旦两国开始贸易，平衡就会被打破。

怎么被打破的呢？我们来举个例子。

这是国际外贸商老六，他专门做两国进出口贸易。假设现在中美两国开始允许贸易，在规定上仅限于服装产品，对手机实施严格管制。那么大家很快就会发现，老六的生意很一般，换汇热情也不高，因为换来的外汇只能进口衣服。但是不管是中国的衣服在美国，还是美国的衣服在中国，销量都很惨淡。原因也很简单，服装嘛，传统行业，没啥技术壁垒，属于劳动密集型产业。小乙做的衣服和小毕做的衣服质量都大差不差，导致能卖的价格也大差不差。中国100人民币的衣服出口到美国卖100美元，美国100美元的衣服在中国也只能卖100人民币。

假设美国衣服在中国市场上销量只有10件，那么即使银行里有1万美元的外汇额度可以进口100件衣服，但老六最多也只愿意换1000人民币来兑换1000美元进口10件美国衣服。同理，美国人也只愿用1000美元兑换1000人民币进口10件中国衣服。

很显然，在这种情况下，人民币对美元的实时汇率就是1:1。甲乙丙ABC这六个人的收入也相等，依然谁也不羡慕谁。

如果这时候我们来统计GDP，那么甲乙丙一天创造的GDP就是20份外卖加20件衣服加20部手机，合计22200人民币。同理，ABC创造的GDP也是22200美元。由于当前汇率是1:1，所以GDP就是1:1，两国并列第一，没有问题。

于是两国决定进一步开发贸易，取消手机管制。

按照之前1:1的汇率，一台1000人民币的中国手机在美国的售价就是1000美元，一台1000美元的美国手机在中国的售价就是1000人民币。但这时候奇怪的事情出现了——中国手机在美国市场表现不佳，但美国手机在中国市场却异常受欢迎，性价比拉满了，上市当天就直接售罄。许多狂热粉丝甚至开始在店门口通宵排队抢手机，黄牛市场上，一台美国手机的成交价飙升到了7000人民币。

看到这样的场景，老六的眼睛都亮了。因为他知道，现在银行里那1万美元的背后，已经不再是当初100件卖不动的衣服了，而是这台供不应求的手机。只要把银行里的1万美元全部买到手，再进口10台手机，转手一卖——轻松赚7倍的利润。

而当老六兴奋地跑到银行准备大赚一笔的时候，却发现大厅里早就挤满了同行——老七、老八、老九，大家挤破头都想抢美元赚差价。但是银行和外汇市场暂时就只有这1万美元现金。咋整？还能咋整，竞标拍卖呗。

很显然，只要1美元的价格低于7人民币，就会有人加价。最终这1万美元果然精准地以7万人民币的价格兑换成交。

老六兑换了1万美元，进口了10台小C手机，售价7000人民币。美国人又换来了7万人民币，进口了700件小乙衣服，售价15美元。

那么很显然，这时候美元对人民币的实时汇率就变成了1:7。同时按照汇率计算，两国的GDP也变成了1:7。

所以你看，前一天还谁也不羡慕谁的六个人，一夜之间都不淡定了。因为按照汇率计算，现在ABC的收入已经变成了甲乙丙的7倍。

于是小蒋给小A打电话："兄弟，听说你现在送外卖的收入是我的7倍，是不是很爽啊？"小A说："啊？没感觉呀。我的房租还是收入的一半儿啊，买个手机还是得工作10天呀。"

小丙给小C打电话："兄弟，听说你现在组装手机的收入是我的7倍了，是不是很爽啊？"小C说："啊？没感觉呀。我点的外卖还是收入的1/10啊。而且最近厂里的出口订单爆了，天天加班累得要死。"

小乙又给小B打电话："兄弟，听说你现在做衣服的收入是我的7倍了，是不是很爽啊？"小毕说："爽个屁！你的衣服现在出口到我们这儿只卖15美元，把我们的衣服厂都挤得关门倒闭了。"小乙说："啊，不好意思兄弟，没想到我竟然把你搞失业了。那你咋办嘞？"小毕说："还好，我听说小C的手机厂子扩招，我现在准备去小C那儿打工了。"

所以你看，虽然两边的人均收入差了7倍，但是甲乙丙ABC六个人的体感其实并不明显。为什么呢？

这是因为社会上的商品和服务需要被分为两大类——可贸易商品和不可贸易商品。衣服、手机、汽车、玩具属于可贸易商品，只要不人为设置障碍和关税，商品就会通过市场竞争和汇率校准变成全球统一价。比如小毕的服装厂如果不愿意降价，就会被小乙的服装厂取代；小丙的手机厂如果不能升级产品，就会被小C的手机厂取代。

而房租、外卖、理发却属于不可贸易商品，进而会呈现区域价格垄断，有点类似于之前被管制的商品，虽然价格虚高，但是不可替代，所以依然有人买单。比如虽然小A的外卖比小蒋贵了7倍，但是小蒋不能跨过太平洋取代小A，所以小A不需要降价。ABC的房租虽然也贵了7倍，但是他们的房东不会被甲乙丙的房东所取代，所以美国房东不需要降价。

而可贸易商品的开放导致美国服装厂倒闭、手机厂扩招，小毕变成了小C的同事；中国的手机厂倒闭、服装厂扩招，小丙变成了小乙的同事。这种区域性产业和人才结构的重塑现象，就是我们常说的国际贸易分工。

我们再来看汇率。由于货币互换和外汇交易的核心场景主要集中在衣服、手机等这类可贸易商品，因此汇率天然的更多的是在体现其对于可贸易商品的购买力，而不是所有商品的购买力。

比如故事里1:7汇率的本质其实是——因为人民币愿意用7倍中国手机的价格来换美国手机，所以美元就可以用卖手机换来的钱，以1/7美国衣服的价格来换7倍数量的中国衣服。仅此而已。体现的是货币对于可贸易商品的购买力。

而ABC的房租和外卖价格虽然也是甲乙丙的7倍，但这属于不可贸易商品，天然就和汇率绝缘。对于不经常出国的六个人来说，这7倍的名义汇率对他们的日常生活影响不大，所以他们的体感不会明显。

这就是巴拉萨-萨缪尔森效应，简称巴萨效应。

它告诉我们：发达地区可贸易商品的生产效率和产品利润更高，因此可贸易部门的平均收入就更高，货币汇率就更高。但是发达地区的劳动力在各部门之间又是流动的，流动就会导致劳动力价格的统一。因此，发达地区不可贸易部门的收入就会跟着可贸易部门的收入水涨船高。

换句话说，一个地区可贸易部门的效率越高，不可贸易部门的性价比就越低。可贸易部门和不可贸易部门之间的效率差，才是导致货币实际汇率和真实购买力偏差的根本原因。

所以许多外企都喜欢在中国设厂。所以中国外卖小哥一单只收5人民币。

Wanna be wanna be, 听懂了没？

## 叙事手法拆解

### 1. 开场：具体生活场景 + 反常识数字

"美国外卖小哥跑一单赚5美元，中国外卖小哥跑一单赚5人民币。干同样的活儿，凭啥美国外卖小哥可以多赚7倍的钱？"

**与做空案例开场对比：** 做空是"资产贬值的时候可以赚钱吗？"——先抛问题再建世界。巴萨效应是先给具体画面（两个外卖小哥），再给数字差（7倍），最后才说"答案是巴萨效应"。两个开场同一模式：具体场景→反常识数字→概念名。

### 2. 六角色平行建世界（比做空更复杂）

做空用了两个角色（老王+你）+ 层层放大。巴萨效应用了六个角色——小蒋/小A（外卖）、小乙/小毕（服装）、小丙/小C（手机）——三组镜像角色。

**为什么需要六个角色：** 巴萨效应需要同时展示"可贸易"和"不可贸易"两个维度对三个职业的影响。三组角色对应三个层次：外卖（不可贸易）、服装（可贸易但无技术优势）、手机（可贸易有技术优势）。

每个角色的第一天都是"100元/美元收入，50房租，10外卖，100衣服，1000手机"——完全对称的设计，让观众一眼看清"现在大家平等"。

### 3. 两阶段贸易推演（渐进式解锁）

不是一次性打开全部贸易，而是分两步走：

- **阶段一：仅开放服装（可贸易但无技术差）** → 价格大差不差 → 汇率1:1 → 大家仍然平等
- **阶段二：开放手机（可贸易有技术差）** → 美国手机碾压 → 汇率1:7 → 均衡被打破

**为什么分两步：** 如果一步到位开放所有商品，观众会搞不清到底是"贸易本身"导致了汇率变化，还是"技术效率差"导致了汇率变化。两阶段设计把这两个变量拆开了——先证明纯贸易不改变汇率（阶段一），再证明技术效率差才是核心变量（阶段二）。

### 4. 竞争场景的戏剧化（老六抢汇）

老六发现了7倍利润机会 → 冲到银行 → 发现老七老八老九已经在排队 → 竞标拍卖 → 汇率精准落在1:7。

**为什么加这个场景：** 这不是经济学科普，这是一个商战小故事。观众在跟着老六从眼睛发亮→冲到银行→发现竞争→参与竞标的过程中，已经忘了自己在学一个经济学概念。汇率1:7不是一个抽象的数字，是老六跟老七老八老九抢出来的。

与做空案例的同构——做空的"你借钱买黄金→金价翻倍→卖金还钱→净赚90万"也是让观众跟着算。巴萨效应的"老六竞拍换汇"同样是让观众跟着竞标。

### 5. 三通电话（汇率≠体感）

汇率变成1:7之后，用一个舞台剧式的手法——三通跨国电话——来展示"数字变了但体感没变"这个反直觉结论：

- 小蒋→小A（外卖）："收入7倍了，爽吗？""没感觉，房租还是50%。"
- 小丙→小C（手机）："收入7倍了，爽吗？""没感觉，外卖还是10%。"
- 小乙→小B（服装）："收入7倍了，爽吗？""爽个屁，你把我厂挤倒闭了。"

三通电话，三种反应：无感（不可贸易部门）、无感但忙（可贸易优势部门）、失业（可贸易劣势部门）。

**手法亮点：** 前两通电话铺垫"汇率涨了但体感没变"，第三通电话突然转调——小B不仅没变爽，反而被挤失业了。这是观众第一次意识到"贸易开放不只是数字游戏，会让一些人丢饭碗"。

### 6. 关键概念二分法（可贸易 vs 不可贸易）

全篇的知识核心用一句话切开——

"衣服、手机、汽车、玩具 → 可贸易商品 → 全球统一价。房租、外卖、理发 → 不可贸易商品 → 区域价格垄断。"

这六个例子全是刚才故事里出现过的，观众不需要重新理解新概念。故事里的材料和结论里的分类完全闭合。

### 7. 收尾：公式化表达 + 接地气落点

"一个地区可贸易部门的效率越高，不可贸易部门的性价比就越低。"

然后立刻接地气——"所以许多外企都喜欢在中国设厂。所以中国外卖小哥一单只收5人民币。"——从抽象经济学原理直接落回开场的外卖小哥画面。

最后一句"Wanna be wanna be, 听懂了没？"——回到孩子面前，回到账号的标志性句式。与做空的"听到了没？"同一模式。

## 与做空案例的横向对比

| 维度 | 做空 | 巴萨效应 |
|------|------|---------|
| 角色数量 | 2+1（老王+你→层层放大） | 6+1（六角色+老六） |
| 世界构建 | 一人连串动作 | 六人平行对称 + 贸易推演 |
| 推演阶段 | 两层（做多→做空） | 两阶段（仅服装→加手机） |
| 核心变量 | 借资产方向（借现金vs借资产） | 可贸易vs不可贸易 |
| 竞争场景 | 无（单人操作） | 有（老六老七老八老九竞标） |
| 结尾模式 | "听到了没？" | "听懂了没？" |
| 篇幅 | ~1200字 | ~3000字（约2.5倍） |

**共同手法：**
- 平行世界叙事：不说"今天讲XX"，直接建世界
- 用"你/具体人物"让观众代入
- 层层推演，每一步观众都跟着算
- 概念定义出现在故事之后，不是之前
- 结尾回到标志性句式

**巴萨效应比做空更复杂的点：**
- 需要平衡六个人物的叙事权重
- 需要两阶段贸易推演来拆开"贸易"和"技术差"两个变量
- 需要解释"汇率变了但体感没变"这个反直觉结论（三通电话）
- 需要在故事中同时展示赢家、输家、无感者三种结果

## 可复用手法矩阵

| 手法 | 在手法的位置 |
|------|------------|
| 镜像角色建世界 | 六角色三组对应，对称设定让规律自动浮现 |
| 渐进式变量解锁 | 分两阶段开放贸易，拆开"贸易"和"技术差"两个变量 |
| 竞标场景戏剧化 | 把抽象的汇率形成过程变成老六抢汇的商战小故事 |
| 多通电话展示多结果 | 同一事件（汇率变动）对不同角色的不同影响，一通电话一种命运 |
| 概念二分法 | 用故事中已出现的例子切开可贸易/不可贸易，不引入新概念 |
| 回到开场画面收尾 | 从抽象理论落回外卖小哥，从哪来回哪去 |
| 标志性结尾句式 | "听懂了没？"——建立账号辨识度 |

## 适用场景

- 经济学/金融概念的中长篇讲解
- 需要多个角色展示"同一个变化对不同人的不同影响"
- 反直觉结论（数字变了但体感没变）需要分阶段推演才能说清
