# 科普概念·汽油标号·叙事拆解

> 来源：抖音「一二三周爸爸」| 保存：2026-07-11
> 性质：✅ 正向案例
> 出镜形式：真人出镜 · 场景叙事（会议桌前对双胞胎儿子提问→白板讲解→结尾问"懂了没有"）
> 类型：口播。隐喻翻译法——先建一个完全不同的世界（马+饲料），再逐词翻译回真实世界（发动机+汽油）。

---

## 完整文案

为什么92号、95号、98号汽油的价格不一样？它们到底有什么区别？

答案是，它们的抗爆性能不同。

是这样的——

这是一台发动机，我们可以把它想象成古代马车里提供动力的马。这是加油站里的汽油，我们可以把它想象成马饲料。

通常来说，马的肌肉越强壮，马上的动力就越强；反之，肌肉越弱，动力也就越弱。与此同时，人们还发现一个问题——越强壮的马，情绪越不稳定，越容易生气撂蹶子。

为了解决撂蹶子的问题，人们想了一个办法，那就是在饲料里添加镇静剂来安抚马儿的情绪。

添加镇静剂是个技术活儿——量太少，对强壮的马没有效果，还是会撂蹶子；量太多，柔弱的马就会消化不良。

所以结论就是：我们需要根据不同身体条件的马，来调配不同镇静效果的饲料。

---

现在我们把这个故事重新翻译一遍。

首先，衡量汽车发动机肌肉强弱的核心指标叫做**发动机压缩比。** 压缩比越高，发动机的动力就越强。

而高压缩比发动机容易撂蹶子的现象叫做**发动机爆震。** 爆震越频繁，发动机的寿命就越短。

于是，为了解决发动机的爆震问题，人们想了个办法，那就是往汽油里添加**抗爆剂。**

添加抗爆剂也是一个技术活——因为高压缩比的发动机用低抗爆性能的汽油，还是会爆震；而低压缩比发动机用高抗爆性能汽油，则会燃烧不充分，产生积碳。

所以结论就是：我们需要给不同压缩比的发动机来使用匹配不同抗爆性能的汽油。

而汽油抗爆性能的量化单位叫做**辛烷值。** 辛烷值越高，抗爆性能就越高。

于是加油站里就出现了——

抗爆性能为92%辛烷值的92号汽油，来适配压缩比为8~9的发动机；

抗爆性能为95%辛烷值的95号汽油，来适配压缩比为10~12的发动机；

以及抗爆性能为98%辛烷值的98号汽油，来适配压缩比大于等于13的发动机。

---

综上所述，不同标号的汽油根本区别在于它们抗爆指数的不同，和汽油的品质无关。

而98号汽油之所以更贵，主要是因为高抗爆性汽油的制作工艺更加复杂，成本更高而已。

而真正决定汽油品质的，其实是不同厂家的原油质量以及加工技术。

所以大家平时都喜欢加什么牌子的汽油呢？

## 叙事手法拆解

### 1. 隐喻翻译法（本篇核心手法）

全篇结构是一个"翻译机"：

```
古代世界（马+饲料+镇静剂）
        ↓ 逐词翻译
现代世界（发动机+汽油+抗爆剂）
```

**这不是比喻装饰，这是认知脚手架。** 作者先让观众在一个完全熟悉的领域里建立理解（马强壮→容易撂蹶子→加镇静剂，这件事不需要任何汽车知识就能懂），然后再把这套理解结构完整迁移到目标领域。

**与做空/巴萨效应的区别：**

| 手法 | 做空 | 巴萨效应 | 汽油标号 |
|------|------|---------|---------|
| 建世界方式 | 直接在金融世界建角色 | 直接在经济世界建角色 | 先建一个完全不同的世界，再翻译 |
| 观众认知路径 | 跟着角色在目标领域里推导 | 跟着角色在目标领域里推导 | 先在熟悉领域建立直觉，再迁移 |
| 适用场景 | 概念本身不需要前置知识 | 概念拆开就能跟着算 | 概念需要先有身体直觉才能理解 |

**什么时候用隐喻翻译法：** 当目标概念对观众来说完全陌生、缺乏直觉基础时。汽油标号——压缩比、辛烷值、爆震——这些词对普通人来说是黑箱。但"马强壮→容易撂蹶子→加镇静剂"人人秒懂。

### 2. 开场：日常问题 + 简短答案

"为什么92、95、98号汽油价格不一样？到底有什么区别？"

——每个人加油时都见过这三个数字，但几乎每个人都说不清区别。这是一个"天天遇到但不理解"的问题池。

然后立即给答案："抗爆性能不同。"——不卖关子，因为观众对汽油标号没兴趣，只对"我该加哪个"有兴趣。先把答案摆出来，再用故事解释为什么。

### 3. 翻译结构的精妙之处：一一对应

故事的每个要素在翻译时都能被精确对应：

| 古代世界 | → | 现代世界 |
|---------|---|---------|
| 马 | → | 发动机 |
| 马饲料 | → | 汽油 |
| 马的肌肉强弱 | → | 发动机压缩比 |
| 强壮的马撂蹶子 | → | 高压缩比发动机爆震 |
| 镇静剂 | → | 抗爆剂 |
| 量太少没效果 | → | 低抗爆→高压缩比仍爆震 |
| 量太多消化不良 | → | 高抗爆→低压缩比积碳 |
| 按马调配饲料 | → | 按压缩比选汽油标号 |

**没有任何遗漏，没有任何多余。** 这种严格的对应让"翻译"这个动作变得可信，观众不需要在翻译过程中处理任何新信息。

### 4. 先给结论再翻译（不是边讲边翻）

作者不是讲一句马的故事就翻译一句，而是把整个马的故事先讲完，让观众在脑子里形成一个完整的画面。然后才说"现在我们把这个故事重新翻译一遍"。

**为什么不分段翻译：** 如果边讲边翻，观众会被来回切换打断。先把古代世界完整建立好，观众已经"懂了"这个故事——然后翻译就是单纯地把词换掉，认知负担为零。

### 5. 结尾：打破一个常见误解 + 互动CTA

"不同标号的汽油根本区别在于抗爆指数，和汽油的品质无关。"

——这是大多数人的误解（以为98号"更纯""更好"）。用一个完整故事铺垫之后，一句话打碎这个误解。

然后解释价格差异的真正原因（工艺复杂度+成本），再补一句更底层的品质决定因素（原油质量+加工技术）。

最后用"大家平时都喜欢加什么牌子的汽油"收尾——轻松的互动CTA，不追问"懂了没"因为这个话题不需要。

## 隐喻翻译法的适用条件

不是所有概念都适合用这招。需要同时满足三个条件：

1. **目标概念对观众完全陌生**（压缩比/辛烷值/爆震 → 黑箱）
2. **能找到一一对应的日常类比**（马+饲料的逻辑链跟发动机+汽油完全同构）
3. **类比世界的逻辑链足够短**（马的故事4步就讲完，不需要长篇大论）

如果找不到严格一一对应的类比，不要强行用翻译法——用做空/巴萨效应的直接建世界手法更稳。
