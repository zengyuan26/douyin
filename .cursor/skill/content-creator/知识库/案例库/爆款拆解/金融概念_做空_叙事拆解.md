## 完整文案

> 资产贬值的时候可以赚钱吗？当然可以，怎么赚钱呢？答案是做空。啥是做空呀？这是你的邻居老王，他手里有100万现金和1000g黄金，假设目前金价是1000元每克，那么1000g黄金就是100万，加在一起，老王妥妥的200万资产没有问题。这是屏幕前的你，虽然身无分文，但是你认为明天金价会大涨，于是你找到老王说，兄弟，借你100万用一下，明天还你，外加10万利息。老王一听一天就有10万利息，立刻答应把100万借给了你。你拿到100万之后，立刻买入了1000g黄金。第二天，果然如你所料，金价暴涨一倍，每克变成了2000元。于是你又果断把黄金卖掉，变现200万，其中110万连本带利还给老王，自己净赚90万。我们把这种资产上涨时靠借钱买资产获利的操作叫做做多。做多在生活中很常见，比如贷款买房，借钱炒股，本质上都是在做多。我们再来看老王，他现在笑得比你还开心，不但赚了10万的利息，自己手里的金条也升值了一倍，加在一起资产来到了310万。但是你突然又预感到明天黄金会暴跌，该怎么办？聪明的你想到了一个办法，你又找到老王说，兄弟，借你的金条用一下，明天还你还是10万利息。尝到甜头的老王想都没想说，OK, 金条借你拿到金条之后，你立刻出手把金条卖掉，换来了200万现金。第三天又果然如你所料，金价暴跌50%，回到了前天的1000元每克。于是你又用100万把金条买回来，金条还给老王，加上10万利息，自己又赚了90万。我们把这种资产下跌时借资产卖钱获利的操作叫做做空，你看你通过自己精准的做多和做空操作，短短两天时间就凭空赚了180万，不仅如此，金价的后续波动，不管是涨还是跌，只要你能赌对，就能继续收割。而且，你不仅可以收割黄金，同样套路还可以收割其他资产。比如，如果我们把故事里的黄金换成股票，把老王换成券商，你既可以向券商借钱买股票，也可以向券商借股票卖钱。那么恭喜你，你现在的名字叫做私募基金。不管股票涨跌，你都有办法赚钱。如果我们把时间单位从1天改成1秒，再把股市里成千上万只股票毫秒级的价格波动和买卖操作，全部交给人工智能和计算机，那么恭喜你，你现在的名字叫做量化机构，靠算法和机器自动收割。如果我们把黄金换成泰铢，把老外换成跨国银行，把时间换成1997年，那么恭喜你，你现在的名字叫做索罗斯。你在1997年成功特工泰铢，狂赚20亿美元的同时，还引爆了亚洲金融危机。如果我们把黄金换成美元，把老王换成美联储，那么恭喜你，你现在的名字叫做华尔街资本。你利用美元的世界货币地位，以及美联储加息降息所制造出来的美元潮汐，轻松收割世界财富好了，现在化身为机构资本和国家机器的你，手握天定的资金和影响力强的可怕，因为你发现在你这个段位做多做空需要的。不再是运气，而是科技与狠活。与此同时，你更是既惊讶又惊喜，你不明白，自己明明已经这么强了，为什么那些可爱的散户朋友们却依然排队入场，一点都不怕你呢？听到了没？

## 叙事手法拆解

### 1. 直接建世界，不给任何介绍

不说"今天讲做空"。第一句就是"这是你的邻居老王，他手里有100万现金和1000g黄金"——观众已经在故事里了。没有"大家好"、没有"今天我们来聊聊"、没有铺垫。

### 2. 用"你"让观众进场

不是"有一个人"、不是"比如说"。是"这是屏幕前的你，虽然身无分文"——观众被迫代入角色。没法划走，因为故事在说你。

### 3. 具体的人物 + 具体的数字

老王。100万。1000g。1000元每克。10万利息。不是抽象概念，是能看见的画面和能跟着算的数字。

### 4. 一步一步，让观众自己算

借100万 → 买1000g黄金 → 金价翻倍 → 卖200万 → 还110万 → 净赚90万。每一步观众都在心里跟着算。算完了，概念（做多/做空）不用你解释——观众已经自己推导出来了。

### 5. 层层放大（核心手法）

黄金 → 股票 → 私募基金 → 量化机构 → 索罗斯 → 华尔街资本。同一个逻辑，每放大一层"恭喜你，你现在的名字叫做XX"——观众"哇"一次。

### 6. 结尾直接跟观众对话

"听到了没？"——像朋友讲完一个秘密。不是"总结一下"、不是"以上就是"。

## 适用场景

- 解释任何抽象概念（金融、商业、投资）
- 需要让观众"自己推导"而不只是听你讲
- 概念本身简单但需要让人记住
