# 图文拆解案例库

> 自己的图文作品拆解。提取可复用的爆款规律和避坑教训。
> 与 [爆款拆解](../爆款拆解/)（外部对标账号的视频拆解）互补——那边学叙事手法，这边学图文打法。

## 分析框架

每篇图文拆解从 6 个维度解剖：

| 维度 | 核心问题 |
|------|---------|
| **选题信号** | 蹭的什么事件/情绪？时效窗口多长？ |
| **标题钩子** | 用了哪几个标题要素？数字/对比/反转/时效？ |
| **结构流** | 页面怎么排？翻页逻辑是什么？ |
| **人设视角** | 谁在讲？跟观众什么关系？ |
| **视觉设计** | 配色/材质/风格？跟内容匹配吗？ |
| **转化设计** | 收藏理由？评论钩子？CTA路径？ |

## 通用规律提炼

### 分析型图文（备电）的 5 个共同特征

1. **事件锚点 + 个人视角**：不是"行业分析"，是"我看到一个信号，拆给你看"
2. **P2 直接给答案**：第二页必须用数据卡片/对比把核心结论砸出来。禁止铺垫
3. **每页有判断句**：不只罗列事实。每一页都有一句"所以呢？"
4. **一个争议点**：全文只放1个争议/风险点（通常在P4），保持诚实
5. **从大到小落地**：宏观政策/产业趋势 → 具体到"你"能做什么

### 教程型图文（南漳黄姐）的 5 个共同特征

1. **翻车痛点做钩子**：不打"怎么做"，打"怎么不翻车"（一晒就酸/一蒸就爆/原来做错了）
2. **每个建议带数字**：温度/时间/比例/间距——"适当""适量"=零收藏
3. **对仗句式**：一晒就酸，一切就散 / 别扔！救回你的肉钱
4. **结构可视化**：三栏/四宫格/checklist/前后对比——一屏讲清，截图即收藏
5. **评论CTA换互动**："评论区说你的城市气温""打香肠避坑"——评论=算法加权

### 跨类型通用规律

| 规律 | 分析型（备电） | 教程型（南漳黄姐） |
|------|--------------|------------------|
| P1钩子 | 事件+数字 | 痛点+对仗/疑问 |
| P2灵魂页 | 数据卡片给结论 | 三栏/四宫格给方案 |
| 收藏动机 | 投资判断 | 照做避坑 |
| CTA | 私信关键词 | 评论互动/点赞收藏 |
| 系列IP | Vol.1/2/3 | 合集·XXX注意事项 |

### 反面图文的 3 个危险信号

1. **公司/产品中心**：以某家公司为叙事主角，而不是以观众的问题为中心
2. **没有"谁在讲"**：缺乏身份锚点。读者不知道"我为什么要听这个人讲"
3. **收尾无紧迫感**：结尾是"等等看"而不是"现在该做什么"

## A型 vs B型 使用决策

| 场景 | A型（多张轮播） | B型（单张信息图） |
|------|----------------|-------------------|
| 内容深度 | 需要逐层展开的逻辑链 | 一张图能讲清的关系/流程 |
| 用户行为 | 左滑翻阅，每页一个信息点 | 截图保存，一次看完全局 |
| 适合选题 | 事件分析、认知反转、投资逻辑、分步教程 | 产业链图、流程说明、三栏条件对比 |
| 制作成本 | 4-7张独立生图 | 1张信息图 |
| 爆款潜力 | 高（页页有钩子，翻到底=完播率） | 中（收藏率高但互动弱） |
| 南漳黄姐验证 | 4-5张轮播，72.7万浏览 | 三栏条件图（P2），4.8万浏览 |

## 创作前必读清单

> 每次创作图文类内容前，先对照本库：

1. **选题类型**：分析型（备电#1-5）还是教程型（南漳黄姐#6-11）？
2. **钩子公式**：事件+数字 / 翻车痛点+对仗 / 常识挑战+原来做错了
3. **P2灵魂页**：数据卡片 / 三栏信息图 / 四宫格步骤 / 前后对比
4. **数字密度**：每个建议是否带具体参数？
5. **CTA设计**：评论互动 / 私信关键词 / 点赞收藏
6. **反面检查**：是否犯了反面图文的3个危险信号？
