## 三、可复用手法

### 1. 常识挑战框架

```
大家都在做X → 真的对吗？ → 其实应该Y → 为什么（危害） → 正确做法
```

适合任何"大家都以为XXX"的选题。

### 2. 左右对比分屏

```
错误做法 | 正确做法
冷色调   | 暖色调
❌       | ✅
```

一屏看完结论，适合划走型用户。

### 3. 危害三步递进

```
Step1 → Step2 → Step3 → 结果清单
```

把"为什么错"变成可视化故事，比讲道理有效。

### 4. Why+How双栏

```
左栏：好处/原理（Why）
右栏：步骤/操作（How）
```

信息图标配结构，收藏率高于单栏。

### 5. 额外技巧增值

正文讲完后，P5再给"牙签判断""不要先切"——超出预期的细节提升收藏和分享。
