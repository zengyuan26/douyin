## 三、可复用手法

### 1. 三栏并列信息图

适合"N个条件/要素/步骤"类选题：
```
条件1 | 条件2 | 条件3
每栏：图标 + 核心数字 + 一句话 + [记好]
```

### 2. "记好"收藏暗示

每栏底部加"记好"按钮（视觉元素，非真实按钮），暗示用户"这条值得存"。

### 3. 卡通角色做对比

```
低温+风 → 干燥发酵 → 开心腊肠
高温/潮湿 → 发霉 → 难过腊肠
```

抽象概念用角色表情替代文字解释。

### 4. 季节窗口内容

灌香肠/晒香肠/备年货——绑定季节行为，每年可复用同一套结构换数据。
