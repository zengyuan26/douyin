## 二、结构逐页拆解

```
P1 诊断页    → "问题1：葱姜水加多了" + 红X标记 + 解决方案
P2 翻车现场  → "一蒸就爆？肉全散了！" + 爆肠实拍
P3 四宫格    → 加蛋/7-8分满/扎孔排气/80°C煮1小时
P4 总结清单  → 5条checklist + 空气炸锅180°C + 评论CTA
```

### P1：问题诊断页

**文字**：
```
问题1：葱姜水加多了
肉馅吸不动，水分流失，松散
加1个鸡蛋锁水
```

**视觉**：调馅碗+红X标记

**为什么有效**：
- "问题1"——暗示有系列（问题2、3），驱动翻页
- 红X——错误示范，比文字说"不对"直观10倍
- 每个问题配解决方案——不是只指出错误

### P2：翻车现场封面

**文字**：
```
在家做香肠
一蒸就爆？肉全散了！
别心疼！3步救回，下次做超紧实
超干货在这 👍
```

**为什么有效**：
- 爆肠实拍——视觉冲击，划走率极低
- "别心疼！"——情绪共鸣，像朋友在安慰
- "3步救回"——数字承诺+救场框架

### P3：四宫格步骤（灵魂页）

**四格内容**：
```
加1个鸡蛋+减半葱姜水  |  灌7-8分满，留膨胀空间
每厘米扎1孔，彻底排气   |  冷水下锅，80°C煮1小时
```

**为什么有效**：
- 2×2四宫格——一屏看完4步，完播率友好
- 每格一个动作+一个数字——可照做
- "7-8分满"配角标——关键数字二次强调
- 温度计80°C实拍——证据感

### P4：总结清单+延伸

**文字**：
```
✓ 加蛋减葱姜水防松
✓ 灌7-8分满不鼓胀
✓ 扎孔排气防爆开
✓ 冷水80°C煮保嫩
✓ 空气炸锅烤更出香

空气炸锅180°C 烤5分钟，香到流油
评论区打"香肠避坑"
```

**为什么有效**：
- 5条checklist——收藏型结构
- 延伸到空气炸锅——给"下一步"场景，不只是解决问题
- 评论关键词CTA——"香肠避坑"可统计、可互动

## 三、可复用手法

### 1. 问题编号驱动翻页

```
问题1：XXX
问题2：XXX
问题3：XXX
```

每页一个问题，用户为了看"还有啥问题"会翻到底。

### 2. 红X错误标记

错误示范用红X覆盖，正确做法另起一格。比"不要这样做"有效得多。

### 3. 四宫格一屏四步

```
步骤1 | 步骤2
步骤3 | 步骤4
```

适合3-4步的实操教程，完播率高于逐步展开。

### 4. 诊断→处方结构

```
你的症状（一蒸就爆）
  → 原因（葱姜水加多了）
    → 处方（4步操作）
      → 总结清单（5条checklist）
        → 延伸场景（空气炸锅）
          → 评论CTA
```

完整的"问题解决"链路，每一步都有明确功能。

### 5. 具体温度/比例

```
7-8分满、80°C、180°C、每厘米1孔
```

干货类图文的数字密度=收藏率。
