
## 二、独特亮点

### 1. "绿证=碳存折"比喻

一句话让读者理解碳核算体系。不是"绿证是碳核算体系中的绿色电力消费凭证"——那是政策文件。**"存折"人人懂。**

### 2. 对比算账页（P5）

```
现在签                    以后签
绿证1.12元/张            绿证5.84元/张
年成本≈1.1万             年成本≈5.8万
签3年≈3.4万             签3年≈17.5万
差距：14万。
```

左右两栏，数字对比，一眼看出差距。**不写"建议尽早签"，让数字自己说话。**

### 3. 三层变化框架（P2）

```
① 身份变了：环保标签 → 法定凭证
② 需求变了：出口零散买 → 全行业碳双控
③ 供给变了：随便发 → 五部门规范收紧
```

"不是绿证涨价了。是碳有了价格，绿证就是碳的存折。"——收在概念金句上。
