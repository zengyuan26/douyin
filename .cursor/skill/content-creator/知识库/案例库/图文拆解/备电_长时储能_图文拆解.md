> 选题：星辰新能 Pre-IPO 融资近5亿——长时储能品类的信号

## 一、翻车诊断：5个致命问题

### 问题1：公司为中心，不是观众为中心

```
这篇的叙事主角：星辰新能
爆款图文的叙事主角：读者的认知/决策/钱包
```

封面直接写"星辰新能 Pre-IPO 近5亿"。对不认识这家公司的读者来说，这是一个零信息量的标题。他不是行业里的人，不知道星辰新能是谁，也不关心它融了多少钱。

对比钠电CVC的封面："宁德刚签了60GWh大单"——宁德人人都知道。事件足够大，读者不需要认识谁也能被钩住。

**教训**：公司名只在读者已经认识那家公司时才有效。否则必须用事件/问题/数据开场，公司名作为证据出现，而不是作为钩子。

### 问题2：没有"谁在讲"

四篇正向案例全都有明确的讲述者身份——"刚入行的CVC，边学边干"。长时储能篇从头到尾没有身份锚点。

没有身份 = 读者不知道用什么框架来接收信息。是行业专家在讲？是媒体在报道？是销售在铺垫？不确定 → 防御心态 → 划走。

**教训**：P1或P2必须让读者知道"谁在讲"和"为什么在讲"。

### 问题3：目标人群分裂

```
目标人群：工厂老板（储能选型）+ 投资者/股民（产业链上下游机会）
```

两类人群的信息需求完全不同。工厂老板关心"我要不要上液流、怎么算回本"。投资者关心"产业链上谁值得投"。

同时服务两类人 = 两类人都不满足。工厂老板觉得 P4 产业链跟自己无关，投资者觉得 P3 三张账单太浅。

对比钠电CVC——目标人群清晰：关注新能源投资的从业者。全篇围绕"能不能投+投谁"展开。

**教训**：一篇图文只服务一类人。如果选题天然跨圈层，拆成两篇。

### 问题4：钩子不是痛点

```
封面钩子：一轮融资就是一次站队。这一局，谁上桌了？
```

这句话的预设是"读者关心谁能上桌"。但大部分读者连桌子在哪都不知道——他不是觉得"我也该上桌"，而是"这跟我有什么关系"。

对比：
- 钠电CVC：宁德签大单→能不能投？（决策问题，人人会问）
- 绿证：1块涨到5块8→你以为环保情怀？（认知反转，人人好奇）
- AI耗电：卡在99%→不是服务器？（集体痛点，人人经历过）

长时储能：融资5亿→谁上桌了？（......我连公司都不认识，问我谁上桌？）

**教训**：钩子必须基于读者已经有的问题/痛点/好奇心。不能假设读者关心你关心的事。

### 问题5：收尾无行动驱动

```
最后一页：信号看完了。等下一张牌。
```

"等下一张牌"——主动告诉读者不要行动，等着。对比钠电CVC的"门票价格还没开始涨"和绿证的"现在签vs以后签差14万"——都在制造"现在就要关注/行动"的紧迫感。

**教训**：收尾必须有行动暗示。可以是CTA（私信）、可以是判断（我觉得该投X）、可以是紧迫感（现在不看就晚了）。"等等看"是图文层面的弃权。

## 二、做对了什么（不是全盘否定）

### 视觉创新

每页是真实物理场景摄影（木桌/黄铜铭牌/玻璃展板/蓝图/仪表盘），而不是抽象排版。这个方向本身有辨识度——比纯色背景+文字排版更有质感。

问题在于：**画面美但跟内容情绪脱节**。暗色木桌+黄铜仪表的质感是"沉稳、严肃、远距离"，但长时储能的内容需要的是"机会、信号、别错过"。

### 三张账单框架（P3）

```
峰谷套利 → 锂电
需量管理 → 4h+ 看液流
离网备电 → 液流
```

这三张账单是整篇最接近爆款逻辑的一页——按用电场景匹配技术路线，工厂老板能直接对号入座。但这个好框架被放在 P3 而不是 P2，被品类分化的抽象概念隔断了。

## 三、如果要重做，怎么改

### 新封面钩子

```
现在：星辰新能 Pre-IPO 近5亿。一轮融资就是一次站队。
改为：同样装储能，有人3年回本，有人8年还没回。差别在哪？
```

钩子从"一家公司融资了"变成"一个工厂老板都会问的问题"。

### 新结构

```
P1 钩子 → "同样装储能，回本差5年。不是运气。是选的时长。"
P2 结论 → 三张账单直接放P2（峰谷/需量/备电→锂电/4h液流/液流）
P3 信号 → "液流赛道刚拿近5亿——不是一家公司的事，是品类在分化"
P4 产业链 → 从钒矿到电站，谁有定价权（公司名作为证据出现，不是主角）
P5 坎 → 初始投资+30~50%，钒价波动±40%。不是替代，是场景选择
P6 CTA → "你工厂的用电曲线，适合锂电还是液流？私信「算账」"
```

核心改动：
- 公司从封面主角变成中间页证据
- 三张账单从P3提前到P2（直接给答案）
- 增加身份锚点
- 收尾从"等等看"变"私信帮你算"

## 四、反面案例的 5 条避坑铁律
