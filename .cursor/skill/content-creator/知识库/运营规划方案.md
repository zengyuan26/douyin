## 一、核心定位

### 一句话

**成过败过。判断力是摔出来的，不是学出来的。**

14年创业实战，产业私募基金负责人。帮高耗能制造企业做微电网+AI技改→资产证券化退出。

不招居间人。不做居间人。

### 信任路径（vs 朱莉娅）

朱莉娅：判断先行 → 概念命名 → 六类权威弹药扫射 → 落观众。信任来自判断力+弹药密度+跨域连接，零个人经历也能成立。

增元走两条路：
- **Track A** 同构朱莉娅模式——判断力输出，六类权威交叉扫射。信任来自"这人能看到我看不到的连接"。
- **Track B** 增元独占——坐在投行椅子上看到信号→翻译成谁会睡不着觉→判断→落观众。信任来自"这人在那个房间里，我没在"。

朱莉娅需要10篇稿子建立信任。增元的Track B可能只需要2篇——只要那2篇讲的是"我经历过"。Track A的信任来自判断本身的锋利程度和弹药的密度。

**信任壁垒**：工厂老板同时反感两类人——卖设备的销售、空谈金融的投行。增元站在中间——既懂窑炉温度、熔炼负荷、错峰生产，又懂REITs结构、ABS打包、Carry分成。两边的人都觉得你是自己人。这是任何纯内容创作者无法复制的信任路径。

### 为什么是你

| 层 | 能力 | 观众看到什么 |
|------|------|------|
| 经历的形状 | 不是"成功"，是"重新开局的能力"。换了4个赛道，每次都从零重新开局 | 当他说"这个生意会死"，不是在分析，是在回忆 |
| 双重视角 | 操作者×投资者。14年自己做生意+现在做CVC投资 | 做生意的人觉得"他真干过"，做投资的人觉得"他判断准" |
| AI原生 | 不是讲AI，是用AI改过命。帮母亲做到全县第一 | 讲AI是"工具×判断力"的乘积效应。AI不是主角，判断力才是 |
| 草根×精英 | 草根路线翻身上来+现在在资本系统里 | 能讲底层怎么翻身、能讲资本怎么运作、能讲两个世界怎么互相看不懂 |

**组合公式**：14年实战操作者 × CVC投资人视角 × AI工具改过命 × 四次重新开局 × 草根进精英系统 = 中国内容赛道里找不到第二个人。

### 框架的来处顺序（关键差异）

```
朱莉娅：先学框架 → 用框架看世界 → 写成内容
增元：  先摔出直觉 → 回头发现"原来芒格也这么说" → 用芒格的话包装自己的直觉
```

增元的内容结构应该是：
```
真问题 → 我的判断（摔出来的）→ 回头验证（原来某某人也这么说过）→ 你能拿走用
```
不是：
```
某某框架 → 用框架分析 → 举例 → 结论
```

                    │  第3层：行业判断    │  ← CVC视角，不限新能源
                    │  （行业信号/政策翻译/趋势拆解）│     新能源/AI/消费/科技都有

## 四、内容四象限

### 四象限框架

```
                          看外部（项目/机会/行业）
                ┌──────────────────────────┐
         框架   │  行业判断               │  框架判断              │
         拆解   │  多行业信号（不限新能源）  │  投资框架/商业判断     │
                │  政策翻译/趋势拆解      │  跨领域思维模型        │
                │                          │  芒格式认知工具        │
                ├──────────────────────────┤
         故事   │  实战判断               │  来处判断              │
         经历   │  项目案例/帮人看项目     │  来时路/身边人故事     │
                │  交易结构/融资包装      │  经典拆解→框架        │
                │                          │  读书快拆/认知分享     │
                └──────────────────────────┘
                          看内部（人/自己/认知）
```

**两条轴**：
- **横轴**：看外部（项目/机会/行业）↔ 看内部（人/自己/认知）
- **纵轴**：框架拆解（给方法给判断）↔ 故事经历（给信任给共鸣）

### 四个象限详解

| 象限 | 是什么 | 内容举例 |
|------|------|------|
| **行业判断** | 多行业信号（不限新能源）。用CVC视角看行业变化 | 利率→你的房贷、AI写代码→技能贬值、芯片管制→供应链、分时电价→电费单 |
| **框架判断** | 投资框架、商业底层逻辑、芒格式思维模型。不限行业 | 定价权/护城河/安全边际/反过来想/杠杆的四种形态 |
| **实战判断** | 帮人看项目的判断、交易结构拆解。主角是老板/普通人，不是你自己 | 预制菜老板融资被一个问题沉默、两个工厂估值差10倍 |
| **来处判断** | 判断力从哪来：经历、身边人案例、经典拆解、认知分享 | 四次从零开始、读芒格拆解、身边人选错的教训、三件事拼成一个判断 |

### 新能源含量控制

**新能源/微电网内容占比不超过25%**（一周最多1-2条）。被贴"能源博主"的标签 = 天花板到了。
新能源/微电网是你的弹药库之一，不是你的人设。你的人设是"判断力"和"帮高耗能制造业老板看清资产方向"。

### 四象限 → 三维度映射

每个选题必须落进钱/关系/认知至少一个领域：

| 象限 | 默认落领域 | 翻译方向 |
|------|-----------|----------|
| 行业判断 | **钱** | 不讲"XX政策意味着什么"，讲"你的电费/成本/利润会怎么变" |
| 框架判断 | **钱** 或 **认知** | 不讲"XX思维模型"，讲"你看项目总不对劲，一个方法让你看穿" |
| 实战判断 | **钱** 或 **关系** | 不讲"项目进展"，讲"EMC从签字到回款踩过的坑" |
| 来处判断 | **关系** 或 **认知** | 不讲"我的经历"，讲"你觉得到谷底了？谷底下面还有坑，但有一条路能上来" |

## 五、受众分层

### 核心受众

**顶层："想拥有专家视角但不需要成为专家"的人**。上过大学但不深耕，知道量子物理没读过论文。不满足于"怎么做"，想知道"为什么"和"底层是什么"。崇拜西方科学但也自豪东方智慧。基数最大，传播发动机。

**底层：高耗能制造业老板**（水泥/压铸/玻璃/陶瓷/化工/锻造）。看到项目判断力、交易结构设计、资产证券化路径。目标客户。原中层（100-500万中小企业主）和底层（>500万高净值企业主）合并——不管资产量级，只要是高耗能工厂老板就是同一个目标客户。

```
公开内容 → 底层认知（所有层级通用）
  ├── "想拥有专家视角但不需要成为专家"的人（<100万）：看到判断方法、获得解释框架、建立信任。传播发动机。
  └── 高耗能制造业老板（水泥/压铸/玻璃/陶瓷/化工/锻造）：看到项目判断力、交易结构、资产证券化路径。目标客户。
```

### 内容策略

- **公开内容不做人群分层**。同一期内容，不同层级各取所需。
- **高价值内容进私域/圈子**——项目机会、交易结构细节、具体判断。
- **知识产品（书/课程/工具）不主动推**，用户来问才有。
- **企业融资包装**——有融资需求的高耗能工厂老板找过来，微电网+AI机器人+AI培训→形成稳定现金流→打包ABS/REITs退出。

## 六、内容原则

```
□ 选题第一性原理：流量第一性原理是选题，选题第一性原理是共鸣。不是"这个行业趋势值得讲"，是"谁在因为这个睡不着觉"
□ 三维度过滤（钱/关系/认知）：每个选题必须落进至少一个领域。落不进去就不发
□ 行业信号→真问题翻译：看到信号第一问不是"意味着什么"，是"会让谁睡不着觉"
□ Step 0 开局决策：每个选题先定分析线/感受线/混合线，再选结构类型
□ 生活化翻译是必过层：每篇必须用日常场景（餐厅/谈恋爱/开车/买房）翻译硬概念
□ 框架的来处顺序：先摔出直觉 → 回头验证 → 提炼框架。不从框架出发，从真问题出发
□ 新能源占比≤25%：弹药库之一不是唯一。被贴标签=天花板来了
□ 不讲"我的项目"，讲"我见过的判断"：主角是老板/普通人，不是你自己
□ 信任是第一优先。每一期内容结束问：观众更信任我的判断力了吗？
□ 来处判断是冷启动底盘——先让人知道你判断力哪来的，再展示判断力
□ 跨界视角是核心武器——实战+框架+AI+CVC，四个视角叠在一起
□ 判断先冲出来，框架只是工具。不是先搭框架再给判断，是先给判断再用框架解释
□ 不堆数据，不堆术语，不堆框架名称。数据是弹药，一枪一发，打完就走
□ 层层追问到机制层。新闻是起点不是素材，不把新闻直接丢给AI生成
□ 不懂不发。自己没搞明白的内容不出
□ 不招居间人。不提居间人。内容里不出现这个词
□ 记录即资产——每次发布后提取概念/数据/判断到 Obsidian 知识库
```

## 七、最重要的10条创作纪律

1. **从真问题出发，不从行业信号出发**。观众心里已有的困惑 > 你想告诉他的信息
2. **每条必须经过生活化翻译**。不用生活化的例子 = 没有在跟观众说话
3. **判断先冲出来，框架只是工具**。不是先搭框架再给判断，是先给判断再用框架解释
4. **新能源是弹药库之一，不是唯一**。被贴标签 = 天花板来了
5. **不讲"我的项目"，讲"我见过的判断"**。你是提供判断的人，不是推销公司的人
6. **每篇留一句替观众总结感受的判断句**（认可 = 点赞发动机）
7. **每篇留一个可讨论的方法论口子**（槽点 = 评论发动机）
8. **每篇留一句观众想转给别人的金句**（嘴替 = 转发发动机）
9. **不堆数据，不堆术语，不堆框架名称**。数据是弹药，一枪一发，打完就走
10. **信任是第一指标**。不是播放量、不是粉丝数——是"这一期结束后，观众更信任你了吗？"

## 八、快速自检清单（写完每篇稿子逐条过）

```
□ 钩子：是从一个人的真问题出发的吗？（不是行业事件、不是书、不是概念）
□ 翻译：有没有用生活化类比讲核心概念？（餐厅/谈恋爱/开车/买房）
□ 判断：核心判断句在第几段？太靠后了吗？（应该在中间偏前）
□ 情绪：定好了起点→终点情绪弧线了吗？
□ 认可：有没有"替观众总结他自己感受"的判断句？
□ 槽点：有没有留一个方法论上的可讨论空间？
□ 嘴替：有没有一句"观众想转给别人看"的金句？
□ 信任：看完这一篇，观众会觉得这个人更值得信任吗？
□ 自嗨检查：有没有出现"我的项目""我的公司""我们这行"？
□ 新能源检查：如果这篇讲新能源，有没有被框死的风险？能不能换个生活化角度？
```

## 十一、实战项目怎么讲（不做自嗨）

```
❌ 自嗨式："我们在巴南落地了微电网项目，用了18层套利模式……"
✅ 判断式："我见过一个工厂老板，电费一年200万。他找了3家售电公司报价，选了最便宜那家。一年后电费涨到260万——不是电价涨了，是他的用电习惯被人摸透了。"
```

**讲法规则**：
- 主角是老板/普通人，不是你——你在幕后，判断是箭头
- 给的是判断，不是项目描述——观众拿走的是"我也该检查一下"
- 生活化类比兜底——哪怕是讲EMC，也用"婚前协议"翻译
- 每篇只一个核心判断——不要一篇里面塞18层套利+代理购电+微电网+碳交易

## 十三、日更节奏：三层金字塔

### 核心理念

日更 ≠ 追热点。日更 = 每天收集信息，每天拼框架，每天给判断。爆款是偶尔的烟花，日常是地基。

| 目标 | 需要什么 | 频率 |
|------|---------|------|
| 引流（让人看到你） | 爆款，追热点 | 偶尔，月1-2条 |
| 留人（让人记住你） | 稳定、有规律、能预期 | 每天，轻量 |
| 建信（让人信任你） | 深度、有判断、有来处 | 每周，1条深度 |

### 三层结构

```
第一层  每日学习笔记（轻量·地基·日更）
        100-200字图文卡片，5分钟写完。
        每天学到的信息拼成判断就是内容，不需要额外创作。

第二层  每周深度一条（中量·信任锚·周更）
        行业信号深拆/框架判断/项目复盘/经典拆解。
        30-60分钟，有框架有判断。

第三层  每月爆款一条（重量·引流口·月更）
        追大热点，用跨界框架给出别人给不了的判断。
        时机到了才发，不强求。
```

### 学习笔记固定格式

```
🔋 学习笔记 | #XX

一句话判断：XX就是……

今天看到了XX → 拼上之前知道的YY → 给出一个判断：……

#学习笔记 #判断力 #框架思维
```
