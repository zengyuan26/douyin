> v6.0 | 2026-08-12
> 跨行业内容生产与获客引擎。一份通用流程，多份项目 config，无限内容资产。

---

## 一、系统概览

母系统解决一个问题：**你做多个账号/多个行业的内容，不用每次从头想流程。**

架构 = **1 个母系统（通用创作流程）+ N 个项目单元（config 定义差异）。**

```
母系统（skill.md）
  ├─ 4 阶段创作流水线（0→1→2→3→4）
  ├─ 3 轨道路由（Track A 认知判断 / Track B 行业信号 / Track C 身份定位）
  └─ 知识库（方法论文库 + 案例库 + 规则库 + 通用框架）

项目单元（项目/<项目名>/）
  ├─ config.md        ← 身份/受众/声音/合规/恐惧池/标杆
  ├─ 选题池.md
  ├─ 案例资产/
  └─ 输出/（内容台账 + 脚本 + 物料）
```

**核心理念**：每次创作 = 加载项目 config → 走通用 4 阶段流程 → 产出内容 + 提取资产。

## 三、核心概念

### 3.1 项目分级

| 级别 | 定义 | 成本 | 每个项目必做 |
|------|------|------|------------|
| L0 候选 | 看到信号，记录到选题池 | 零 | 无 |
| L1 轻实验 | 3-5 期验证钩子/受众/转化 | 3-5 篇 | 选题池 + 台账 |
| L2 MVP | 跑通全流程（30-60天） | 持续 | 完整 config + 台账 + 资产提取 |
| L3 长期资产 | 持续产出 + 商业化收益权 | 持续 | 全部 5 类资产 |

### 3.2 Config 驱动

所有创作参数由 `项目/<项目名>/config.md` 定义：
- **身份**：一句话定位、权威来源、不可复制性
- **受众漏斗**：L1-L4 四层 + 圈层钩子关键词
- **声音/语域**：朱莉娅/路边大哥 + 术语策略 + 禁止语域
- **合规规则**：敏感词替代表、CTA 限制、免责声明
- **恐惧池**：六池映射 + 选题偏好
- **标杆/对标**：领域标杆账号 + 类型标杆变体

母系统只提供流程。身份是谁、对谁说话、什么不能说——全是 config 的事。

### 3.3 三轨创作

| | Track A | Track B | Track C |
|------|------|------|------|
| 判断从哪来 | 我对世界有看法 | 我在行业看到信号 | 我见过足够多人卡在同一个地方 |
| 典型结构 | 反常识阶梯 | 信号翻译→机制推导 | 清单骨架（场景归位→算账收束） |
| 声音 | 朱莉娅（高处） | 偏朱莉娅 | 路边大哥（旁边） |
| 钩子开头 | 纯判断句 | 翻译：谁会睡不着觉 | 日常场景画面 |

### 3.4 五类资产

一个项目结束后只拿到钱 = 劳动。拿到模板/框架/案例 = 资产。
详见 `资产提取规则.md`。

## 四、新建项目（Step by Step）

### 第一步：填写立项卡

对照 `项目评估方法论.md` 的立项资格 6 条，确认项目成立。填写：
- 项目名、定位、受众、商业模式
- 表达者、你的角色
- 风险分级、退出阈值
- 首批 3 期选题

### 第二步：创建 config

```bash
cp 母系统/config.template.md 项目/<项目名>/config.md
```

逐节填写。**最小可启动配置**：0-6 节（元信息、身份、受众、声音、配比、合规）。

### 第三步：创建目录

```
项目/<项目名>/
├── config.md
├── 选题池.md
└── 输出/
    └── 内容台账.md  # 按 母系统/内容台账模板.md 格式
```

### 第四步：首次创作

对 Claude 说："用 content-creator，项目 <项目名>，选题是 XXX"

母系统自动：
1. 加载 `项目/<项目名>/config.md`
2. 走 4 阶段 30+ 步骤流程
3. 定稿后回写台账

## 五、创作流程速览

```
阶段零 · 选题加工（8 步）
  加载 config → 自问三句 → 信任闸门 → 识别输入 → 讨论加工
  → 产业链分析 → 轨道路由 → 六池自检 → 选题卡入库

阶段一 · 开局（7 步）
  开局决策 → 感受翻译 → 锁定受众 → 对抗力量定位
  → 定位闸门 → 层层追问 → 不懂不发闸门

阶段二 · 准备（12 步）
  锁定标杆 → 信任复利 → 声线+情绪 → 独家价值 → 锚点重量
  → 钩子锚 → 恐惧线 → 列框架 → 对照爆款 → Track C 对照
  → 弹药选择 → 弹药定位句

阶段三 · 生成（4 步）
  导演分析 → 分镜预设 → 逐页/逐镜生成 → 反常识阶梯标注

阶段四 · 发布前（6 步）
  15 项自检 → 口语化终审 → 朗读自检 → 延伸话题
  → 回写选题池 → 知识库沉淀
```

两个强制确认点（🔴）：2.8 框架确认、3.1 导演分析确认。

## 六、内容台账

每篇定稿后在 `项目/<项目名>/输出/内容台账.md` 记录一行：

| # | 日期 | 标题 | 类型 | 领域 | 真问题（入口） | 带走什么（出口） | 文件 |
|---|------|------|------|------|---------------|-------------------|------|
| 1 | 2026-08-01 | 逆向选择 | 口播 | 关系 | 为什么追我的人我不想结婚 | 好车不按喇叭——不是你的问题 | [口播](脚本/口播_XX.md) |

**核心约束**：真问题（入口）↔ 带走什么（出口）必须闭合。带走的是判断工具（能对闺蜜说出来），不是自省问题（只能自己想）。

顶部维护三领域统计概览（财富/关系/认知的数量和占比）。

## 七、资产提取与结项

### 日常提取（Step 4.6）

每篇定稿后：
1. 核心概念 → Obsidian `15-财富与认知/`
2. 定稿脚本 → Obsidian `12-项目/<项目名>/输出/`
3. 行业判断 → Obsidian `11-行业与公司/`
4. 新方法论 → Obsidian `13-内容创作/方法论/`

### 结项检查

项目归档前，按 `资产提取规则.md` 五项检查：
- □ 判断框架 ≥1
- □ 标准流程模板 ≥1
- □ 数据资产已更新
- □ 案例资产已归档
- □ 收益权已确认

5 项全过 → 项目资产完整 → 移入 `已结束项目/`。

## 八、常见场景

**Q：现有 config 不满足新项目需求？**
A：修改对应项目 config.md。模板没覆盖的字段可自加。母系统的 config.template.md 是起点不是上限。

**Q：想加一个完全不同的内容类型？**
A：在 `知识库/方法论库/` 下新建方法论文件 → 在 skill.md 知识库路由中添加该类型的加载列表 → 在 `知识库/工作流/类型标杆映射表.md` 注册新类型。

**Q：项目跑不下去了？**
A：对照 config 里的退出阈值 → 达标则执行结项检查 → 移入 `已结束项目/` → 更新 `项目/README.md` 状态。

**Q：临时帮朋友写一篇稿？**
A：不走项目立项。按无 config 模式：临时补齐 config 字段 → 走完整流程 → 不建立台账（除非朋友变长期合作）。

**Q：知识沉淀去了哪？**
A：两个地方——
- douyin 仓库（`项目/<项目名>/`）：完整产出物 + 台账
- Obsidian（`知识库/`）：提取的核心概念/判断/方法论，跨项目可检索

## 九、维护守则

1. **修改 skill.md 前先 git diff**——改动影响所有项目
2. **新增步骤编号遵循现有体系**——0.x=阶段零, 1.x=阶段一, 2.x=阶段二, 3.x=阶段三, 4.x=阶段四
3. **config 字段加"强制/可选"标签**——不让新项目猜哪些必须填
4. **维护日志记录每次变更**——版本号 + 日期 + 改了啥
5. **不推未经用户确认的改动到 GitHub**
