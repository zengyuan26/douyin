# 项目评估方法论

> 母系统强制。新项目立项/旧项目退出必须走本方法论。关联：[[资产提取规则]]

## 目标

最低成本验证一个项目值不值得做。**不立项 ≠ 不做，最贵的决策是启动即烧 50 期内容。**

## 项目分级（风险递进）

| 级别 | 定义 | 成本 | 示例 |
|------|------|------|------|
| **L0 候选** | 有信号、零投入，只记录到选题池 | 0 | 看到某个赛道有流量但不确定 |
| **L1 轻实验** | 3-5 期内容验证钩子/受众/转化 | 3-5 篇脚本 | 风水项目 |
| **L2 MVP** | 跑通可复制的流程（选题→路由→生成→发布→资产提取） | 30-60天 | 儿童成长项目 |
| **L3 长期资产** | 持续内容+资产提取+商业化收益权。常驻 项目/ | 持续投入 | 备电 |

## 立项资格（全部满足才从 L0 升级）

1. **有持续表达者** — 本人 IP 或 商业化合伙人（朋友出镜/交付，你做内容和商业化）
2. **有一手专业信源** — 行业判断力、独特经验、不可复制的背景
3. **商业模式清晰** — 至少一条获客→转化→变现路径
4. **内容能跑 4 阶段流水线** — 选题/开局/准备/生成/发布，不依赖完全定制
5. **资源承诺明确** — 谁出时间/精力/资金，写下来
6. **不稀释主线** — 与现有项目协同或隔离，不影响备电主航道

## 边界（这些不算项目）

- 一次性任务（帮朋友写一篇稿）→ 不立项，走临时任务
- 非内容型业务 → 不归母系统管
- 与现有项目选题池高度重叠 → 合并，不新建
- 无法承诺 3-5 期试产 → 退回 L0

## 退出条件（任一命中即停/归档）

- **内容信号消失** — 连续 N 期无数据反馈（N 在立项卡定义）
- **转化率低于预设阈值** — 内容→咨询→成交，任一环节断链
- **表达者断供** — 出镜/交付方不继续
- **选题池干涸** — 无法持续产出差异化选题
- **收益权无法落地** — 分成谈不拢、协议签不了
- **触发合规红线** — 平台限流/封号/法律风险

满足任一条件 → 移到 已结束项目/，**先按 资产提取规则 跑结项检查**，再归档。
