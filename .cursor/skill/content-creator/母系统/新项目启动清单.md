## 三、两个必须分清的层

### 3.1 爆款案例库：结构层 vs 赛道层

```
结构层标杆（"诊断型怎么搭骨架"）→ 共享：知识库/案例库/爆款拆解/
赛道层标杆（"亲子赛道这篇爆款长啥样"）→ 项目：标杆映射表.md + 案例资产/
```

- 结构手法（三分法递进、反问链、钩子公式）跨赛道通用，复用母系统
- 赛道拆解（亲子头部账号、本项目的爆款复盘）换账号就用不上，必须项目化

### 3.2 个人档案：必须含「声音」章节

config 里只有一句"声音原型"，不够锁住口气。个人档案要单开「声音」章节，落到可执行：

- 方言词库 / 口头禅句式 / 情绪基调 / 禁止语域

否则每篇写稿都靠猜口气（备电的增元档案 39KB，就是完整的表达者资产）。

## 四、缺失提醒机制

创作时用到项目信息、但对应资产缺失 → **提醒补充，不静默跳过**。

| 触发点 | 检查 | 缺失时 |
|---|---|---|
| Step 0.0 加载 config | 按项目分级检查必建资产 | L2+ 缺个人档案/标杆映射表 → 提醒补 |
| Step 2.1 判断类型 | 赛道领域标杆 | 缺标杆映射表 → 提醒补赛道标杆 |
| Step 2.3 声线合约 | 个人档案的「声音」章节 | 缺声音方言库 → 提醒补，口气别靠猜 |

- **L1 轻实验**：只需 config + 选题池 + 台账，不强求个人档案/标杆
- **L2 起**：个人档案 + 标杆映射表是必建，创作前缺了先提醒

## 五、新建项目最小操作

1. `cp 母系统/config.template.md 项目/<项目名>/config.md` → 填 0-6 节
2. 建 `选题池.md`
3. 建 `输出/内容台账.md`（按 母系统/内容台账模板.md）
4. **L2 起**：补 `个人档案.md`（含声音章节）+ `标杆映射表.md`
5. 走 L1 轻实验 → 首篇定稿后开建 `案例资产/`
