# 运营规划方案（模板）

> 母系统标准模板。复制到 `项目/<项目名>/运营规划方案.md` 后逐节填。
> 一句话判断：**定位 → 对谁说话 → 说什么 → 验证什么 → 什么时候退**，五问答完，方案就立住了。
> 字段分级：强制 / 可选。分级：L1 精简 / L2 标准 / L3 完整（见文末对照表）。
> 参考原型：项目/备电/运营规划方案.md（16 章完整版，是 L3 的样板）

---

## 一、核心定位（强制）

- **一句话**：______（谁，帮谁，解决什么问题。备电例：成过败过，帮高耗能制造企业做微电网+AI技改→资产证券化退出）
- **信任路径**：______（观众为什么信。见个人档案第四节）
- **为什么是你 / 不可复制性**：______（换个人做不了的地方）

---

## 二、受众分层（强制）

- **目标客户（付费人）**：______（身份定位，逐字准确）
- **传播发动机（观众，可能≠付费人）**：______（谁在转发扩散）
- **分层维度**：按身份分 / 按资产量级分

> 铁律：受众定位是决策记录，不能靠推演猜。写内容前逐字读 config 第 2 节，禁止凭记忆简写。

---

## 三、内容策略（强制）

- **内容类型**：口播 / 图文 / 短视频 / 长文
- **选题来源**：______（从什么现实问题出发，不是从行业事件出发）
- **声音**：______（见个人档案第五节）

---

## 四、验证目标（强制·分级）

| 阶段 | 验证什么 |
|------|---------|
| L1 轻实验 | 钩子是否成立、受众是否精准、转化是否可行 |
| L2 MVP | 哪类问题产生咨询、哪种形式带来线索、愿意为什么付费、交付能否形成满意案例 |
| L3 长期 | 内容体系化 + 产品化（付费方案/课程/社群）+ 口碑传播 |

**退出阈值**（强制，提前写死，达标即停）：______
> 例：30 天内无有效咨询线索 / 平台违规警告 / 投诉争议 / 表达者无法稳定交付。

---

## 五、阶段规划（强制）

- **当前**：L1 / L2 / L3
- **通过后**：升到哪一级、做什么
- **风险**：______（如风水=平台高风险类目，出现警告即停；需隔离红线——独立账号/独立核算/不关联主品牌）

## 六、内容原则（L3）

选题第一性原理、三维度过滤、生活化翻译必过层……通用原则直接引用母系统，这里写项目专属原则。

## 七、创作纪律（L3）

最重要的 N 条。通用纪律引用母系统，这里写项目专属（如备电「微电网占比≤25%」）。

## 八、自检清单（L3）

写完每篇逐条过。通用清单引用母系统，这里写项目专属项。

## 九、周节奏（L3）

哪天上什么内容、选题来源、轨道轮换。

## 十、阶段配比（L3）

四阶段路线图：冷启动 → 信任建立 → 行业破圈 → 私域转化，每阶段各象限占比。

## 十一、系列选题（L3·可选）

深度系列内容规划（如备电概念图谱 15 期）。

## 十二、互动策略（L3·可选）

评论区怎么回、质疑怎么处理、合作怎么接。
