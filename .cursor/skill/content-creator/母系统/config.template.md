## 2. 受众漏斗（强制）

### 受众战略分层（强制·先写这个）

- **目标客户（付费人）**：____________（身份定位，逐字准确）
- **传播发动机（观众，可能≠付费人）**：____________（谁在转发扩散，逐字准确）
- **分层维度**：按身份分 / 按资产量级分（明确是哪种，别混）

> **铁律**：受众定位是决策记录，不是能靠推演猜出来的东西。写内容前逐字读本字段，禁止凭记忆简写。典型错误：把「想拥有专家视角但不需要成为专家的人」简写成「聪明普通人」——丢失核心动机（身份焦虑：转发=我在思考深刻的东西），受众必错。

### 受众语言层级（各取所需）

- **L1 泛人群**（钩子+例子）：
- **L2 泛商业**（框架+例子）：
- **L3 从业者**（利益点+算账）：
- **L4 专业**（术语直给+"他们不知道的东西"）：
- **圈层钩子表**（圈层 → 关键词）：
- **受众画像（生图用·强制）**：性别/年龄/审美偏好。Image2 生图 prompt 必须参考此字段，让视觉风格贴合目标受众。例："25-40岁女性为主，偏好温暖手工感/真实人物/生活场景，排斥冷冰科技感/数据图表感/男性化硬朗风"。无此字段→视觉可能跑偏到错误人群。
