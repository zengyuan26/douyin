# 内容台账模板

> 母系统强制。每个项目在 `项目/<项目名>/输出/内容台账.md` 维护。
> 每篇定稿后强制记录。领域默认：财富/关系/认知。项目可扩展。

## 台账格式

```
| # | 日期 | 标题 | 类型 | 领域 | 真问题（入口） | 带走什么（出口） | 文件 |
|---|------|------|------|------|---------------|-------------------|------|
| 1 | YYYY-MM-DD | XX | 概念型 | 认知 | XX | XX | [口播](脚本/口播_XX.md) |
```

可选扩展列（项目按需添加）：

```
| 载体 | 数据表现 | 复盘 |
```

## 字段说明

- **类型**：选题阶段确定的结构类型（概念型/诊断型/故事型/框架型/祛魅型 等）
- **领域**：财富 / 关系 / 认知。用于统计内容结构分布
- **真问题（入口）**：钩子对应的真实困惑。一句话。观众点进来之前心里的那句话
- **带走什么（出口）**：看完后脑子里的新东西。框架/判断/概念/视角。一句话
- **文件**：脚本/图文/视频文件的相对路径（相对于 `输出/`）。用 Markdown 链接格式
- **数据表现**（可选）：播放/点赞/评论/收藏/转发。可后续补
- **复盘**（可选）：数据出来后写。为什么爆/为什么凉

## 强制规则

- 定稿即记录。不能事后补
- 真问题 + 带走什么 必须闭合。对不上 = 稿子有问题
- 闭合检查：带走的东西必须直接回答真问题。带走的是判断工具（能对闺蜜说出来），不是自省问题（只能自己想）
- 每季度跑一次领域统计，检查内容结构是否偏离定位
- 废弃/重做内容用删除线标注（`~~内容~~`），不删除记录
