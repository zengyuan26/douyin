## 呼出流程

**Step 0**：开局决策（全类型强制，选题后执行）——选题卡入库后，确认线型和结构类型。

| 决策项 | 选项 | 说明 |
|--------|------|------|
| 线型 | **分析线** / **感受线** / **混合线** | 分析线=数据/机制/判断为主。感受线=情绪/共鸣/替观众说话为主 |
| 比例 | 分析线默认 事实≥60% 态度≤40%。感受线默认 态度≥60% 事实≤40%。混合线各~50% | 这条线观众看完要带走什么？数据判断还是情绪确认？ |
| 结构类型 | **确认/调整**选题卡的建议结构类型 | 不是推荐——选题卡入库时已经绑了建议类型，这里只做最终确认或手动覆盖 |

<a name="结构类型表"></a>

**线型 → 结构类型对照**：

| 线型 | 结构类型 | 代表场景 |
|------|-------------|----------|
| 分析线 | 诊断型 / 框架型 / 验证型 / 模型重塑型 | 钠电CVC、比亚迪、宁德、行业判断、产业链拆解 |
| 感受线 | 祛魅型 / 故事型 / 概念型 | 毒油事件、关系洞察、打破幻觉、替观众命名感受 |
| 混合线 | 跨学科论证型 / 箴言型 | 既有数据弹药又有情绪收束的深度长文 |

感受线 + 图文组合标注：⚠️ **感受线图文适配仍在探索中。** 哎呀朱莉亚式感受线已验证于口播，图文载体下"替观众命名感受"的手法尚未定型。生成前确认是否接受探索版输出。

**Step 0.5**：感受翻译（感受线/混合线强制，分析线跳过）——把真问题用哎呀朱莉亚声音翻译一遍。标准：≤10字/句、句号密度极高、全程"你"。翻译不出来或翻译完不像"这就是我"→ 真问题还没找到 → 回到 Step 0 重定线型或选题。

```
分析脑输出 → 感受脑翻译
"观众不理解标准对比" → "每次出事你第一反应是等反转"
"验收标准被改了10倍" → "你想问谁批的。但你知道问了也没人答"
```

自检：读完钩子，第一反应是"对，这就是我"还是"哦，原来是这样"？前者通过。后者重写。

**Step 1**：自动加载信息——读取运营规划、客户档案、行业分析。

## 阶段零：素材加工 → 选题入库

**没有原材料 → 不推荐选题，不进入下一步。**

**冷启动触发器**——不知道聊什么的时候，翻这六个问题：

- 看到了什么让你停下来的事/热点新闻？
- 最近看了什么书/电影/文章？
- 刷到了什么有趣的博主/观点？
- 跟谁聊天让你觉得"这个问题不止他一个人有"？
- 自己遇到了什么反复想的事？
- 行业里出了什么信号你觉得不止是新闻？

### Step 0.0：信任与数字资产闸门（强制前置）

所有内容的目的是建立数字资产，围绕信任。进入阶段零加工前，先过这道闸门。

**判据——四条问自己：**

| # | 判据 | 问法 | 通过标准 |
|---|------|------|----------|
| 1 | **时间抗衰性** | 一年后有人翻出来看，还成立吗？ | 框架/判断/机制层的东西不会过期。纯信息/蹭热点/新闻播报→不过 |
| 2 | **判断密度** | 观众看完拿走的是一个判断框架，还是一个知识？ | 判断框架→数字资产。纯知识/冷知识/趣味事实→不是资产，是消耗品 |
| 3 | **人设复利** | 这期发出去，陌生人看完会更想找你聊吗？ | "这人能帮我看清东西"→资产在涨。"这人懂挺多"→资产没涨 |
| 4 | **来的方向** | 核心判断来自你的经历/观察/交手，还是来自别人的文章/新闻/二手信息？ | 一手经历+判断→壁垒。纯转述别人的框架→没有壁垒，谁都能讲 |

四条全过 → 进入 Step 0.1。任一条不过 → **不发**。宁可不发，不发消耗品。

这不是选题质量判断——质量在后面的 20 步里验证。这道闸门只判断一件事：**这个东西发出去，是在往信任账户里存钱，还是在取钱。**

### Step 0.05：轨道决策（强制，Step 0.0 通过后执行）

信任闸门过了，判断这条内容走哪条创作轨道。

| | Track A：认知判断 | Track B：行业信号 |
|------|------|------|
| **判断从哪来** | 我对世界/人性/市场有一个看法 | 我在行业位置上看到了信号 |
| **信任靠什么** | 判断力 + 弹药密度 + 跨域连接 | 行业入场券 + 亲身经历 + 判断力 |
| **案例弹药** | 六类权威交叉扫射（科学/东方经典/西方哲学/商业符号/历史事件/文学） | 行业案例 + 项目见闻 + 数据 + 六类权威辅助 |
| **个人经历** | 可选，不强制 | 经常需要（来时路/项目路） |
| **适合类型** | 口播脚本、A型图文 | 口播脚本、A型图文、清单体 |
| **顶层怎么进** | 钩子天然人人中枪 | 钩子需要翻译——信号→谁会睡不着觉 |
| **话题生命周期** | 常青判断为主 | 信号驱动 + 常青判断 |

**决策规则：**

1. 判断来自对世界/人性/市场的观察？→ **Track A**。从"我的判断是什么"开始。
2. 判断来自坐在投行椅子上看到的信号/项目/交易？→ **Track B**。从"这个信号会让谁睡不着觉"开始。
3. 两边都有 → **默认 Track A**。行业触觉当弹药使，不当前台。

详见下方 Step 0.2 分轨入口。

### Step 0.1：识别输入类型

用户丢进来的原材料分三种，加工路径不同：

| 类型 | 输入形式 | 加工路径 |
|------|----------|----------|
| **A. 碎片** | 看到的事件/想到的话题/聊到的信号 | Step 0.05 轨道决策 → 进入 Track A 或 B 的起点 |
| **B. 外部内容** | 别人的稿子/文章/视频 | Step 0.05 轨道决策 → Track A 提取判断 → 概念命名；或 Track B 提取信号 |
| **C. 自己的草稿** | 用户写的半成品稿子 | Step 0.05 轨道决策 → 提取判断 → 重构真问题+角度 → 重写 |

### Step 0.2：讨论加工

四段递进：需求端（谁痛）→ 问题深挖（障碍、代价和出路）→ 供给端（为什么是我来说）→ 市场端（外部差异化窗口）。需求端起点的 Step 1 分两轨：Track A 认知判断（形成判断→概念命名）或 Track B 行业信号（识别信号→翻译→提取概念），汇合后走共享步骤 2-8。三道闸门：Step 0.0 信任/资产 → Step 0.05 轨道路由 → Step 8 共鸣预检。

**Track A（认知判断）——A1. 形成初始判断**

不是"它讲了什么概念"。是"我对这件事的判断是什么"。

**判断 → 概念。不是概念 → 判断。**

| 不是这样 | 是这样 |
|------|------|
| 我要讲"解释权"这个概念 | 我觉得控制世界的不是有钱人有权人，是能解释一切的人 |
| 我要讲"市场规模陷阱" | 我觉得正确决定本身就是陷阱——你做对了每一步，然后死了 |
| 我要讲"感情阶级" | 我觉得感情走不下去不是不够好，是你在跟低级情感能力的人谈高级需求 |

判断是你对世界的看法。不是从书里读到的，是你本来就有的——只是需要一个外部素材来触发它浮上来。

**Track A——A2. 概念命名**

给自己的判断起一个名字。一个词或短语。这个名字就是本期内容的核心概念。

| 判断 | 命名 |
|------|------|
| 控制世界的是能解释一切的人 | **解释权** |
| 改变世界的人不追成功，他们在修行 | **入世/出世** |
| 正确决定本身就是陷阱 | **市场规模陷阱** |
| 感情走不下去是因为情感能力的层级不匹配 | **感情阶级** |

概念是工具，判断是武器。概念服务于判断，不是反过来。

命名后 → 进入共享 Step 2（维度穷举）。

---

**Track B（行业信号）——B1. 识别信号**

行业里在发生什么变化？这个信号/事件/数据在说什么？不是"什么意思"，是"什么正在改变"。

**Track B——B2. 翻译：谁会睡不着觉**

把信号翻译成顶层受众能感受到的痛。**不做翻译 = 只在行业圈传。**

| 信号 | 翻译 |
|------|------|
| 钠电CVC策略调整 | 每个人都以为钠电要爆了，但我在会议室里看到的是另一件事 |
| 储能区域格局变化 | 一个省的政策变了，三个省的投资全白费 |
| 某公司砍掉整条业务线 | 你做的每一个正确决定，都在给对手送练兵场 |

**Track B——B3. 提取核心概念**

翻译之后，这个东西在讲什么概念？用一句话能说出来。

命名后 → 进入共享 Step 2（维度穷举）。

---

**共享 Step——以下两轨共用**

**2. 概念 → 维度穷举（强制）**

一个概念能切进几个维度？每个维度对应不同人群、不同真问题。先穷举再选。

| 维度 | 问法 | 判断标准 |
|------|------|----------|
| **钱** | 跟挣钱/守钱/传钱有关吗？ | 观众拿走的是"我该怎么操作" |
| **关系** | 跟人之间的绑定/信任/冲突有关吗？ | 观众拿走的是"我该跟谁站在一起" |
| **认知** | 跟看世界的方式/打破幻觉有关吗？ | 观众拿走的是"原来我是这样想的" |

示例——市场规模陷阱：

| 维度 | 能讲吗 | 对应人群 | 真问题方向 |
|------|------|------|------|
| **认知** | ✓ | 三层都有 | 你不是在选择——有台机器在替你算 |
| **钱** | ✓ | 股民、企业主 | 每次操作都对但账户没变 / 砍业务都对但生意变窄 |
| **关系** | ✓ | 企业主、高净值 | 大客户在替你选业务方向 |

一个概念 → 多个维度 → 多篇内容。每篇只打一个维度。大部分概念只能打一个维度，不强求。

**3. 选本期维度**

选一个主力维度。标准：哪个维度覆盖的顶层受众（"想拥有专家视角但不需要成为专家"的人）最广、最痛。

**4. 按资产量级锁定受众层（强制）**

维度定了，再从漏斗顶端穷举受众。没有外围观众就没有启动数据。

| 资产层 | 谁 | 体量 | 角色 |
|--------|------|------|------|
| <100万 可投资产 | "想拥有专家视角但不需要成为专家"的人 | 最大 | 传播发动机。上过大学但不深耕，知道量子物理没读过论文。不想被当普通人，想知道"为什么"和"底层是什么"。崇拜西方科学但也自豪东方智慧。转发=我在思考深刻的东西 |
| 100-500万 可投资产 | 中小企业主 | 中等 | 潜在客户。看项目判断力，被筛进圈子 |
| >500万 可投资产 | 高净值企业主 | 最少 | 高价值客户。看格局和传承，主动来找 |

**钩子必须覆盖顶层。** 顶层打不中→启动数据为零→算法不推→下面两层也看不到你。

详见 memory `audience-asset-funnel`。

**5. 在本维度内穷举真问题（强制）——每层受众对应一层的痛**

维度 + 受众都定了，再穷举真问题。真问题是整条链的起点——决定对抗力量层次、钩子方向、情绪弧线起点、锚点场景。真问题错了，后面全错。

示例——市场规模陷阱，认知维度：

| 受众层 | 真问题 | 什么时候痛 | 程度 |
|--------|--------|-----------|------|
| 股民/普通人（<100万） | 不是你在选股，是情绪在替你选 | 打开收益曲线，每次都"看对了没做对" | 酸痛 |
| 中小企业主（100-500万） | 你不是在选择业务方向，是大客户在替你选 | 大客户说今年预算砍半，你无路可退 | 刺痛 |
| 高净值企业主（>500万） | 不是不想变，是每次算都对。然后十年没变 | 看同行转行成功，自己还在原地 | 后怕 |

**6. 真问题压力测试（强制，靶心层必须四道全过）**

| # | 测试 | 问法 | 通过标准 |
|---|------|------|----------|
| 1 | **谁能对上** | 这个真问题说出来，谁会在屏幕前停下来？ | 能说出一个具体的人：不是"泛商业人群"，是"33岁在工位上算年终奖发现每条路都算对了但就是觉得哪里不对的人" |
| 2 | **什么时候痛** | 这个痛在什么具体时刻发作？ | 能说出一个场景：不是"做决策时"，是"周一早上打开电脑看到隔壁工位空了，那个人去搞AI了" |
| 3 | **他试过什么** | 他为这个痛做过什么但没用？ | 能说出一个动作：不是"想过转行"，是"刷了三个月招聘网站，最后关掉了，因为算了一下跳槽涨30%但新行业降40%" |
| 4 | **不说会怎样** | 如果没有人替他说出来，他会继续怎样？ | 能说出一个后果：不是"继续痛苦"，是"三年后还在同一张椅子上，菜单只剩三碗面，然后告诉自己这是成熟" |

四道全过 → 真问题成立。任一道卡住 → 真问题还没找到 → 回退到穷举层重新选靶。

**7. 定位观众 + 确定角度**

真问题定了，受众自然就出来了——谁痛就是谁。角度就是"我们从哪一层打进去"。本期选的是哪个维度，结尾就落哪个维度。

**8. 共鸣预检（五维快速版，需求端末尾强制）**

需求端走完，选题是否成立？五维快速扫一遍。一个不过→回退重新选靶心或换维度。

| # | 检查项 | 问法 | 通过标准 |
|---|--------|------|----------|
| 1 | **流量** | 钩子方向 3 秒刺得进去吗？ | 能说出观众停在屏幕前的那个感受 |
| 2 | **点赞** | 真问题说出来是"这就是我"还是"哦"？ | "这就是我"——被替他说出来了 |
| 3 | **评论** | 有没有天然槽点？ | 方法论争议，安全分歧区。门槛低到任何人能搭话 |
| 4 | **转发** | 看完会想转给谁？ | 能说出一个具体的人：合伙人/同事/一起做决定的人 |
| 5 | **情绪** | 起点→终点有弧线空间吗？ | 不是平的。有转折有降落。能画出一条完整曲线 |

五维全过 → 选题成立 → 继续往下走。任一项卡住→回退。

**问题深挖——为什么一直没解决，障碍、代价和出路**

**9. 常识 → 反常识（强制）**

反常识是钩子的原材料。不搞清楚常识是什么，反常识就是自说自话。

```
常识：做正确决定 = 好的
反常识：正确决定本身就是陷阱

常识：听客户的话 = 对的
反常识：客户说真话，但真话指向昨天

常识：我在优化人生
反常识：一台机器在替你优化，你不是在选
```

反常识建立后 → 开场方向自然出来。

**10. 定位冲突类型（强制）**

痛点发生在哪里？决定情绪质地和叙事空间。

| 冲突发生在 | 例子 | 情绪质地 |
|------------|------|----------|
| **人与自己** | "你心里有一台机器在替你算" | 内省、安静、后怕 |
| **人与系统** | "不是你不努力，是分配规则就不让你看见那个市场" | 揭露、清醒、愤怒 |
| **人与人** | "你说服不了你的老板，因为他也在被同一台机器算" | 无奈、对抗、理解 |
| **人与环境** | "整个行业都在砍菜单，你不砍就是异类" | 孤立、压力、站队 |

市场规模陷阱是**人与自己**——冲突不在伯利恒的会议室，在观众脑子里那台按确定性分配的机器。这个判断直接影响开场：不是讲别人怎么死的，是让你看见自己也在做一模一样的事。

**11. 为什么一直没解决**

挖掘障碍的根。以市场规模陷阱为例：

- 不是对抗愚蠢，是对抗聪明。"正确决定"在当下就是对的——你在 1985 年没法证明 3.5 寸硬盘有未来。客户说不要，数据说不划算，所有人说对。
- 越聪明的系统越难自我纠正。希捷工程师在实验室做出了原型机——颠覆他的东西他自己先造了出来。还是没推出去。

障碍的本质：不是信息不够，是"对"的反馈太强。

**12. 解决的难度**

| 难度层 | 问题 | 例子 |
|--------|------|------|
| **技术难度** | 这事能做吗？ | 希捷工程师做出了 3.5 寸原型机——技术不难 |
| **认知难度** | 你敢信吗？ | 在所有人都说"对"的时候，相信一个看起来错的东西 |
| **系统难度** | 你推得动吗？ | 资源分配机器不让你投那个只赚 7% 的市场 |

三层难度定位 → 观众知道这不是"努力一下就行"的事。

**13. 替代方案与代价**

| | 不解决 | 解决 |
|------|------|------|
| 短期 | 安全、确定、赚钱 | 可能浪费时间、可能失败、别人眼里"不务正业" |
| 长期 | 菜单只剩三碗面 | 可能还是失败。但至少名字还记得 |

代价不是一边全好一边全坏——两边都痛。这就是收尾两难的原材料。

**14. 相关资源推荐**

根据选题方向，搜索并推荐能帮观众继续深挖的资源。不是为了堆参考文献，是为"真想往下走的人"指路。

| 方向 | 什么资源 | 例 |
|------|----------|-----|
| 项目相关 | 行业里正在发生的事/案例 | 亚马逊 Kindle 团队独立于总部运营 |
| 认知相关 | 框架/书/概念 | 《创新者的窘境》克里斯坦森 |
| 信息差相关 | 别人不知道但知道了会不一样的事 | 希捷花 10 亿美元买回原型机的细节 |
| 金融/商业相关 | 交易结构/模式 | 独立小组织怎么分钱、怎么不被母公司渗入 |
| 创作相关 | 这个话题怎么写/怎么拍 | 案例库中对标作品的叙事手法 |
| 方法论 | 可操作的步骤/工具 | "划一块不受值不值得管的时间" |

选 2-3 个最相关的方向推荐。这些资源可能在内容中出现，也可能只放在延伸话题里。

**15. 观众拿走什么（强制）**

| 类型 | 例子 | 对应 |
|------|------|------|
| 命名一个说不出来的感受 | "你不是在选择，是被一台机器替你选" | 替我说 |
| 一个判断框架 | "每次做正确决定，你都在放弃一个市场" | 让我看见 |
| 一个问题 | "名字还记得吗" | 沉默、回想 |

三个至少出一个。出不来→这个选题不值得做。这个判断直接影响收尾设计。

**供给端——我能给什么，为什么是我来说**

**16. 内容线归属（强制）**

| 线 | 锚点 | 判断来源 | 开场感觉 |
|----|------|----------|----------|
| **事业线** | 来时路 | 我自己经历过、跨过行、交过学费 | "我十年前也在砍菜单" |
| **项目线** | 项目路 | 我在做、在看、在验证 | "我看过的项目里，死掉的都不是做错了" |

同选题不同线 → 开场完全不同。锚点类型决定人设语气和故事选择。

**17. 价值观决策（条件强制）**

价值观不是每期都要亮。三个条件勾一个就亮旗：

```
☐ 事业线 → 必亮
☐ 冲突类型 = 人与自己 → 必亮
☐ 观众拿走 = 判断框架 → 必亮

三个全没勾 → 价值观隐在判断里，不用单独亮。
至少勾一个 → 阶段零就定调：这一期我的价值观落在哪一句。
```

市场规模陷阱三个全勾——事业线 + 人与自己 + 判断框架。"你不是在选择"那句本质上就是价值观——增元信的是"人应该自己选，不该被机器替"。

**18. 独家素材预检**

快速三问：

```
- 有没有个人经历能拿出来？（事业线）
- 有没有行业里亲眼看到的事？（项目线）
- 素材池/案例库里有没有匹配的弹药？
```

三问全空 → 只能讲别人的故事 → 没有壁垒 → 不发或降级为练习稿。

**市场端——外部差异化窗口**

**19. 竞争环境**

这个话题别人怎么讲的？标准说法是什么？

```
标准说法："小市场养不活大公司"
我们要说的："不是养不活，是分钱的机器根本看不见小市场"
```

不搞清楚标准说法，反常识就没有靶子。

**20. 话题生命周期**

| 类型 | 特征 | 策略 |
|------|------|------|
| **信号驱动** | 新闻/政策/事件触发 | 有时效窗口，优先排期 |
| **常青判断** | 框架/概念/认知类 | 随时可发，填充队列 |

市场突变时，常青选题可能升级为信号驱动→抢窗口。

### Step 0.3：输出选题卡 → 入库

讨论完成后输出一张选题卡：

| 字段 | 内容 |
|------|------|
| 核心概念 | 一句话 |
| 靶心真问题 | 选的那一层 |
| 备选真问题层 | 其他层，标记为"延伸话题"或"系列下一篇" |
| 冲突类型 | 人与自己 / 人与系统 / 人与人 / 人与环境 |
| 常识→反常识 | 标准说法 → 我们要说的 |
| 为什么没解决 | 障碍的根 |
| 解决的难度 | 技术/认知/系统，哪层最难 |
| 替代方案与代价 | 解决 vs 不解决，两边都痛 |
| 相关资源 | 项目/认知/信息差/金融/创作/方法论，选 2-3 个方向 |
| 观众拿走什么 | 命名感受 / 判断框架 / 问题（至少一个） |
| 内容线 | 事业线 / 项目线 |
| 价值观 | 亮/隐。亮则写一句价值观句 |
| 独家素材 | 有/无，具体是什么 |
| 竞争环境 | 别人怎么说的，我们哪里不同 |
| 话题生命周期 | 信号驱动 / 常青判断 |
| 领域 | 钱/关系/认知（必须至少落一个，落不进去→不发） |
| 认知差 | ★★★ 大部分人不知道 / ★★☆ 部分人不知道 / ★☆☆ 常识级 |
| 主力受众 | 谁痛（具体到一个人） |
| 覆盖资产层 | <100万 / 100-500万 / >500万（钩子必须覆盖顶层） |
| 角度 | 从哪一层打进去 |
| 建议结构类型 | 选题卡入库时绑定，见 [结构类型表](#结构类型表) |

认知差★☆☆的选题不发。

入库后 → 用户从选题候选队列中选择 → 进入 Step 0（开局决策）。
**Step 3.3**：真问题领域闸门（全类型强制）——每个选题必须落进钱/关系/认知至少一个领域。落不进去→不发。增元的行业信号（D类来源）必须翻译成"这个信号会让谁睡不着觉？"之后才是选题。详见 memory `feedback-topic-from-problem`。
**Step 3.5**：锁定受众漏斗——确认后回答三层：主力人群（L?）、延伸人群（L?）、触达人群（L?）。不同层级决定翻译深度和例子选择。L4专业→术语直给。L1泛人群→全部翻译成日常语言。记录到内容文件 1.1 选题信息表。详见下方 [受众漏斗层级](#受众漏斗层级)。
**Step 3.6**：对抗力量定位（全类型强制）——在列框架前，确定这篇稿子对抗力量的层次。对抗力量越强，故事越充分。

| 层次 | 名称 | 定义 | 例子（以"存钱 vs 滚资产"为例） | 力度 |
|------|------|------|------|------|
| 第1层 | **相反价值** | 挑战方法——"你的做法不是最优的" | "存钱不是好策略" | 弱——观众反应"知道了" |
| 第2层 | **矛盾价值** | 挑战结果——"你的做法适得其反" | "你越存钱越穷" | 中——观众反应"真的假的" |
| 第3层 | **否定之否定** | 挑战存在位置——"你不是方法错了，你是站在了别人的循环里" | "你一辈子在替欠钱的人打工，你的存款是别人的本金" | 强——观众反应"这就是我" |

**操作**：列框架前，用一句话写下对抗力量。如果只到第1层→框架先别确认，往上推一层再定。口播/短视频的对抗力量默认目标：**至少第2层，力争第3层**。图文可接受第2层但结尾必须给一个第3层的提问。

**Step 3.7**：定位闸门（全类型强制）——防止被框死在单一领域标签。问自己：这期内容如果不发在"新能源/CVC/微电网"的账号里，换一个泛商业/泛认知账号发，观众还能看完吗？

```
能看完 → 通过。你在做认知品牌，不在做行业号。
看不懂/需要行业背景才能跟 → 危险。你在往下钻，越钻越窄。
```

**策略硬约束**：至少每 3 期中有 1 期必须跨出能源/微电网/储能领域，落在泛认知/泛商业的框架判断上。详见 memory `content-strategy-positioning`。选题阶段就检查——如果连续两期都是行业纵深选题，第三期默认选框架型/概念型。

**Step 4**：用户选择选题
**Step 4.5**：层层追问（分析/判断/科普型强制，教程型可选）。用户抛出真实疑问 → AI 协助探索回答 → 追问到机制层（至少5层中的第3层）→ 记录完整 Q&A 链。**机制层跳层检查（强制）**：追问链必须至少有一问跳出事件本身，进入社会/心理/群体行为机制层（例：不是"原料标准是多少"，是"为什么所有人只传成品标准数字、没人传原料标准数字"）。没有跳出→继续追问。加载 [层层追问工作流](知识库/工作流/层层追问工作流.md)。
**Step 4.6**：不懂不发闸门——用户确认三项：能用自己的话讲给外行听？被追问能再深一层？具体场景能回答？三项全✓通过。任一项✗→回 Step 4.5。反复追问仍无法通过→搁置选题。
**Step 5**：判断内容类型 → 加载对应知识库文件。将 Step 4.5 的追问链提取为内容骨架。

**Step 5.5**：信任复利检查（全类型强制）——回顾最近 2-3 期内容的判断层，确认本期判断和之前的连续性。
- 最近 3 期的核心判断句各是什么？本期判断和之前有没有矛盾或断崖式跳话题？
- 读者连续看完最近三期，会对你形成一个什么样的印象？这个印象是在叠加还是自相矛盾？
- 如果是系列内容：本期是推进了一层还是重复了上一期？
- 执行方式：系统自动加载最近 3 期内容的"核心观点"字段，一条一行呈现在会话中。详见 memory `writing-style-formula` 信任复利。

**Step 6**：视觉风格——不预设固定风格，交给生图 AI 自行发挥。**唯一铁律：同一套图文内必须统一**（母题/光源色温/材质调色板贯穿全篇，页与页之间不能换世界）。详见 memory `feedback-let-image2-decide-visuals`。
**Step 7**：确认人设语气（五种人设选一 + 温度配比）+ 选定情绪弧线类型（祛魅型/验证型/框架型三选一，定起点情绪→终点情绪，详见 memory `writing-style-formula` 情绪弧线原型）。句式参考 [[句式弹药库]]（钩子/推进/归纳/收束 18 种句式，默认加载）。本次使用句式如有习惯偏好→更新弹药库。
**Step 7.5**：独家价值确认——检查素材池检索结果 + 四层独家价值三问。AI 搜不到的素材是内容差异化的根，没有独家层的内容不发。
```
三问：
1. 有没有"只有你能说"的东西？（L1 一手对话/个人经历/CVC圈子观察）
2. 观众能不能拿走一个"AI 给不了"的工具？（L2 判断框架/算账方法/避坑清单）
3. 跟 AI 直接回答差在哪一层？（L1/L2/L3/L4，至少满足一层才发）
```
**Step 7.6**：列框架 → 用户确认（全类型强制）——框架 ≤10 行，一眼看完。


#### 时长计算公式

```
建议时长 = (口播总字数 ÷ 基准字速) × 情绪加权系数 + 停顿补偿

基准字速（语速预设）：
  慢速：5.0 字/秒（每100字≈20s）  — 深情、沉思、强调
  正常：6.7 字/秒（每100字≈15s）  — 默认
  快速：10 字/秒（每100字≈10s）   — 犀利、密集输出、紧张

情绪加权系数（情绪曲线越起伏→系数越大）：
  全程单一情绪（如纯干货）：1.0
  标准起伏（2-3个情绪转折）：1.05
  强情绪波动（4+个情绪转折，含愤怒/兴奋）：1.10

停顿补偿：
  每个空行（换话题）= 0.5s
  每个关键停顿标注（如"停一秒"）= 1s
  结尾停顿 = 1-2s（收束留白）
```

**示例计算（短视频脚本）：**

```
口播总字数：约 260 字（5镜口播内容合计）
语速：正常 → 6.7字/s → 260÷6.7 ≈ 39s 纯口播
情绪系数：标准起伏（好奇→恍然→清醒→专注→确信，5个情绪点）→ 1.05
停顿补偿：约10个空行×0.5s + 结尾停1s + 关键停顿3处×0.5s = 8s
即梦文字动画消耗：每镜约2-3s文字淡入/淡出/定格 → 5镜×2.5s ≈ 13s

建议时长 ≈ 39×1.05 + 8 + 13 ≈ 62s → 取整 60s 或 75s

若选 60s：口播语速需微提至 ~7.5字/s（偏快），情绪镜3/镜5不放慢
若选 75s：口播语速 ~5.5字/s（偏慢），金句和停顿有足够时间呼吸 → 推荐 75s
```

**鸿沟自检（Step 8c 逐段执行，全类型强制）**——来自罗伯特·麦基《故事》。故事产生于主观期望和客观结果之间的裂缝。每一段（每一个"事件"）写完后，自问：

```
观众读到这段开头，以为会发生什么？
  └── 这段结尾实际发生了什么？
      └── 有没有裂开一道口子？
```

没有鸿沟 = 这段只有信息，没有事件。信息是"中等收入陷阱的定义"。事件是"你以为中等收入陷阱是穷——不是，是循环断了"。前者观众左耳进右耳出，后者脑子里被撕开了一道口子。

**操作铁律**：不在段首预告结论。先让观众以为事情是这样的，然后在段尾撕开。每段结尾检查——观众的期望被打破了吗？如果没有，这段重写。

**鸿沟力度递进检查**：整篇稿子的鸿沟不能是同一力度。第一段→小裂口（"原来是这样"），中间段→中裂口（"等等，那岂不是……"），最后一段→大裂口（"所以我一直在……"）。序列逐级加深。

**硬性比例约束（全类型强制）**：事件事实 ≤40%，态度+共鸣 ≥60%。事实=数据/事件经过/机制解释/标准对比。态度+共鸣=个人判断/替观众说心声/经历故事/升维视角。生成后数每页归属→事实侧超4成则砍事实加态度。详见 memory `feedback-default-writing-engine`。

**四维度内容约束（全类型强制，生成时同步检查）**：
1. **情绪粒度**：每页的情绪描述够精确吗？不是"焦虑"→是"交出键盘让他接管了整个服务器"。笼统词（焦虑/愤怒/释然）替换成一句话能命名的具体感受。
2. **认可双形态**：全文搜索——有"替我说"（确认已有认知）吗？有"让我看见"（扩展认知边界）吗？至少各一句。"让我看见"比"替我说"更值钱。
3. **嘴替三动机**：嘴替金句是替自己/对别人/对群体？不能只有第一种。至少设计一个"替他对别人说"或"替他站队"。
4. **受众筛选信号**：有没有一个只有目标受众能识别的东西（名字/场景/概念）？一个就够。大众共鸣负责传播面，精准信号负责筛选。

**危机两难检验规则（全类型强制）**——来自罗伯特·麦基《故事》。危机必须是真正的两难之境——两善取一或两恶择轻。不是"要不要做"，是"两个都要不了"。

```

  └── 例："从一张网开始" —— 观众想"好的"，然后没有然后了。

两难选择（合格）：两个都对、或两个都痛。观众脑子里开始打架。
  └── 例：文凭信号相亲结尾 —— "你看到了什么信号，让你觉得这人行——或者不行？" —— 每个人被迫站队，没有标准答案。
  └── 例：幂律结尾 —— "多数人一生在优化'不输'。少数人知道，有些事值得你接受更高的失败率。" —— 你不用回答，但脑子里在比较自己属于哪边。
```

**操作**：结尾写完后问自己——观众看完最后一句话，是"嗯有道理"（关掉），还是"但是……"（打字）。如果答案是前者，把结尾从"给答案"改成"给两难"。

## 核心思维

### 封面三要素（全类型强制）

用户决定继续看一个内容，最多只花 **2 秒**。封面不是摘要，是在这 2 秒内制造认知缺口。详见 [设计规则](知识库/规则库/设计规则.md)。

```
旧：锚点 + 判断
新：粉碎默认假设 + 锚点 + 判断方向
```

五种封面模式：反常识结论式 / 身份标签式 / 数字对撞式 / 概念折叠式 / ROMO式。硬核分析默认反常识结论式。

### 背景设计铁律（全类型强制）

**严禁纯色背景。绝对禁止。** 纯白 [#ffffff]、纯黑 [#000000]、纯灰、纯任何单色——全部禁止。

每页/每镜必须有背景图，且要包含与选题相关的视觉元素（三选一，至少满足一个）：
- **渐变底**：至少两个颜色的渐变过渡（如蓝白→薄荷绿）
- **纹理底**：纸张纹理、胶片颗粒、磨砂质感、毛玻璃
- **光影底**：光束、环境光、暗角、光源方向

在此基础上，背景中必须有**至少一个与选题领域相关的抽象视觉元素**：
- 选题是储能/电池 → 流线、波形、能量网格、电路纹理
- 选题是金融/投行 → 数据流、K线纹理、几何网格
- 选题是工厂/制造 → 工业肌理、金属拉丝、蓝图线条

```
□ 每页背景是否纯色块？ → 是 → 不发。重做背景。
□ 每页背景是否有相关抽象元素？ → 没有 → 不发。
□ prompt 是否只写了颜色代码（如 #ffffff）？ → 是 → 不发。
```

**注意**：背景元素是氛围层，不是信息层。用 3-8% 透明度、虚化、半透明叠加——隐约可见即可，不能抢文字。

### 图文页面设计铁律（全类型强制）

**严禁全文字页面。** 每页必须至少有 1 个非文字视觉元素：图表、对比图、数据环、进度条、波形图、时间线、结构图——任选其一。

- 封面：数据环/进度环/大数字+图表元素，文字≤3行
- 内页：对比图/条形图/结构图/时间线 占画面 ≥40%，文字≤60字
- 禁止段落文字堆砌。能用图就不用字。

```
□ 每页是否有非文字视觉元素（图/表/环/条/线）？ → 没有 → 不发。
□ 文字是否超过 60 字？ → 超过 → 砍。
□ 这页能不能 3 秒扫完？ → 不能 → 用图代替字。
```

### GPT Image2 生图 prompt 写作铁律（A型图文强制）

**Image2 是"相机"，不是"设计师"。** 给它场景、材质、光线，它出好图。给它排版指令、抽象元素、渐变描述，它只会堆文字。

#### 核心原则：描述摄影场景，不描述图形设计

```
旧（抽象设计 — 禁止）：Soft gradient background from white to mint green. A luminous cyan ring floats center. Minimalist fintech poster aesthetic. Ample negative space.

新（摄影场景 — 必须）：Top-down shot of a dark walnut desk. Warm amber desk lamp casts a focused pool of light. A brushed brass plaque engraved with text sits in the light. The rest fades to deep shadow.
```

#### 每条 prompt 必须包含的 5 个要素

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | **物理场景** | 真实的地点/表面 | 深色木桌面、玻璃展板挂在墙上、蓝图摊在金属绘图桌上 |
| 2 | **具体材质** | 实物材料，不是抽象色块 | 黄铜铭牌、磨砂玻璃、牛皮纸、拉丝钢板、奶油色卡片 |
| 3 | **光源方向** | 光源类型+方向+色温 | 左上角窗外自然光、琥珀色台灯聚光、暖色工业吊灯 |
| 4 | **实物道具** | 场景中的真实物品 | 钢笔、计算器、咖啡杯、金属尺、文件夹、便签纸 |
| 5 | **文字载体** | 文字出现在什么实物上 | 刻在黄铜铭牌上、手写在便签纸上、印在蓝图上、标在仪表盘上 |

#### 严禁使用的抽象描述（直接拉黑）

```
❌ "gradient background"         → 改用真实材质：wood grain, brushed steel, frosted glass
❌ "clean / minimalist / airy"   → 改用具体描述：a single document on an empty desk, spot-lit
❌ "[element] floats / is placed" → 改用实物载体：printed on..., engraved on..., handwritten on a sticky note
❌ "abstract [anything]"         → 全部改成具体实物
❌ "premium / modern aesthetic"  → 改用具体材质：brass and dark wood, glass and chrome
❌ 纯色代码（#ffffff, #1a1e24）  → 改用材质描述：dark walnut wood, matte charcoal wall
```

#### prompt 质量门禁

```
□ 能不能拍成照片？ → 不能 → 重写。prompt 描述的场景必须可以用相机拍出来。
□ 文字在实物上吗？ → 浮在空中 → 重写。文字必须出现在纸张/铭牌/屏幕/卡片/玻璃等实物载体上。
□ 有光源吗？ → 没有 → 加。每条 prompt 必须至少有一个明确光源。
□ 有材质吗？ → 只有颜色代码 → 重写。必须描述物理材质（木/金属/玻璃/纸张/皮革/石材）。
□ 是不是"海报/设计稿"思维？ → 是 → 重写。切换到"摄影师拍一张照片"思维。
```

#### 页面间统一性

同一套图文的 7-8 页之间，通过以下方式保持视觉统一，同时每页又有独立的摄影场景：
- **统一光源色温**：全篇用同一种灯光色调（如琥珀暖光 或 自然白光）
- **统一材质调色板**：限定 2-3 种核心材质贯穿全篇（如深色木+黄铜+玻璃）
- **首尾呼应**：P1 和 P7 回到同一个场景/同一张桌子，形成闭环

```
□ 7页光源色温一致吗？ → 不统一 → 统一。
□ 材质调色板贯穿了吗？ → 每页完全不同材质 → 选2-3种核心材质贯穿。
□ P1和P7有呼应吗？ → 没有 → P7回到P1的场景。
```

### 开场钩子 + 超出预期（口播/视频强制）

前 1.5-3 秒决定观众是否划走。详见 [开场方法论](知识库/方法论库/开场方法论.md)。

三个万能开头公式：反常识断言式 / 身份标签式 / 静默中断式。选题类型自动匹配。

整条视频的预期管理节奏：0-3s 打破预期 → 3-15s 建立信任 → 15-45s 层层剥茧（每 15s 切换）→ 45-55s Wow Moment（75-85%位置）→ 最后 5s 收束。

Wow Moment 四种类型：认知反转 / 框架赠予 / 概念折叠 / 诚实时刻。

### 案例库驱动创作（全类型强制）

每次创作前，必须查案例库 README 索引表。案例库现有 20 篇正向案例、6 个对标账号。

**三步查法：**

```
Step A（选题阶段）：扫 README "适用场景"列 → 找到与当前选题领域/结构相近的案例
Step B（生成阶段）：读目标案例的"可复用手法矩阵" → 选 2-3 个技法嵌入当前内容
Step C（自检阶段）：用目标案例的"核心可复用点"对照当前内容 → 缺了什么？
```

**按内容类型匹配案例账号：**

| 内容类型 | 优先参考账号 | 为什么 |
|---------|------------|--------|
| A型图文（观点/判断） | 哎呀朱莉亚 | 论点宣言开场 + 证据级联 + 哲学三角收束 |
| A型图文（概念讲解） | 一二三周爸爸 | 平行世界叙事 + 隐喻翻译法 |
| 口播脚本（投行视角） | 哎呀朱莉亚 | 投行思辨表达 + 制度归因 + 跨学科引证 |
| 口播脚本（实操框架） | 爆米花企业赋能 | 三层框架 + 反例开场 + 货币化命名 |
| 清单体口播 | 投研号 #1 #2 | 清单体/深度报告体结构模板 |
| 短视频（即梦） | 一二三周爸爸 + 小德momo | 场景叙事 + 架空世界降低制作门槛 |

**反面案例的价值：**

即使案例库当前只有正向案例，创作时也要反向检查——
- 这个选题观众能"拿走"什么？（可拿走性原则——反面教材病因全是"观众什么都没拿到"）
- 有没有堆积多个概念？（深度进化Theo 反面教训：每期只讲一个核心概念）
- 平台敏感词触发了吗？（备电合规：禁用投资/研判/暴增/赚/满产满销/翻倍，公司名≤5次）

**案例库文件路径：**
- 视频/口播案例：`知识库/案例库/爆款拆解/`（外部对标账号，20篇）
- 图文案例：`知识库/案例库/图文拆解/`（自有作品拆解，11篇。10正向+1反面。含备电5篇+南漳黄姐6篇）

### 可拿走性原则

每篇内容生成后，问一句话：**观众看完能拿走什么？**

- "了解了X" → 不合格。了解 = 什么都没拿到。重写
- "能判断X" / "能算出Y" / "能避开Z" → 合格
- 答案如果只是知识 → 把知识变成工具（判断标准/计算公式/避坑清单）

反面教材：翻车案例库 5 支，病因全部指向"观众什么都没拿到"

### 七种观众心理钩子

内容必须至少触发以下一种心理，否则观众不会互动也不会看完：

| # | 心理 | 脚本策略 | 适用场景 |
|---|------|---------|---------|
| 1 | **想纠正你** | 故意留破绽/争议点，让观众忍不住评论纠正 | 知识类、教程类、盘点类 |
| 2 | **想看结果** | 开头抛悬念，用结果延迟制造好奇心 | 挑战类、实验类、对比类 |
| 3 | **想证明自己** | 抛出挑战/测试，让观众在评论区证明"我能" | 技能类、挑战类、测评类 |
| 4 | **想看你翻车** | 真实记录翻车过程，制造戏剧性和共鸣 | Vlog、教程、新手记录 |
| 5 | **想给你出招** | 求助型内容，让观众有参与感和掌控感 | 选择困难、求助、投票 |
| 6 | **想看看真假** | 揭秘/验证型，满足观众的怀疑和探究欲 | 辟谣、实测、行业揭秘 |
| 7 | **想代入自己** | 让观众看到"我也能"，建立身份共鸣 | 教程、经历分享、转型故事 |

**使用规则：**
- 每篇内容选 1 个主导心理 + 最多 1 个辅助心理，不贪多
- 选题阶段就确定心理钩子，不是生成后再贴标签
- 自检：生成后问"观众看完会做什么？"——如果答案只是"知道了"，说明没触发任何心理，重写

### 内容温度模型

三要素：有趣 + 有用 + 共鸣。至少满足两个。
情绪基调：意见领袖60% + 情绪领袖40%。

五种人设：陪伴者/教导者/崇拜者/陪衬者/搞笑者
备电定位：陪伴者（我跟你一样在学）+ 教导者（但我帮你整理好了）

## 受众漏斗层级

创作前强制锁定。层级决定翻译深度、例子选择、信息密度。

```
L1 泛人群     — 刷抖音路过。没有商业知识。不会被专业概念留住。
               钩子驱动。全部翻译成日常语言。每页不超过一个数字。

L2 泛商业     — 买过股票、关心赚钱、知道基本概念（PE/营收/利润）。
               给框架不给术语。用对比和故事。每页可以有2-3个数字。

L3 从业者     — 工厂老板、企业主、行业里的人。
               直接讲利益。算账。不绕弯。可以上专业词但必须立刻翻译。

L4 专业       — 投资人、分析师、看财报的人。
               术语直给。数字密集。不需要翻译。但要给"他们不知道的东西"。
```

**使用规则：**
- 每篇内容锁定 1 个主力层级 + 最多 1 个延伸层级 + 1 个触达层级
- L1 触达靠钩子和封面，L2-L3 主力靠正文框架，L4 延伸靠评论区深度讨论
- 主力层级决定页数：L1≤4页、L2≤6页、L3≤7页、L4≤8页
- 自检：生成后问"主力人群看完能拿走什么？延伸人群会不会觉得太浅/太深？"

**主力层级速判：**

| 选题特征 | 主力层级 |
|---------|---------|
| 热点新闻、平台热搜 | L1 泛人群触达 → L2 泛商业主力 |
| 产业对比、估值框架、公司分析 | L2 泛商业主力 → L3 从业者延伸 |
| 工厂算账、电费优化、设备选型 | L3 从业者主力 → L2 泛商业延伸 |
| 交易结构、估值模型、政策机制 | L4 专业主力 → L3 从业者延伸 |
