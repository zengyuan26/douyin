跨行业内容生产与获客引擎。母系统提供通用创作流程，项目 config 定义身份/受众/合规。**每次创作第一步：加载 `项目/<项目名>/config.md`（无 config 则按 `母系统/config.template.md` 初始化）。**

- 阶段零是选题加工——分析/判断型强制 0.5（产业链）→ 0.6（轨道路由）。教程/故事型跳过 0.5

- **追溯表有"跳过/待补"→不报确认。** 必须补完再报 🔴
- 2.8（框架）和 3.1（导演分析）是两个独立的 🔴 确认点，不能合并
- 用户说"继续/OK/好"≠可以跳过下一步。必须先报站说清下一步是什么
- 0.8 选题卡入库 ≠ 用户已选这篇。用户选择是显式的步骤
- 1.1 载体决策必须重跑决策树。禁止继承上期载体

## 内容类型速查

| 选题特征 | 类型 | 篇幅 | 比例 |
|---------|------|------|------|
| 新闻事件/政策解读/观点输出 | A型图文 | 7-8张 | 9:16 |
| 产业链/知识框架/流程图 | B型图文 | 1张 | 3:4 |
| 深度讲解+个人观点 | 口播脚本 | 3-4分钟 | — |
| 泛人群扩圈/信息密度/高频更新 | 清单体口播 | 2-4分钟 | 16:9 |
| 短平快拆解/AI即梦生成 | 短视频（即梦） | 60-90秒 | 9:16 |
| 深度报告/系列总结/公众号 | 长文 | 500-2000字 | — |
| 培训/路演/系统性讲解+幻灯片 | PPT视频（自配音） | 5-15分钟 | 16:9 |

### 载体选择决策树

选题确认后，按以下顺序决定载体：

```
Step 1: 观众需要"看见"数据对比/结构关系？
  ├─ 是 → 图文
  │      ├─ 单主题深度观点/判断输出 → A型图文（7-8页 9:16）
  │      └─ 知识框架/流程图/产业链 → B型图文（1张 3:4）
  └─ 否 → 继续

Step 2: 需要"我这个人"出来说话？
  ├─ 是 → 口播/视频
  │      ├─ 深度判断+弹药密度驱动 → 口播脚本（3-4分钟）
  │      ├─ 短平快拆解+AI分身 → 短视频即梦（60-90秒）
  │      ├─ 系统性讲解+幻灯片辅助 → PPT视频（5-15分钟 自配音）
  │      └─ 信息密度高+高频更新 → 清单体口播（2-4分钟 16:9）
  └─ 否 → 继续

Step 3: 需要信息密度极高+可搜索/可引用/可深度阅读？
  └─ 是 → 长文（500-2000字）
```

**铁律**：
- **口播脚本是默认载体**。不确定用什么时，先写口播脚本——口播稿可以降维成图文，但图文升维成口播要重写。
- 同一选题可以用多种载体打（如口播 → 图文 → 长文），每种载体独立走完整流程。口播和图文算两条台账记录。
- PPT视频 = A型图文视觉规则 + 口播台词规则。生成时两者同步加载。

## 呼出流程

**Step 1.1**：开局决策（全类型强制，选题后执行）——选题卡入库后，确认线型和结构类型+载体。

| 决策项 | 选项 | 说明 |
|--------|------|------|
| 线型 | **分析线** / **感受线** / **混合线** | 分析线=数据/机制/判断为主。感受线=情绪/共鸣/替观众说话为主 |
| 比例 | 分析线默认 事实≥60% 态度≤40%。感受线默认 态度≥60% 事实≤40%。混合线各~50% | 这条线观众看完要带走什么？数据判断还是情绪确认？ |
| 结构类型 | **确认/调整**选题卡的建议结构类型 | 不是推荐——选题卡入库时已经绑了建议类型，这里只做最终确认或手动覆盖 |

<a name="结构类型表"></a>

**线型 → 结构类型对照**：

| 线型 | 结构类型 | 代表场景 |
|------|-------------|----------|
| 分析线 | 诊断型 / 框架型 / 验证型 / 模型重塑型 / 定价纠正型 | 钠电CVC、比亚迪估值、DeepSeek、行业判断、产业链拆解 |
| 感受线 | 祛魅型 / 故事型 | 毒油事件、关系洞察、打破幻觉、替观众命名感受 |
| 混合线 | 概念型 / 跨学科论证型 / 箴言型 / 对照型 | 既有数据弹药又有情绪收束的深度长文 / 两个系统逐层并置对照。概念型=经济学/哲学/科学弹药 + 判断先行 + 情绪收束 |
| Track C | **清单体** / **案例体** | 日常场景切入→逐层归位→算账收束。清单体=5层递进，案例体=先案例后提炼 |

感受线 + 图文组合标注：⚠️ **感受线图文适配仍在探索中。** 哎呀朱莉亚式感受线已验证于口播，图文载体下"替观众命名感受"的手法尚未定型。生成前确认是否接受探索版输出。

**选题归属检查（Step 1.1 强制，结构类型确认后执行）**

| 检查项 | 问法 | 不过标准 |
|--------|------|---------|
| 归属 | 选题是"我的事"还是"他们的事"？观众第一反应是"XX真惨"还是"这就是我"？ | "他们的事"→换切角。把新闻事件换成事件揭示的人性机制 |
| 可晒性 | 观众看完有什么可以晒到评论区的？具体的东西（数据/经历/层级/答案） | 只有笼统共鸣（"我也亏过"）→补具体触发器 |

注：时间抗衰性已在 Step 0.2 信任闸门 #1 检查，此处不重复。

**Step 1.2**：感受翻译（感受线/混合线强制，分析线跳过）——把真问题用哎呀朱莉亚声音翻译一遍。标准：≤10字/句、句号密度极高、全程"你"。翻译不出来或翻译完不像"这就是我"→ 真问题还没找到 → 回到 Step 1.1 重定线型或选题。

```
分析脑输出 → 感受脑翻译
"观众不理解标准对比" → "每次出事你第一反应是等反转"
"验收标准被改了10倍" → "你想问谁批的。但你知道问了也没人答"
```

## Step 0.1 · 自问三句（动手前强制·选题确认后立即执行）

选题确定后、进入任何流程步骤前，先写三句话回答自己。**在流程概览中处于阶段零之前——是每次创作的第一道闸门。****三句全过 → 进入阶段零。任一句不过 → 不发或重定选题。**

| # | 自问 | 不过标准 | 为什么 |
|---|------|---------|--------|
| 1 | 观众看完最想发给谁？为什么？ | 答不出具体的人+原因 | 没有分享动机的内容不可能爆 |
| 2 | 我在故事里的什么位置？ | 故事外（讲台/分析师）= 对抗姿态 | 观众不信任站在外面审判他们的人 |
| 3 | 观众看完的能量比打开前高还是低？ | 低（沉默/被戳穿/无力） | 低能量 = 不分享。分享需要"你看这个"的冲动 |

**参考**：
- 幂律分布：①发给也在纠结选安全还是选冒险的朋友 ②我在失败名单里（同一层）③更高（被理解→有力量）
- 连锁补错（反例）：①答不出→没分享动机 ②我在故事外审判观众 ③更低（被戳穿→沉默）

## 阶段零：素材加工 → 选题入库

**没有原材料 → 不推荐选题，不进入下一步。**

**冷启动触发器**——不知道聊什么的时候，翻这六个问题：

- 看到了什么让你停下来的事/热点新闻？
- 最近看了什么书/电影/文章？
- 刷到了什么有趣的博主/观点？
- 跟谁聊天让你觉得"这个问题不止他一个人有"？
- 自己遇到了什么反复想的事？
- 行业里出了什么信号你觉得不止是新闻？

### Step 0.2：信任与数字资产闸门（强制前置）

所有内容的目的是建立数字资产，围绕信任。进入阶段零加工前，先过这道闸门。

**判据——四条问自己：**

| # | 判据 | 问法 | 通过标准 |
|---|------|------|----------|
| 1 | **时间抗衰性** | 一年后有人翻出来看，还成立吗？ | 框架/判断/机制层的东西不会过期。纯信息/蹭热点/新闻播报→不过 |
| 2 | **判断密度** | 观众看完拿走的是一个判断框架，还是一个知识？ | 判断框架→数字资产。纯知识/冷知识/趣味事实→不是资产，是消耗品 |
| 3 | **人设复利** | 这期发出去，陌生人看完会更想找你聊吗？ | "这人能帮我看清东西"→资产在涨。"这人懂挺多"→资产没涨 |
| 4 | **来的方向** | 核心判断是你自己形成的，还是从别人的文章/新闻里搬来的？ | 从自己经历/观察/交手中形成的判断→壁垒。纯转述别人的框架→没有壁垒。注意：这里问的是判断的**来源**，不是证明判断的弹药。弹药用外部权威，判断用自己的世界观 |

四条全过 → 进入 Step 0.1。任一条不过 → **不发**。宁可不发，不发消耗品。

这不是选题质量判断——质量在后面的 20 步里验证。这道闸门只判断一件事：**这个东西发出去，是在往信任账户里存钱，还是在取钱。**

### Step 0.3：识别输入类型

用户丢进来的原材料分三种，加工路径不同：

| 类型 | 输入形式 | 加工路径 |
|------|----------|----------|
| **A. 碎片** | 看到的事件/想到的话题/聊到的信号 | Step 0.24 轨道路由 → 进入 Track A/B/C 的起点 |
| **B. 外部内容** | 别人的稿子/文章/视频 | Step 0.24 轨道路由 → Track A 提取判断 → 概念命名；或 Track B 提取信号；或 Track C 识别场景+定位劣势 |
| **C. 自己的草稿** | 用户写的半成品稿子 | Step 0.24 轨道路由 → 提取判断 → 重构真问题+角度 → 重写 |

### Step 0.4：讨论加工

四段递进：需求端（谁痛）→ 问题深挖（障碍、代价和出路）→ 供给端（为什么是我来说）→ 市场端（外部差异化窗口）。需求端起点的 Step 1 分三轨：Track A 认知判断（形成判断→概念命名）或 Track B 行业信号（识别信号→翻译→提取概念）或 Track C 身份定位（识别场景→定位隐藏劣势→概念命名），汇合后走共享子步骤 S2-S20。三道闸门：Step 0.0 信任/资产 → Step 0.24 轨道路由 → Step 0.2 共鸣预检。

**Track A（认知判断）——A1. 形成初始判断**

不是"它讲了什么概念"。是"我对这件事的判断是什么"。

**判断 → 概念。不是概念 → 判断。**

| 不是这样 | 是这样 |
|------|------|
| 我要讲"解释权"这个概念 | 我觉得控制世界的不是有钱人有权人，是能解释一切的人 |
| 我要讲"市场规模陷阱" | 我觉得正确决定本身就是陷阱——你做对了每一步，然后死了 |
| 我要讲"感情阶级" | 我觉得感情走不下去不是不够好，是你在跟低级情感能力的人谈高级需求 |

判断是你对世界的看法。不是从书里读到的，是你本来就有的——只是需要一个外部素材来触发它浮上来。

**Track A——A2. 概念命名**

给自己的判断起一个名字。一个词或短语。这个名字就是本期内容的核心概念。

| 判断 | 命名 |
|------|------|
| 控制世界的是能解释一切的人 | **解释权** |
| 改变世界的人不追成功，他们在修行 | **入世/出世** |
| 正确决定本身就是陷阱 | **市场规模陷阱** |
| 感情走不下去是因为情感能力的层级不匹配 | **感情阶级** |

概念是工具，判断是武器。概念服务于判断，不是反过来。

命名后 → 进入共享子步骤 S2（维度穷举）。

---

**Track B（行业信号）——B1. 识别信号**

行业里在发生什么变化？这个信号/事件/数据在说什么？不是"什么意思"，是"什么正在改变"。

**Track B——B2. 翻译：谁会睡不着觉**

把信号翻译成顶层受众能感受到的痛。**不做翻译 = 只在行业圈传。**

| 信号 | 翻译 |
|------|------|
| 钠电CVC策略调整 | 每个人都以为钠电要爆了，但我在会议室里看到的是另一件事 |
| 储能区域格局变化 | 一个省的政策变了，三个省的投资全白费 |
| 某公司砍掉整条业务线 | 你做的每一个正确决定，都在给对手送练兵场 |

**Track B——B3. 提取核心概念**

翻译之后，这个东西在讲什么概念？用一句话能说出来。

命名后 → 进入共享子步骤 S2（维度穷举）。

---

**Track C（身份定位）——C1. 识别场景**

不是形成判断——是先找到一个具体的日常画面。让观众10秒内看见自己在里面。

**不用概念开火。用场景开火。**

| 不是这样（Track A的钩子） | 是这样（Track C的钩子） |
|------|------|
| "拥挤的不只是编制——是你整张资产负债表" | "你去窗口办审批，材料被退回——你站在那里不知道该说什么" |
| "失败率越高，判断越准？" | "你逛超市，只会想贵不贵——但有人看到的是利润是怎么被分配的" |

场景标准：
- 用"你"开头——"你去XX""你刷到XX""你打开XX"
- 必须是大多数人做过的动作——排队/逛超市/刷招聘网站/点奶茶
- 场景里有一个"卡住"的瞬间——被退材料/看到价格/不知道该选哪条路

**Track C——C2. 定位隐藏劣势**

画面里的人——他不知道自己在犯什么错。这个"不知道"就是选题。

**强制问：这个错让他亏了多少钱？** 算出一个具体金额或金钱逻辑。算不出来→这个场景不够痛→退回 C1 重选场景。Track C 的选题出口必须落钱——和变强起点五篇一样，不管入口是什么话题，出口是钱。

| 画面 | 他以为 | 实际上 | 亏了多少钱 |
|------|------|------|------|
| 刷招聘网站用"离钱远近"量每条路 | 自己在做理性选择 | 在用一个被篡改的计算器——只显示月薪，不显示五年后 | 每月多拿2000，五年多拿12万。亏的是第五年第八个月的跳变——那个跳变值多少？ |
| 逛超市只看贵不贵 | 自己是个好消费者 | 从来没被教过用商人的眼睛看世界 | 同一家超市，有人看到成本结构，他只看价格——每个月错过多少信息差的钱？ |
| 去窗口办审批被退回 | 自己按规矩来 | 用身体硬刚一个可以绕过去的坑 | 省了15块，搭进去一整天+来回车费+重新打印+憋着的气 |

**Track C——C3. 概念命名**

给隐藏劣势起名字。和 Track A 相同——一个词或短语。

| 隐藏劣势 | 命名 |
|------|------|
| 用"离钱远近"量每条路——每条都不达标 | **30岁财富死线** / 人生折现率 |
| 没人教过用商人的眼睛看世界 | **60天视角训练** |
| 省到最后把自己省成了死局 | **小钱开路** |

命名后 → 进入共享子步骤。**Track C 的共享子步骤和 Track A/B 共用编号，但部分步骤适用性不同——见下方标注。**

**共享子步骤——以下为 Step 0.2 内部子步骤（编号 S2-S20），与主流程步骤编号无关。三轨共用。**

**S2. 概念 → 维度穷举（强制）**

> Track C 适用性：⚠️ 改为"场景穷举"。Track C 不穷举钱/关系/认知维度——改为穷举"这个隐藏劣势在哪些日常场景里发作"。选最痛、最多人经历过的场景作为钩子。完成后直接进入 S4 受众锁定。

一个概念能切进几个维度？每个维度对应不同人群、不同真问题。先穷举再选。

| 维度 | 问法 | 判断标准 |
|------|------|----------|
| **钱** | 跟挣钱/守钱/传钱有关吗？ | 观众拿走的是"我该怎么操作" |
| **关系** | 跟人之间的绑定/信任/冲突有关吗？ | 观众拿走的是"我该跟谁站在一起" |
| **认知** | 跟看世界的方式/打破幻觉有关吗？ | 观众拿走的是"原来我是这样想的" |

示例——市场规模陷阱：

| 维度 | 能讲吗 | 对应人群 | 真问题方向 |
|------|------|------|------|
| **认知** | ✓ | 三层都有 | 你不是在选择——有台机器在替你算 |
| **钱** | ✓ | 股民、企业主 | 每次操作都对但账户没变 / 砍业务都对但生意变窄 |
| **关系** | ✓ | 企业主、高净值 | 大客户在替你选业务方向 |

一个概念 → 多个维度 → 多篇内容。每篇只打一个维度。大部分概念只能打一个维度，不强求。

**S3. 选本期维度**

选一个主力维度。标准：哪个维度覆盖的顶层受众（"想拥有专家视角但不需要成为专家"的人）最广、最痛。

**S4. 按资产量级锁定受众层（强制）**

维度定了，再从漏斗顶端穷举受众。没有外围观众就没有启动数据。

| 资产层 | 谁 | 体量 | 角色 |
|--------|------|------|------|
| <100万 可投资产 | "想拥有专家视角但不需要成为专家"的人 | 最大 | 传播发动机。上过大学但不深耕，知道量子物理没读过论文。不想被当普通人，想知道"为什么"和"底层是什么"。崇拜西方科学但也自豪东方智慧。转发=我在思考深刻的东西 |
| 100-500万 可投资产 | 中小企业主 | 中等 | 潜在客户。看项目判断力，被筛进圈子 |
| >500万 可投资产 | 高净值企业主 | 最少 | 高价值客户。看格局和传承，主动来找 |

**钩子必须覆盖顶层。** 顶层打不中→启动数据为零→算法不推→下面两层也看不到你。

详见 memory `audience-asset-funnel`。

**S5. 在本维度内穷举真问题（强制）——每层受众对应一层的痛**

维度 + 受众都定了，再穷举真问题。真问题是整条链的起点——决定对抗力量层次、钩子方向、情绪弧线起点、锚点场景。真问题错了，后面全错。

示例——市场规模陷阱，认知维度：

| 受众层 | 真问题 | 什么时候痛 | 程度 |
|--------|--------|-----------|------|
| 股民/普通人（<100万） | 不是你在选股，是情绪在替你选 | 打开收益曲线，每次都"看对了没做对" | 酸痛 |
| 中小企业主（100-500万） | 你不是在选择业务方向，是大客户在替你选 | 大客户说今年预算砍半，你无路可退 | 刺痛 |
| 高净值企业主（>500万） | 不是不想变，是每次算都对。然后十年没变 | 看同行转行成功，自己还在原地 | 后怕 |

**S5.5. 真问题严重性三问（强制，S5 穷举完靶心层真问题后立即执行）**

稿子写得再好，真问题本身不够痛——弹药打在水面上。三道全过才进入 S6 压测。

| # | 问 | 不通过标准 | 为什么重要 |
|---|------|---------|----------|
| 1 | **严重吗？** 不说出来，他会继续付出代价吗？ | 代价是"隐隐不安"而非"正在亏钱/正在错过/正在被消耗" | 痛感决定停留时长。痒=划走，痛=停下滑动找答案 |
| 2 | **只有我能解决吗？** 这个解法，是稀缺的还是人人能给的？ | "不要盲从""要有批判思维"——谁都能说。解法稀缺性决定关注动机 | 观众关注一个人，是因为"只有他能给我这个"。洞察好≠解法稀缺 |
| 3 | **有这个问题的人多吗？** 能不能在公共场合大方承认？ | 说出来触发防御而非共情——"考编上岸了但后悔"=不敢公开说 | 能大方说的痛=评论区有内容=算法推。不能说的痛=沉默消费=没有互动数据 |

**评分规则：**

- 三道全过 → 进入 S6。真问题有传播潜力
- 两过一不过 → 🔴 暂停，标注哪道没过，和用户讨论后再决定是否继续
- 两道不过 → 不发。回退 S5 重新选靶心或换维度

**事故记录——2026-08-07 正确答案的悖论：** 真问题"选了安全但不安"痛感是痒不是痛（#1 不过）、解法稀缺性不够高（#2 不过）、公开承认触发防御（#3 不过）。稿子弹药密度够、结构对、金句有力——但真问题只过了一道半。结果：长文过千阅读，12赞0评3收藏。同期幂律分布三问全过，数据差距来自真问题痛感等级，不是稿子质量。

**S6. 真问题压力测试（强制，靶心层必须四道全过）**

| # | 测试 | 问法 | 通过标准 |
|---|------|------|----------|
| 1 | **谁能对上** | 这个真问题说出来，谁会在屏幕前停下来？ | 能说出一个具体的人：不是"泛商业人群"，是"33岁在工位上算年终奖发现每条路都算对了但就是觉得哪里不对的人" |
| 2 | **什么时候痛** | 这个痛在什么具体时刻发作？ | 能说出一个场景：不是"做决策时"，是"周一早上打开电脑看到隔壁工位空了，那个人去搞AI了" |
| 3 | **他试过什么** | 他为这个痛做过什么但没用？ | 能说出一个动作：不是"想过转行"，是"刷了三个月招聘网站，最后关掉了，因为算了一下跳槽涨30%但新行业降40%" |
| 4 | **不说会怎样** | 如果没有人替他说出来，他会继续怎样？ | 能说出一个后果：不是"继续痛苦"，是"三年后还在同一张椅子上，菜单只剩三碗面，然后告诉自己这是成熟" |

四道全过 → 真问题成立。任一道卡住 → 真问题还没找到 → 回退到穷举层重新选靶。

**S7. 定位观众 + 确定角度**

真问题定了，受众自然就出来了——谁痛就是谁。角度就是"我们从哪一层打进去"。本期选的是哪个维度，结尾就落哪个维度。

**S8. 共鸣预检（五维快速版，需求端末尾强制）**

需求端走完，选题是否成立？五维快速扫一遍。一个不过→回退重新选靶心或换维度。

| # | 检查项 | 问法 | 通过标准 |
|---|--------|------|----------|
| 1 | **流量** | 钩子方向 3 秒刺得进去吗？ | 能说出观众停在屏幕前的那个感受 |
| 2 | **点赞** | 真问题说出来是"这就是我"还是"哦"？ | "这就是我"——被替他说出来了 |
| 3 | **评论** | 有没有天然槽点？ | 方法论争议，安全分歧区。门槛低到任何人能搭话 |
| 4 | **转发** | 看完会想转给谁？ | 能说出一个具体的人：合伙人/同事/一起做决定的人 |
| 5 | **情绪** | 起点→终点有弧线空间吗？ | 不是平的。有转折有降落。能画出一条完整曲线 |

五维全过 → 选题成立 → 继续往下走。任一项卡住→回退。

### Step 0.5：产业链前置分析（分析/判断型触发，v5.57 新增）

选题方向初步确定后，先画产业链。看结构再找问题，不靠搜索词反推。

**触发条件**：分析/判断/行业型。教程型/故事型/个人经历型跳过此步。

**操作**（5分钟快速版）：

```
1a 画链条映射表
  上/中/下游 + 横向支持。每环节填：代表玩家、集中度、毛利率区间、定价权方向。
  模板见 知识库/通用框架/产业链分析框架.md → 空白模板。

1b 三步定位
  瓶颈：毛利率最高 + 集中度最高 + 不可替代 = 谁在卡脖子
        ⚠️ 分散型产业链的瓶颈不一定是人——猪周期、政策、气候也可以是"自然瓶颈"
  夹心层：上下游同时挤压的环节。四面夹击（上游涨价+下游压价+替代品+同行）
  依赖陷阱：严重依赖单一上游或单一下游的环节

1c 矛盾性质判断（重点——这一步决定轨道）
  □ 结构性卡脖子（某环节垄断、毛利率断崖明显）     → 提示轨道路由选 Track A
  □ 分散型+周期性生存困境（全链分散、无人暴利、被周期碾压） → 提示选 Track C
  □ 行业信号/翻译（新政策/新技术/新事件需要翻译给圈外人） → 提示选 Track B
```

**产出**：三步定位结果 + 矛盾性质判断 → 带入 Step 0.24 轨道路由。

完整方法论和示例（动力电池 / 手工灌香肠双轨案例）见 [产业链分析框架](知识库/通用框架/产业链分析框架.md)。

### Step 0.6：轨道路由（强制，Step 0.5 完成后执行。教程/故事型无 0.5 则直接执行）

Step 0.22 的产业链分析已经揭示了矛盾的底层性质。现在确认轨道。

**链条矛盾 → 轨道映射：**

| 矛盾性质 | 轨道 | 为什么 |
|---------|------|--------|
| 结构性卡脖子（某环节掐着所有人） | Track A 认知判断 | 这是权力的游戏。需要判断句+反常识阶梯 |
| 分散型+周期性生存困境 | **Track C** 身份定位 | 这是生存的游戏。需要场景代入+清单骨架。矛盾不在"谁掐谁"而在"谁在苟着、谁能做大" |
| 行业信号/政策/新技术 | Track B 行业信号 | 需要翻译——信号→谁会睡不着觉 |

**三轨特征（确认参考）：**

| | Track A：认知判断 | Track B：行业信号 | Track C：身份定位 |
|------|------|------|------|
| **判断从哪来** | 我对世界/人性/市场有一个看法 | 我在行业位置上看到了信号 | 我见过足够多的人卡在同一个地方 |
| **信任靠什么** | 判断力 + 弹药密度 + 跨域连接 | 行业入场券 + 亲身经历 + 判断力 | 在场经验 + 见过的样本量 + "我在你前面一步" |
| **案例弹药** | 六类权威交叉扫射 | 行业案例 + 项目见闻 + 数据 + 六类权威辅助 | 个人在场观察 + 见过的典型样本 + 日常场景细节 |
| **个人经历** | 可选，不强制 | 经常需要（来时路/项目路） | **强制。** "我在XX干了X年+我见过X种人"是信任锚点 |
| **结构类型** | 反常识阶梯——每层推翻上一层 | 信号翻译+机制推导 | **清单骨架**——每层让观众归位一次 |
| **钩子进入方式** | 纯判断句。句号。不铺场景 | 钩子需要翻译——信号→谁会睡不着觉 | 钩子是日常场景——"你去窗口办审批" |

**决策规则：**

1. 判断来自对世界/人性/市场的观察？→ **Track A**。从"我的判断是什么"开始。
2. 判断来自在行业位置上看到的信号/项目/交易？→ **Track B**。从"这个信号会让谁睡不着觉"开始。
3. 话题是日常场景 + 解法是具体动作（不是认知框架）+ 观众拿走的是一个明天就能做的动作？→ **Track C**。从"他们卡在哪"开始。
4. 两边都有 → **默认 Track A**。行业触觉当弹药使，不当前台。
5. **Step 0.22 执行过** → 链条矛盾性质已给出提示，对照确认而非重新决策。

详见下方 Step 0.2 分轨入口。

### Step 0.7：选题锚六池自检（全类型强制，v5.54 新增）

选题锚是"这事跟观众有什么关系"。不是事件/概念有没有意思——是**观众脑子里有没有一个已经存在的痛点，能被这个选题激活。**

63篇爆款的选题锚全部落在6个恐惧池里。无一例外。落不进去→不发。

| # | 恐惧池 | 观众内心独白 | 识别信号 |
|---|--------|------------|---------|
| 1 | **努力无效** | "我做了所有对的事，为什么结果不对" | 选题涉及"努力→回报"的断裂 |
| 2 | **被收割/被控制** | "我是不是正在被人耍、被人赚我的钱" | 选题揭示一个隐藏的操控系统 |
| 3 | **财富流失/赚不到钱** | "钱到底怎么才能留住/赚到" | 选题涉及钱的方向/逻辑/分配 |
| 4 | **选错/被辜负** | "我选的人/路/关系是不是错了" | 选题涉及重大选择 |
| 5 | **被淘汰/出路焦虑** | "时代变了，我会不会被甩下车" | 选题涉及外部变化威胁 |
| 6 | **身份/自我怀疑** | "我是不是不够好/不够聪明/有问题" | 选题涉及自我认知 |

**选题锚三道关（落池后强制）：**

```
第一关：这个痛点，观众不看我的内容就已经有了吗？
  ├─ 是。已经在疼了。我只是帮他命名 → ✅
  └─ 不是。需要我先教育他"你应该疼" → ❌ 选题不成立

第二关：这个痛点，他今晚睡不着的时候会想到吗？
  ├─ 会。不是"有意思"，是"这就是我" → ✅
  └─ 不会。只是好奇，不是疼 → ⚠️ 可以写，但别指望爆

第三关：看完之后，他能不能用一句话转述给朋友？
  ├─ 能。而且朋友听完也会疼 → ✅
  └─ 不能。需要铺垫上下文才能理解 → ⚠️ 传播链路断
```

**六池 × Step 0.24 轨道路由（Track A/B/C 选题偏好）：**

| 轨道 | 首选恐惧池 | 为什么 |
|------|----------|--------|
| Track A 认知判断 | 努力无效 / 被收割 / 身份自我怀疑 | 判断先行天然适配"你以为X，其实是Y" |
| Track B 行业信号 | 被淘汰 / 财富流失 | 信号翻译后落"谁会睡不着觉" |
| Track C 身份定位 | 财富流失 / 身份自我怀疑 | 定位焦虑驱动向上动机，出口必须落钱 |

**六池 → 领域自动映射（原 Step 3.3 并入）：**

| 恐惧池 | 领域 |
|--------|------|
| 努力无效 | 认知 |
| 被收割/被控制 | 认知 |
| 财富流失/赚不到钱 | 财富 |
| 选错/被辜负 | 关系 |
| 被淘汰/出路焦虑 | 认知 |
| 身份/自我怀疑 | 认知 |

六池落池 = 领域自动确定。不需要再单独查"钱/关系/认知"。

选题卡入库时标注激活的恐惧池编号 + 对应领域。详见 `知识库/方法论库/锚点双环决策系统.md`。

**问题深挖——为什么一直没解决，障碍、代价和出路**

**S9. 常识 → 反常识（强制）**

反常识是钩子的原材料。不搞清楚常识是什么，反常识就是自说自话。

```
常识：做正确决定 = 好的
反常识：正确决定本身就是陷阱

常识：听客户的话 = 对的
反常识：客户说真话，但真话指向昨天

常识：我在优化人生
反常识：一台机器在替你优化，你不是在选
```

反常识建立后 → 开场方向自然出来。

**S10. 定位冲突类型（强制）**

痛点发生在哪里？决定情绪质地和叙事空间。

| 冲突发生在 | 例子 | 情绪质地 |
|------------|------|----------|
| **人与自己** | "你心里有一台机器在替你算" | 内省、安静、后怕 |
| **人与系统** | "不是你不努力，是分配规则就不让你看见那个市场" | 揭露、清醒、愤怒 |
| **人与人** | "你说服不了你的老板，因为他也在被同一台机器算" | 无奈、对抗、理解 |
| **人与环境** | "整个行业都在砍菜单，你不砍就是异类" | 孤立、压力、站队 |

市场规模陷阱是**人与自己**——冲突不在伯利恒的会议室，在观众脑子里那台按确定性分配的机器。这个判断直接影响开场：不是讲别人怎么死的，是让你看见自己也在做一模一样的事。

**S11-S15 问题深挖段 · Track C 精简**

> Track C 适用性：⚠️ **精简。** Track C 不深度挖掘障碍/难度/替代方案——太重了。Track C 的解法是轻的：一个具体动作（递瓶水/拆利润/看缺口）。S11-S15 对于 Track C 只需回答一句话："观众今天能做什么？" → 直接跳到 S16。

**S11. 为什么一直没解决**

挖掘障碍的根。以市场规模陷阱为例：

- 不是对抗愚蠢，是对抗聪明。"正确决定"在当下就是对的——你在 1985 年没法证明 3.5 寸硬盘有未来。客户说不要，数据说不划算，所有人说对。
- 越聪明的系统越难自我纠正。希捷工程师在实验室做出了原型机——颠覆他的东西他自己先造了出来。还是没推出去。

障碍的本质：不是信息不够，是"对"的反馈太强。

**S12. 解决的难度**

| 难度层 | 问题 | 例子 |
|--------|------|------|
| **技术难度** | 这事能做吗？ | 希捷工程师做出了 3.5 寸原型机——技术不难 |
| **认知难度** | 你敢信吗？ | 在所有人都说"对"的时候，相信一个看起来错的东西 |
| **系统难度** | 你推得动吗？ | 资源分配机器不让你投那个只赚 7% 的市场 |

三层难度定位 → 观众知道这不是"努力一下就行"的事。

**S13. 替代方案与代价**

| | 不解决 | 解决 |
|------|------|------|
| 短期 | 安全、确定、赚钱 | 可能浪费时间、可能失败、别人眼里"不务正业" |
| 长期 | 菜单只剩三碗面 | 可能还是失败。但至少名字还记得 |

代价不是一边全好一边全坏——两边都痛。这就是收尾两难的原材料。

**S14. 相关资源推荐**

根据选题方向，搜索并推荐能帮观众继续深挖的资源。不是为了堆参考文献，是为"真想往下走的人"指路。

| 方向 | 什么资源 | 例 |
|------|----------|-----|
| 项目相关 | 行业里正在发生的事/案例 | 亚马逊 Kindle 团队独立于总部运营 |
| 认知相关 | 框架/书/概念 | 《创新者的窘境》克里斯坦森 |
| 信息差相关 | 别人不知道但知道了会不一样的事 | 希捷花 10 亿美元买回原型机的细节 |
| 金融/商业相关 | 交易结构/模式 | 独立小组织怎么分钱、怎么不被母公司渗入 |
| 创作相关 | 这个话题怎么写/怎么拍 | 案例库中对标作品的叙事手法 |
| 方法论 | 可操作的步骤/工具 | "划一块不受值不值得管的时间" |

选 2-3 个最相关的方向推荐。这些资源可能在内容中出现，也可能只放在延伸话题里。

**S15. 观众拿走什么（强制）**

| 类型 | 例子 | 对应 |
|------|------|------|
| 命名一个说不出来的感受 | "你不是在选择，是被一台机器替你选" | 替我说 |
| 一个判断框架 | "每次做正确决定，你都在放弃一个市场" | 让我看见 |
| 一个问题 | "名字还记得吗" | 沉默、回想 |

三个至少出一个。出不来→这个选题不值得做。这个判断直接影响收尾设计。

**供给端——我能给什么，为什么是我来说**

**S16. 内容线归属（强制）**

> Track C 适用性：⚠️ **默认事业线。** Track C 的在场经验天然落在事业线——"我在XX干了X年+我见过X种人"。不需要每次决策。

| 线 | 锚点 | 判断来源 | 开场感觉 |
|----|------|----------|----------|
| **事业线** | 来时路 | 我自己经历过、跨过行、交过学费 | "我十年前也在砍菜单" |
| **项目线** | 项目路 | 我在做、在看、在验证 | "我看过的项目里，死掉的都不是做错了" |

同选题不同线 → 开场完全不同。锚点类型决定人设语气和故事选择。

**S17. 价值观决策（条件强制）**

> Track C 适用性：⚠️ **跳过。** Track C 的价值观隐含在场景和定位句里，不单独亮旗。观众不需要知道"我信什么"——只需要看见自己站在哪层。

价值观不是每期都要亮。三个条件勾一个就亮旗：

```
☐ 事业线 → 必亮
☐ 冲突类型 = 人与自己 → 必亮
☐ 观众拿走 = 判断框架 → 必亮

三个全没勾 → 价值观隐在判断里，不用单独亮。
至少勾一个 → 阶段零就定调：这一期我的价值观落在哪一句。
```

市场规模陷阱三个全勾——事业线 + 人与自己 + 判断框架。"你不是在选择"那句本质上就是价值观——增元信的是"人应该自己选，不该被机器替"。

**S18. 独家素材预检**

快速三问：

```
- 有没有个人经历能拿出来？（事业线）
- 有没有行业里亲眼看到的事？（项目线）
- 素材池/案例库里有没有匹配的弹药？
```

三问全空 → 只能讲别人的故事 → 没有壁垒 → 不发或降级为练习稿。

**市场端——外部差异化窗口**

**S19. 竞争环境**

这个话题别人怎么讲的？标准说法是什么？

```
标准说法："小市场养不活大公司"
我们要说的："不是养不活，是分钱的机器根本看不见小市场"
```

不搞清楚标准说法，反常识就没有靶子。

**S20. 话题生命周期**

| 类型 | 特征 | 策略 |
|------|------|------|
| **信号驱动** | 新闻/政策/事件触发 | 有时效窗口，优先排期 |
| **常青判断** | 框架/概念/认知类 | 随时可发，填充队列 |

市场突变时，常青选题可能升级为信号驱动→抢窗口。

### Step 0.8：输出选题卡 → 入库

讨论完成后输出一张选题卡：

| 字段 | 内容 |
|------|------|
| 核心概念 | 一句话 |
| 靶心真问题 | 选的那一层 |
| 备选真问题层 | 其他层，标记为"延伸话题"或"系列下一篇" |
| 冲突类型 | 人与自己 / 人与系统 / 人与人 / 人与环境 |
| 常识→反常识 | 标准说法 → 我们要说的 |
| 为什么没解决 | 障碍的根 |
| 解决的难度 | 技术/认知/系统，哪层最难 |
| 替代方案与代价 | 解决 vs 不解决，两边都痛 |
| 相关资源 | 项目/认知/信息差/金融/创作/方法论，选 2-3 个方向 |
| 观众拿走什么 | 命名感受 / 判断框架 / 问题（至少一个） |
| 内容线 | 事业线 / 项目线 |
| 价值观 | 亮/隐。亮则写一句价值观句 |
| 独家素材 | 有/无，具体是什么 |
| 竞争环境 | 别人怎么说的，我们哪里不同 |
| 话题生命周期 | 信号驱动 / 常青判断 |
| 恐惧池 | 努力无效 / 被收割 / 财富流失 / 选错 / 被淘汰 / 身份自我怀疑（六选一，Step 0.25 确定） |
| 领域 | 钱/关系/认知（恐惧池自动映射，不需单独判断） |
| 认知差 | ★★★ 大部分人不知道 / ★★☆ 部分人不知道 / ★☆☆ 常识级 |
| 主力受众 | 谁痛（具体到一个人） |
| 覆盖资产层 | <100万 / 100-500万 / >500万（钩子必须覆盖顶层） |
| 角度 | 从哪一层打进去 |
| 建议结构类型 | 选题卡入库时绑定，见 [结构类型表](#结构类型表) |

认知差★☆☆的选题不发。

入库后 → Step 4 用户选择选题 → 进入 Step 0（开局决策）。
**Step 3.5**：锁定受众漏斗——确认后回答三层：主力人群（L?）、延伸人群（L?）、触达人群（L?）。不同层级决定翻译深度和例子选择。L4专业→术语直给。L1泛人群→全部翻译成日常语言。记录到内容文件 1.1 选题信息表。详见下方 [受众漏斗层级](#受众漏斗层级)。
**Step 1.4**：对抗力量定位（全类型强制）——在列框架前，确定这篇稿子对抗力量的层次。对抗力量越强，故事越充分。

| 层次 | 名称 | 定义 | 例子（以"存钱 vs 滚资产"为例） | 力度 |
|------|------|------|------|------|
| 第1层 | **相反价值** | 挑战方法——"你的做法不是最优的" | "存钱不是好策略" | 弱——观众反应"知道了" |
| 第2层 | **矛盾价值** | 挑战结果——"你的做法适得其反" | "你越存钱越穷" | 中——观众反应"真的假的" |
| 第3层 | **否定之否定** | 挑战存在位置——"你不是方法错了，你是站在了别人的循环里" | "你一辈子在替欠钱的人打工，你的存款是别人的本金" | 强——观众反应"这就是我" |

**各维独立原理：**
- 机制 vs 信息差：机制是"一台坏机器在运行"（揭露系统存在）。信息差是"有一个平行世界你看不见"（当导游）。一个触发愤怒，一个触发好奇。
- 机制 vs 对立面：机制是"系统怎么运作"（结构）。对立面是"谁在挡你""什么在消耗你"（敌人）。一个是地图，一个是挡路的人。
- 人群 vs 对立面：人群是"多少人受影响"（规模）。对立面是"谁该负责"（指向）。

**为什么这七维有效：** 变强起点五篇——每篇从个人切入立刻上升到系统机制。"穷人的孩子混社会"不是一个孩子，是一个阶层。幂律分布——"投了20多家公司全死了，包括我的"——量级+极端结果+在场+信息差（VC失败名单是外人看不到的），一秒钟完成归位。闲鱼暗网——信息差（"暗网"重新定义整个平台）+对立面（"你以为闲鱼是二手平台"）。

**检查方法**：选定科学锚后问三个问题——
1. 这个锚定义了概念本身，还是验证了概念？
2. 如果是定义者——有另一个同等权威的人独立做过同样的定义吗？
3. 没有 → 必须用它。有 → 可选。

**为什么重要**：感情阶级 v1 用戈特曼换掉巴斯。戈特曼证明的是"感情可诊断"，不是"感情有阶级"。概念骨架散了——观众看完觉得"说得对，但跟我有什么关系"。定义者锚换不得，换了概念就站不住。

| **西方哲学** | 西方思想家有没有独立定义过这个概念？ | 柏拉图《会饮篇》灵魂之爱 |
| **商业符号** | 能不能用商业/金融语言翻译给观众？ | 投资类比——长期持有 vs K线套利 |
| **历史事件** | 历史上有没有人/事件验证了同一个机制？ | 戴安娜王妃——连王妃都逃不过 |
| **文学** | 小说/电影/文学里有没有人物是这个词条的具象化？ | 琼瑶——连写了一辈子爱情的人也逃不过 |

**弹药密度要求：**
- **全 Track A 强制：至少覆盖 4 个不同领域。** 结构类型（概念型/框架型/故事型/对照型/定价纠正型）决定推翻机制，不影响弹药数量。推翻力度都需要 ≥4 域交叉验证。同领域堆案例（如两个商业案例）不计入交叉火力。
- Track B 行业信号：行业案例 + 数据 + 六类辅助即可，不作领域数量硬性要求。
- 4 类不到 → 回六域框架逐域搜索：科学/东方经典/西方哲学/商业符号/历史事件/文学，每域问"这个机制在这里有没有对应验证？"。确实搜不到 → 在弹药表标注"该领域无对应验证，原因：____"。不硬凑，但必须记录为什么缺。

**核弹级案例标准：**
不是"这个例子能说明道理"——是**观众看完会想"连她都逃不过，我怎么可能逃得过"**。
- 感情阶级 v2 的琼瑶案例：写了一辈子爱情的人，死在低级感情里。观众没法反驳。
- 选核弹案例的三问：①这件事人人都知道？②观众本能觉得"这个人是幸福的/成功的/懂行的"？③然后翻转——TA 也栽在这件事上了？三项全 ✓ = 核弹级。

**弹药设计自检清单（Step 7.7 执行，全 Track A 强制）：**

```
□ 六类权威扫了几类？ ≥4 类 ✓
□ 有没有定义者锚？ 没有 = 概念没有学术骨架，不发
□ 有没有核弹级案例？ 没有 = 观众会听完但不会被击穿
□ 弹药是同一领域堆量还是跨域交叉？ 同域 ≥2 个 = 裁掉一个，补其他域
□ 有没有个人经历？ Track A 默认弹药全来自外部引用。个人经历仅在外部锚点确实找不到时作为补充，且必须标注"个人经历→无外部替代，降级为叙事调味品"。
□ 避免"百科全书式炫技"。每一条弹药必须直接服务于核心机制。
```

**弹药反模式（来自感情阶级 v1→v2 实战教训）：**

| v1 错误 | v2 修正 | 教训 |
|---------|---------|------|
| 戈特曼替代巴斯——戈特曼只验证了"感情可诊断"，未定义"感情有阶级" | 巴斯归位——巴斯直接定义了择偶动机的高低阶之分 | **定义者锚不可替换** |
| 弹药 3 个（巴斯+戈特曼+戴安娜），两个心理学同域重复 | 弹药 5 域 6 弹（科学+哲学+历史+文学+商业） | **跨域交叉 > 同域堆量** |
| 结尾自省问题——"你爱的是他还是付出" | 结尾判断工具——"你爱的是投资人还是交易者" | **商业翻译 = 观众能转述 = 传播** |
| 预告弹药——"我给你看三个证据""第一个东西""再给你看一个更远的例子" | 弹药直接切进去，不预告数量、不预告结构、不预告"下一个是什么" | **禁止预告弹药。打断节奏。观众不需要知道还有几个证据——跟着走就行。** |
| 核弹级案例一笔带过——达西/威克姆只给5行 | 琼瑶案例展开一整段：她的经历→她付出了什么→泡泡怎么破的→她的结局。讲完故事，结论自己砸下来 | **核弹级案例必须展开讲一个人的一生。不是在举例——是让人看到自己。** |

**Step 7.75**：Track A 弹药定位句（v5.50 新增，全 Track A 强制）

每条弹药展开后，结尾落一个定位句。把这段弹药揭示的**认知差距翻译成身份差距**。

```
格式："你在 [旧认知/行为]，[新维度] 在 [另一边]"

- "你在拥挤的路上排队，系统在另一边放大结果"
- "你不是在选正确答案——你是在为正确答案付溢价"
- "你用来证明冒险不行的那个词——前提你没有满足"
```

**为什么强制：** 幂律分布 P2-P4 每段都有隐式定位句（"你习惯的世界 vs 真实的世界""大多数人 vs 顶级VC""犯错的成本 vs 正确的收益"）。正确答案悖论 v1 弹药段没有定位句——纯反常识过渡。数据差距（12赞0评 vs 幂律分布）部分来自这里。反常识过渡告诉观众"你想错了"。定位句告诉观众"你现在站在错的那边——那边有人在替你亏钱"。

**执行规则：**

| 规则 | 说明 |
|------|------|
| 每条弹药 ≥1 个定位句 | 展开完毕、过渡句之前落。不写 = 弹药没落地 = 打回 |
| 定位句不替代反常识过渡 | 定位句是弹药内部收尾，反常识过渡是弹药之间的桥梁。两者独立 |
| 全篇定位句数 ≥ 弹药数 | 4段弹药 ≥ 4个定位句 |
| 定位句格式 | "你在X，Y在另一边" 或 "你不是在X——你是在Y"。不用"而"，用逗号或破折号 |

**定位句 vs 反常识过渡（区分）：**

| | 定位句（弹药内部） | 反常识过渡（弹药之间） |
|------|------|------|
| 位置 | 每段弹药最后一句 | 两段弹药之间 |
| 作用 | 让观众归位——"我在错的那边" | 推翻上一段建立的判断——"你以为到这儿就完了？" |
| 例子 | "你在用科学名词，给你的恐惧买单" | "到这儿你脑子里可能已经弹出——幸存者偏差" |
| 删掉会 | 观众知道错了但跟自己没关系 | 段与段之间变成并列，失去推翻感 |

**Step 2.9**：框架对照爆款（列框架后强制）——框架列完后、提交用户确认前，打开最近一条同类型爆款拆解，过四步自查。**四步全过 → 提交确认。任一步不过 → 调整框架后再提交。**

| # | 检查项 | 问法 | 不过标准 |
|---|--------|------|---------|
| 1 | **开场姿态** | 爆款作者站在**人群里**还是**讲台上**？我的框架开场是同一层（"我也在这张图里"）还是审判者（"你有个毛病"）？ | 讲台/审判者 → 重定站位 |
| 2 | **反常识结构** | 先确认结构类型，再按类型检查推翻机制：**概念型**→反常识阶梯（"你以为X？→实际是Y"）；**框架型**→层级碾压（"你以为到顶了？上面还有一层"）；**故事型**→情节转折（角色选择→意外结果，推翻内生）；**对照型**→差距对照（A做X←→B做相反的Y，差距=推翻）。还是**柱子**（同一结论换案例）/**放大**（同一结论换尺度）？ | 柱子或放大 → 重写。推翻机制跟结构类型不匹配 → 重定结构类型或重写衔接 |
| 3 | **认知增量** | 逐段标注：这一段让观众知道了什么**上一段不知道**的事？任意两段答案重复 → 合并或砍掉。 | 有重复 → 框架不过，砍完再提交 |
| 4 | **收尾能量** | 爆款收尾让人想**截图转发**（"我学到了这个"）还是**沉默**？我的收尾观众看完是想分享，还是自己坐着想？ | 沉默/内省 → 收尾方向调整 |

**反常识阶梯 vs 柱子 vs 放大（强制区分）：**

| 类型 | 过渡句特征 | 读者反应 | 例 |
|------|------|------|------|
| **柱子** | "韩国也一样""2015年也是""一文钱也是" | "知道了。下一个。" | ❌ |
| **放大** | "放大到国家呢""个人是这样，群体也是" | "同一个东西变大而已。" | ❌ |
| **推翻** | **"你以为搞清楚就不会再犯了？"** | **"等等，不只这样？"** | ✅ |

**反常识阶梯公式：**
```
Layer N 结论 → 读者自然形成判断 A
Layer N+1 开头 → "你以为 A？"
Layer N+1 内容 → 实际是 B（B 打开了上一层没有的新维度）
```

⚠️ **稻草人检查（概念型强制）**：每个"你以为A"的A，必须是**公众真实持有的默认信念**。不是你自己构造来推翻的靶子。自检：随便问一个人，他真会这么以为吗？不会→这个A是稻草人→过渡句不能用"你以为"，改用直陈判断"但A不对。B才对。"或"还有一个问题。A解释不了X。"

**幂律分布的反常识阶梯（8 层，每层一个维度）：**
你以为正确决定让你接近目标？→ 越正确离想要的越远 → 你以为高失败率=完了？→ 顶级风投觉得还不够激进 → 你以为命中率高=好？→ 命中率高说明你避开了赢家 → 你以为好机会好看？→ 真正的好机会看起来像坏主意 → 你以为需要大部分正确？→ 一个对的覆盖一千个错的 → 你以为专家能知行合一？→ Graham：我做不到 → 你以为你在理性选择？→ 你的感受器长在错误的世界里 → 你以为该问"万一不成"？→ 该问"成了够不够覆盖"。

**反常识阶梯 8 层维度模板（全类型强制参考）：**

| 层 | 维度 | 做什么 | "你以为"→"实际是" |
|------|------|------|------|
| 1 | **反常识命题** | 打破一个所有人都点头的常识 | 你以为X是坏事？→ X反而是____ |
| 2 | **视角反转** | 换站位——不是观众以为的那个原因 | 你以为是因为A？→ 实际是因为B（B更深一层） |
| 3 | **框架** | 给结构/命名——让观众拿到概念武器 | 经济学给这事起了名字 → 但名字救不了你 |
| 4 | **认知** | 改感知——标准答案/常识答案打错了靶子 | 标准答案是____ → 但问题本身问错了 |
| 5 | **算术** | 数字震慑——用具体数据把个人体验放大到系统级 | 你以为只是你一个人的事？→ 这个数字告诉你不是 |
| 6 | **人性** | 权威/古典证据——连____都逃不过/500年前就写透了 | 你以为这是现代/偶然的？→ 它是人性底层代码 |
| 7 | **自照** | 焊到观众身上——"你也是一样的" | 你以为离你很远？→ 那个感觉你认识 |
| 8 | **工具** | 能带走的判断——下次能用 | 你以为分不清/做不到？→ 你分得清 |

**每层 ≤ 6 行。故事段落（层 1/2/6）≤ 8 行。节奏铁律：读者形成判断→立刻打破→下一层。不给读者喘息时间。**

**自检**：逐段读框架，每段结尾问——读者现在会形成什么判断？下一段开头——打破这个判断了吗？没打破 → 是柱子或放大 → 重写衔接。

**结构类型 × 反常识阶梯适配（Step 7.6 选型后强制参考）**

以上 8 层模板是概念型的推翻机制。不同结构类型使用**不同的推翻机制**——选错机制，框架再对也没用。

| 结构类型 | 推翻机制 | 驱动力 | 过渡特征 | 代表案例 |
|---------|---------|--------|---------|---------|
| **概念型** | "你以为X？实际是Y" | 认知被打破的震惊 | 外部嫁接推翻公式。每个"你以为"打开新维度 | 牛奶方盒、零价效应、一瓶水 |
| **框架型** | "你以为这就是顶？上面还有一层" | 认知饥渴——到底还有几层？ | 层级碾压。每层是上一层的升级版，讲完一层观众觉得到顶了，下一层说"不，还有更高的" | 财富扩张地图（Netflix入口→三种杠杆→复制系统→习惯护城河→卖规则） |
| **故事型** | 角色选择→意外结果→观众自己得出判断 | "然后呢？"的叙事悬念 | 推翻内生。不靠"你以为"公式——情节转折本身就是推翻。角色冒险→结果反转→观众自己推翻之前的预期 | 小岛经济学（艾伯饿肚子做渔网→日捕3条→全岛产量×6→长老印鱼券→崩盘→冰岛复苏） |
| **对照型** | A做X ←→ B做相反的Y。差距本身就是推翻 | "为什么A赢B输？" | 两个系统从头到尾不换。每层：A的机制→B的做法→差距。观众自己得出"原来B一直在反着做" | 游戏化教育（游戏的多巴胺曲线←→作业的神经荒漠。游戏反馈2.8秒←→教育反馈3个月） |
| **定价纠正型** | 市场在用一把错的尺子量这个东西 → 我告诉你尺子错在哪 → 正确的尺子是什么 | "等等，尺子歪了？" | 层级碾压+对比。每层：市场在定价X→实际应该定价Y→差距=定价错误。P4是尺子页（全篇唯一争议点），P5是预期差，P6站队收尾。工具选择：单一业务→PS倍数横向对比 / 多元业务→SOTP拆解 | DeepSeek（PS 150x vs OpenAI 66x——PS倍数对比）、比亚迪估值（四个业务市场只算了一个——SOTP拆解）、比亚迪储能（宁德首选→出局——同一赛道两套标准） |

**故事型反常识阶梯模板（8步）**：

```
1. 建立简单世界 + 具体角色（有名字）+ 一个约束 → 让观众跟着具体的人走
2. 英雄打破循环：角色冒险 → 结果反转 → L1 反常识命题
3. 涟漪扩散：创新产生新问题 → L2 视角反转
4. 权力/腐败进入系统 → L3 框架层
5. 后果叠加 → 数字震慑 → L4-L5 算术/人性
6. 真实世界镜子：虚构+真实案例交替（瑙鲁/冰岛/2008）→ L6 锚定
7. 回到观众："你就是艾伯。你的渔网是什么？" → L7 自照层
8. 带走清单：N条可操作原则 → L8 工具层
```

**对照型反常识阶梯模板（6步）**：

```
1. 具体对照场景：一个可以"看见"的差距（游戏6h vs 作业8min）
2. 宣告结构："他们用了什么手段？为什么我们反着做？" —— 建立对照预期
3. Layer 1：A机制X → B做法 → 差距 → 权威+数字
4. "但X只是第N层" → Layer 2（显式层级递进，创造结构预期）
5. 持续4-5层对照，每层揭示一个新的差距维度
6. 转折："问题变了——不是怎么打败A，是怎么把A的机制搬过来" → 工具化
```

**框架型反常识阶梯模板（5步）**：

```
1. 极端对比钩子：两个结果差100倍的选择（16h×10年→100万 vs 2h×3年→1000万）
2. 宣告结构："5个维度，5次跃迁，每一层都在重构你的认知"
3. Layer 1：最低级（你以为这就是答案？）
4. 层级碾压递进："但更狠的还在后面""真正的终局是..." 每层讲完→观众觉得到顶→下一层说"不，还有"
5. 收尾：你现在哪一层？→ 用尽全力往上爬一级。给动作不给感悟。
```

**定价纠正型反常识阶梯模板（6步）**：

```
1. 封面三层递进：公司名 + 具体数字 → 反常识判断 → 标签行。钩子模式=极端对比型或事件反差型
2. P2 灵魂页：2×2 数据卡片直接给答案。不铺垫。核心工具路由——单一业务→PS倍数横向对比 / 多元业务→SOTP拆解
3. P3 纠正认知：打破一个市场共识。每页一个认知点+一个判断句。"你以为X？实际市场在定价Y。"
4. P4 尺子页：全篇唯一争议点+可截图金句。同一个赛道，两把尺子——尺子歪在哪。争议方法论，不争议价值观。
5. P5 预期差：拉终局。三种情形/超大数字。一句判断收束。
6. P6 站队收尾：二选一 + 填空/晒数据触发器。不给标准答案。观众带着立场进评论区。
```

**铁律**：
- P1 封面禁止问号标题/悬念词/金句/结论。三层递进缺一不可。
- P4 尺子页是全篇情绪最高点——前面在"给信息"，P4 是"亮立场"。此页必须有一句能脱页传播的判断句。
- P6 站队前加一句话收束——观众能转述的完整判断句。不是"你怎么看？"→是"尺子歪了。三年后回来翻。"
- 评论触发器 ≥2 个：P3-P5 埋一个填空/晒数据 + P6 站队。类型不重复。
- 窄选题（只有圈内人在乎）→ 靠人设拉近："跟你一样刚看到的人一起拆"。不靠降维科普。

**推翻机制适用判断（Step 7.6 选题时决定）**：

| 判断条件 | 结构类型 |
|---------|---------|
| 选题有**一个核心概念**，要在不同领域/深度验证它 | 概念型 |
| 选题有**一个层级体系**，要展示从低到高的跃迁 | 框架型 |
| 选题可以**编成一个寓言故事**，故事弧线=认知曲线 | 故事型 |
| 选题有**两个天然对照物**，分别代表"对的做法"和"错的做法" | 对照型 |
| 选题有一个**具体公司/事件**，涉及"值不值/贵不贵/定价错没错"的判断，有数字+反转+争议空间 | 定价纠正型 |

参考文件：`知识库/案例库/爆款拆解/认知概念_幂律分布_叙事拆解.md`（六项核心手法 + 与不爆内容对比表）

**Step 8a**：导演分析（Phase 1）——先定情绪弧线（起点→终点，对应 Step 7 选定的弧线类型），再输出 directorAnalysis JSON（情绪弧线/主线/钩子/情绪曲线/观众逐页追踪/视觉比喻/关键画面）。

**钩子方向决策（强制，钩子自检前执行）**——人不是因为"有个好东西想得到"而动，是因为"有个坏东西想躲开"而动。苦难是引擎，恐惧是油门。

| 方向 | 驱动力 | 观众反应 | 适用 |
|------|--------|----------|------|
| **回避** | 怕失去/怕正在做错/怕被落下 | "操，这就是我" → 看完→想→行动 | 概念型/故事型/祛魅型——打破幻觉，默认方向 |
| **趋近** | 想得到好东西/想变更好 | "有意思，收藏了" → 收藏→忘记 | 框架型/教程型——给具体工具时使用 |

**操作**：动笔前先定方向。默认走回避——让观众感觉到"我正在做的正确决定可能正在害我"。趋近方向仅在给具体可操作工具/框架时使用。判断标准：看完钩子，观众是想"躲开一个坏东西"还是"靠近一个好东西"？前者才会看完。

**钩子类型确认**：回看 Step 7.56 选定的11型钩子锚类型。Step 8a 不重新选型——只确认 Step 7.56 的选型结果是否匹配钩子方向（回避/趋近）和结构类型。不匹配→回 Step 7.56 重选。

**铁律**：Track A 钩子 = 纯判断句。句号结尾。不铺场景。钩子是内容的结论，不是内容的广告。句法遵循 Step 7.56 三模板公式。Track C 钩子 = 日常场景/行为复述。两轨句法不混用。

**钩子共鸣自检（强制）**：①谁会睡不着觉想这个？②观众反应是"有意思"还是"这就是我"？两道全过才往下走。详见 memory `feedback-hook-from-real-problem`。

**槽点预埋（强制）**

**数量规则（按格式分流）**：
- 图文/轮播：≥1 个争议点，放在 P4（尺子页）。P6 放评论触发器，不放槽点。
- 口播/短视频：≥2 个槽点，至少一个在 P3-P5 中间，一个在 P7-P8 结尾。

**递进式证明结构（强制）**——槽点不能直接抛"你怎么看"。先点火，再开口。

```
证明矛盾 → 命名问题 → 定性判断 → 未来后果 → 开口
```

| 步 | 做什么 | 例（比亚迪估值P4） |
|----|--------|-------------------|
| 1. 证明矛盾 | 两组数据/事实放一起，矛盾自己刺眼 | "宁德标签→PE 20倍。比亚迪标签→PE 17倍。储能系统出货第一 vs 只卖电芯。" |
| 2. 命名问题 | ≤6字可传播标签，观众评论区引用的弹药 | "尺子歪了。" |
| 3. 定性判断 | 不是偶然。是系统性的错误。 | "不是一天的歪法。" |
| 4. 未来后果 | 矛盾继续存在的后果，制造紧迫感 | "当储能占比12%→20%+，'车企'标签还挂得住吗？" |
| 5. 开口 | 到这里才问。观众已被点燃。 | "你怎么看？" |

**可传播命名要求（强制）**：每个槽点必须产出一个 ≤6 字的标签（如"尺子歪了""场景牌最硬""标签的差距"）。观众在评论区用这个标签吵架。没有命名 = 有情绪没弹药，评论打不出来。

**槽点质量检查**：①门槛低到任何人能搭话？②95%对+5%在方法论上留白？③安全争议区——争议点在方法论上不在价值观上？④递进五步完整？没有跳步直接问"你怎么看"？⑤有 ≤6 字可传播命名？详见 memory `feedback-comment-bait-design`。

**评论触发器设计（强制，≥2 个，类型不重复）**

槽点是让人"想辩论"。评论触发器是让人"想晒"。两种都要有，放在不同位置。

| 类型 | 公式 | 例 | 评论门槛 |
|------|------|-----|---------|
| 填空型 | "你的____是什么？" | "你的渔网是什么？" | 零门槛，看完就能填 |
| 晒经历型 | "你有没有被____过？" | "你有没有被免费试用套路过？" | 零门槛，人人有经历 |
| 晒数据型 | "算一笔账：你的____是多少？" | "你的时薪是多少？" | 有具体数字可晒 |
| 站队型 | "你觉得是A还是B？" | "自律问题还是激励问题？" | 零门槛，需要观点 |
| 猜测游戏型 | "笑得最大声的不是你猜的那个" | "这一单笑得最大声的可能不是你猜的那个" | 零门槛，好奇心驱动 |

**触发器位置规则**：
- 填空型/晒经历型/站队型：收尾段优先，也可放中间
- **猜测游戏型：只放 P3-P5 中间**，不放收尾。收尾猜谜 = 玩观众。

**铁律**：
- 触发器答案不能是"对/不对"——必须是"我的版本是____"。观众带着自己的答案进评论区。
- 填空型和晒经历型优先——门槛最低。至少有一个放在收尾段。
- 触发器是视频内容的一部分，不是评论区运营文案。视频里就要问出去。

**首评引导策略（强制，发布时写入评论区）**

首评定调子。首评写什么，评论区就长什么样。不是"运营动作"——是给观众示范这儿的评论区怎么玩。

| 线型 | 首评模式 | 作用 | 例 |
|------|---------|------|-----|
| 分析线 | 表态 + 具体判断 + 抛问题 | 定调子：这儿是辩论场。教观众怎么辩。 | "我的判断：能投。但投的不是'钠电'这个概念，是正极材料和系统集成。你怎么看？" |
| 感受线 | 填空/晒经历触发器 | 定调子：这儿是自白室。教观众怎么晒。 | "你现在在补什么仓。不是钱。是____。" |

**首评铁律**：
- 不中立。先表态。创作者没立场，评论区就没方向。
- 分析线首评必须包含一个具体判断（不是"我觉得都有道理"），给观众一个可以反对的靶子。
- 感受线首评把收尾触发器放进首评——视频里问了，首评第一个答。降低第一个评论者的门槛。
- 首评不等同于槽点或触发器。首评是**运营执行**——把视频里的触发器节奏延续到评论区。

**收尾设计决策（强制）**

| 决策项 | 选项 | 不过标准 |
|--------|------|---------|
| 收尾类型 | 工具型（四问/铁律）/ 公式型（价值=×）/ 自定位型（你现在哪一层）/ 原则清单型（N条原则）/ 预告型（下期讲X）/ 站队型（二选一，观众带立场进评论区） | 感悟型（"道理简单做到最难"）/ koan型（"补仓还是补面子"）→重写 |
| 可转述 | 观众看完能对朋友说出一句完整的话？读出来试试 | 说不出一句完整的话→收尾缺锚点 |

**互动心理钩子（强制）**：从下表选 1 个主导心理 + 最多 1 个辅助心理。选题阶段就决定——决定"观众看完会做什么"，直接影响槽点选型和评论触发器方向。

#### 时长计算公式

```
建议时长 = (口播总字数 ÷ 基准字速) × 情绪加权系数 + 停顿补偿

基准字速（语速预设）：
  慢速：5.0 字/秒（每100字≈20s）  — 深情、沉思、强调
  正常：6.7 字/秒（每100字≈15s）  — 默认
  快速：10 字/秒（每100字≈10s）   — 犀利、密集输出、紧张

情绪加权系数（情绪曲线越起伏→系数越大）：
  全程单一情绪（如纯干货）：1.0
  标准起伏（2-3个情绪转折）：1.05
  强情绪波动（4+个情绪转折，含愤怒/兴奋）：1.10

停顿补偿：
  每个空行（换话题）= 0.5s
  每个关键停顿标注（如"停一秒"）= 1s
  结尾停顿 = 1-2s（收束留白）
```

**示例计算（短视频脚本）：**

```
口播总字数：约 260 字（5镜口播内容合计）
语速：正常 → 6.7字/s → 260÷6.7 ≈ 39s 纯口播
情绪系数：标准起伏（好奇→恍然→清醒→专注→确信，5个情绪点）→ 1.05
停顿补偿：约10个空行×0.5s + 结尾停1s + 关键停顿3处×0.5s = 8s
即梦文字动画消耗：每镜约2-3s文字淡入/淡出/定格 → 5镜×2.5s ≈ 13s

建议时长 ≈ 39×1.05 + 8 + 13 ≈ 62s → 取整 60s 或 75s

若选 60s：口播语速需微提至 ~7.5字/s（偏快），情绪镜3/镜5不放慢
若选 75s：口播语速 ~5.5字/s（偏慢），金句和停顿有足够时间呼吸 → 推荐 75s
```

**Step 8c**：逐页/逐镜生成（Phase 2）——基于确认的导演分析+预设条件。图文按连续性系统标注。口播按 audienceMap 逐段追踪。短视频每镜写入形象锁定+场景锁定+即梦 prompt。运镜按 seedance-camera 6维合约输出，灯光按 seedance-lighting 7维合约输出，连续性按 shot-list-continuity 9维台账追踪。

**鸿沟自检（Step 8c 逐段执行，全类型强制）**——来自罗伯特·麦基《故事》。故事产生于主观期望和客观结果之间的裂缝。每一段（每一个"事件"）写完后，自问：

```
观众读到这段开头，以为会发生什么？
  └── 这段结尾实际发生了什么？
      └── 有没有裂开一道口子？
```

没有鸿沟 = 这段只有信息，没有事件。信息是"中等收入陷阱的定义"。事件是"你以为中等收入陷阱是穷——不是，是循环断了"。前者观众左耳进右耳出，后者脑子里被撕开了一道口子。

**操作铁律**：不在段首预告结论。先让观众以为事情是这样的，然后在段尾撕开。每段结尾检查——观众的期望被打破了吗？如果没有，这段重写。

**鸿沟力度递进检查**：整篇稿子的鸿沟不能是同一力度。第一段→小裂口（"原来是这样"），中间段→中裂口（"等等，那岂不是……"），最后一段→大裂口（"所以我一直在……"）。序列逐级加深。

**槽点落地检查（Step 8c 生成后强制，Step 8a 槽点预埋的对应执行）**——导演分析里预埋的槽点，必须出现在脚本正文里。扫描全稿：
```
□ 槽点1（导演分析预埋位置____）在脚本正文第____行？ → 没找到 → 补一句。门槛低到买菜大妈能搭话
□ 槽点2（导演分析预埋位置____）在脚本正文第____行？ → 没找到 → 补一句。争议在方法论不在价值观
```
槽点不是金句，不是判断句。槽点是一个**开放的口子**——"那你觉得呢""你是不是也遇到过""评论区说说"。不提问的槽点不是槽点。

**两难落地检查（Step 8c 生成后强制，Step 8a 危机两难的对应执行）**——导演分析里定的两难，必须在收尾段落直接缝进去。扫描收尾：
```
□ 观众读完最后一句，脑子里在打架吗？（"但……""可是……""那万一……"）
□ 还是读完就关掉了？（"嗯有道理"→划走）
```
收尾是答案 → 重写。收尾是"我不确定，但至少我知道了……" → 合格。**两难不用"你"给，用"我"给。** 不是"你应该……但是……"（说教），是"我知道……但我也知道……"（陪伴）。

**冲突呼吸检查（Step 8c 生成后强制）**——对抗力量揭晓后，不能立刻给答案。观众需要在"等等，那岂不是……"的状态里待一会儿。

```
□ 核心反转（如"没想过可以不要弓"）出现后，隔了多少行才给下一段答案？
  → 少于3行 → 太快。观众还没消化。插入一个停顿/一个反问/一个个人反应
```

**硬性比例约束（全类型强制）**：按 Step 0 选定的线型检查，不设独立数字。

| 线型 | 事实 | 态度+共鸣 |
|------|------|----------|
| 分析线 | ≥60% | ≤40% |
| 感受线 | ≤40% | ≥60% |
| 混合线 | ~50% | ~50% |

事实=数据/事件经过/机制解释/标准对比。态度+共鸣=个人判断/替观众说心声/经历故事/升维视角。生成后数每页归属→超比例则砍超限侧、补不足侧。详见 memory `feedback-default-writing-engine`。

**四维度内容约束（全类型强制，生成时同步检查）**：
1. **情绪粒度**：每页的情绪描述够精确吗？不是"焦虑"→是"交出键盘让他接管了整个服务器"。笼统词（焦虑/愤怒/释然）替换成一句话能命名的具体感受。
2. **认可双形态**：全文搜索——有"替我说"（确认已有认知）吗？有"让我看见"（扩展认知边界）吗？至少各一句。"让我看见"比"替我说"更值钱。
3. **嘴替三动机**：嘴替金句是替自己/对别人/对群体？不能只有第一种。至少设计一个"替他对别人说"或"替他站队"。
4. **受众筛选信号**：有没有一个只有目标受众能识别的东西（名字/场景/概念）？一个就够。大众共鸣负责传播面，精准信号负责筛选。

**危机两难检验规则（全类型强制）**——来自罗伯特·麦基《故事》。危机必须是真正的两难之境——两善取一或两恶择轻。不是"要不要做"，是"两个都要不了"。

```
算术题（不合格）：只有一个正确答案。观众算完就走了。
  └── 例："从一张网开始" —— 观众想"好的"，然后没有然后了。

两难选择（合格）：两个都对、或两个都痛。观众脑子里开始打架。
  └── 例：文凭信号相亲结尾 —— "你看到了什么信号，让你觉得这人行——或者不行？" —— 每个人被迫站队，没有标准答案。
  └── 例：幂律结尾 —— "多数人一生在优化'不输'。少数人知道，有些事值得你接受更高的失败率。" —— 你不用回答，但脑子里在比较自己属于哪边。
```

**操作**：结尾写完后问自己——观众看完最后一句话，是"嗯有道理"（关掉），还是"但是……"（打字）。如果答案是前者，把结尾从"给答案"改成"给两难"。
| 12 | 生活化类比 | 核心概念有没有用一个日常场景/物体/动作来翻译？不是"用学术语言解释学术概念"，是"用一个每个人都见过的东西讲一件每个人都没想过的事"。详见 `writing-style-metaphor-storytelling` |

| 14 | 结尾判断工具 + 可用性 + 能量 | **可用性**：观众下周能用它做什么？说不出一件具体的事→不改不发。**内容**：结尾是判断工具（能对朋友说出来）还是自省问题（只能自己想）？结尾有问号→警惕。结尾反问观众→重写。结尾给观众拿去问别人→合格。**能量确认**：收尾能量↑还是↓？↓→回 Step 8a 收尾设计决策。 |

**#12 生活化类比检验（全类型强制）**——核心概念必须翻译成日常语言。检查方式：把核心概念那段拿出来，遮住所有术语和书面语，剩下的部分还能不能让人听懂？

不合格：渔网思维 → "基于资产抵押的循环信贷扩张机制。"
```

框架型/诊断型内容最容易漏类比——因为结构本身就是解释，容易跳过翻译这一步。生成后强制检查。

**#13 可截图金句检验 + 方向（全类型强制）**——来自幂律分布爆款拆解六项核心手法 + 连锁补错反例。

**方向先查（强制）**：观众把这句话截图发朋友圈/微信群——是在**炫耀**（"我学到了这个框架"）还是在**自首**（"这是我的毛病，你看看"）？
- 炫耀 → 合格。观众戴着这句话像戴一枚徽章。
- 自首 → 不合格。没人截图骂自己的话发出去。重写。

**内容再查**：全文中找一句话，满足：
1. 脱离上下文独立成立（不需要"前面我们讲了……"）
2. 反常识结构（多数人/少数人、你以为/实际上、A叫X B叫Y）
3. 是判断不是忠告（不是"你应该"，是"世界是这样"）

```
合格（炫耀方向）：多数人一生在优化"不输"。少数人知道，有些事值得你接受更高的失败率。
不合格（自首方向）：承认自己错了——比亏还难受。（观众不会截图骂自己）
不合格（忠告）：所以建议大家多看失败案例。
```

如果全文找不到→结尾重写。这是全文唯一可以脱离内容传播的东西。**方向比内容更决定性——先查方向，再查内容。**

**#14 结尾判断工具检验 + 可用性（全类型强制）**——结尾不能是自省问题，必须是判断工具。

**可用性先查（强制）**：观众下周能用它做什么？说不出一件具体的事 → 不改不发。
- 幂律分布："下次站在两个选项前，问自己：成了够不够覆盖前面的不成？" → 能用 ✓
- 连锁补错（反例）：说不出来 → 观众沉默了，没有工具能带走 ✗

**内容再查**：结尾不能是自省问题，必须是判断工具。

```
自省问题（不合格）：让观众自己想去。沉默，划走，没有东西能带走。
  └── 例："你爱的是他——还是你在他身上那些掏空的付出。" → 观众沉默了。没法截图、没法转述、没法下次用。

判断工具（合格）：给观众一个框架，下次遇到直接套。观众能对别人说出来。
  └── 例："你爱的是一个值得长期持有的投资人，还是一个只想短线套利的交易者？" → 两个选项，观众立刻对号入座，截图转发。
```

**为什么写错**：情绪推到高点→本能想收→留白→自省问题。这是文学结尾的本能，不是短视频/长文的结尾。观众刚被刺痛、被吓到，情绪在高点——这时候给工具，她马上能用。给问题，她只能沉默然后划走。

**操作**：结尾写完后问自己——观众看完最后一句，能不能**对闺蜜/朋友说出来**？
- 能说出来 → 判断工具 ✅
- 只能自己想 → 自省问题 ❌ → 重写为二选一命名

**重写公式**：把"你想想A还是B"改成"你要么是A，要么是B"。
- ❌ 你爱的是他，还是付出？→ 自省
- ✅ 你爱的是投资人，还是交易者？→ 判断工具
- ❌ 你的努力是方向对还是方向错？→ 自省
- ✅ 多数人在优化"不输"。少数人在优化"能赢"。→ 判断工具

**例外**：只有一种情况结尾可以是问题——问题是替观众问别人的（"下次相亲，你看到了什么信号"），不是让观众问自己的。**问观众自己 = 不合格。给观众拿去问别人 = 合格。**

**#15 反常识阶梯检验（全类型强制·统一定义见 Step 7.65 反常识阶梯 vs 柱子 vs 放大）**——框架阶段 Step 7.65 先查，定稿后 Step 9 复查。推翻类型必须是**推翻**（层层翻折，每段新认知踩在上段肩上），不能是**放大**（同一结论换尺度）或**柱子**（同一结论换不同案例反复证明）。

**检查方法**：列出每段的核心认知增量——"这一段让观众知道了什么上一段不知道的？"

- 三段都在证明同一个结论 → 只留最有力量的一段（最不可替代的案例），其余砍掉或压缩成一句

## 核心思维

### 封面三要素（全类型强制）

用户决定继续看一个内容，最多只花 **2 秒**。封面不是摘要，是在这 2 秒内制造认知缺口。详见 [设计规则](知识库/规则库/设计规则.md)。

```
旧：锚点 + 判断
新：粉碎默认假设 + 锚点 + 判断方向
```

五种封面模式：反常识结论式 / 身份标签式 / 数字对撞式 / 概念折叠式 / ROMO式。硬核分析默认反常识结论式。

### 背景设计铁律（全类型强制）

**严禁纯色背景。绝对禁止。** 纯白 [#ffffff]、纯黑 [#000000]、纯灰、纯任何单色——全部禁止。

每页/每镜必须有背景图，且要包含与选题相关的视觉元素（三选一，至少满足一个）：
- **渐变底**：至少两个颜色的渐变过渡（如蓝白→薄荷绿）
- **纹理底**：纸张纹理、胶片颗粒、磨砂质感、毛玻璃
- **光影底**：光束、环境光、暗角、光源方向

在此基础上，背景中必须有**至少一个与选题领域相关的抽象视觉元素**：
- 选题是储能/电池 → 流线、波形、能量网格、电路纹理
- 选题是金融/投行 → 数据流、K线纹理、几何网格
- 选题是工厂/制造 → 工业肌理、金属拉丝、蓝图线条

```
□ 每页背景是否纯色块？ → 是 → 不发。重做背景。
□ 每页背景是否有相关抽象元素？ → 没有 → 不发。
□ prompt 是否只写了颜色代码（如 #ffffff）？ → 是 → 不发。
```

**注意**：背景元素是氛围层，不是信息层。用 3-8% 透明度、虚化、半透明叠加——隐约可见即可，不能抢文字。

### 图文页面设计铁律（全类型强制）

**严禁全文字页面。** 每页必须至少有 1 个非文字视觉元素：图表、对比图、数据环、进度条、波形图、时间线、结构图——任选其一。

- 封面：数据环/进度环/大数字+图表元素，文字≤3行
- 内页：对比图/条形图/结构图/时间线 占画面 ≥40%，文字≤60字
- 禁止段落文字堆砌。能用图就不用字。

```
□ 每页是否有非文字视觉元素（图/表/环/条/线）？ → 没有 → 不发。
□ 文字是否超过 60 字？ → 超过 → 砍。
□ 这页能不能 3 秒扫完？ → 不能 → 用图代替字。
```

### GPT Image2 生图 prompt 写作铁律（A型图文强制）

**Image2 是"相机"，不是"设计师"。** 给它场景、材质、光线，它出好图。给它排版指令、抽象元素、渐变描述，它只会堆文字。

#### 核心原则：描述摄影场景，不描述图形设计

```
旧（抽象设计 — 禁止）：Soft gradient background from white to mint green. A luminous cyan ring floats center. Minimalist fintech poster aesthetic. Ample negative space.

新（摄影场景 — 必须）：Top-down shot of a dark walnut desk. Warm amber desk lamp casts a focused pool of light. A brushed brass plaque engraved with text sits in the light. The rest fades to deep shadow.
```

#### 每条 prompt 必须包含的 5 个要素

| # | 要素 | 说明 | 示例 |
|---|------|------|------|
| 1 | **物理场景** | 真实的地点/表面 | 深色木桌面、玻璃展板挂在墙上、蓝图摊在金属绘图桌上 |
| 2 | **具体材质** | 实物材料，不是抽象色块 | 黄铜铭牌、磨砂玻璃、牛皮纸、拉丝钢板、奶油色卡片 |
| 3 | **光源方向** | 光源类型+方向+色温 | 左上角窗外自然光、琥珀色台灯聚光、暖色工业吊灯 |
| 4 | **实物道具** | 场景中的真实物品 | 钢笔、计算器、咖啡杯、金属尺、文件夹、便签纸 |
| 5 | **文字载体** | 文字出现在什么实物上 | 刻在黄铜铭牌上、手写在便签纸上、印在蓝图上、标在仪表盘上 |

#### 严禁使用的抽象描述（直接拉黑）

```
❌ "gradient background"         → 改用真实材质：wood grain, brushed steel, frosted glass
❌ "clean / minimalist / airy"   → 改用具体描述：a single document on an empty desk, spot-lit
❌ "[element] floats / is placed" → 改用实物载体：printed on..., engraved on..., handwritten on a sticky note
❌ "abstract [anything]"         → 全部改成具体实物
❌ "premium / modern aesthetic"  → 改用具体材质：brass and dark wood, glass and chrome
❌ 纯色代码（#ffffff, #1a1e24）  → 改用材质描述：dark walnut wood, matte charcoal wall
```

#### prompt 质量门禁

```
□ 能不能拍成照片？ → 不能 → 重写。prompt 描述的场景必须可以用相机拍出来。
□ 文字在实物上吗？ → 浮在空中 → 重写。文字必须出现在纸张/铭牌/屏幕/卡片/玻璃等实物载体上。
□ 有光源吗？ → 没有 → 加。每条 prompt 必须至少有一个明确光源。
□ 有材质吗？ → 只有颜色代码 → 重写。必须描述物理材质（木/金属/玻璃/纸张/皮革/石材）。
□ 是不是"海报/设计稿"思维？ → 是 → 重写。切换到"摄影师拍一张照片"思维。
```

#### 页面间统一性

同一套图文的 7-8 页之间，通过以下方式保持视觉统一，同时每页又有独立的摄影场景：
- **统一光源色温**：全篇用同一种灯光色调（如琥珀暖光 或 自然白光）
- **统一材质调色板**：限定 2-3 种核心材质贯穿全篇（如深色木+黄铜+玻璃）
- **首尾呼应**：P1 和 P7 回到同一个场景/同一张桌子，形成闭环

```
□ 7页光源色温一致吗？ → 不统一 → 统一。
□ 材质调色板贯穿了吗？ → 每页完全不同材质 → 选2-3种核心材质贯穿。
□ P1和P7有呼应吗？ → 没有 → P7回到P1的场景。
```

### 开场钩子 + 超出预期（口播/视频强制）

前 1.5-3 秒决定观众是否划走。详见 [开场方法论](知识库/方法论库/开场方法论.md)。

### 案例库驱动创作（全类型强制）

每次创作前，必须查案例库 README 索引表。案例库现有 63 篇（51 篇爆款拆解 + 12 篇图文拆解），覆盖 7 个对标账号（朱莉娅/周一二/momo/变强起点/认知便利店/半佛/巫师）+ 商业对照类 + 投研类 + 用户备电。

**三步查法：**

```
Step A（选题阶段）：扫 README "适用场景"列 → 找到与当前选题领域/结构相近的案例
Step B（生成阶段）：读目标案例的"可复用手法矩阵" → 选 2-3 个技法嵌入当前内容

## 受众漏斗层级

创作前强制锁定。层级决定翻译深度、例子选择、信息密度。

```
L1 泛人群     — 刷抖音路过。没有商业知识。不会被专业概念留住。
               钩子驱动。全部翻译成日常语言。每页不超过一个数字。

L2 泛商业     — 买过股票、关心赚钱、知道基本概念（PE/营收/利润）。
               给框架不给术语。用对比和故事。每页可以有2-3个数字。

L3 从业者     — 工厂老板、企业主、行业里的人。
               直接讲利益。算账。不绕弯。可以上专业词但必须立刻翻译。

L4 专业       — 投资人、分析师、看财报的人。
               术语直给。数字密集。不需要翻译。但要给"他们不知道的东西"。
```

**使用规则：**
- 每篇内容锁定 1 个主力层级 + 最多 1 个延伸层级 + 1 个触达层级
- L1 触达靠钩子和封面，L2-L3 主力靠正文框架，L4 延伸靠评论区深度讨论
- 主力层级决定页数：L1≤4页、L2≤6页、L3≤7页、L4≤8页
- 自检：生成后问"主力人群看完能拿走什么？延伸人群会不会觉得太浅/太深？"

**主力层级速判由 config 定义。** 通用规则：热点新闻→L1泛人群、产业框架→L2泛商业、算账利益→L3从业者、交易结构→L4专业。

## 内容台账记录（每篇强制）

内容定稿后，在 `项目/<项目名>/输出/内容台账.md` 顶部新增一行记录。格式见 `母系统/内容台账模板.md`。

**规则：**

1. **真问题（入口）**：钩子对应的真实困惑。一句话。观众点进来之前心里的那句话
2. **带走什么（出口）**：看完后脑子里的新东西。框架/判断/概念/视角。一句话
3. **领域归类**：财富 / 关系 / 认知，三选一。同选题的口播+图文算两条独立记录
4. **更新统计**：新增后同步更新顶部统计概览的三领域数量和占比

**闭合检查**：记录时自检——真问题和带走的东西是不是同一根线的两端？如果真问题是"为什么总选错人"但带走的是"戈特曼94%预测率"，就没闭合。带走的东西必须直接回答真问题。**带走的东西必须是判断工具，不能是自省问题。**

```
□ 真问题写清楚了吗？（观众进来之前的内心独白）
□ 带走什么写清楚了吗？（观众出去时脑子里的新东西）
□ 真问题 → 带走什么 闭合了吗？（出口直接回答入口）
□ 带走的是判断工具还是自省问题？（观众能对闺蜜说出来吗？不能→重写结尾）
□ 领域归类正确吗？（财富/关系/认知）
□ 统计概览更新了吗？
```
