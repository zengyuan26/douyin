# 短视频脚本输出规范

> 基于 2026-07-07 杠杆脚本定稿提炼。所有短视频（即梦/Seedance）脚本强制执行此规范。
> 生成前必须加载本文 + 形象库 + 场景库 + 口语化脚本规则。

---

## 一、文件命名

```
短视频_{核心概念}_{YYYYMMDD}_{内容线}.md
```

示例：`短视频_杠杆_20260707_备电.md`

---

## 二、文件头部

```markdown
# 短视频_{核心概念}_{YYYYMMDD}_{内容线}

> 内容类型：短视频（即梦/Seedance）| {N}镜 | 9:16竖版 | ~{X}s
> 视觉风格：深夜书房 — 暖琥珀光 + 木质书桌 + 手绘叙事
> 内容线：{项目路/来时路} | 生成日期：{YYYY-MM-DD}
```

## 三、导演分析摘要（必须）

```
主线：一句话。核心概念。叙事路径。
钩子：{公式类型}。"{完整钩子文本}"
      不是"今天讲XX"。是{做什么——替观众问/打碎默认认知/身份共鸣}
情绪：{情绪1} → {情绪2} → ... → {情绪N}
核心手法：概念名=开场锚点。平行世界=含义落地。翻译=闭环。
```

**钩子公式三选一**：
- 反常识断言式："你以为X。但Y。"
- 身份标签式："如果你也在[做某件事]——"
- 静默中断式：(停顿) + 一句话推翻（进阶，有信任基础后用）

## 四、分镜预设条件（必须）

| # | 条件 | 值 |
|---|------|-----|
| 1* | 出镜形象 | {从形象库选取。默认：增元·商务休闲} |
| 2* | 场景 | {从场景库选取。默认：深夜书房} |
| 3 | 关键道具 | 白纸+钢笔。所有镜头核心动作——边画边讲 |
| 4* | 时长 | 建议 {X}s。口播≈{N}字÷6.8×{情绪系数} + 停顿10s + 即梦动画10s ≈ {X}s |
| 5* | 视频比例 | 9:16 竖屏 |
| 6 | 帧率 | 24fps |
| 7* | 方言 | 普通话 |
| 8* | 语速 | 正常（6.8字/s） |
| 9 | 字幕 | 开启 |
| 10 | BGM | 开启（低沉钢琴loop。翻译时刻音量微推） |

**时长计算公式**：`建议时长 = (口播总字数 / 6.8) × 情绪加权 + 停顿补偿 + 即梦动画补偿`

| 参数 | 值 |
|------|------|
| 基准字速 | 6.8 字/秒（正常） |
| 情绪加权 | 标准起伏 1.05 |
| 停顿补偿 | ~10s |
| 即梦动画补偿 | ~10s |

## 五、逐镜脚本（必须）

### 每镜结构

```
### 镜{N}：{标题}（{start}-{end}s）

**【口播台词】**
{code block。每行≤12字。空行=停顿。破折号=悬念}

**【即梦 prompt】**
角色：{从形象库复制分身描述。镜1写全，后续用"Same man"引用}
场景/光影：{从场景库复制光影描述。光源方向、色温、阴影质感}
动作：{本镜他要画什么。每个关键句标注手势节奏。何时画、何时停、何时看镜头}
机位/构图：9:16 vertical。{景别}。{构图说明}。Camera fixed/movement。
视线：{何时看镜头，何时看纸}
声音：Quiet study ambience。{BGM描述}。{环境音}。
字幕：开启。底部居中。白色字体。

**【连续性】**
transition: {硬切/叠化}。{说明}
carryOver: {从上一镜延续什么}
newElements: {本镜新增什么}
emotionLink: {上一镜情绪} → {本镜情绪}（"{观众心里话}"）

**【视线流量】**
进入: {视线从画面哪个位置进入——左上/中央/底部/由人物视线引导}
慢下来: {在哪个元素上减速——人脸/手部动作/纸面内容/道具}
落点: {最终视线落在哪里——这是本镜的信息核心}
出口: {从哪个位置离开画面准备下一镜——右下/由人物视线方向引出}

**【audienceMap】**
| 眼睛 | 心里 |
|------|------|
| {观众看到什么} | {观众心里想什么} |
```

### 即梦 prompt 质量门禁

每条 prompt 必须逐项检查后才输出：

```
□ 词数 — 80-120 词。不超 150 词（即梦字符上限）
□ 单镜时长 — ≤15s。超过需拆分为多个即梦片段（seedance-continuation 续接）
□ 角色描述 — **每镜必须写全**（服装+体型）。即梦无跨镜记忆，不可用"Same man"引用
□ 场景/光影 — 光源方向+色温+阴影。每镜写（或"Same desk, same warm amber light"）
□ 动作 — 具体画什么。关键句配手势。"when he says X, he does Y"
□ 机位/构图 — 9:16 vertical + 景别 + 构图 + camera状态
□ 视线 — 看镜头 vs 看纸。标注关键句视线切换
□ 声音 — 环境音 + BGM + 特殊音效
□ 字幕 — 每镜标注
□ prompt 自包含 — 不看前后镜也能建立画面
□ 英文书写
□ 自然语言 — 紧凑段落，不使用结构化标签（角色：/场景：/动作：等）
□ 色彩动机 — 颜色来自画面内部实物光源（台灯/窗外光/仪表盘/屏幕光），不凭空加色调滤镜
```

### 道具演变追踪

纸面内容必须逐镜累积，在连续性台账中追踪：

```
镜1：{纸上画了什么}
镜2：+{新增了什么}
镜3：+{新增了什么}
镜N：全貌（{所有内容的总结}）
```

## 六、连续性台账（9维摘要）

| 维度 | 镜1 | 镜2 | ... | 镜N |
|------|------|------|------|------|
| **形象** | {服装} | ← | ← | ← |
| **场景** | {场景} | ← | ← | ← |
| **光线** | {光源} | ← | ← | {变化说明} |
| **景别** | {中景} | {中近景} | {略宽} | {特写/回镜1} |
| **纸面内容** | {基础} | +{新增} | +{新增} | 全貌 |
| **视线** | {看镜头/看纸} | ← | ← | ← |
| **视线流量** | {进入→慢→落→出} | {进入→慢→落→出} | ... | {进入→慢→落→出} |
| **节奏** | {快/稳/慢} | ← | ← | ← |
| **情绪** | {情绪1} | {情绪2} | ... | {情绪N} |

> ← 表示与上一镜相同。只在变化处写新值。

## 七、开场结构（建议自检，不强制写入每篇）

```
参考账号开法：
  {反常识问题} → 答案是{概念名}。→ 啥是{概念名}呀？→ {建世界}

我们这一版：
  {反常识问题} → 答案是{概念名}。→ 啥是{概念名}呀？→ {建世界}

概念名在前5秒就说了。
观众N秒后再听到这个词，词还是那个词，但重量完全不一样。
```

## 八、即梦 prompt 一致性检查（建议）

```
□ 所有镜 prompt 自包含——比例(9:16)、场景({场景})、形象({服装}) ✓
□ avatar 一致性由分身系统保证，prompt 中描述统一 ✓
□ 道具演变：白纸从空 → {镜1内容} → +{镜2内容} → ... → 全貌 ✓
□ 景别叙事：镜1中景引入 → 镜2-3中近景看画 → 翻译特写 → 回中景 ✓
□ 光线一致：{光源描述}。末镜微暗——情绪收束 ✓
□ 视线叙事：镜1开场看镜头→画画看纸。中间看纸为主关键处看镜头。翻译+结尾全程看镜头 ✓
```

## 九、自检清单（强制）

```
□ 开场公式：{问题/断言} → 概念名5秒内出现 → "啥是XX呀" → 进入平行世界
□ 概念名在前5秒就说了。不是藏到最后
□ 中间全程在故事里。除了开场的概念名，不引入第二个术语
□ 到翻译时刻，观众追了N秒的概念终于懂了
□ 人物/故事驱动——观众记住的是画面和命运，不是定义
□ 结尾反问或留钩子。不给答案
□ 情绪曲线：{完整情绪链} ✓
□ 人设：CVC投行分享认知工具。不讲课 ✓
□ audienceMap 逐镜追踪 ✓
□ 连续性9维台账 ✓
□ 即梦 prompt 英文、自包含、7要素完整 ✓
□ 9:16 竖屏 ✓
□ 平台合规（禁用词检查） ✓
□ 每镜口播台词 ≤ 50字，每句 ≤ 12字 ✓
□ 反模板：金句镜/收尾镜的构图是否跟上一期重复？重复就换构图策略 ✓
□ 反模板：第三镜（或末镜）是否又用了"空房间+遗物"式收尾？是就换成人物在动/关系在变 ✓
```
