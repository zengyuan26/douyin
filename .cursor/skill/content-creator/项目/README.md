## 新建项目

1. 复制 `母系统/config.template.md` → `项目/<项目名>/config.md`
2. 填写 [立项卡](母系统/项目评估方法论.md)
3. 创建 `输出/` 目录
4. 走 L1 轻实验 → 3-5 期内容验证
