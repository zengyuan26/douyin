# 儿童成长 · 选题池

> 初始选题。按 项目评估方法论 的 L2 MVP 验证目标排列。

## 首批验证选题（优先）

1. **孩子厌学** — "他不是不想学。他是学不动了。" / 家长最常见的错误反应
2. **亲子冲突** — "你吼完孩子，孩子记住的不是道理——是你吼他的样子。" / 冲突后的修复方法
3. **青春期情绪** — "不是叛逆。是他的大脑正在重建。" / 家长怎么接住
4. **隔代养育** — "奶奶一套、你一套。孩子其实比你聪明。" / 怎么对齐
5. **注意力/学习习惯** — "不是不专注。是专注错了地方。" / 野路子方法

## 验证指标

- 话题→播放量：哪个话题自然流量最大
- 播放→互动：哪个话题评论/私信最多
- 私信→咨询：哪个话题最容易转化为有效咨询
- 咨询→付费：家长愿意为什么产品付多少钱

## 扩展方向（验证通过后）

- 单问题→系列化（如"厌学"拆成5期：识别→原因→沟通→方案→复盘）
- 免费内容→低价测评→付费方案
- 具体问题→家长社群→长期陪伴
