# 儿童成长 · 运营规划方案

> 状态：L2 MVP（30-60天验证四件事）
> 表达者：重庆朋友（商业化合伙人）。主体档案见 `个人档案.md`。

---

## 一、核心定位

帮家长建立面对孩子情绪和沟通冲突的处理流程。不卖理论，卖"能用的方法"。

（信任路径：朋友线下大量真实咨询案例 + 野路子但有效 + 11万粉验证观众缘。待补具体案例）

## 二、内容策略

- **内容类型**：口播（朋友出镜）+ 清单体图文（家长爱收藏）+ 短视频（问题场景→方法）
- **选题来源**：家长真实困扰——厌学/亲子冲突/青春期情绪/隔代养育
- **声音**：路边大哥，野路子不装专家，重庆方言自然带入

## 三、验证目标（L2 MVP 30-60天）

1. 哪类家长问题最容易产生咨询（选题→私信转化）
2. 哪种内容形式最容易带来有效线索
3. 家长愿意为什么产品付费（单次咨询/方案/课程/社群）
4. 朋友的交付是否能形成满意案例和口碑传播

**退出阈值**：30天内无有效咨询线索 或 朋友交付无法形成满意案例

## 四、阶段规划

- **当前**：L2 MVP，验证钩子/受众/转化
- **通过后**：L3 长期资产，内容体系化 + 产品化（付费方案/课程/社群）
- **待填**：周节奏、阶段配比（验证期先跑通转化，暂不定死）
