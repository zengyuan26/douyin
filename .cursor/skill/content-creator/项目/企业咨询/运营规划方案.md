# 企业咨询 · 运营规划方案

> 级别：L2 标准（对齐母系统模板）。
> 表达者：吕老师（主体档案见 `个人档案.md`）。
> 来源：吕老师 IP 与产品体系设计手册 V1.0。
> ⚠️ 手册是「战略总纲」，定位/方法论/产品体系已清晰，但**目标客户具体画像、周节奏、产品名称价格**手册标「待定」——这些【待访谈/待定】项需吕老师基础信息收齐后再落。

---

## 一、核心定位（强制）

- **一句话**：吕老师，帮陷入困境/迷茫的人看清真正症结——**先承认问题，再给方向**。不卖工具，帮人看见问题、找到问题、打通问题。母题收口在钱 / 关系 / 认知，覆盖个人成长到企业经营。
- **信任路径**：人生阅历 + 真实经历 + 客户案例 + 长期判断力（见个人档案第四节，实战×直觉 + 案例密度）。
- **为什么是你 / 不可复制性**：能帮人「看见真正问题」的判断力，来自阅历和真实案例，不是标准化工具可替代的。

---

## 二、受众分层（强制）

- **目标客户（付费人）**：【待访谈】手册只给了分层逻辑，没给具体画像。按问题阶段分，不按资产量级分：
  - **前端**：问题模糊，甚至不承认问题 → 免费内容，先让他「看见自己」
  - **中段**：意识到问题但不知道症结 → 入门产品（识别问题、建立框架）
  - **后端**：问题明确且复杂 → 中阶/高阶（判断、方案、陪伴、资源）
  - **企业级**：组织问题与个人问题交织 → 企业咨询、项目制服务
- **传播发动机（观众，可能≠付费人）**：顶层受众——即使不买，也持续获得认知价值的人。身份焦虑/成长焦虑驱动转发。
- **分层维度**：按问题阶段分（漏斗 + 剥洋葱两个比喻同时成立）。

> 铁律：受众定位是决策记录，不能靠推演猜。写内容前逐字读 config 第 2 节（config 待改，见文末）。

---

## 三、内容策略（强制）

- **内容类型**：【待定】手册提到短视频 / 直播 / 文章，具体以吕老师出镜意愿定。
- **选题来源**（手册给了 7 个，不是从行业事件出发）：
  1. 自身经历（失败、选择、转折、吃亏、看懂一件事的过程）
  2. 客户案例（企业、个人成长、关系、经营中的真实问题与变化）
  3. 身边故事（会议、交流、合作中听到的一句话或现象）
  4. 热点事件（不追热点本身，借热点找钱/关系/认知的长期议题）
  5. 书籍与经典（AI 辅助读书 + 吕老师经历二次表达）
  6. 历史故事、典故与人物（用旧故事解释当下人性和决策）
  7. 用户问题（评论区、社群、咨询中反复出现的问题）
- **声音**：隔壁大哥式（见个人档案第五节）。

## 四、验证目标（强制·L2）

| 验证什么 | 落点 |
|---------|------|
| 哪类问题产生咨询 | 钱 / 关系 / 认知三母题，哪个最容易选题→私信转化 |
| 哪种形式带来线索 | 哪个栏目 / 形式（口播/图文/短视频/直播）线索最有效 |
| 愿意为什么付费 | 入门→中阶→高阶产品，用户在哪一层第一次掏钱 |
| 交付能否形成满意案例 | 吕老师的诊断/陪伴能否稳定形成口碑传播 |

**退出阈值**（提前写死，达标即停）：30 天内无有效咨询线索 或 吕老师无法稳定交付 或 出现焦虑贩卖式投诉。

---

## 五、阶段规划（强制）

- **当前**：L2 MVP —— 验证「先诊断后处方」这套方法能不能换来咨询 + 付费 + 口碑。
- **通过后**：L3 长期资产，跑通产品递进（手册已确认的结构模型，具体产品待定）：

| 阶段 | 典型状态 | 核心价值 | 可能形态 |
|------|---------|---------|---------|
| 免费内容/公域 | 问题模糊，甚至不承认问题 | 看见自己、产生共鸣 | 短视频、直播、文章 |
| 入门产品 | 意识到问题，但不知道症结 | 识别问题、建立初步框架 | 体验课、轻咨询、诊断型产品 |
| 中阶产品 | 问题已较明确，需要行动与反馈 | 方法、训练、陪伴、纠偏 | 小班、成长营、阶段陪跑 |
| 高阶产品 | 问题复杂且高度个性化 | 深度诊断、判断、方案、资源、陪伴 | 高阶咨询、长期顾问、私董/深度项目 |
| 企业级服务 | 组织问题与个人问题交织 | 组织诊断、战略/经营/团队支持 | 企业咨询、项目制服务 |

> 核心判断：产品不是彼此孤立的「课包」，是用户问题深入后自然出现的下一站。**好的升级不是硬推销，是用户走到那一步自己发现需要。**（先建立关系，再发生交易。）
> 具体产品名称、价格、时长、交付频次：**全部待定**，手册明确不视为正式定案。

- **风险**：目标客户画像未访谈，可能定位漂移；产品体系跨度大（个人→企业），冷启动别贪全。

## 六、内容原则（L2）

- **诊断先行**：先让人承认问题，再给方向。跳过前三步（望闻问）直接给方法 = 说教/卖货。
- **讲的是别人，照见的是自己**：故事 + 映射 + 洞察 + 方法，不直接贴标签。
- **回扣三母题**：钱 / 关系 / 认知，长期形成账号内容心智。
- **持续价值 > 偶发爆款**：让观众形成稳定预期「今天看有收获，下次还愿意回来」。

---

## 七、创作纪律（L2）

- 不贩卖焦虑：**上头是入口，正视问题是出口**。只做入口 = 焦虑贩卖；入口 + 出口 = 诊断先行。
- 少用训导句式（「你应该 / 你必须 / 正确答案是」），多用「我以前也遇到过 / 我见过一个客户 / 换成我会先问自己三个问题」。
- 锋芒指向问题，不指向人格。
- 先讲具体的人和事，再提炼判断；先让人感到「被理解」，再让人接受观点。

---

## 八、自检清单（L2）

写完每篇逐条过（手册十六节团队校验标准，8 条）：

1. 是在「教知识」，还是帮用户「看见自己」？
2. 落到钱 / 关系 / 认知哪个主题？
3. 像「大哥聊天」，还是「老师训话」？
4. 有没有真实的人、事、场景，而不是抽象概念？
5. 有没有持续价值，而不只是追热点？
6. 在制造焦虑，还是帮用户真实承认问题？
7. 这一个产品解决哪一阶段的问题？边界清晰吗？
8. 用户完成这一阶段后，下一个问题是什么？升级自然吗？
