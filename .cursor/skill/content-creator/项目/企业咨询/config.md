# 项目配置：儿童成长

> 状态：L2 MVP | 商业化角色：商业化合伙人
> 表达者：重庆朋友（11万粉，口语能力强，野路子儿童心理/成长咨询）
> 你的角色：内容和商业化合伙人（非心理服务提供者）

---

## 0. 元信息

- **项目名**：儿童成长
- **项目状态**：L2 MVP（30-60天验证四件事）
- **账号/主体**：待定（可复用朋友现有账号）
- **商业化角色**：商业化合伙人
- **输出目录**：项目/儿童成长/输出/

## 1. 身份

- **一句话定位**：帮助家长建立面对孩子情绪和沟通冲突的处理流程。不卖理论，卖"能用的方法"。
- **权威来源/信任路径**：朋友线下大量真实咨询案例。野路子但有效。11万粉验证了观众缘和表达力。
- **不可复制性**：大量一手案例+野路子解决问题能力。不是学院派，但家长认。

## 2. 受众漏斗

### 受众战略分层

- **目标客户（付费人）**：正在被具体问题困扰、愿意付费咨询/买方案的家长。
- **传播发动机（观众）**：焦虑家长（孩子不听话/管不了/跟孩子越来越远）。观众是父母，不是孩子——讲孩子的问题，追根让父母意识到自己的问题。
- **分层维度**：按身份分（父母），不按孩子年龄分。

- **L1 泛人群**：刷到育儿内容的家长。钩子驱动。"你家孩子是不是也这样？"
- **L2 问题家长**：正在被某个具体问题困扰（厌学/情绪/冲突）。想找方法。
- **L3 深度需求**：愿意付费咨询、购买课程/方案。需要系统性解决。
- **圈层钩子表**：

| 圈层 | 关键词 |
|------|--------|
| 焦虑妈妈 | "孩子""不听话""怎么办""管不了" |
| 教育从业者 | "方法""体系""底层逻辑" |
| 隔代养育家庭 | "奶奶说""爸爸不管""两套标准" |

## 3. 声音/语域

- **声音原型**：路边大哥（朋友出镜，口语化强）。野路子但有效，不装专家
- **口语化程度**：极高。重庆方言自然带入，忌书面语
- **术语策略**：心理学/教育学术语必须翻译成日常场景语言。"回避型依恋"→"孩子不跟你说话了"
- **禁止语域**：学院腔、治疗腔、焦虑贩卖

## 4. 内容配比与定位闸门

- **领域标签**：亲子 / 成长 / 心理
- **定位闸门参数**：不做硬性跨领域要求。内容聚焦亲子问题。
- **内容类型倾向**：口播（朋友出镜，口语表达强）+ 清单体图文（家长喜欢收藏）+ 短视频（问题场景→方法）

## 5. 恐惧池/锚点池

- **选题锚六池映射**：
  - 恐惧池：孩子被耽误、管不了、跟孩子越来越远
  - 贪婪池：别人家孩子怎么教的、领先一步的方法
  - 身份池：我是负责任的好家长、我不是不会教
  - 认知池：原来问题不在孩子身上、情绪不是管教出来的
  - 关系池：亲子关系、夫妻教育分歧、隔代冲突
  - 好奇池：野路子方法为什么有效、真实案例怎么解决的

## 6. 合规规则

- **敏感词替代表**：禁止"治愈""治疗""心理疾病""改变孩子人生""保证效果""成功率"。涉及心理咨询/治疗必须由持证专业人员负责。
- **免责声明句**：个人经验分享 | 不构成心理治疗建议 | 严重问题请寻求专业帮助
- **CTA 限制**：可引导私信咨询，禁用"马上报名""名额有限"
- **公司名密度上限**：不涉及
- **发布前自检清单**：□ 无治愈/治疗/保证效果 □ 有免责声明 □ 无恐吓式营销 □ 朋友已审核交付内容

## 11. 首要验证项（L2 MVP 30-60天）

1. 哪类家长问题最容易产生咨询（选题→私信转化）
2. 哪种内容形式最容易带来有效线索
3. 家长愿意为什么产品付费（单次咨询/方案/课程/社群）
4. 朋友的交付是否能形成满意案例和口碑传播

## 12. 立项卡

- **定位**：面向焦虑家长，"野路子但有效"的亲子沟通方法
- **受众**：3-15岁 + 大孩子/成年子女家长（全年龄段覆盖），正在被具体问题困扰
- **商业模式**：免费内容→私信咨询→付费方案/课程→社群/长期陪伴
- **表达者**：重庆朋友（出镜+交付）
- **你的角色**：内容和商业化（选题/产品设计/获客/转化/流程标准化）
- **风险分级**：L2 MVP
- **退出阈值**：30天内无有效咨询线索 或 朋友交付无法形成满意案例
- **首批选题**：孩子厌学怎么沟通 / 亲子冲突的野路子解法 / 青春期情绪怎么接 / 隔代养育冲突怎么办
