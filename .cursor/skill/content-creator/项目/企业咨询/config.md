## 1. 身份

- **一句话定位**：帮助人看见真正问题的人——先承认问题，再给方向。不卖工具，帮人看见问题、找到问题、打通问题。母题收口在钱 / 关系 / 认知。
- **权威来源/信任路径**：人生阅历 + 真实经历 + 客户案例 + 长期观察与判断力（不是头衔）。实战 × 直觉 + 案例密度。
- **不可复制性**：能帮人「看见真正问题」的判断力，来自阅历和真实案例，不是标准化工具可替代的。
- **表达者个人档案**：`项目/企业咨询/个人档案.md`

## 2. 受众漏斗

### 受众战略分层

- **目标客户（付费人）**：【待访谈】手册只给了分层逻辑，没给具体画像。按**问题阶段**分：前端（问题模糊不承认）→ 中段（知道有问题不知症结）→ 后端（问题明确复杂）→ 企业级（组织问题）。
- **传播发动机（观众，可能≠付费人）**：顶层受众——即使不买，也持续获得认知价值的人。身份焦虑 / 成长焦虑驱动转发（「想看得清的人，不一定要成为专家」）。
- **分层维度**：按问题阶段分（漏斗 + 剥洋葱），**不按资产量级分**。
