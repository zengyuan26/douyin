# EMC 合同能源管理：收益框架与行动框架

> 备电 CVC 投行视角 | 2026.06

---

## 一、收益全景

### 短期收益（项目投产即兑现）

| 收益项 | 逻辑 | 变现方式 |
|--------|------|---------|
| 工程差价 | PE 投 800 万建，实际成本 650 万 | 差价进总包口袋 |
| 设备集采返点 | 一年做几十个项目，电池/PCS 的量价谈判 | 吃返点 |
| 建设补贴 | 各地储能/光伏补贴，几毛到一块多每瓦 | 项目投产即兑付 |
| 绿证 | 屋顶光伏发电即发绿证，单张几十块 | 当天挂网卖，量大是纯利 |

### 中期收益（25 年合同期内，年年有）

| 收益项 | 逻辑 | 备注 |
|--------|------|------|
| 省电分成 | 核心收入。一年 120-160 万，你分 60-70% | 25 年雷打不动 |
| 峰谷套利 | 储能每天一充一放，电价差就是利润 | AI 自动跑，边际成本接近零 |
| 需量管理 | 按住工厂峰值用电，一年省 15-20 万 | 不增一砖一瓦，纯靠 AI |
| 需求响应 | 电网喊停你就停，广东 3.5 元/度、深圳 5 元/度 | 一年几次，纯额外 |
| 调峰辅助 | 日常搭把手，几毛到一块多一度 | 每天有活，积少成多 |
| 容量备用 | 按装机容量拿固定底薪 | 不充不放也收钱 |
| 碳资产 | 工厂减碳，碳配额可卖 | 运营商分成或代销 |

### 长期收益（金融属性 + 平台溢价）

| 收益项 | 逻辑 |
|--------|------|
| 25 年稳定流水 | 几十上百个工厂，每月电费从你手里走。流水 = 融资工具：ABS 发债、合同质押贷款、供应链金融 |
| 负荷聚合资格 | 手里工厂多了，你就是天然负荷聚合商。调度资格+交易牌照，越做越值钱 |
| 电力交易套利 | 替工厂进电力市场买电。现货价低多买、高时少买，差价你吃 |
| 数据资产 | 25 年上百个工厂的用电曲线。建新站、做预测、做碳核算——数据就是壁垒 |
| 资产残值 | 25 年后设备送工厂是合同写法。实际电池换几轮了，旧电池回收卖钱；PCS 寿命超 25 年，折价转让 |
| 客户复购 | 锁了一个工厂 25 年。中间扩产、加储能、加充电桩、换设备——获客成本为零，复购无限 |

## 二、核心公式

```
设备赚一次 + 电费省 25 年 + 流水融 N 次
```

- **赚一次**：工程差价、集采返点、建设补贴、绿证
- **省 25 年**：省电分成、峰谷套利、需量管理、需求响应、调峰、容量、碳资产
- **融 N 次**：流水 ABS、合同质押、电力交易套利、客户复购

长期看，最值钱的是**手里几百个工厂的聚合调度能力**——那时候你就是一个小电网。

## 三、我们要干什么（CVC 投行角色）

定位：**资本中介 + 交易设计者**。不出设备、不跑工地、不研电池。出钱、出结构、匹配两头。

### 第一优先：建居间人网络

你的核心竞争力不是认识工厂老板，是**认识"认识工厂"的人**。

| 居间人来源 | 他们手里有什么 |
|-----------|-------------|
| 设备商（储能/PCS/光伏销售） | 装完设备就知道这个厂还能不能挖 |
| 园区招商 / 管委会 | 哪个厂来了、哪个厂用电大，第一时间知道 |
| 电力设计院 / 工程队 | 工厂配电房长什么样，比你熟 |
| 节能服务公司 | 已经在帮工厂做节能改造，客户重合 90% |

模式：居间人带项目 → 你出钱出结构 → 按成交额给居间费。杠杆最高：一个人跑工厂一年签不了几个，100 个居间人帮你跑，你在后面做筛选和交易设计。

### 第二优先：养风控，不养分析师

需要一个人能判断三件事：

1. 工厂能不能活 25 年（看现金流、行业周期、老板背景）
2. 电费账单是真是假（12 个月电费单，别被粉饰过）
3. 电价价差够不够覆盖回报（广东行，某些省可能不够）

这人叫**风控**，不叫分析师。别一上来组研究团队写行业报告——那是花钱的，不是赚钱的。

### 第三：你亲自签合同

居间人敲门、做热关系。你进去收尾：聊交易结构、算回报、签合同。时间花在"成交"上，不是"找客户"上。

## 四、一句话总结

```
居间人获客。你设计交易、匹配资本。风控筛掉烂项目。
你是坐在牌桌中间的人，不是满街发名片的。
```
