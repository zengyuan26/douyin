## 导演分析摘要

```
主线：政策文件从不说"投储能赚钱" → 投行人读的是"什么变贵了、什么变便宜了" → 一切归因到电价差
钩子：论点宣言开场。"政策文件里，从来没有写过'建议你投储能'。"
情绪：被震住 → 恍然 → 从历史看到现在 → 想自己去看 → 知道看什么
核心手法：制度归因——把分散的政策信号归到一个变量上（电价差），
          就像朱莉亚把中国人的行为模式归到税制上一样。
```

## 四、评论区运营

**首评：**

> 政策文件从不说"投储能能赚钱"。它说"完善分时电价""构建新型电力系统""鼓励源网荷储一体化"。投行人翻译一下——它在让峰谷价差变大、让电变成生鲜、让储能从"选配"变"要求"。你所在省的峰谷价差现在是多少？评论区聊聊。

**回复话术：**

1. 回复"浙江峰谷价差真有1.2？"→"浙江大工业用电，尖峰时段vs低谷时段，价差最高1.2元/度。2021年分时电价改革之前大概0.5元。翻了一倍多。你算一下：一度电差1块2，1000度就是1200块。一个月3万度=3万6。"
2. 回复"现货市场是什么"→"电每15分钟重新定价一次。不是你签死一个电价了。中午光伏多的时候电便宜，傍晚大家都在用的时候电贵。有储能的，中午吃便宜电，傍晚放出来——你不是在'省电'，你是在做日内套利。"
3. 回复"辅助服务储能怎么赚钱"→"电网需要有人'待命'——负荷低了帮你吸、负荷高了帮你放。储能蹲着不动，电网付你'调频费'。这块收入跟峰谷套利是两条线。叠加起来回本更快。"
4. 回复"电价差会不会缩小"→"会。制度给的，制度能收回去。所以不是'投储能稳赚'——是'读懂信号早半步'。三年前峰谷价差不到现在的一半，那会儿装储能回本要8年。现在4年。什么时候收窄？关注政策——它在文件里写过。"
