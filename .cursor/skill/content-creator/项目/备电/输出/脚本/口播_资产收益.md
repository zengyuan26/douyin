## 一、导演分析摘要

```
主线：资产收益。增元抛出一个反常识问题。小周替观众问出
      每一个问题。一问一答间，三层概念自然剥开。
钩子：反常识断言式。"工厂省下来的电费——算利润吗？"
      小周觉得算。增元说——叫利润和叫资产收益，厂值不同的钱。
情绪：被问住 → 困惑 → 恍然 → 紧张 → 笃定 → 升级 → 打通 → 期待
核心手法：小周=观众嘴替。每个问题都是观众正在想的。增元=拆解者。
```
