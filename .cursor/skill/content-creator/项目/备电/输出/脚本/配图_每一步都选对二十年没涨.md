# 配图：每一步都选对二十年没涨

> 对应稿子：口播_正确答案的悖论_每一步都选对二十年没涨.md
> 用途：长文封面 + 内文配图
> 视觉：交给 Image2 自行决定。各图同属一个视觉世界。

---

## 一、封面

比例 9:16 竖版 1080×1920px。安全区 120px~1750px。

```
任务：反常识锚点 + 悬念，不给结论，不给金句。
让读者停下来想"什么意思？"。

画面：一条路，路上挤满了人——所有人都在往同一个方向走，
每人手里拿着一张相同的地图。路的尽头被雾遮住。
但画的右下角，有一个人站在原地没走，手里没有地图。

文字：主标题"每一步都选对，二十年没涨"，
副标题"有一种亏法，叫所有正确答案都指向同一个方向"。
文字区占画面不超过 1/3。大字体，直接。
```

### Image2 prompt

```
A 9:16 vertical image (1080x1920px). ALL on-screen text must be in CHINESE.
Cover image for a long-form article about decision-making and the hidden cost of
following consensus. The visual metaphor: a crowded road stretching into fog.
Hundreds of people walking in the same direction, each holding an identical map.
In the bottom-right foreground, one person standing still — no map in hand,
looking in a different direction. The atmosphere should be contemplative, slightly
unsettling, not dark or scary. Large bold Chinese title text occupying no more than
1/3 of the frame: "每一步都选对，二十年没涨". Below it, smaller subtitle:
"有一种亏法，叫所有正确答案都指向同一个方向".
No conclusions, no golden quotes, no CTAs. The image should make the viewer stop
and feel the tension between the crowd and the solitary figure.
Content safe zone: 120px to 1750px from top.
```

## 二、配图1 · 拥挤交易

比例 16:9 横版。内文插图，配合弹药1段落。

```
任务：把"拥挤交易"视觉化——所有人买同一张债券，出口在裂开。

画面：一扇巨大的门，门上有四个大字"正确答案"。
门前挤满了人，黑压压一片，争着往里进。
但仔细看，门框上方已经出现了裂缝，碎屑正在往下掉。
门后面什么都看不清——不是光明，是曝光过度的白。
人群最前面的人已经进去了，但后面还有看不到尽头的人在挤。
色调：冷灰底+门上的裂缝是暗橙/琥珀色。
```

### Image2 prompt

```
A 16:9 horizontal image. ALL on-screen text must be in CHINESE.
Editorial illustration about the concept of "crowded trade" — when everyone
rushes into the same safe asset, the exit itself begins to crack. A massive
doorway with the Chinese characters "正确答案" inscribed above it. A sea of
people pushing toward this single door, packed tightly. The doorframe has visible
cracks spreading from the top, with small fragments falling. Beyond the door is
not darkness but an overexposed white void — not bright hope, just blank
uncertainty. The crowd stretches to the horizon. Muted cool grey tones overall,
with the cracks rendered in dark amber/orange as the only warm accent. No text
overlay on the image itself — this is an in-article illustration.
```

## 三、配图2 · 幂律曲线平淡期

比例 16:9 横版。内文插图，配合弹药2段落。

```
任务：幂律分布曲线的视觉化——前面漫长的平坦期，
看起来跟失败一模一样，大部分人在跳变前退出了。

画面：一条从左到右的曲线，前80%几乎贴着地面，然后突然陡峭上升。
平坦段上散落着很多脚印——方向都是往回走的。
有人在平坦段的中间停下来，转身，往回走。
曲线右侧的陡峭段上，只有极少数人的身影。
色调：干净的白底+深蓝黑曲线+退出的脚印是灰的。
整个画面不是鼓励也不是批判——是客观的"这就是那个图"。
```

### Image2 prompt

```
A 16:9 horizontal image. NO on-screen text needed — purely visual illustration.
A clean, almost scientific visualization of a power law curve, but rendered as
an editorial illustration. The curve runs left to right: nearly flat along the
ground for the first 80% of its length, then bends sharply upward at the right
edge. On the long flat section, many footprints in the dirt — all pointing
backward, away from the curve's direction. A few silhouette figures visible
midway through the flat section, turning around, walking back. On the steep
rising section at far right, only two or three tiny figures, barely visible.
The mood is matter-of-fact, not motivational. Clean off-white background, the
curve in deep navy-blue, the retreating footprints in pale grey.
```

## 四、配图3 · 画地图的人

比例 16:9 横版。内文插图，配合弹药4段落。

```
任务：弹药4的核心画面——画地图的人自己站在地图外面。

画面：一个大桌子上铺着一张巨大的地图，地图上标注着各种路线和"最优解"。
一个人站在桌子旁边——但他不在看地图。他面朝窗外的旷野。
他的手指着地图上的路线给别人看，但他的脚朝向窗外。
身后墙上挂着他走过的路——不是地图上的任何一条。
色调：暖暗调。桌上一盏台灯照亮地图，人脸的半侧在灯光中，另半侧在阴影里。
窗外的光不是暖的，是冷的——与台灯形成双色对比。
```

### Image2 prompt

```
A 16:9 horizontal image. NO on-screen text needed — purely visual illustration.
Editorial illustration for an article about the paradox of advice-givers.
A large wooden table with an enormous map spread across it — routes, labels,
"最优解" marked in several places. A person stands beside the table, but is not
looking at the map. Their body is turned toward a window showing open wilderness
outside. One hand gestures at the map — showing others the path — but their feet
point toward the window. On the wall behind them, faint markings of a different
route they actually walked, which matches none of the paths on the map. A single
desk lamp casts warm amber light across half the person's face and the map.
Through the window, cold blue-grey natural light enters, creating a two-color
tension across the scene. The mood is contemplative, not judgmental.
```

## 五、制作规范

| 项目 | 规格 |
|------|------|
| 封面 | 9:16 竖版 1080×1920px · 安全区 120px~1750px |
| 内文配图 | 16:9 横版 · 无安全区限制（内文插图，不被UI遮挡） |
| 视觉约束 | 不限定风格，交 Image2 自行决定。四张图同属一个视觉世界 |
| 封面文字 | ≤2 个信息模块（主标题 + 副标题） |
| 内文配图 | 无叠加文字，纯画面 |
| 共同禁止 | emoji、手机 Mockup、段落文字、抽象渐变背景 |
