# 选题库

> 定位：CVC投行投资人。看新能源、看AI、看人看项目。信息散落→拼成框架→给出判断。
> 更新：2026-07-28 | 移除预置选题池，替换为"从原材料到选题"强制流程。选题不从库存翻，从当下真实观察提炼

---

## 一、选题生成方式

选题不是"想一个话题"。选题是：**今天看到/学到/想到了什么信息 → 拼上已有的认知 → 能给出什么判断**。

| 方式 | 公式 | 适用象限 |
|------|------|------|
| **信号→判断** | 行业信号 + 框架拆解 + 判断 | 行业判断 |
| **概念→框架** | 学到的概念 + 跨界连接 + 方法论 | 框架判断 |
| **经历→判断** | 过去踩坑/项目进展 + 现在怎么看 + 可用的判断 | 实战判断 |
| **拆解→框架** | 一本书/一个案例/身边人故事 → 快速拆 → 整理成框架 | 来处判断 |
| **AI→实操** | 用了AI做了什么 + 过程分享 + 观众看到可能性 | 行业判断/框架判断 |

## 二、从原材料到选题（强制流程）

**选题不从库存翻。选题从最近的真实观察里提炼。**

### 第一步：收集原材料

用户带来最近接触的输入，一起讨论加工。没有原材料 → 不推荐选题。

```
最近：
- 看到了什么让你停下来的事/热点新闻？
- 最近看了什么书/电影/文章？
- 刷到了什么有趣的博主/观点？
- 跟谁聊天让你觉得"这个问题不止他一个人有"？
- 自己遇到了什么反复想的事？
- 行业里出了什么信号，你觉得不止是新闻？
```

讨论后两条路：
- **吸收为知识** → 沉淀到 Obsidian 知识库
- **结合自己的判断输出内容** → 进入真问题→选题性质→结构匹配流程

### 第二步：原材料 → 真问题

每个原材料追问：这件事会让谁睡不着觉？落在哪个领域？

| 领域 | 观众的真正问题 |
|------|--------------|
| **钱** | 怎么挣、怎么守、怎么传 |
| **关系** | 跟谁绑在一起、谁能信任、孩子接不接 |
| **认知** | 换了眼镜看世界、打破幻觉、看见自己 |

落不进钱/关系/认知任一领域 → 不做。

### 第三步：真问题 → 选题性质 → 结构匹配

选题性质自然走向对应的结构类型，不是拿着结构列表往里填。

| 选题性质 | 自然走向 | 给什么 |
|---------|---------|--------|
| 推翻一个常见理解 | 概念型 | 一种视角 |
| 诊断一个时代病 | 诊断型 | 三张处方 |
| 拆穿一个幻觉 | 祛魅型 | 一根针 |
| N个案例浮现同一个模式 | 故事型 | 一个判断 |
| 一个框架反复切 | 框架型 | 一套工具 |
| 一个模型解释万物 | 模型重塑型 | 一个开关 |
| 理论+干净实验验证 | 验证型 | 一种确信 |
| 多学科拆一个命题 | 跨学科论证型 | 重新理解 |
| 输出世界观 | 箴言型 | 一套心智模型 |

### 为什么不要预置选题池

预置选题 = 从库存翻 = 脱离当下观察 = 失去共鸣。

选题第一性原理是共鸣，共鸣从具体的人和具体的问题里长出来，不从事先写好的列表里翻出来。选题池已被移除——每次选题从零开始，从原材料出发。

## 六、选题自检

生成选题后问自己：

```
□ 这个选题给出了什么判断？（不能只是"介绍"或"分享"）
□ 判断的来处清楚吗？（经历/框架/身边案例/经典拆解——至少一个）
□ 观众能拿走什么？（判断/方法/认知——不能只是"了解"）
□ 跟上一期内容角度不一样吗？（同象限内也要差异化）
□ 这个判断只有你能给吗？（跨界视角是壁垒）
```

三个不要：
- 不要"讲知识"——没人缺知识。缺的是"你怎么判断"
- 不要"汇报进展"——巴南落地不是新闻。落地过程中学到了什么判断才是内容
- 不要"罗列信息"——AI能搜到的内容你讲没有价值。你的价值是拼成框架、给出判断
