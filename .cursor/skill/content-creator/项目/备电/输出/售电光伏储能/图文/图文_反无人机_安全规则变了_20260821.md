## 二、标题设计

> 标题决定 80% 点击率。本篇命中「数字 + 对比 + 悬念」三要素。

### 主标题

**研发两年，两个月被抄——安全规则变了**

- 数字：两年 / 两个月（时间成本，具体不是模糊）
- 对比：研发两年 vs 两个月被抄（反差拉满）
- 悬念：安全规则怎么变了？（不剧透答案）

### 副标题

**不是内鬼，是无人机**

- vs 对比结构：内鬼（防人）vs 无人机（漏天）——为 P4 认知反转埋线

### 封面建议

| 要素 | 内容 |
|------|------|
| 开头词 | 研发两年（数字 + 时间成本锚点） |
| 情绪驱动 | 损失厌恶——「你研发的两年，对手只用了两个月」 |
| 必须包含 | 具体数字背书：两年 / 两个月 / 3000 万（不用「几十万」这种模糊词） |

## 五、配文

苏州一家精密光学厂，研发两年的高端镜片，上市两个月就被对手抄走——定价比你低 30%，客户订单直接切走。你砸几千万搞研发，他零成本抄，价格还更低。法院判了 3000 万，但市场已经没了。最痛的不是赔钱，是你研发的两年，对手只用了两个月。查遍内部没泄密，最后发现：一年来每周有辆面包车停在围墙外，架无人机飞到 50 米偷拍。秘密不是被偷走的，是被拼出来的——无人机拍的设备布局，加上公开专利、招聘启事、采购记录，还原出你的工艺路线。俄乌战场上几亿的坦克扛不住几千块的无人机，你几百万的围墙也一样。安全规则变了——先抬头看天，再谈安保。行业观察笔记。
