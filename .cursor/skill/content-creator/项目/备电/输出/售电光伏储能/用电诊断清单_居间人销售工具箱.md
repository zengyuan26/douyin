# 工厂用电诊断清单 —— 居间人销售工具箱

> 用法：去工厂之前看一遍，知道要什么数据。见到老板，拿其中一项帮他现场算账。算出一笔他白交的钱，后面的事就好谈了。

---

## 诊断项一：容量电费 —— 最容易白交的钱

### 你要什么数据
- 变压器台数 × 每台容量（kVA）
- 过去12个月每月最大负载（kW）
- 目前计费方式：按变压器容量 / 按最大需量

### 判断标准

```
负载率 < 50%  → 改需量计费更划算
多台变压器，部分长期低负载 → 报停/减容
```

### 跟老板怎么说

> "老板，你这台800kVA的变压器，过去一年最高负载才300kW。按容量交基本电费，800 × 30块 = 每个月24000。如果改成按需量交，300 × 40块 = 12000。一个月多交了12000，一年14万多。"

### 省多少

| 场景 | 操作 | 年省（估算） |
|------|------|------------|
| 单台变压器负载率 < 50% | 改需量计费 | 8-15万 |
| 多台变压器，可报停1台 | 报停 + 负荷合并 | 20-40万 |
| 3台以上，负载均偏低 | 报停1台 + 其余改需量 | 30-60万 |

### 注意
- 改需量计费后，若某月负载突然飙升，当月电费可能反而更高
- 报停有最短时限（通常6个月），中间不能随时恢复
- 如果配了储能，减容后的尖峰风险被储能兜住了 → 这正好是储能的卖点

---

## 诊断项二：峰谷时段 —— 生产排程就是印钞机

### 你要什么数据
- 过去3个月每日24小时负荷曲线（供电局电费单上有）
- 当地峰谷时段划分和电价
- 工厂目前的生产排班表

### 判断标准

```
峰段用电占比 > 40% 且 有部分生产环节可调 → 有优化空间
峰谷价差 > 0.6元/度 → 值得认真算
```

### 跟老板怎么说

> "老板，你这粉碎车间每天下午2点到5点开工，刚好是大工业峰段，1度电1块2。如果挪到晚上11点以后，1度电3毛。一天省多少？粉碎机200kW × 3小时 × 9毛差价 = 540块。一个月开工22天，就是1万2。一年14万。这个电费差，就是挪一下上班时间的区别。"

### 省多少

| 场景 | 操作 | 年省（估算） |
|------|------|------------|
| 单台大功率设备可调时段 | 挪到谷段 | 5-15万 |
| 多条产线可调 | 集中谷段生产 | 15-40万 |
| + 配储能做峰谷套利 | 储能每天一充一放 | 另加10-30万 |

### 注意
- 不是所有环节都能调（热处理、连续工艺不行）
- 挪到夜班涉及人工成本，要综合算
- 装了储能以后，储能替产线"扛"峰段，产线不用调 → 更灵活

---

## 诊断项三：力调电费 —— 电费单上被忽略的那一行

### 你要什么数据
- 过去12个月电费单上的"功率因数"（cosφ）
- 每月力调电费金额（罚款/奖励）

### 判断标准

```
功率因数 < 0.90 → 在交罚款
功率因数 < 0.85 → 罚款比例高，优先处理
功率因数 > 0.90 → 有奖励，不用管
```

### 跟老板怎么说

> "老板，你看电费单这一行'力调电费'，每个月加收8%。这是因为厂里电机多、功率因数低，供电局罚的。加一套无功补偿装置，几千到一两万，装完这个罚款清零。你现在一个月电费20万，罚款8%就是1万6，一年19万。花一万块装个电容柜，一年省19万。"

### 省多少

| 功率因数 | 罚款比例 | 月电费10万时年损失 | 月电费30万时年损失 |
|----------|---------|------------------|------------------|
| 0.85 | +5% | 6万 | 18万 |
| 0.80 | +10% | 12万 | 36万 |
| 0.75 | +15% | 18万 | 54万 |

### 注意
- 加电容补偿是最简单的方案，成本低、见效快
- 如果厂里有大量变频器/整流设备，可能需要有源滤波（贵一些）
- 储能PCS本身具备无功调节能力 → 装了储能可能连电容柜都省了

## 诊断项四：储能经济性 —— 一句话判断有没有空间

### 你要什么数据
- 当地峰谷电价差
- 工厂每日用电负荷曲线
- 变压器剩余容量

### 判断标准

```
峰谷价差 > 0.7元/度 → 值得细算
峰谷价差 > 0.8元/度 → 大概率能投
峰谷价差 < 0.5元/度 → 暂时不用看
```

### 快速估算公式

```
储能容量（kWh）≈ 峰段用电量（度/天）× 60%
年套利收入 ≈ 储能容量 × 峰谷价差 × 330天
投资回收期 ≈ 储能总投资 ÷ 年套利收入

回收期 < 5年 → 可以推
回收期 < 4年 → 重点推
回收期 > 7年 → 先放一放
```

### 跟老板怎么说

> "老板，你白天峰段一天用3000度电。装一个2000度（2MWh）的储能柜，晚上3毛充满，白天1块2放出来。一天套利：2000 × 0.9 = 1800块。一年330天，就是60万。设备投资大概140万，两年半回本。设备寿命10年以上，后面7年半都是净赚——白拿450万。"

### 注意
- 这是最简化的算法，实际还要算：需量管理收益、需求响应补贴、以后偏差考核对冲
- 储能是"一鱼多吃"的资产，别只算峰谷套利一个账
- 如果客户装了储能，前面的诊断项一（容量电费）和诊断项二（峰谷时段）都跟着受益

## 诊断项五：偏差考核 —— 售电合同里最贵的条款

### 你要什么数据
- 目前售电合同里的偏差考核范围（±X%）
- 过去12个月每月申报电量和实际用电量
- 偏差超限时的惩罚电价

### 判断标准

```
偏差考核范围从 ±5% 收窄到 ±3% → 风险敞口增加
过去12个月有 ≥ 3次偏差超限 → 已经在亏钱了
有储能 → 储能可以做偏差对冲，风险可控
没储能 → 偏差风险暴露
```

### 跟老板怎么说

> "老板，现在售电市场全国都在收紧偏差考核，广东已经降到±3%了。什么意思？你申报100万度，实际用97万度就罚款。偏差超过1度，罚款可能是正常电价的1.5倍。如果你配了储能，用电多了储能放，用电少了储能充——储能就是偏差的'海绵'，你申报多少，储能帮你调到多少。"

### 量化

| 场景 | 年用电量 | 偏差率 | 年罚款（估算） |
|------|---------|--------|--------------|
| 轻度偏差 | 500万度 | ±5% | 5-15万 |
| 中度偏差 | 1000万度 | ±8% | 20-50万 |
| 重度偏差 | 2000万度 | ±10% | 60-150万 |

### 注意
- 偏差考核是政策趋势，只会收紧不会放松
- 工厂订单波动越大，偏差风险越高——订单型企业尤其需要储能对冲
- 对居间人来说：客户因为偏差被罚了钱，是你推储能的最强触发点

## 现场操作流程

```
进门前：看电费单 → 锁定1-2个最明显的诊断项
见老板：现场算一笔账 → "你这一个项，一年白交XX万"
      ↓
老板感兴趣：要12个月电费数据 → 回去做完整诊断报告
老板不感兴趣：换个诊断项再试 → 五个诊断项总有一个打得中
      ↓
出报告：五个诊断项全部覆盖 → 每个都给出"现在多少 / 能省多少 / 怎么操作"
      ↓
成交点：诊断报告里最省钱的1-2项，就是你推储能/售电/综合能源的切入点
```

---

## 一句话记五条

> **容量看负载率，峰谷看排班表，力调看罚款比例，储能看价差，偏差看订单波动。**
> 
> 每条都能量化成"一年省XX万"，跟老板不说术语，只说数字。
