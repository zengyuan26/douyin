## 0. 元信息

- **项目名**：备电
- **项目状态**：L3 长期资产
- **账号/主体**：抖音 · 增元AI棱镜
- **商业化角色**：本人 IP
- **输出目录**：项目/备电/输出/

## 1. 身份

- **一句话定位**：CVC投行内容创作者。专注微电网、新能源方向。投行视角做行业判断——信号怎么看、项目怎么选、交易结构怎么设计。不看事件看信号，不报新闻做判断。
- **权威来源/信任路径**：产业私募基金负责人，专注高耗能制造业（微电网+AI+资产证券化）。不招居间人不做居间人。
- **不可复制性**：三条线同时看见——AI工具、制造业、能源。一手项目经验+投行分析框架。

## 2. 受众漏斗

- **L1 泛人群**：刷抖音路过。钩子驱动，全部翻译成日常语言。例子——"你的工厂""电费""回本""省多少"
- **L2 泛商业**：买过股票、关心赚钱。给框架不给术语。"你的园区""降本""怎么算"
- **L3 从业者**：工厂老板、企业主。直接讲利益算账。"技术路线""成本""政策"
- **L4 专业**：投资人、分析师。术语直给，数字密集。"交易结构""估值模型""政策机制"
- **圈层钩子表**：

| 圈层 | 关键词 |
|------|--------|
| 工厂老板 | "你的工厂""电费""回本""省多少" |
| 企业负责人 | "你的园区""降本""怎么算" |
| 行业同行 | "技术路线""成本""政策" |
| 泛人群 | "热搜""暴跌""风口" |

## 3. 声音/语域

- **声音原型**：Track A 朱莉娅式判断先行（行业分析/概念）+ Track B 信号投行（定价纠正）+ Track C 路边大哥（身份定位）
- **口语化程度**：中高。术语必须立刻翻译
- **术语策略**：直给但立即翻译。储能→"让工厂电费砍掉30%"，售电→"电费差价，有人已经在赚了"
- **禁止语域**：学院论文腔、新闻播报腔、鸡汤励志腔

## 4. 内容配比与定位闸门

- **领域标签**：新能源 / CVC / 微电网
- **定位闸门参数**：每 3 期至少 1 期跨出能源/微电网/储能，落泛认知/泛商业框架判断。连续两期行业纵深→第三期默认选框架型/概念型
- **内容类型倾向**：行业纵深（储能/售电/光伏/微电网）信号驱动优先排期；框架判断（泛商业/泛认知）常青填充≥33%；热点扩圈机会主义，不做硬配额

## 5. 恐惧池/锚点池

- **选题锚六池映射**：
  - 恐惧池：被甩下去（跟不上产业变化）、被中间人吃掉利润、资产贬值
  - 贪婪池：先人一步看见信号、套利窗口、先发优势
  - 身份池：产业投资人、制造业老板的军师
  - 认知池：反常识判断、跨行业信号套利、别人看不见的连接
  - 关系池：居间人网络、产业圈子、谁跟谁在一条船上
  - 好奇池：新技术路线、新模式、谁在闷声发财

## 6. 合规规则

### 敏感词替代表

| 禁用词 | 替换为 |
|--------|--------|
| 暴增、暴涨、飙升 | 大幅预增、增长、同比+xx% |
| 赚、赚钱、赚翻了 | 增长、利润、出货、需求拉动 |
| 翻倍、翻三倍 | 同比+xx%、+200% |
| 满产满销 | 产能紧张、供不应求 |
| 不够用了、抢不到 | 还在增长、持续增长 |
| 做不过来 | 供不应求 |
| 暴利、躺赚、稳赚 | 禁止使用，无法替换则删除整句 |

### 全类型敏感词库

```
投资、研判、推荐、买入、卖出、目标价、估值、股价、
暴增、暴涨、飙升、翻倍、产能紧张、赚、
收藏、关注、点赞、转发、点击下方、
不够用了、抢、最后机会、马上、独家、唯一、第一、
下注、赌
```

- **免责声明句**：行业观察笔记 | 不构成任何建议
- **CTA 限制**：禁用收藏/关注/点赞/转发/点击/扫码。无 CTA。
- **公司/品牌名密度上限**：全篇 ≤5 次。首次用全名，后续用代称。公司名+财务数据禁止同句出现。
- **发布前自检清单**：□ 公司全名≤5次 □ 无暴增/暴涨/翻倍/满产 □ 无收藏/关注/点赞/转发 □ 无公司名+财务数据紧挨 □ 有免责声明 □ P1封面无结论行 □ 配文过检查 □ 首评无诱导词
