## 一、业务权责边界

- [ ] 「有备无患」作为入口项目，商务合同主体是谁？（威堉智能 还是 单独主体）

- [ ] 避免后期业务做大后权责、收益划分纠纷

## 二、国企股东角色厘清

- [ ] 国企是 财务参股 / 产业合作 / 实控参与经营？
  - 财务参股：主要信用背书，资源支持有限
  - 产业入股：可对接园区、政府技改补贴、安监/经信委政策资源，项目申报优势强
- [ ] 对外宣传口径合规，严禁夸大「国企控股、国资全额担保」

## 三、资产归属（重中之重，关系 ABS/REITs 打包）

- [ ] EMC 模式：光伏、储能设备所有权归属（建设期 / 合同期内 / 到期后）
- [ ] 数字化技改、机器人、反无人机设备资产确权
- [ ] 合同回款应收账款归属
- [ ] 直接决定能否打包资产证券化

## 四、区域权限界定

- [ ] 湖北全域授权？还是划分片区？

## 五、收益分成规则

## 六、风控要点（合同与尽调标准化）

- [ ] EMC 合同模板必须总部统一出具，**不要自行修改关键条款**（合同主体、屋顶租赁协议、资产确权文件）
