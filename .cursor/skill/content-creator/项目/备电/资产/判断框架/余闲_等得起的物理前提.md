# 判断框架：余闲 = 等得起的物理前提

> 来源：口播_余闲_等得起_20260813
> 类型：判断框架（认知/财富）
> 提取日期：2026-08-13

## 判断句

等得起 ≠ 等得久。等得起的根不是心态、不是判断力，是余闲——一种由前期积累决定的物理状态。

## 机制链

- 正循环：积累 → 闲钱 → 空脑袋（带宽）→ 能想十年后的事 → 判断力 → 更多积累
- 负循环：没钱 → 疲于奔命 → 带宽占满 → 短视 → 更穷

## 核心弹药

- 正例：段永平（闲钱买网易，没看准却拿住 20 年）
- 反例：范进（等 50 年中举疯了，没余闲接不住命运垂青）
- 机制：田北辰《穷富翁大作战》+《稀缺》带宽理论
- 东方经典：老子「有之以为利，无之以为用」

## 判断标准（可复用）

怎么判断一个人/一家企业有没有余闲？就一个标准——他敢不敢让这个选择，不影响他接下来十年的生活。

## 可复用场景

- 判断一个人/企业的「长期主义」是真是假
- 拆解「求稳」决策（买房/考编/进大厂）是资产积累还是余闲损耗
- 识别「确定性溢价」的代价
