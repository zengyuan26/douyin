# 判断框架：升降加速（通道变窄 + 效率变高）

> 类型：判断框架 | 来源：口播_阶级电梯_20260814
> 一句话：一个系统出现"通道变窄 + 流动加速"并存，说明它已经进入赢家通吃阶段。

## 框架

```
判断一个领域/系统是否进入"赢家通吃"阶段，看三个信号：

1. 头部集中度：头部（前3名/少数几家）吃掉多少份额？
   → 电影排片：3部片锁死 84.5%
   → 越集中，越接近赢家通吃

2. 上升速度：一个素人/新玩家，能不能一夜之间冲到头部？
   → 能（直播、风口）→ 上升靠"命中"不靠"积累"
   → 上升越快，下滑也越快（同一部电梯）

3. 中间层的稳定性：中间位置是"安全区"还是"中转站"？
   → 中间层随时被上下挤压 → 已经进入"升降加速"
   → 中间没有"停靠层"，只有"上升"或"下滑"两个状态
```

## 核心判断

**"固化"和"高流动"是两种完全不同的社会状态，不要混为一谈。**

| 状态 | 特征 | 大众误读 |
|------|------|---------|
| 固化 | 你在哪层就一直在哪层（低流动） | — |
| 升降加速 | 快速上升 + 快速下滑（高流动） | 被误读成"固化"（因为流动快到让人不敢动） |

## 应用场景

- 行业判断：看一个行业是否进入"赢家通吃"（头部通吃、腰部死亡、长尾荒诞）
- 个人定位：判断自己的位置是"挣来的"还是"电梯票"
- 内容选题：任何"中产消失/阶级固化"类话题，都可以用"升降加速"重新解释
