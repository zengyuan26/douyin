# 合规红线：私募基金 + 无线电 + 宣传口径

> 来源：豆包对话（用户提供）｜2026-08-22
> 用途：写内容前自检合规时加载。所有红线汇总，避免踩坑。

---

## 一、私募基金合规

- 纳客资本作为私募基金：募资范围、合格投资者、备案合规
- 资本服务（上市/并购）**不能做保本收益承诺**
- 广告话术合规（不承诺收益、不夸大）

## 二、EMC / 光储 / 安防合规

- EMC 光伏储能、工业反无人机、智慧安防全套方案：**无线电备案、安监验收、环评合规**
- 大功率无线电干扰设备属**管控设备**，整套反无人机系统需向公安、无线电管理部门备案审批
- **企业不能私自架设全向大功率干扰机**，干扰周边通信/导航要担责（合规=定向、窄带、可开关、白名单、日志留存）

## 三、宣传口径红线（对外必守）

| 禁止 | 原因 |
|------|------|
| 夸大「国企控股、国资全额担保」 | 对外宣传口径务必合规，国企股东角色要厘清 |
| 承诺资本服务收益 | 上市/并购不能保本承诺 |
| 表述「所有技改设备全部零元安装」 | 只有光储 EMC 可零投入，技改/反无人机/机器人默认不是零投入 |
| 拿「全国百亿反无人机市场」对外宣讲 | 大部分是军方/公安/临时安保，工厂技改占比小，易被资方质疑赛道匹配 |
| 谎称案例是威堉/纳客落地 | 案例定位「湖北同模式成功参考」，数据引公开报道/上市公司公告 |

## 四、对外宣传正确口径

- 只讲 **EMC 零投入建设光储**（有备无患）
- 技改/反无人机/机器人 = 企业自筹 或 优质大厂整体打包洽谈托管/分期（视尽调审批）
- 国企股东：区分财务参股/产业合作/实控经营，不混为一谈
