# 工业反无人机（工业 C-UAS）：技术与选型

> 来源：豆包对话（用户提供）｜2026-08-22

## 定义

面向化工、水泥、电厂、冶炼、油气、数据中心、港口等高耗能/高危关键工业基础设施的低空防御体系，防范「低慢小」无人机黑飞偷拍、窃密、投放危险品、干扰生产、安全破坏。

**与军警反无人机最大区别**：工业场景**严禁随意硬杀伤**（激光/高炮/动能弹）——工厂大量易燃易爆物料、高压设备，无人机锂电坠落、碎片火花极易引爆。优先软反制、网捕取证，合规第一。

## 威胁4类

1. 商业窃密：航拍生产线/新设备/工艺布局/堆场库存
2. 安全生产风险：无人机坠落管道/储罐/配电室引发火灾爆炸；携带粉末化学品投放
3. 合规舆情：非法航拍外流，环保/安全信息泄露
4. 未来风险：FPV穿越机、无人机集群袭扰

## 三层架构

| 层 | 名称 | 设备/能力 |
|----|------|----------|
| 一 | 探测预警（眼睛）多传感器融合 | 低空雷达（全域扫描定位）+ 射频测向（无源频谱侦测，定位飞手）+ 光电/红外云台（AI识别机型、白名单、区分飞鸟风筝） |
| 二 | 决策调度（大脑） | AI研判、分级处置、日志留痕、对接厂区安防大屏/门禁/报警；白名单/可疑/高危三级区分，全程可溯源 |
| 三 | 分级反制（手脚） | 见下表选型红线 |

**反制选型红线：**

| | 手段 | 说明 |
|---|------|------|
| ✅ 推荐 | 导航诱骗（GPS/北斗欺骗） | 引导无人机到安全点降落，不干扰周边通信，化工厂/电厂首选 |
| ✅ 推荐 | 定向射频干扰 | 窄带精准压制图传/遥控，非全域大功率屏蔽 |
| ✅ 推荐 | 网捕拦截 | 完整俘获、保留存储卡取证，危化园区优选 |
| ❌ 谨慎/禁止 | 高能激光/高功率微波/动能弹 | 碎片/高温/电磁辐射，易引爆危化品、损坏工控电力设备 |

> ⚠️ **与微电网强相关**：定向射频干扰必须避开厂区 DCS 自控、对讲机、**微电网通信**——这是高耗能微电网项目的关键兼容点。

## 行业选型差异（贴合水泥/压铸/化工）

| 行业 | 选型要点 |
|------|---------|
| 化工/炼油/LNG储罐区 | 禁激光、禁全域干扰 → 导航诱骗 + 网捕为主 |
| 水泥/冶炼/压铸（粉尘大、电磁复杂） | 雷达+红外优先（抗粉尘），定向精准干扰，保护自动化/微电网通信 |
| 变电站/电网枢纽 | 严控大功率电磁，无源侦测 + 导航诱骗 |
| 港口/物流园区 | 范围广，多站点组网，车载移动式反无单元 |

## 法规边界（工厂常踩坑）

大功率无线电干扰设备属**管控设备**，整套系统需向公安、无线电管理部门备案审批。**企业不能私自架设全向大功率干扰机**，干扰周边通信/导航要担责。合规方案 = 定向、窄带、可开关、白名单管理、全程日志留存。

## 商业模式

工业反无人机属**厂区安全技改项目**，可跟微电网、AI安防机器人、数字化改造打包成园区安全资产，入 ABS/REITs 底层。交付模式：
1. 一次性设备采购 + 施工部署
2. 服务租赁（按年安防托管/值守运维，适合重资产平滑支出，更适合证券化）
3. EPC总包（空域勘测/方案/软硬件/验收备案/运维）

## 痛点 + 趋势

**痛点**：① 复杂厂区雷达虚警高、飞鸟误报；② 新型无射频链路无人机（光纤系留/自主离线）射频侦测失效；③ 厂商只卖硬件、不懂工控电力兼容，反无设备干扰生产线自控/微电网调度。

**趋势**：① AI全域融合（低空+周界+机器人+能源平台统一大屏）；② 分布式轻量化组网；③ 低空数字化管理随法规落地，高耗能工厂低空安全渐成安监硬性要求。
