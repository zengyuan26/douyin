## 谈单固定顺序（5步，严格规避工厂反感点）

1. **开场**：纳客资本合伙人，专注高耗能制造企业的能源与安全技改，联合威堉智能（重庆巴南智造园、国企参股）落地执行
2. **切入点**：不谈机器人、不谈 REITs、不谈并购 → 只聊工厂电费压降、光储 EMC、轻投入甚至零投入降电费
3. **建立信任**：出示样板项目、展厅资料、股东背景
4. **铺垫增值**：能源跑通后，如有安监整改/自动化减人/低空安防需求，可配套一体化技改；长期优质资产可对接资本盘活
5. **收尾**：现场收集用电量、屋顶荷载、用电账单，安排总部免费方案测算

## EMC 零投入标准话术

> 企业**零资金投入、不垫资、不担保、不承担设备运维风险**；威堉智能联合纳客资本全额出资建设整套光伏+储能微电网。
> 合作前提：工厂提供可用屋顶/空地、稳定用电负荷、配合并网施工；项目建设期+运营期设备产权归投资方，合同到期整套设备无偿移交工厂。

**运作逻辑（避开金融黑话讲）：**
- 全额出资方：纳客资本资金 + 威堉智能总包，覆盖勘测/设计/采购/施工/并网/运维/维修/更换全部费用
- 企业收益：自用光伏储能电，电价低于电网原价，削峰填谷减需量费；不用出钱、不用管运维、不担设备风险
- 投资方回款：合同周期（常见10-15年）内通过优惠售电、节能收益分成收回投资

## Q&A 标准应答（4条）

| 问题 | 应答要点 |
|------|---------|
| Q1 真一分钱不花？有没有隐形收费 | 建设/设备/施工/并网/维修/配件全我方承担，无预付款/保证金/分期工程款，企业只按月结算实际用电（约定优惠电价） |
| Q2 合同期设备谁的？换老板/搬迁怎么办 | 合作期内资产归投资方；搬迁/转让按合同约定处置；到期整套设备无偿归工厂 |
| Q3 后续想做机器人/安防必须找你们吗 | 不强制捆绑。能源EMC独立合作；跑通后再提供一体化技改，企业自主选择 |
| Q4 什么工厂不符合零投入EMC | 屋顶荷载不足、产权不清、负荷波动极大、征信重大风险 → 前期尽调筛除，不落地 |

## 0 投入边界（商务务必讲清，避免纠纷）

| 项目 | 是否 0 投入 |
|------|------------|
| 光伏储能一体化（有备无患） | ✅ 可做企业 0 投入 EMC（资金方持资产、长期分成，适合后期证券化） |
| 数字化技改 / 反无人机 / AI机器人 | ❌ **默认不是零投入**。两方案：①企业自筹采购+年度运维；②优质大厂整体打包，洽谈合同托管/分期付费（视纳客资本尽调审批，不对外承诺全部零投入） |
