## 顶层架构

```
纳客资本（私募基金，投行朋友操盘）
  └─ 控股/投资 → 威堉智能（框架平台公司，含国企股东，重庆巴南智造园管委会一楼自有展厅）
       ├─ 具身AI机器人
       ├─ 工业反无人机
       ├─ 智慧数字化技改
       ├─ 光伏储能一体化
       └─ 入口级项目：有备无患（能源入口抓手）
```

## 商业模式：能源技改获客入口 → 分层交付 → 资产资本化

1. **第一步（入口，最容易成交）**：光伏+储能一体化、EMC 合同能源管理（能源降本）
2. **建立信任后分层交付**：厂区安全生产数字化技改 ｜ 微电网 ｜ AI机器人 ｜ 低空反无人机安防 ｜ 资本服务（并购/股改/上市辅导/ABS/REITs）
3. **定位逻辑**：以能源技改获客，持续挖掘工厂全生命周期产业服务与资产资本化机会

## 身份

**产业私募基金**（纳客资本合伙人，资本端）——联合威堉智能（国企参股产业实施端）落地

## 核心优势（4点）

1. **入口低门槛、成交容易**：老板优先关心电费，EMC 光储是「省钱项目」，不是纯投入的安全技改，谈判阻力小；先用收益型项目建立信任，再导入合规类技改、硬件。
2. **主体背书强**：威堉智能含国企股东 + 园区管委会一楼自有展厅 + 实体样机（机器人/安防/数字化平台），解决工厂「反感纯销售、空谈投行」的痛点。
3. **业务矩阵完整、现金流充足**：短期=光伏EPC/储能建设；中期=数字化技改/反无人机/AI机器人+多年运维（ABS/REITs 优质底层现金流）；长期=资产打包证券化+并购上市。
4. **产业闭环**：产业项目落地 → 形成可确权资产包 → 私募基金资本化运作。
   `纳客资本（资金端）↔ 威堉智能（产业工程/技改实施端）↔ 制造工厂（资产场景）`
