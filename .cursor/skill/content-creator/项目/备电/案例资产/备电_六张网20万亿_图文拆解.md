## 一、为什么有效

### 三层驱动

```
第一层：热搜事件 → "六张网冲上热搜第一"——你刷到了，我也刷到了，但我帮你拆明白了
第二层：数据冲击 → 20万亿、5万亿、7万亿——钱往哪砸
第三层：个人落地 → "普通人三条路"——从宏大叙事到你能做什么
```

大多数政策解读停在第二层（这是什么、有多大）。这篇的关键差异是 P6"普通人三条路"——把国家20万亿的产业版图翻译成**你可以上桌的三张牌**。

### 两版互补策略

| | A型（7张轮播） | B型（1张信息图） |
|------|------|------|
| 用途 | 抖音/小红书左滑浏览 | 截图收藏+转发 |
| 深度 | 逐页展开逻辑链 | 一张图看完全局 |
| 风格 | 深色+琥珀（财新周刊暗调） | 白底+彩条（摩尔产业观察） |
| 优势 | 翻页=完播率 | 收藏率高，长尾流量 |

A型负责"刷到→看完"，B型负责"收藏→转发"。两版不是替代关系，是互补——同一选题打两个用户行为。

## 二、结构逐页

```
P1 封面  → "六张网"+"20万亿" 双概念砸出。热搜标签+时间链
P2 为什么 → 4月定调→6.12新华网→今天热搜，一条线串起来
P3 是什么 → 六张网速览，一网一行+图标，扫读友好
P4 钱往哪 → 20万亿拆解，数据条对比，相当于过去三年基建总和
P5 重点拆 → 新型电网+算力网，两张跟目标人群最近的网
P6 怎么切 → 工商业储能EMC / 居间人撮合 / 微电网配套服务
P7 时间窗 → 2026十五五起点，窗口刚打开+CTA
```

**翻页逻辑**：热搜→为什么→是什么→多少钱→重点在哪→我能干啥→现在就要动。一条线串到底，每页回答一个问题，下一页的问题从上一页的答案里长出来。

## 三、可复用手法

### 1. 政策链三节点

```
四月定调 → 六月新华网发文 → 今天冲上热搜
```

不是"国家推出六张网政策"，而是"这件事有一条清晰的时间线，我帮你串起来了"。**读者感觉你做了功课。**

### 2. 从大到小的漏斗

```
宏观：六张网 20万亿
  ↓
中观：重点拆新型电网+算力网
  ↓
微观：三条路。你能做哪个
```

每层缩小一步，每步离读者的钱包近一步。最后一页是"评论区聊聊，你在哪个省？做什么的？"——从国家政策聊到个人情况。

### 3. 数字锚点

- 20万亿（封面主数字）
- 7万亿（2026年当年）
- 5万亿+（新型电网一张网）
- 3条路（普通人落地方案）

数字从大到小递进——先砸大数制造冲击，再用小数给出路径。

## 四、一句话总结

**政策解读类图文的命门是"跟我有什么关系"。这篇用三层漏斗（宏观→中观→微观）回答了这个问题，最后落在"三条路，总有一条你能走"。**
