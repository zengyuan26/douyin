## 一、为什么有效

### 它跟钠电/绿证/六张网都不一样

前三篇都是事件驱动型（新闻+分析+判断）。这一篇是**痛点驱动型**——不靠新闻热点，靠集体记忆。

```
99%卡死 → 每个人都经历过
排队6小时 → 付费用户更大的愤怒
充了会员照样排 → 付费无解=最深的痛点
```

然后归因反转："不是你网络不好。不是服务器不够。是电。"——读者被卡了无数次，从来没想过这个原因。

### 视觉策略的特例

前三篇都是深色底+琥珀强调（财新风格）。这一篇改成**亮白底+自然光摄影**。为什么？

| 内容 | 深色模式 | 亮白模式 |
|------|---------|---------|
| 投资/政策分析 | ✓ 合适（严肃感） | |
| 日常痛点/生活化 | 太压抑 | ✓ 合适（真实感） |

AI视频耗电的选题是"每个人都在经历的日常"，用深色学术风会产生距离感。亮白生活场景（咖啡桌、便利贴、电表）让读者觉得"这就是我的桌面"。

### 翻页逻辑：缩放

```
我的手机（P1）
```

## 三、可复用手法

### 1. 集体痛点做钩子

不是"AI耗电量巨大"（行业标题），而是"每次用即梦卡在99%"（个人体验）。**把行业话题藏在个人经历里。**

### 2. 归因反转

```
你以为 → 服务器/网速/免费优先
实际 → 是电
```

反转的关键：**归因不能被猜到**。如果读者猜得到原因，反转就失效了。"是电"——没想到，但听完有道理。

### 3. 缩放结构

```
近距离（我的手机）→ 中距离（技术原理）→ 近距离（我的账单）→ 远距离（全球数据）→ 收束线
```

来回切换镜头距离，避免一镜到底的单调。

### 4. 首尾闭合

P1 的 99% 进度条在 P6 回归——"不是服务器不想动。电不够。"读者从封面滑动到最后一页，视觉锚点回到起点。闭合制造满足感。

---

## 四、一句话总结

**不靠新闻热点，靠集体痛点。把"AI耗电"藏进"你被卡在99%的那个下午"。读完的人觉得自己被理解了——不是被教育了。**
