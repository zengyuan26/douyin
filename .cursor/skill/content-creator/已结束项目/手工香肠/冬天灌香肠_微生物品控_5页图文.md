### P2：核心结论

> ⚠️ **P2是整篇的灵魂。必须直接给答案，禁止铺垫、禁止大段文字。**

**【连续性】**
```

  transition: 硬切。冷白雾气→夏天暖黄 vs 冬天冷白对比分屏
  carryOver: 冷白色温、香肠元素
  newElements: 对比表（夏天 vs 冬天）、核心结论句
  emotionLink: 停下来 → 原来如此
```

**【画面描述】**
背景：对比分屏。左半夏季暖黄调、模糊的变质肉质。右半冬季冷白调、紧实透亮的香肠。冬季侧更大更亮占60%。
布局：竖版9:16，对比卡片 + 底部结论
元素：左右对比，温度数字标注
禁止：段落文字超过3行

**【文字内容】**
```
主标题：不是手艺问题。是微生物。

对比表：
夏天 >15°C | 冬天 <10°C
杂菌抢跑 | 乳酸菌慢慢做工
乳酸菌没机会 | 蛋白质→氨基酸→鲜味
肉酸了 | 风味出来了

底部结论：夏天手艺再好也灌不出冬天的味。
```

### P3：逐条拆解① —— 夏天为什么不行

**【连续性】**
```
P2→P3:
  transition: 硬切。对比分屏→温度计大特写
  carryOver: 冷白色温从P2冬季侧过渡、温度数字（15→25）
  newElements: 温度计25°C特写、手套、背景虚化夏天肉表面
  emotionLink: 原来如此 → 懂了（"怪不得"）
```

**【画面描述】**
背景：温度计大特写，水银柱指到25°C。背景虚化——夏天的肉表面发粘、失去光泽。一只手（戴手套）拿着温度计。
布局：竖版9:16，温度计居中偏上，文字在下方
元素：温度计+手套+虚化背景
禁止：段落文字超过3行

**【文字内容】**
```
主标题：不是手艺不好。你在跟天气作对。

肉温超过 15°C → 有害菌几个小时就赢了
空调房也不行——空调控空气温度，控不了肉温

再好的师傅，夏天灌的香肠
跟你冬天灌的——不是同一个东西。

你们夏天灌的香肠，放几天有没有酸味？
```
