## 六、制作规范

### 设计规格

```
✅ 图片数量：6 张（9:16 竖版 1080×1920px）
✅ 视觉风格：台风预警科普——亮白底 + 台风蓝 #00BFFF 主色 + 警示橙/红（✗/危险）+ 正确绿（✓）
✅ 封面例外：P1 走深色写实灾难现场（台风风眼/灾难场景）做冲击力；P2–P6 才是亮白预警科普
✅ 图示语言：每个动作 = 扁平图标 + 箭头 + ✓/✗，像气象预警海报，能照着做
✅ 贯穿意象：气压差（气压天平 / 窗被吸出）出现在 P2/P3/P5；危险信号（变形/抖动/异响）P1 埋、P5 兑现
✅ 文字大小：标题≥40pt，动作句≥28pt，正文≥16pt
✅ 每页≤3 个信息模块，每页≤60 字，手机端可读性优先
✅ 安全区：核心内容 120px–1750px；顶部 0–120px（摄像头区）+ 底部 1750–1920px（抖音描述区）留白
✅ 具体动作＞模糊说法（“毛巾塞窗轨”不是“做好防水”）
✅ 末尾必须有 CTA（转给家人）
```

