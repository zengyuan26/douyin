## 二、设计逻辑

**结构**：严重性提前到 P2。先让观众感到"这事跟我有关，会死人"，再讲机制、再给方案。

```
P1 封面 — 紧急+直接威胁，粉碎"台风只影响沿海"
P2 严重性 — 热射病不是中暑，死亡率50%，三重地理锁
P3 关联 — 台风空调外机效应，为什么是湖北（严重性在前，机制在后）
P4 预防 — 怎么不让自己中暑
P5 救治 — 身边人倒了怎么救
P6 收尾 — 发给你在湖北的家人
```

**为什么严重性放 P2**：封面制造威胁感 → P2 立刻用数字和机制确认"你没有过度反应，这事真的会死人"。先确立严重性，观众才会认真看后面的预防和救治。反过来——先讲机制再讲严重性——前半段观众还在"哦原来是这样"的认知模式里，没进入"我得记住这个"的行动模式。

**情绪弧（警示弧）**：

```
P1 恐惧  →  "台风跟湖北跟我有什么关系？不对。有关系。"
P2 警觉  →  "死亡率50%。三重锁同时扣上。这是真的。"
P3 恍然  →  "原来台风是这样让湖北更热的"
P4 专注  →  "我在哪一类？我该怎么防？"
P5 有底气 →  "旁边人倒了我能救"
P6 行动  →  "这条得发给我爸妈"
```

**设计原则**：用每个人都说过的口头禅"热死了"做封面——但这次是字面意思。观众 1 秒认出这句话，第 2 秒意识到"不是玩笑，是真的"。

```

              一道粗壮红色气流箭头从台风西侧爆出，直指画面右下
[350-650px]   主标题（超大字号 120px+，暖白 #f0ead6，字距紧凑）
              "热死人"
              真不是开玩笑
[650-900px]   副标题（48px，警示红 #cc3333）
              巴威来了。深圳已经有人死了。
              湖北。40°C。轮到你认真看了。
[900-1050px]  底线（36px，暖灰）
              台风外围=空调外机。正对着你家。
[1750px附近]  角标：7月10日深圳梧桐山·热射病死亡 / 7月13日·中央气象台
```

**封面自检**：
- 口头禅变字面意思："热死人"人人说过 → 这次是真的 ✓
- 粉碎默认假设："台风危险在沿海" → 错，深圳已死人了，湖北40°C ✓
- 直接关联观众："轮到你认真看了""正对着你家" ✓
- 数字锚：40°C + 真实死亡案例 ✓
- 2秒决策：第1秒认出"热死人"，第2秒被"不是开玩笑"+"已经有人死了"拉住 ✓
