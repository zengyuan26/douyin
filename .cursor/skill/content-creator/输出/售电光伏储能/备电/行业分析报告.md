## 二、投资方向判断

### 核心方向：工业微电网EMC

```
微电网 = 分布式光伏 + 储能 + 充电桩 + AI调度
EMC = 投资方出钱，工厂出屋顶。省了电费分钱。
```

**EMC的本质**：不是缴费代理（渝众通/利安帮人缴水电费），也不是卖设备。是**带资进场的资产运营+金融套利**。类比——在别人家屋顶上建电站，锁定一个25年不用找下家的"租户"。

**为什么这个方向最值得投**：
- 工厂零投入，决策门槛低
- 25年合同，现金流稳定
- AI调度多赚15-30%，技术壁垒
- 绿证+碳核算新规，工厂必须绿电

### EMC 收益全景

**核心公式：设备赚一次 + 电费省25年 + 流水融N次**

| 时段 | 收益项 | 逻辑 |
|------|--------|------|
| 短期 | 工程差价 | PE投800万建，实际成本650万，差价进总包 |
| 短期 | 设备集采返点 | 量价谈判，电池/PCS返点 |
| 短期 | 建设补贴+绿证 | 各地补贴几毛到一块多每瓦，绿证当天卖 |
| 中期 | 省电分成 | 一年120-160万，分60-70%，25年雷打不动 |
| 中期 | 峰谷套利 | 储能每天一充一放，AI自动跑，边际成本近零 |
| 中期 | 需量管理 | 按住峰值，不增一砖一瓦，一年省15-20万 |
| 中期 | 需求响应+调峰+容量备用 | 电网喊停3.5-5元/度；日常搭把手；不充放也收钱 |
| 中期 | 碳资产 | 减碳配额可卖 |
| 长期 | 25年稳定流水 | 几十上百个工厂，每月电费从手里过 → ABS、合同质押 |
| 长期 | 负荷聚合资格 | 工厂多了就是天然负荷聚合商，牌照越做越值钱 |
| 长期 | 电力交易套利 | 进电力市场替工厂买电，现货价差套利 |
| 长期 | 数据资产+客户复购 | 25年用电曲线壁垒；锁了工厂，扩产加储获客成本为零 |

### 园区级微电网 vs 单厂EMC

| | 单厂EMC | 园区级微电网 |
|---|---|---|
| 投资标的 | 赌一家工厂的命 | 赌一个区域的产业密度 |
| 用能主体 | 1个 | 几十上百个 |
| 某厂倒闭 | 设备吃灰 | 电给隔壁用，不影响 |
| 退路 | 基本没有 | 新企业入驻持续有需求 |

**最佳切入口：新建园区**——还没建配电网，从零规划成本最低；管委会在抢企业，替你保证用能负荷；零碳园区考核压力下，你能谈的不止电费分成。

### 延伸方向：代理交易服务

2026年15分钟电价+现货市场，储能投资方和售电公司都需要AI交易能力。代理交易 = 帮他们做交易，收服务费。

## 三、CVC视角 vs 传统PE/VC

| | 传统PE/VC | CVC |
|------|------|------|
| 投资逻辑 | 财务回报 | 产业协同+财务回报 |
| 投后管理 | 派董事、看报表 | 下场做渠道、做交易 |
| 退出周期 | 3-5年 | 更长，但现金流稳定 |
| 在能源行业的优势 | 资金量大 | **懂产业+有产业资源** |

**CVC在能源行业的核心优势**：不只是给钱，是给渠道、给交易能力、给客户。这也是备电做代理交易平台的逻辑——投完之后，帮被投项目跑起来。

### CVC 投行行动框架

**优先级排序：**

| 优先级 | 要做什么 | 细节 |
|--------|---------|------|
| 第一 | 建居间人网络 | 设备商/园区招商/设计院/节能公司 —— 居间人带项目，你出钱出结构，按成交给居间费 |
| 第二 | 养风控（不养分析师） | 一个人判断三件事：工厂能不能活25年、电费账单真假、电价价差够不够 |
| 第三 | 你亲自签合同 | 居间人敲门、做热关系。你进去收尾——聊交易结构、算回报、签合同 |

**一句话：居间人获客。你设计交易、匹配资本。风控筛掉烂项目。你坐在牌桌中间，不是满街发名片。**
