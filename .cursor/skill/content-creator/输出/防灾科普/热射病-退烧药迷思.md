## 二、设计逻辑

**一句话主线**：体温高≠发烧。发烧是空调设定温度调高了（退烧药有用），热射病是空调压缩机坏了（退烧药没用且伤肝伤肾）。

**问题链**：身体发烫为什么不能吃退烧药？→ 发烧和热射病有什么区别？→ 吃了退烧药会怎样？→ 正确的急救是什么？

**情绪弧**：

```
P1 好奇 → "发烧吃退烧药不是常识吗？为什么热射病不行？"
P2 恍然 → "原来发烧和热射病是两种完全不同的热——一个空调调高了，一个空调坏了"
P3 警觉 → "吃了不光没用，还会直接伤肝伤肾——两种药各有一种杀法"
P4 专注 → "那正确做法是什么？物理降温，不是吃药"
P5 行动 → "记住。下次有人中暑，拦住递药的手"
```

### P2｜本质——"发烧是空调调高了。热射病是空调坏了。"

```
[1500-1750px] 判断句色块
```

### P3｜拆解——"两种退烧药，各有一种杀法。"

**连续性**：P2→P3：从机制对比切换到药物危害。红色警示从"机制不同"升级到"吃了会怎样"。情绪：恍然→警觉。

```
[120-180px]   顶条（36px，红字）
              《中国热射病诊断与治疗指南（2025版）》：
              "禁用非甾体类解热药。不仅不能退热，反而损害肝脏和凝血功能。"
[180-550px]   模块1｜对乙酰氨基酚（扑热息痛/泰诺）→ 伤肝
              正常情况：肝脏安全代谢，排出体外
              热射病时：肝脏血流大幅减少，肝细胞已在受损
               → 药物代谢产物 NAPQI 堆积，肝脏无法清除
               → 急性肝衰竭风险急剧升高
              【美国重症医学会 SCCM 2025 指南】明确建议：避免使用对乙酰氨基酚降温
[550-950px]   模块2｜布洛芬（芬必得/美林）→ 伤肾 + 凝血崩溃
              正常情况：抑制前列腺素→退烧止痛
              热射病时：严重脱水，肾脏血流已经锐减
               → 布洛芬让肾血管进一步收缩 → 急性肾损伤
               → 热射病已有凝血功能障碍（DIC），布洛芬抑制血小板 → 加重出血
              【解放军总医院 吴海云 主任医师】退烧药更准确叫"消炎药"，
              本身没有降温作用。中暑是散热中枢出问题，吃退烧药适得其反。
[950-1250px]  模块3｜共同的致命后果
              【广东省第二人民医院急诊科 李悦 副主任】
              "热射病高热切忌自行服用布洛芬、美林等退烧药。

              是吃了药，你以为在"治疗"，错过了真正救命的30分钟。
[1500-1750px] 判断句色块

```

### P4｜落地——"唯一有效的降温。物理的。"

**连续性**：P3→P4：叠化过渡——从"不能做什么"到"应该做什么"。颜色从全红过渡到红+绿对比。情绪：警觉→专注。

```

              ① 脱离热环境 → 移到阴凉/空调房，平躺，脚抬高
              ② 冷水浇淋 → 20°C左右冷水浇全身，持续浇
                 最有效的方法：把患者浸在凉水里
              ③ 冰袋敷大血管 → 颈部两侧、腋下、腹股沟
                 这些地方血管浅，降温最快
              ④ 打120 → 同时进行。物理降温不要停，直到急救人员接手
[800-1200px]  模块2｜绝对禁止（红底白字，对比放在右侧）
```
