## 二、设计逻辑

**问题链**：P1 悬念（三件事有关系？）→ P2 本质（台风=巨型空调）→ P3 原因（湖北为什么最惨）→ P4 严重性（热射病不是中暑）→ P5 误区（你以为安全的都错了）→ P6 升华（预防+救治两条命脉）→ P7 判断（发给你在湖北的家人）

**结构公式（P2-P7 统一）：**

```
[信息模块 1-3 个] → 用数据/事实/图解回答本页问题
     ↓
[判断句色块] → 收束，给态度。固定在画面下部，琥珀底
```

**情绪弧（警示弧）：**

```
P1 好奇  →  "三件事有关系？"
P2 恍然  →  "原来是一条物理链"
P3 专注  →  "湖北为什么最惨"
P4 警觉  →  "这不是中暑，是会死人的"    ← 情绪爬升

P7 行动   →  "这条得发给家人"           ← 收束
```
