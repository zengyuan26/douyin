## 二、5 张图设计

### 封面 · 让读者点"展开全文"

```
┌─────────────────────┐
│                     │
│                     │
│   承认自己错了       │  ← 主标题 · 超大 · 粗黑
│                     │
│   比亏还难受         │  ← 副标题 · 中号 · 低饱和色
│                     │
│                     │
│   这是人性           │  ← 锚点 · 小号 · 更轻
│   不接受反驳         │
│                     │
└─────────────────────┘
```

- **任务**：停下来，点"展开全文"。跟图文封面同一个钩子，但多一层"这篇文章值得读完"的暗示。
- **主标题**：承认自己错了 —— 超大号，粗黑，页面重心
- **副标题**：比亏还难受 —— 中号，低饱和色，层级落差明显
- **锚点**：这是人性，不接受反驳 —— 小号，更轻，挑衅收尾
- **信息模块**：3 个

---

### 插图1 · 机制概念图

- **插入位置**：日常场景之后，"放大一万倍——"之前
- **任务**：观众刚在烂片/恋爱里点头。趁热把这套机制钉进脑子——不出现韩国、不出现数据，纯概念。让读者先"看见"连锁补错长什么样，然后再砸证据。
- **视觉方向**：一个链式/螺旋结构向下。每个节点独立看都标注了 ✓，但整条链的尽头是暗的/空的。抽象示意，不是信息图表。
- **图内文字**：不超 8 字。让画面说话。
- **信息模块**：1 个（概念图本身）

### 插图2 · 双链证据

- **插入位置**：个人 2015 段结束后，经济学段之前
- **任务**：韩国链条 + 2015 链条上下并置，格式完全一致。读者扫一眼就看见：不同的国家、不同的人、不同的时代——同一张图。这就是"是不是觉得眼熟"的视觉答案。
- **视觉方向**：两条链上下/左右并置，节点数量一致、走向一致。让相似性自己跳出来。底部一行判断："同一张人性图谱"。
- **图内文字**：两条链的节点标签 + 底部判断句
- **信息模块**：2 个（双链 / 底部判断）

### 插图3 · 一文钱古典链

- **插入位置**：一文钱故事讲完之后
- **任务**：读者已经见过两次链条格式了（插图1 抽象 → 插图2 双链证据）。第三次出现同一个格式——但材质从现代信息图变成了古典书卷残页。500 年前就长这样。毛骨悚然不是靠文字，是靠"同一个结构跨了 500 年"自己砸下来。
- **视觉方向**：古典书卷/木板印刷/旧纸质感。链式结构跟插图1-2一样，但箭头可能是竖排、从右往左。材质变了——现代干净 → 古旧残破。格式不变。
- **图内文字**：一文钱 → 赌输 → 骂娘 → 上吊 → 走错门 → 移尸 → 诬陷 → 杀仆 → 十三条命。底部："每一步单看都没毛病。停下来等于承认——前面全错了。"
- **信息模块**：2 个（古典链 / 底部判断）

### 插图4 · 尾图（镜子）

- **插入位置**：文章最后，"难"字之后
- **任务**：首尾闭合。构图呼应封面——同样的留白方式、同样的直接面对读者的感觉。但封面是定罪，尾图是问出去。从"我告诉你"变成"你自己看着办"。
- **视觉方向**：极简。一个问题居中。大量留白。没有链条、没有数据、没有装饰。读完 600 字翻完 4 张图，回到跟封面一样的构图——但看见的不再是判断，是自己。
- **图内文字**："大多数人谈恋爱半年就知道不对了。有几个人能果断分手。" 下方更小："难"
- **信息模块**：1 个（一个问题）

## 三、视觉连续性策略

| 图 | 角色 | 链条格式 | 材质感 |
|------|------|------|------|
| 封面 | 定罪 | 无链·纯文字 | 干净/直接 |
| 插图1 | 概念 | 抽象链式图 | 现代/干净 |
| 插图2 | 证据 | 双链并置 | 信息图感 |
| 插图3 | 压轴 | 同款链·古典材质 | 古书/旧纸 |
| 插图4 | 镜子 | 无链·极简 | 同封面 |

- 三张链式图：抽象 → 并置证据 → 古典材质，层层递进
- 封面 + 尾图：无链，纯文字，构图呼应，首尾闭合
- 5 张同属一个视觉世界
