### P2：拆恐惧 — 旧地图

**【连续性】**
```
P1→P2:
  transition: 同一束琥珀光从左上移到正中——照亮整张旧地图
  carryOver: 旧地图、琥珀光束、深黑底
  newElements: 背面透光——纸后面隐约有新的坐标网格、光从地图背面穿过纸
  emotionLink: 被看穿 → 不安（"我手里的地图也是旧的？"）
```

**【画面描述】**
同一张旧地图被推到画面中央的光下。地图正面标注密密麻麻——"降煤耗""调配方""提运转率""降本增效"——都是对的方向。但光从地图背面透过来——纸的背面隐约透出新的坐标网格、新的标注。观众发现：这张精密的地图，画的是旧大陆。

**【文字内容】**
```
做对了——为什么是陷阱？

"对"是旧规则的对。
规则一换。满分变零分。

你在旧地图上找新大陆。
```

**Image prompt:**
```

Introduces the visual metaphor: an old map, precise and detailed, but drawn for the wrong continent. Chinese text: "做对了——为什么是陷阱？" "'对'是旧规则的对。规则一换。满分变零分。" "你在旧地图上找新大陆。" The key visual metaphor introduced here carries through all remaining pages. Content safe zone: 120px to 1750px from top.

### P3：弹药① — 水泥厂老板。每一步都对。

**【连续性】**
```

  newElements: 工厂办公桌、三张报表（煤耗下降曲线+利润折线+碳配额测算单）
  emotionLink: 不安 → 懂了（"他也是每一步都做对了"）
```

**【画面描述】**
工厂老板的实木办公桌。旧地图被推到画面左下角桌边。三张报表占据画面主体：第一张——煤耗三年下降曲线，一路向下（做对了）；第二张——行业利润折线图，从1867亿跌到290亿（跌84.5%）；第三张——碳配额成本测算单，红色圈出"48元/吨"。琥珀光照在三张报表上。窗外是水泥厂的轮廓。

**【文字内容】**
```
水泥厂老板。降煤耗三年。

做对了所有事。然后规则换了。

### P4：弹药② — 两个世界的成本结构

**【连续性】**
```
P3→P4:
  transition: 三张报表被推开。画面一分为二——不是等分
  carryOver: 旧地图（左侧暗处桌角）、琥珀光→左侧暗暖调
  newElements: 右侧亮冷调——光伏板阵列+储能柜+绿色显示屏读数"0"、电费单对比
  emotionLink: 懂了 → 被击中（"他在另一个维度"）
```

**【画面描述】**
对比分屏。左侧40%暗暖调——传统水泥厂的电费单（每月几十万）、煤耗表、旧地图在桌角。右侧60%亮冷调——济宁海螺工厂：光伏板阵列在阳光下、储能柜、一块绿色显示屏放大显示"外购电量：0"。右半更大更亮——因为你有判断。两半之间不是直线分割——是光从右侧渗向左侧。

**【文字内容】**
```

济宁海螺。零外购电。

省3000万/年。减碳10万吨。

不是多一种省钱技巧。
是两套成本结构。

  emotionLink: 被击中 → 清醒（"不是水泥的事。是我的事。"）

## 五、制作规范

### 设计规格

```
✅ 图片数量：6张（9:16竖版）
✅ 文字大小：标题≥40pt，正文≥16pt
✅ 配色：深炭黑底+琥珀强调+冷白文字+绿色读数（P4）
✅ 对比权力关系：P4右侧有判断→更大更亮更冷（60%）
✅ 核心观点：每张图有1个金句视觉块
✅ 互动引导：P3槽点 + P6填空，2个评论触发器
✅ 文字密度：每页≤60字
✅ 禁止项：手机Mockup、emoji、特殊符号、大段文字段落（超过3行）
✅ 连续性：旧地图贯穿6页——P1边缘→P2正面→P3桌角→P4左侧→P5背面→P6右下角
```

### 字体规范

```
✅ 字体选择：思源黑体
✅ 禁止特殊字符：代码块符号、数学符号、装饰符号、Emoji
✅ 中文标点：逗号（，）、句号（。）、顿号（、）
✅ 排版简化：文字一行说完。每页≤60字。禁止竖排文字
```
