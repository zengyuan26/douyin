# 绿电直供 · 观众心理线

> 不是我要讲什么，是观众想知道什么。每页三个问题对齐。

---

```
P1  他刷到封面：绿证涨了快十倍？！
     答案：悬念，不答。
     他冒出：这什么东西？为什么涨？

P2  他进这页：绿证到底是什么？
     答案：绿色电力身份证。分三档——普通几毛、中级三五块、顶级七块七。
         （证明精度不一样，跟身份证分户口本/临时/护照一个道理）
     他冒出：那我需要哪种？在哪买？还能涨吗？

P3  他进这页：在哪交易？还能涨吗？有风险吗？
     答案：北京广州两个交易所。8月新政策还要涨。两年有效期，买错年份血本无归。
     他冒出：交易地方都一样，为什么有的几毛有的七块多？

P4  他进这页：为什么价格差这么多？
     答案：区别在怎么产出来的。普通→电网混在一起→年度平均。直供→物理专线直连→小时级溯源。这就叫绿电直供。
     他冒出：这东西到底在解决什么实际问题？

P5  他进这页：绿电直供在解决什么实际问题？
     答案：碳关税（欧盟加税）、碳足迹（大客户在查）、绿证不够硬（哪一天的哪度电？）。
        三个问题一个解法：物理溯源。
     他冒出：政策有动静吗？谁在做了？

P6  他进这页：政策开了什么门？谁在动了？
     答案：650→688号文，一对一升级到集群共享。两群人——买方要硬绿证，卖方能产硬绿证。
     他冒出：具体怎么操作？门槛在哪？

P7  他进这页：怎么操作？有什么门槛？
     答案：四个硬指标。核心小时级溯源+以荷定源。电源方和负荷方合资。
     他冒出：有人跑通了吗？

P8  他进这页：有没有人已经做了？
     答案：大丰港（降75%）、铁山港（98.6%）、宜宾（10亿度/年）。都是物理溯源。
     他冒出：跟微电网什么关系？怎么选？对我有什么机会？

P9  他进这页：跟我有什么关系？
     答案：微电网园内+绿电直供园外=两条腿。四件拼成零碳园区。
        四层机会——绿证在涨（所有人）/同一度电不同价（有资源）/碳关税绕不开（出口）/缺懂溯源的人（想入行）。
     他冒出：下一期零碳园区是什么？
```
