# 初稿：比亚迪11.275GWh储能大单

> 导演分析通过后出。30 秒扫完的蓝图，确认方向再动笔。

---

## 一、核心观点（一句话）

**比亚迪签了全球最大储能订单，宁德时代被踢出局。这不是"谁能做电池"的比赛——是"谁能在沙漠里做储能"。2710Ah刀片电池+IP66+-30°C到55°C，中国储能出海的门槛不在产能，在场景。**

---

## 二、分支观点（3个）

```
分支① 这不是普通订单——全球首个GW级"全天候"光储项目。
       沙漠夜间输出1GW连续基载电力。以前是妄想，现在是合同。

分支② 宁德时代为什么出局？年初被列为"首选供应商"，最终没上合同。
       不是电池便宜的问题。是沙漠场景壁垒——IP66防护、极端温度、
       千万级监控点位。能造电池 ≠ 能在沙漠里稳定运行。

分支③ 中国储能出海三张牌：电芯、集成、场景。
       中东后面还有沙特、卡塔尔。门票还没涨。
```

**逻辑链：** 这个订单有多牛 → 宁德时代为什么没拿到 → 出海到底拼什么 → 窗口期在哪

## 五、逐段内容骨架

```
P1｜封面 — 强钩子
  追问：无（制造问题：宁德时代怎么被踢了？）
  信息：比亚迪×Masdar / 11.275GWh / 全球最大单一储能采购合同
  判断：无（封面不给结论）
  关键句：宁德时代是"首选供应商"。最终没上合同。

P2｜结论 — 这个订单有多重
  追问："11.275GWh？什么概念？"
  信息：4个数据卡片——
        ① 全球首个GW级全天候光储（5.2GW光伏+19GWh储能）
        ② 沙漠夜间输出1GW连续基载电力
        ③ 2710Ah全球最大储能刀片电池，单体容量提升300%
        ④ 20尺集装箱=10MWh，最小单元14.5MWh，全球之最
  判断：这不是"又签了个大单"。是沙漠极端环境不再是中国储能的禁区。

P3｜认知 — 宁德时代为什么出局
  追问："宁德时代不是首选供应商吗？怎么没上去？"
  信息：① 宁德时代年初被Masdar列为"首选供应商"
        ② 最终合同上：BYD 11.275GWh + 阳光电源7.5GWh。没有宁德时代
        ③ BYD参数：IP66防尘防水、-30°C~55°C、BMS复杂度降70-80%
        ④ 自研GC Master EMS：千万级监控点位、算力提升400%、单站管理15GWh
  判断：不是电池便宜的问题。沙漠里比的不是成本——是谁的设备能不坏。
        能造电池 ≠ 能在沙漠里稳定运行。

P4｜逻辑 — 中国储能出海三张牌
  追问："出海到底拼什么？谁的牌最好？"
  信息：① 电芯牌：谁的能量密度高、谁的电芯大（BYD 2710Ah 碾压级领先）
        ② 集成牌：PCS+BMS+EMS全套方案（阳光电源7.5GWh+2.6GW逆变器）
        ③ 场景牌：极端环境适配能力。中东/北非/中亚——沙漠+高温+沙尘
        ④ 19GWh全部由中国企业包揽（BYD+阳光电源），零外资
  争议点：宁德时代还有机会吗？电池产能全球第一，但场景适配慢了半拍。
  判断：中东第一标，全是中国公司。后面沙特、卡塔尔还在排队。
        出海三张牌，场景牌最硬——谁能在沙漠里站稳，谁就有定价权。

P5｜终局 — 中东储能 = 下一个万亿？
  追问："这个市场有多大？现在进场晚不晚？"
  信息：① 阿布扎比"全天候"项目只是第一个。沙特2030愿景、卡塔尔世界杯后基建
        ② Masdar在全球疯狂扩张可再生能源投资
        ③ 2027年投运——时间窗口就这两年
  判断：中东储能市场刚开了第一枪。设备商已经开始抢座了。
        后面的牌桌——运营、运维、本地化服务——还没人坐。

P6｜CTA — 你怎么看？
  追问：无（收束，抛争议）
  信息：宁德时代"首选"变"出局"——是技术路线问题，还是场景判断慢了？
        阳光电源7.5GWh，跟BYD一起包揽19GWh
  判断：无（留给评论区）
  CTA：私信「储能出海」+ 下期预告：中东储能市场，谁在抢第二标？
```
