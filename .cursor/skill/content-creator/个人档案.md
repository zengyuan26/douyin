### 两轨创作系统（v2.1）

内容走两条轨道，共用同一套受众漏斗。

| | Track A：认知判断 | Track B：行业信号 |
|------|------|------|
| **起点** | 形成判断：我对世界/人性/市场有一个看法 | 识别信号：我在行业位置上看到了什么 |
| **信任来源** | 判断力 + 弹药密度 + 跨域连接 | 行业入场券 + 亲身经历 + 判断力 |
| **案例弹药** | 六类权威交叉扫射（科学/东方经典/西方哲学/商业符号/历史事件/文学） | 行业案例 + 项目见闻 + 数据 + 六类权威辅助 |
| **个人经历** | 可选，不强制 | 经常需要（来时路/项目路） |
| **内容感觉** | "这人能看到我看不到的连接" | "这人在那个房间里，我没在" |
| **适合类型** | 口播脚本、A型图文 | 口播脚本、A型图文、清单体 |

**Track A 对标朱莉娅模式**——判断先行，概念是给判断起的名字。Track B 是增元独有的行业壁垒——坐在投行椅子上看到的信号，朱莉娅讲不了。

### 信任路径（vs 朱莉娅）

朱莉娅的信任来源是学历×机构背书（"哥大沃顿→华尔街→我懂这个系统"）。增元的信任来源是实战×直觉（"成过败过→判断力是摔出来的"）。Track A 走朱莉娅的判断力输出模式，Track B 走增元独有的行业位置壁垒。

| | 朱莉娅 | 增元 Track A | 增元 Track B |
|---|---|---|---|
| 信任来源 | 学历 × 机构背书 | 判断力 × 弹药密度 × 跨域连接 | 行业入场券 × 亲身经历 × 判断力 |
| 内容弧线 | 理论 → 生活应用 | 判断 → 概念命名 → 弹药扫射 → 落观众 | 信号 → 翻译谁会睡不着 → 判断 → 落观众 |
| 情绪底色 | "我懂这个系统，我来给你翻译" | "我看到了一些你没看到的东西" | "我干过，我知道什么会死" |
| 观众感受 | "这人好聪明" | "这人能看到我看不到的连接" | **"这人真干过"** |
| 不可复制性 | 学历和机构资质（可复制） | 判断力+跨域连接（半可复制） | **14年摔出来的判断力（不可复制）** |

### 四重不可复制性

| 重 | 是什么 | 内容含义 |

## 六、内容体系

### 内容定位

**AI让信息平权了。但散落的信息拼成框架、给出判断——这个能力AI替代不了。**

你的内容不是讲知识。是把你看到的信息拼成判断，让别人拿走就能用。每天学到的东西 → 整理成框架 → 给出判断。

### 知识五层金字塔

```
                    ┌─────────────────────┐
                    │  第5层：人生判断    │  ← 14年经历喂出来的底层认知
                    │  （钱的本质/人性的规律）  │     钱/关系/认知 三领域
                    ├─────────────────────┤
                    │  第4层：框架判断    │  ← 芒格式思维模型 + 自己提炼的框架
                    │  （商业逻辑/投资框架/决策方法）│     跨行业通用
                    ├─────────────────────┤
                    │  第3层：行业判断    │  ← CVC视角，不限新能源
                    │  （行业信号/政策翻译/趋势拆解）│     新能源/AI/消费/科技都有
                    ├─────────────────────┤
                    │  第2层：实战判断    │  ← 真实项目+帮人看项目的案例
                    │  （交易结构/融资包装/谈判逻辑）│     不限于自己的项目
                    ├─────────────────────┤
                    │  第1层：生活化表达  │  ← 朱莉娅式翻译层（每篇必过）
                    │  （用逛超市/谈恋爱/点外卖/开小店讲硬逻辑）│
                    └─────────────────────┘
```

**每一条内容必须经过第1层**——用生活化例子翻译。行业判断不经过生活化翻译 = 圈内自嗨。

### 框架的来处顺序（关键）

朱莉娅：先学框架 → 用框架看世界 → 写成内容。
增元：**先摔出直觉 → 回头发现"原来芒格也这么说" → 用芒格的话包装自己的直觉。**

增元的内容结构应该是：
```
真问题（我/我朋友遇到的）→ 我的判断（摔出来的）→ 回头验证（原来某某人也这么说过）→ 你能拿走用
```

不是：
```
某某框架 → 用框架分析 → 举例 → 结论
```

朱莉娅可以做第二种，因为她的信任来源是"她懂框架"。增元做第二种就是在扔自己的武器、捡别人的武器。

### 六类权威弹药库（Track A 专用）

朱莉娅模式的核心：用不同类型的权威从不同角度夹击同一个论点。

| 权威类型 | 代表 | 在论证中的作用 | 给观众的感觉 |
|------|------|------|------|
| **科学权威** | 哈佛/斯坦福/伯克利/NASA/量子物理/神经科学 | "这不是玄学，是科学" | 我在学真正的东西 |
| **东方经典** | 金刚经/易经/庄子/孔子/曾国藩/苏轼 | "古人早就知道了" | 我们的文化不落后 |
| **西方哲学** | 柏拉图/黑格尔/尼采/培根/福柯/波普尔 | "最聪明的人都同意" | 不是东方自嗨，是人类共识 |
| **商业符号** | 乔布斯/马斯克/稻盛和夫/巴菲特/洛克菲勒 | "最成功的人都这么干" | 我学了这个也能成功 |
| **历史事件** | 秦始皇/科举/中世纪教会/尼克松黄金脱钩 | "一直是这样" | 不是新鲜事，是规律 |
| **文学/人物** | 白居易/杜甫/琼瑶/戴安娜/范进中举 | "连他们都逃不过" | 不是我一个人的问题 |

使用原则：
- 每个论点至少从三个角度夹击。总有一发打中观众。
- 交叉对撞：科学↔东方经典、西方哲学↔东方经典、商业符号↔历史事件。
- Track A 弹药可以全部来自外部。零个人经历也能成立。

### 选题第一性原理

**流量第一性原理是选题，选题第一性原理是共鸣。** 不是"这个行业趋势值得讲"，是"谁在因为这个睡不着觉"。

每个选题必须经过三维度过滤——**钱、关系、认知**，至少落进一个。落不进去就不发。

| 领域 | 观众的真正问题 | 例子 |
|------|--------------|------|
| **钱** | 怎么挣、怎么守、怎么传 | 订单多了突然关门、不敢涨价、算错回本周期 |
| **关系** | 跟谁绑在一起、谁能信任、孩子接不接 | 请人管厂利益不一致、孩子不想接班、合伙人选错了 |
| **认知** | 换了眼镜看世界、打破幻觉、看见自己 | 想转型不知道往哪转、信息越多越焦虑、你怕的不是AI |

**对标验证**：对标博主 9 篇爆款——4 篇财富场（钱）、2 篇家庭场（关系）、3 篇世界观场（认知）。0 篇行业问题，0 篇纯技术科普，0 篇"这个趋势意味着什么"。

**行业信号的翻译规则**：看到行业信号后第一问不是"这意味着什么"，是"这个信号会让谁睡不着觉"。

**Step 0 开局决策**：每个选题先定 分析线/感受线/混合线，再选结构类型（详见 skill.md）。

| 线型 | 比例 | 推荐结构 | 
|------|------|----------|
| 分析线 | 事实≥60%，态度≤40% | 诊断型/框架型/验证型/模型重塑型 |
| 感受线 | 态度≥60%，事实≤40% | 祛魅型/故事型/概念型 |
| 混合线 | 各~50% | 跨学科论证型/箴言型 |

### 为什么内容池无限

你天然在收集信息——行业信号、投资框架、AI工具、身边人案例、读到的书。把这些散落的信息拼起来、给出判断，就是内容。不需要额外创作。

### 新能源含量控制

**新能源内容占比不超过25%**（一周最多1-2条）。被贴"新能源博主"的标签 = 天花板到了。
新能源是你的弹药库之一，不是你的人设。你的人设是"判断力"，不是"新能源"。

### 内容四象限

```
                          看外部（项目/机会/行业）
                ┌──────────────────────────┐
         框架   │  行业判断               │  框架判断              │
         拆解   │  多行业信号（不限新能源）  │  投资框架/商业判断     │
                │  政策翻译/趋势拆解      │  跨领域思维模型        │
                │                          │  芒格式认知工具        │
                ├──────────────────────────┤
         故事   │  实战判断               │  来处判断              │
         经历   │  项目案例/帮人看项目     │  来时路/身边人故事     │
                │  交易结构/融资包装      │  经典拆解→框架        │
                │                          │  读书快拆/认知分享     │
                └──────────────────────────┘
                          看内部（人/自己/认知）
```

**两条轴**：
- 横轴：看外部（项目/机会/行业）↔ 看内部（人/自己/认知）
- 纵轴：框架拆解 ↔ 故事经历

**四个象限**：

| 象限 | 是什么 | 内容举例 |
|------|------|------|
| **行业判断** | 多行业信号和趋势（不限新能源）。用CVC视角看行业变化 | 利率变化→你的房贷、AI写代码→技能贬值、芯片管制→供应链 |
| **框架判断** | 投资框架、商业底层逻辑、芒格式思维模型。不限行业 | 定价权/护城河/规模效应vs网络效应/反过来想/安全边际 |
| **实战判断** | 真实案例、帮人看项目的判断、交易结构拆解。主角是老板/普通人，不是你自己 | 预制菜老板想融资被一个问题问沉默、两个工厂估值差10倍 |
| **来处判断** | 判断力从哪来——经历、身边人、经典拆解、认知分享 | 四次从零开始、读芒格的拆解、身边人怎么选错的 |

### 来处判断 · 四个来源

| 来源 | 是什么 | 举例 |
|------|------|------|
| 来时路 | 个人经历，框架怎么长出来的 | 四次从零开始→韧性不是坚持，是知道自己擅长什么 |
| 身边人 | 观察到的案例，别人的选择和结果 | 朋友工厂踩坑→提炼出共性判断 |
| 经典拆解/读书分享 | 一本书/一个模型→快速拆→整理成框架。读得快拆得快，等于帮你读了 | 读芒格→提炼"反过来想"→用在项目判断上 |
| 认知分享 | 信息散落时代，你怎么收集整理形成判断 | "这个结论不是看了一篇新闻，是我把三件事拼在了一起" |

### 四象限 → 三维度映射

每个选题必须落进钱/关系/认知至少一个领域。不同象限默认映射：

| 象限 | 默认落领域 | 翻译方向 |
|------|-----------|----------|
| 行业判断 | **钱** | 不讲"政策意味着什么"，讲"你的成本/利润会怎么变" |
| 框架判断 | **钱** 或 **认知** | 不讲"思维模型"，讲"你看项目总不对劲，一个方法让你看穿" |
| 实战判断 | **钱** 或 **关系** | 不讲"项目进展"，讲"从签字到回款踩过的坑" |
| 来处判断 | **关系** 或 **认知** | 不讲"我的经历"，讲"你觉得自己到谷底了？谷底下面还有坑，但有一条路能上来" |

### 各阶段配比

| 阶段 | 行业判断 | 框架判断 | 实战判断 | 来处判断 | 逻辑 |
|------|---------|---------|---------|---------|------|
| **阶段1** 冷启动 | 15% | 25% | 10% | **50%** | 来处判断是信任核武器。先让人知道你判断力哪来的 |
| **阶段2** 信任建立 | 25% | 35% | 15% | 25% | 框架判断加重，展示专业深度 |
| **阶段3** 行业破圈 | 30% | 30% | 25% | 15% | 行业判断扩大范围，但每篇必过生活化翻译 |
| **阶段4** 私域转化 | 20% | 35% | 30% | 15% | 框架+实战为主，高净值人群从这两块筛出来 |

### 内容定位演进

```
阶段1（冷启动）：让人知道"这个人的判断力是摔出来的" → 来处判断50%
阶段2（信任建立）：让人信"他每次判断都不一样但后来都对" → 框架判断提到35%
阶段3（行业破圈）：圈内开始关注"原来他看新能源也这么准" → 行业判断30%，但保持跨界
阶段4（私域转化）：高净值人群筛选出来 → 框架+实战为主，高价值内容进私域
```

### 实战项目怎么讲（不做自嗨）

不讲"我的项目"，讲"我见过的判断"。

```
❌ 自嗨式："我们在巴南落地了微电网项目，用了18层套利模式……"
✅ 判断式："我见过一个工厂老板，电费一年200万。他找了3家售电公司报价，选了最便宜那家。一年后电费涨到260万——不是电价涨了，是他的用电习惯被人摸透了。我帮他做了一件事……"
```

**讲法规则**：
- 主角是老板/普通人，不是你——你在幕后，判断是箭头
- 给的是判断，不是项目描述——观众拿走的是"我也该检查一下"，不是"你们公司真厉害"
- 生活化类比兜底——哪怕是讲EMC合同，也用"婚前协议"来翻译
- 每篇只一个核心判断——不要一篇里面塞18层套利+代理购电+微电网+碳交易

### 核心受众

**企业主**。

他们为什么看你：你对信息的判断力跟他们认识的所有人都不一样。14年实战喂出来的直觉 + 芒格式框架整理 + AI工具能力 + CVC视角——这个组合，中国内容赛道里找不到第二个人。

**次要目标**：想跨行/转型的人（30-50岁，在一个行业做了很久，想动但不知道往哪走）。

来时路内容对他们天然有共鸣。不是煽情——是"我干过，我知道什么会死"。

**同一期内容，两种人看，两种感受。不矛盾。**

### 情绪锚点

每条内容一个"魂"——观众看完心里留下的那一个感觉。

**来处判断常用**：破除恐惧 / 被理解的踏实 / 我也能 / 这人真实 / 敬佩 / 被看见
**行业判断常用**：刷新认知 / 紧迫感 / 后怕 / 原来如此
**框架判断常用**：实用惊喜 / 被尊重 / 兴奋 / 优越感
**实战判断常用**：心安 / 这人靠得住 / 期待后续

### 情绪调性

直言直语，做人硬派。CVC视角但不装大佬。像朋友分享"我最近看到了什么"——不是讲课，是给你看我的判断框架。

## 十、最重要的10条创作纪律

1. **从真问题出发，不从行业信号出发**。观众心里已有的困惑 > 你想告诉他的信息
2. **每条必须经过生活化翻译**。不用生活化的例子 = 没有在跟观众说话
3. **判断先冲出来，框架只是工具**。不是先搭框架再给判断，是先给判断再用框架解释
4. **新能源是弹药库之一，不是唯一**。被贴标签 = 天花板来了。新能源占比≤25%
5. **不讲"我的项目"，讲"我见过的判断"**。你是提供判断的人，不是推销公司的人
6. **每篇留一句替观众总结感受的判断句**（认可 = 点赞发动机）
7. **每篇留一个可讨论的方法论口子**（槽点 = 评论发动机）
8. **每篇留一句观众想转给别人的金句**（嘴替 = 转发发动机）
9. **不堆数据，不堆术语，不堆框架名称**。数据是弹药，一枪一发，打完就走
10. **信任是第一指标**。不是播放量、不是粉丝数——是"这一期结束后，观众更信任你了吗？"
