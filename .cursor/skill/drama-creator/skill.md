> 版本：2.0.0 | 更新：2026-06-15
> 定位：专门针对剧情类短视频脚本的创作方法论
> 适用时长：20-35秒 | 2-3个镜头
> 核心哲学：**苦难是文学的土壤。喜剧的内核是悲剧。**

## 核心理念

### 苦难不是用来展示的。苦难是用来「压着」的。

> 「饭还热着」里，妈妈说了四次"饭还热着"——不是苦难本身，是她在**压着**苦难。
> 压了四次。最后儿子站在坟前说"饭还热着"——压不住了。
> 苦难才溢出来。

> 苟师（《主角》）从名旦跌落到看门，军绿色工服下面穿红色毛衣，偷偷练功。
> 他不说。他压着。最后81口连珠火——**不是崩溃，是燃烧**。

### 创作的三个层次

| 层次 | 是什么 | 怎么做到 |
|------|--------|---------|
| **内核** | 那个压着的东西。不说出来的伤口。 | 问：这个人物在扛着什么？扛了多久？ |
| **看见** | 有人发现了。不是同情。是认出同类。 | 问：谁有资格看见？她自己经历过什么？ |
| **裂开/燃烧** | 压不住了。被看见之后，绷断了。 | 问：压了多久？这次为什么压不住了？ |

### 一句话定位

> **不是让观众哭。是让观众看见有人在压着。然后发现自己也在压着。**

## 创作流程（8步）

```
找到内核 → 受众设计 → 选叙事框架 → 人物设计 → 场景设计 → 冲突设计 → 情绪节奏 → 时长规划
```

每一步对应一个必须回答的问题。

---

## 第一步：找到内核

### 内核 = 那个不直接说出来的东西

| 找到内核的方法 | 示例 |
|--------------|------|
| 一个执念 | "水不能放超过七天" → 老头每三天换一次 |
| 一个没说出口的请求 | "敲一下门" → 我怕死了没人知道 |
| 一个重复的动作 | 摆拖鞋、倒凉水、敲一下门 |
| 一个物件 | 旧白瓷杯（有茶渍）、铁盒零钱、老照片 |

### 内核自检

```
□ 这个内核能不能用一句话说完？（不能超过20个字）
□ 这个内核是不是「压着」的状态？（不是宣泄，是扛着）
□ 这个内核是不是观众自己也有、但从来没说出口的？
```

**内核不是主题。主题是"独居老人需要陪伴"。内核是"水不能放超过七天，他每三天换一次"。**
——主题是概念，内核是那个让人沉默的具体细节。

---

## 第二步：受众设计

### 三个问题确定受众

```
1. 谁看了会沉默？
2. 他们自己在压着什么？
3. 看完之后他们会做什么？
```

### 受众类型映射

| 受众 | 他们的伤口 | 内核方向 | 例子 |
|------|----------|---------|------|
| 独居老人的子女 | 愧疚。回不去。 | 「不是不想回去」 | 敲一下门 |
| 失去过重要的人 | 遗憾。没来得及说的。 | 「她的话还在」 | 后来呢 |
| 在外打拼的年轻人 | 孤独。没人看见。 | 「有人在」 | 面试 |
| 父母 | 怕自己老了被忘记 | 「每天」 | 敲一下门 |

### 受众自检

```
□ 有没有一个具体的「人」？不要说「25-35岁女性」
□ 这个人在深夜会想什么？
□ 看完之后，她会给谁打电话？
```

## 第三步：选择叙事框架

剧情短片可选四种框架。根据故事类型选择。

### 框架一：英雄之旅（压缩版）—— 最通用

> 适用：有完整人物弧光的故事。「敲一下门」「后来呢」都用的这个。

```
平凡世界 → 冒险召唤 → 差点错过 → 裂开 → 燃烧 → 暖回来
  (日常)    (打破)    (拒绝召唤)  (磨难)  (复活)  (带回灵药)
```

| 节拍 | 时长占比 | 情绪 | 功能 |
|------|---------|------|------|
| 平凡世界 | 15% | 安静 | 建立日常质感。让观众认识这个人。 |
| 冒险召唤 | 10% | 意外 | 一个打破日常的瞬间。不是灾难，是裂缝。 |
| 差点错过 | 20% | 紧张→犹豫 | **最重要的节拍。** 差一点就过去了。 |
| 裂开 | 25% | 绷断 | 压不住了。声音哽住。手抖。沉默。 |
| 燃烧 | 15% | 主动 | 角色自己选择打开。不是被问出来的。 |
| 暖回来 | 15% | 安静→余韵 | 不是大团圆。是「会好的」。 |

### 框架二：误会→翻过来 — 适合强反转

> 适用：开篇需要强钩子的故事。3秒内制造困惑。

```
制造误会(0-8s) → 堆叠证据(8-15s) → 翻过来(15-25s) → 真相的重量(25-40s)
```

| 节拍 | 功能 |
|------|------|
| 制造误会 | 观众和主角同时误解。钩子。 |
| 堆叠证据 | 让误解越来越深。观众开始紧张。 |
| 翻过来 | 一个细节推翻一切。恍然大悟。 |
| 真相的重量 | 翻过来之后不是松一口气——是更重的东西。 |

> 「敲一下门」用的就是：以为要发难→结果是求救。

### 框架三：重复→打破 — 适合日常质感

> 适用：靠重复建立情感，然后打破。Pixar Story Spine 路线。

```
每天如此 → 直到一天 → 因为这样 → 因为这样 → 直到最后 → 从此
```

| 节拍 | 功能 |
|------|------|
| 每天如此 | 重复的动作/对话。建立节奏。 |
| 直到一天 | 一个变化。小变化。 |
| 因为这样 | 连锁反应。情绪累积。 |
| 直到最后 | 最大的那个瞬间。压不住了。 |
| 从此 | 不是结局。是新的日常。 |

> 「饭还热着」就是这个：四次"饭还热着"→最后一次在坟前。

### 框架四：一句话结构 — 极简

> 适用：30秒以内。一个瞬间。一个动作。一句话。

```
沉默 → 动作 → 裂开 → 字幕
(10s)  (8s)  (8s)   (4s)
```

全部情绪压缩在一个微小动作里。没有台词或只有一句台词。

### 框架五：借题→翻过来 — 适合反差/快反馈

> 适用：15-25秒。轻量开场。最后一秒翻出真相。即时情绪反馈。
> 核心：**观众以为在聊A。最后一秒发现聊的是B。B才是真相。**
> 反馈不绑定情绪——可以是好笑、心疼、爽、意外、获得、满足。

```
借题(0-5s) → 展开(5-12s) → 翻过来(12-18s) → 即刻反馈(18-22s)
```

| 节拍 | 功能 | 枣树例子 |
|------|------|---------|
| 借题 | 一个日常话题。轻松。观众没防备。 | "哥。鲁迅写两棵枣树。是不是凑字数？" |
| 展开 | 给出一个合理的解释/讨论。观众跟着走。 | "他写的是孤独。悲凉。这么讲吧……" |
| 翻过来 | **落到对方/观众身上。话题突然变成镜子。** | "你床上有两个枕头。一个是你的。另外一个也是你的。" |
| 即刻反馈 | 观众懂了。不需要再解释。停一秒。结束。 | 沉默。字幕或表情收尾。 |

**公式**：
```
借一个日常话题 → 给一个合理解释 → 翻出真相 → 停。不解释。
```

**各类情绪的翻法**：

| 翻出什么 | 观众反应 | 例子 |
|---------|---------|------|
| 孤独 | 鼻酸 | 两个枕头都是你的 |
| 被偏爱 | 暖 | 别人都记不住。就他记得 |
| 逆袭 | 爽 | 你以为我是实习生？这公司是我开的 |
| 真相 | 意外 | 你以为他在夸你？他是在告别 |
| 知识点 | 获得 | 你以为A。其实B。学到了。 |
| **笑+心酸** | **笑完沉默** | **"别加了。骑个自行车来也不容易。" → "你自行车停我奔驰旁边。我倒不出来了。"** |

### 反差进阶：二层翻

> 普通反差：A → B。观众恍然大悟。
> 二层反差：A → B（看似有道理）→ C（真相。B不是那个意思）→ D（笑完底下还有一层）。

```
会所例子拆开：
  A: 到钟了。加个钟吧。
  B: 别加了。骑自行车来不容易。（观众：她好体贴）
  C: 你自行车停我奔驰旁边。我倒不出来了。（观众：原来不是体贴。是要走）
  D: 笑完。底下还有——他骑自行车。她开奔驰。他来的不容易。她只想走。
```

**二层翻的关键**：第一翻让观众以为懂了。第二翻告诉他们没懂。翻完之后观众自己发现——还有一层。

### 反差的核心技术：模糊诱导

> **用一句可以有两种理解的话。让对方自己填进期望。然后翻出来——其实是另一种意思。**

```
三案例对照：

          借的题          模糊的话                    对方脑补     翻出真相
  ───────────────────────────────────────────────────────────────────
  枣树    鲁迅文章      "一棵是枣树另一棵也是"        凑字数？     孤独。你床上有两个枕头。
  会所    加钟          "别加了骑自行车不容易"        她体贴       你车挡我奔驰了。
  护士    工资          "每月两万起步"               月薪两万      每天走路步数。
```

**模糊是引擎。** 不是骗。是话本身有两种解释。听众自己选了好的那个。翻的时候告诉他——不是那个意思。

造模糊句的方法：
- 省略主语/宾语： "两万起步"——没说是工资还是步数
- 省略动机： "别加了。骑自行车不容易"——没说是体贴你还是想让你走
- 借用典故： "一棵是枣树另一棵也是"——没说是孤独还是凑字

### 框架选择指南

| 故事类型 | 推荐框架 | 最短时长 |
|----------|---------|---------|
| 人物弧光完整、情感沉浸 | 框架一：英雄之旅 | 25-35秒 |
| 开篇强钩子、层层揭开 | 框架二：误会→翻过来 | 25-35秒 |
| 靠重复/日常建立情感 | 框架三：重复→打破 | 25-35秒 |
| 一个瞬间、一个动作 | 框架四：一句话结构 | 20-25秒 |
| **话题借力、最后一秒翻** | **框架五：借题→翻过来** | **15-25秒** |

## 第四步：人物设计

### 三层人设

```
表层身份（TA看起来是谁）
    ↓ 反差
隐藏层（TA真正是什么样的人）
    ↓ 动机
核心目标（TA在扛着什么）
```

### 设计规则

**1. 不写完美的人**

角色必须有一个"笨拙"的地方：
- 妹儿（敲一下门）：被婆婆抓手腕时吓到了，嘴唇动了动没敢说话——**她不是英雄。她是普通人被推到了某个位置。**
- 妹儿（后来呢）：提綦江→沉默→站起来要走——**她怕。怕自己多嘴了。**

**2. 配角比主角更用力**

> 苟师是《主角》的魂。不是忆秦娥。

剧情短片同理——**品牌方的人（送水妹儿）是"看见者"，被看见的人（婆婆/老头）才是情感核心。** 主角的功能是让配角发光。

**3. 人物动机不直接说**

| 不要 | 要 |
|------|---|
| "今天不是来送水的。是来看哈你。" | 空手来了。被问水呢。说"搞忘在车上了"。 |
| "我怕你一个人孤单。" | 倒水。放杯子。坐小凳上。什么都没说。 |

**4. 用一个物件锚定人物**

| 人物 | 物件 | 功能 |
|------|------|------|
| 婆婆 | 旧铁盒零钱+医院挂号单 | 准备了很久。等这一刻。 |
| 老头 | 旧白瓷杯（杯沿茶渍） | 她的杯子。还在用。 |
| 苟师 | 军绿工服+红毛衣 | 压着。但没认命。 |

### 人物设计自检

```
□ 这个人物在扛着什么？扛了多久？
□ 他有一个笨拙的瞬间吗？
□ 他的物件是什么？
□ 观众能在第几秒认出「这个人是真的」？
```

## 第五步：场景设计

### 场景不是背景。场景是情绪的放大器。

| 场景元素 | 情绪功能 | 例子 |
|---------|---------|------|
| 门框 | 冷暖交界。内外世界。 | 妹儿站在门口——走廊冷→屋里暖 |
| 挂钟 | 时间。等待。静止。 | 滴答声贯穿。沉默时只有钟摆。 |
| 光线 | 情绪温度计。 | 暖黄台灯→哽住时阴影遮半边脸 |
| 杯子/物件 | 不在场的人。 | 旧白瓷杯有茶渍——她的杯子。还在用。 |
| 窗外 | 外面的世界 vs 里面的世界。 | 定格窗外——暖黄小窗嵌在深蓝夜色里 |

### 场景三原则

1. **一个场景就够了。** 剧情短片不超过2个场景。最好是1个。
2. **用光线推情绪。** 不是用台词。
3. **场景里有「不在场的人」。** 旧杯子、老照片、空椅子。

## 第六步：冲突设计

### 短视频的三种安全冲突

> ⚠️ 短视频不吃大吵大闹的强冲突。最火的是**小冲突、小情绪、小误会。**

| 冲突类型 | 核心逻辑 | 例子 |
|---------|---------|------|
| **误会型** | 看到表面，没看到真心 | 以为要发难→其实是求救（敲一下门） |
| **错过型** | 差一点点就圆满 | 妹儿起身要走→老头才开口（后来呢） |
| **偏爱型** | 别人都不行，只有你行 | 婆婆只找送水妹儿——没有别人了 |

### 冲突的禁区

- ✗ 不写激烈吵架、辱骂、暴力
- ✗ 不写狗血三观（出轨、背叛、算计）
- ✗ 不写为冲突而冲突

### 冲突设计核心公式

```
冲突 = 一个想给 + 一个不敢接
     = 妹儿想问 + 老头不敢说
     = 婆婆想托付 + 妹儿没反应过来
```

| **反转日常型** | 以为今天跟昨天一样。但昨天已经不一样了。 | 随口问"阿姨了？"→ 阿姨昨晚走了（后来呢） |

### 冲突的禁区

- ✗ 不写激烈吵架、辱骂、暴力
- ✗ 不写狗血三观（出轨、背叛、算计）
- ✗ 不写为冲突而冲突

### 冲突设计核心公式

```
冲突 = 一个想给 + 一个不敢接
     = 妹儿想问 + 老头不敢说
     = 婆婆想托付 + 妹儿没反应过来
```

**冲突不是对抗。冲突是「差点」。**

## 第七步：情绪节奏

### 情绪 = 下行（压抑）× 上行（释放）

| 类型 | 是什么 | 观众反应 |
|------|--------|---------|
| **下行情绪（压）** | 沉默、尴尬、哽住、攥手、错开眼 | 紧张。替角色担心。 |
| **上行情绪（放）** | 笑了、握住手、开口了、送别 | 松一口气。泪点。 |

> **泪点不是哭。是"压→放"的瞬间落差。落差越大，泪点越强。**

### 情绪曲线模板

```
情绪强度
  ↑
  │         ┌─┐ 裂开（最高点）
  │        /   \
  │       /     └─┐ 缓回来
  │      /         └──┐ 余韵
  │  ┌─┐ 差点          └──
  │ /   \
  │/     └ 沉默
  └──────────────────────→ 时间
  日常  冲突  犹豫  裂开  暖回  定格
```

### 情绪节拍密度

| 总时长 | 情绪转折次数 | 每次转折间隔 |
|--------|------------|------------|
| 20-30秒 | 2-3次 | 每8-10秒 |
| 30-45秒 | 3-4次 | 每8-12秒 |
| 45-60秒 | 4-5次 | 每10-12秒 |

### 沉默的力量

> 「后来呢」三个字的力量，来自前面两年的沉默。
> 「拜托老」三个字的重量，来自婆婆一辈子的独自支撑。

**规则：最重的话前面，放最长的沉默。**

## 第八步：时长规划

### 时长 → 镜头数 → 情绪密度

| 目标时长 | 镜头数 | 框架 | 情绪节拍 | 台词字数上限 |
|----------|--------|------|---------|------------|
| 20-25秒 | 2-3镜 | 一句话结构 | 2次转折 | 50字 |
| 30-40秒 | 3-4镜 | 误会→翻过来 | 3次转折 | 80字 |
| 40-50秒 | 3-5镜 | 英雄之旅（完整） | 4次转折 | 100字 |
| 50-60秒 | 4-5镜 | 英雄之旅+日常铺垫 | 5次转折 | 120字 |

### 时长建议原则

```
□ 一个「差点错过」最少需要 3 秒（沉默+起身+停顿）
□ 一个「裂开」最少需要 5 秒（哽住+沉默+接住）
□ 即梦 AI 单次生成上限 15 秒 → 单个镜头不超过 15 秒
□ 台词总字数不超过 120 字 → 每镜不超过 50 字
```

### 给建议时长的方法

1. 先定内核。内核越重，需要的沉默越多。
2. 估算情绪转折次数。一次转折 ≈ 8-10秒。
3. 加上暖回来的余韵（5-8秒）。
4. 就是建议时长。

> 例：「后来呢」初版内核 = 两年没人问。8个节点 × 约5秒 → 建议 40秒。
> 最终版：3个节点（撞见→裂开→掐断），23秒。情绪越浓，时间越短。

### 时长反向原则

```
□ 情绪节点越多 ≠ 越感人。往往是越拖越散。
□ 内核够重 → 不需要铺垫。直接给。
□ 掐断的地方就是终点。不需要暖回来。
□ 写完之后问：能不能再短？砍到不能再砍为止。
```

## 写作铁律

### 铁律一：留白

> **不要说出来。让观众自己发现。**

| 不要说 | 要让观众看见 |
|--------|------------|
| "我担心你" | 空手来。倒水。坐小凳上。 |
| "我想她了" | 旧杯子。茶渍。每三天换一次水。 |
| "我信任你" | 铁盒零钱。挂号单。墙上儿子电话。 |

### 铁律二：去台词化

> **最重的情绪发生在沉默里。**

优先顺序：**动作 > 眼神 > 物件 > 光线 > 字幕 > 台词**

如果一场戏的情绪能用动作表达，就删掉台词。

### 铁律三：字数控制

| 规则 | 数值 |
|------|------|
| 全片台词上限 | 120字 |
| 单镜台词上限 | 50字 |
| 单句呼吸单位 | ≤12字 |
| 最重的那句话 | ≤5字 |

> 「后来呢」——3个字。够了。

### 铁律四：方言原则

剧情类优先使用方言（重庆话/四川话）。方言 = 真实感 + 地域认同 + 情绪颗粒度。

转换规则（重庆话）：
- 了→老 | 的→哩 | 什么→啥子 | 怎么→啷个
- 没有→没得 | 这个→勒个 | 谁→哪个 | 知道→晓得

### 铁律五：品牌落点克制

> **品牌不出现。或只出现一次。在最后。**

- ✗ 不要：角色对着镜头说品牌名
- ✗ 不要：产品占据画面中心
- ✓ 「敲一下门」：定格在门口水桶+一行字
- ✓ 「后来呢」：窗外定格+字幕淡入

**品牌是背景。人是前景。**

### 铁律六：掐断

> **说到一半。声音断了。比说出来重十倍。**

角色想把最痛的东西说出来——但说到一半卡住了。不是不想说。是说不下去。

| 掐断的位置 | 力量来源 |
|-----------|---------|
| "我出去接……" | 后面的事观众自己填。每个人填的都是自己的遗憾。 |
| "她走那天……" | 留白比叙述更有力。 |
| "拜托老。" | 前面说了一大段。最后三个字。断在这里。 |

**规则：在情绪爬升的最高处。戛然而止。不往下接。**

### 铁律七：动作预算

> **动作 = 成本。动作越多，情绪空间越少。**

每个动作占用观众的注意力。动作堆满，观众在"看"，不是"感受"。

| 动作数量 | 观众状态 |
|---------|---------|
| 1-2个/镜 | 能感受。能代入。 |
| 3-4个/镜 | 跟着看。但来不及想。 |
| 5+/镜 | 画面在跳。割裂。出戏。 |

**实操：写完之后，数每镜的动作。超过2个就砍。砍到只剩最核心的。**

> 例：「后来呢」镜2初版有 20+ 个微动作——走过去、停下、嘴动、合上、手抬起、停在半空、收回、肩膀抖、攥茶几、指节发白……砍了七八轮，最后只剩：她问 → 他崩 → 挂钟滴答。

## 结构模板

### 模板A：30秒 误会→翻过来

```
镜1 (0-10s) — 制造误会
  - 日常动作被打断
  - 一个意外的行为 → 主角和观众同时困惑
  - 情绪：紧张、困惑

镜2 (10-20s) — 翻过来
  - 一个细节推翻一切
  - 主角重新理解刚才的事
  - 情绪：恍然→更重的东西压上来

镜3 (20-30s) — 余韵
  - 无声的动作。物件。光线。
  - 字幕淡入。品牌落点。
  - 情绪：安静→暖回来
```

### 模板B：40秒 英雄之旅

```
镜1 (0-15s) — 日常→打破→差点错过
  - 日常质感（一个动作/物件）
  - 意外打破（一句话/一个行为）
  - 沉默→犹豫→差点走→被拉住
  - 情绪：安静→意外→紧张→差点

镜2 (15-30s) — 裂开
  - 再次尝试触碰
  - 对方开始说→哽住→绷断
  - 伸手→握住→缓过来
  - 情绪：犹豫→裂开→被接住→暖

镜3 (30-40s) — 燃烧→暖回来
  - 一个主动的选择（拿出某物/做某事）
  - 镜头拉远。光线变化。声音。
  - 字幕淡入。
  - 情绪：主动→安静→余韵
```

### 模板C：50秒 完整弧光

```
镜1 (0-12s) — 日常质感
  - 一个习惯动作
  - 一个物件锚定人物
  - 情绪：安静、真实

镜2 (12-22s) — 打破→差点错过
  - 意外发生
  - 沉默→犹豫→差点走
  - 情绪：紧张→差点

镜3 (22-35s) — 裂开→燃烧
  - 开口→哽住→绷断
  - 被接住→主动选择
  - 情绪：裂开→燃烧

镜4 (35-50s) — 暖回来+余韵
  - 镜头拉远。光线。
  - 旋律。字幕。品牌落点。
  - 情绪：安静→暖→余韵
```

## 第九步：观众映射

> **不能自嗨。每个情绪节点必须知道：观众感受到什么。想起什么。**

### 三问映射表

写每个情绪节点时，必须回答：

| 问题 | 含义 | 不能是 |
|------|------|--------|
| 画面发生什么 | 角色行为 | — |
| **观众心里什么感受** | 揪心？鼻酸？愣住？心沉？ | "感动""难过"——太泛。要具体到生理反应。 |
| **观众想起了自己的什么** | 记忆中对应的瞬间 | **"不知道" = 这个节点无效。** |

### 映射示例（「后来呢」镜2）

| 画面 | 观众感受 | 观众想起 |
|------|---------|---------|
| "阿姨了？"随口问的 | 跟平时一样。没警觉。 | — |
| "昨天晚上……她还笑起的" | **心里咯噔一下** | "昨晚"——不对。出事了。 |
| "我出去接……"声音断了 | **鼻子一酸** | 那个瞬间。我没在。那通没打的电话。 |
| 挂钟滴答。字幕。 | **沉默。低头。** | 我得给谁打个电话。 |

### 映射自检

```
□ 每个情绪节点，观众感受是什么？（不能只写角色的情绪）
□ 最后一个节点，观众会想起自己的什么？
□ 有没有一个节点"观众无感，只有作者在自嗨"？→ 删掉。
```

## 第十步：留白判断

### 什么不该说？什么不该演？

```
□ 观众已经能看见的 → 角色别说。
  例：茶几上旧杯子+照片 → 不需要说"勒个杯子是她哩"。

□ 观众已经能猜到的结局 → 别演出来。
  例："我出去接……"断了 → 不需要说"人就没得老"。观众自己填。

□ 情绪到顶了 → 别往下接。掐断。
  例：挂钟滴答就够了。不需要倒水、坐下、窗外。
```

### 砍动作口诀

```
写完之后问三遍：
1. 这个动作删了，观众还懂不懂？→ 懂。删。
2. 这句台词删了，情绪还在不在？→ 在。删。
3. 这个镜头删了，故事完不完整？→ 完整。删。
```

## 四线并行图

> **每条线单独看是一个维度。并在一起，能看到情绪是怎么传递到观众身上的。**

### 结构

```
                        掐断点
                          ↓
  情节线  ──→ 冲突 ──→ 反转 ──→ 裂开 ──→ ✗（不往下演）
  人物线  ──→ 压着 ──→ 被问 ──→ 绷断 ──→ 沉默
  物件线  ──→ 凉水 ──→ 照片 ──→ 杯沿茶渍 ──→ 挂钟滴答
  情绪线  ──→ 困惑 ──→ 心沉 ──→ 鼻酸 ──→ 沉默（观众填自己的遗憾）
                          │
                          └── 四条线在这里交汇。
                             画面、人物、物件、观众——全部指向同一个瞬间。
```

### 四线映射表（以「后来呢」23秒版为例）

| 秒 | 情节线 | 人物线（老头） | 人物线（妹儿） | 物件线 | **观众感受** | **观众想起** |
|----|--------|-------------|-------------|--------|------------|------------|
| 0-1 | 黑屏。"你走嘛" | 赶她走。抖。 | 僵住。 | — | 困惑 | — |
| 1-5 | 画面亮。杯子+照片 | 转过身。脸湿。 | 看见了。 | 旧杯子·凉水·照片 | 警觉 | — |
| 5-10 | 她觉得不对劲 | 沉默。 | 没走。在看。 | 杯沿茶渍 | 跟她一样不安 | — |
| 10-12 | "阿姨了？" | — | 随口问。以为在里屋。 | — | 正常。没防备 | 每天一样的问候 |
| 12-15 | "昨天晚上……她还笑起的" | 开始说。 | 在听。 | — | **心一沉** | "昨晚"——坏了 |
| 15-17 | **"我出去接……"断了** | 绷断。满脸。 | 愣住。 | 挂钟滴答 | **鼻酸** | **"我没在"的瞬间。那通电话。** |
| 17-20 | 她看向杯子。明白。 | 说不下去。 | 突然明白。 | 旧杯子。照片。 | 震惊 | — |
| 20-23 | 字幕「后来喃」 | 沉默。 | 没走。 | 挂钟。字幕。 | **沉默。低头。** | **我得给谁打个电话。** |

### 四条线的分工

```
情节线 → 控制信息释放节奏。「先给什么、藏什么、什么时候揭」
人物线 → 控制共情入口。「观众通过谁的眼睛看这件事」
物件线 → 控制视觉锚点。「不说话的时候，什么在说话」
情绪线 → 控制最终落点。「观众看完想起谁」
```

### 交汇点 = 掐断

```
四条线在"我出去接……"这一帧交汇：

  情节 → 信息释放到最关键的一刻。戛然而止。
  人物 → 老头想说。说不下去。妹儿刚明白。
  物件 → 挂钟滴答。杯子是凉的。
  情绪 → 观众鼻酸。不是为老头——是想起自己。

  这一帧之后。什么都不需要了。
```

## 输出要求：设计思路

> **每个剧情脚本必须附带「设计思路」章节。放在脚本正文之后、台词汇总之前。**
> **必须包含：四线映射表 + 四条线分工说明。**

### 设计思路模板

```
## 设计思路

### 一、情绪线（观众视角）

| 时间 | 画面 | 观众感受 | 触发记忆 |
|------|------|---------|---------|
| 0-1s | "你走嘛" | 困惑——发生什么了 | — |
| ... | ... | ... | ... |

### 二、人物线（角色动机）

- **老头**：他在扛什么 → 为什么今天绷不住了 → 他选择说什么
- **妹儿**：她来干什么 → 她发现了什么 → 她做了什么选择

### 三、情节线（信息释放顺序）

先给什么 → 藏什么 → 什么时刻揭 → 什么不揭

### 四、物件线（视觉锚点）

- 每个物件的情绪功能
- 物件状态的变化（凉水→热气；满的→少了）
```

## 自检清单

### 创作前

```
□ 内核是什么？（≤20字）
□ 写给谁看？她深夜会想什么？
□ 选哪个框架？为什么这个框架适合这个故事？
□ 人物在扛着什么？扛了多久？
```

### 脚本写完后

```
□ 前三秒怎么留人？
□ 每镜 ≤ 2个动作？（超过就砍）
□ 情绪最高点在哪里？有没有「掐断」？
□ 有没有「观众映射」？每个节点观众感受到什么？
□ 有没有过度解释？（观众能看见的，角色别说）
□ 有没有过度表演？（观众能猜到的结局，别演）
□ 最重的那句话 ≤5字？
□ 全片台词 ≤ 80字？（剧情类比口播更少）
□ 品牌只出现在最后字幕？
□ 能不能再短？砍到不能再砍为止。
```

### 温度自检

```
□ 有没有人味？（物件、动作、生活质感）
□ 能不能想象用户表情？（掐断那一刻，屏幕前有人低头）
□ 会不会想关注？
□ 观众看完会想起谁？会给谁打电话？（答不上来 = 内核没落地）
```
