### 一、行业分析

- 行业规模：农村土灶市场分散，但随着农村振兴和乡村旅游发展，需求稳定
- 发展趋势：传统土灶回归热（追求柴火饭香）+ 农村自建房刚需
- 季节性特征：冬季建灶多（农闲+春节前翻修）+ 春秋建房季
- 产品类型：非标品服务（根据客户需求定制）

### 二、找蓝海（竞争分析）

- 竞争对手分析：本地零散工匠为主，极少有做线上营销的
- 蓝海机会矩阵：农村土灶建造服务在抖音/小红书几乎是空白
- 红海vs蓝海业务分布：城市厨卫装修是红海，农村土灶是蓝海

### 三、人群细分

- 付费人vs使用人：付费人=使用人（都是农村业主/家庭）
- 客群痛点挖掘：不会建/找不到人建/建得不好/价格不透明
- 客群优先级：农村自建房业主 > 农家乐/民宿 > 老房翻修

### 四、长尾需求

- 不同人群的独特需求：结实耐用 vs 美观好看 vs 省钱实用
- 细分场景需求：婚宴大灶 / 日常小灶 / 农家乐商用
- 蓝海需求发现：上门服务 + 后续维护 + 改造升级

### 五、知识技能解决

- 专业知识技能：土灶结构设计、砌砖技术、烟道处理
- 服务解决方案：一站式上门建造 + 维修 + 改造
- 定制化能力：根据厨房大小/烹饪习惯定制

### 六、搜前搜后

- **搜索前问题（客户在搜索时在想什么）**：
  - 直接需求：农村土灶怎么建 / 打一个土灶多少钱 / 哪里有上门打灶的
  - 关联需求：农村厨房设计 / 柴火灶哪个牌子好
  - 潜在需求：老灶台翻新 / 烟囱改造

- **搜索后问题（搜索后还会问什么）**：
  - 直接关联：能用多久 / 烧什么柴 / 好不好清理
  - 上下游关联：锅具配套 / 柴火存放
  - 决策顾虑：价格多少 / 质量保证 / 工期几天

### 七、行业关联

- 上游关联（客户从哪来）：农村自建房群体、乡村旅游投资、婚宴场地建设
- 下游需求（客户到哪去）：柴火采购咨询、锅具推荐、土特产烹饪
- 关联行业矩阵：农村厨房装修、柴火灶品牌、乡村旅游规划设计
