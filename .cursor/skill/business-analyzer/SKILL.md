# 纳瓦尔框架业务分析专家

## 核心能力

```
分析维度：
├── 定位分析（你是谁？你能提供什么？）
├── 价值分析（你的独特价值是什么？）
├── 经验复利分析（做得越久越值钱吗？）
├── 杠杆分析（你能用什么放大价值？）
└── 子弹剥离分析（你能抽身吗？）

输出物：
├── 机会评估报告
├── 风险分析
├── 行动计划
└── 路线图
```

---

## 分析框架

### 一、定位分析 - 回答"你是谁"

```
你的定位矩阵：

                    高价值输出              低价值输出
              ┌─────────────────┬─────────────────┐
      擅长    │  ★ 核心角色      │    执行角色      │
              │  （你的定位）    │   （替代性强）   │
              ├─────────────────┼─────────────────┤
      不擅长  │    不适合        │    边缘角色      │
              │  （别硬撑）      │   （别做）       │
              └─────────────────┴─────────────────┘

找到你"擅长且高价值"的交叉点 = 你的定位
```

### 二、价值分析 - 回答"你能提供什么"

```
价值层级：
┌─────────────────────────────────────────────────────────────┐
│ 层级4：认知差价值                                            │
│   → 你知道的，别人不知道也不容易知道                           │
├─────────────────────────────────────────────────────────────┤
│ 层级3：匹配价值                                              │
│   → 你能连接对的供给和需求                                    │
├─────────────────────────────────────────────────────────────┤
│ 层级2：执行价值                                              │
│   → 你能做别人不愿意做的事                                   │
├─────────────────────────────────────────────────────────────┤
│ 层级1：体力价值                                              │
│   → 谁都能做的事                                             │
└─────────────────────────────────────────────────────────────┘

你的价值层级越高，不可替代性越强
```

### 五、经验复利分析 - 回答"做得越久越值钱吗"

```
复利业务 vs 线性业务：

┌─────────────────────────────────────────────────────────────────────────┐
│  ★ 复利业务（经验值钱）                                                  │
│   → 做得越久，经验越多，客户越愿意付高价                                  │
│   → 医生、律师、咨询师、高考志愿填报专家                                   │
│   → 10年经验 vs 1年经验，价值天差地别                                    │
├─────────────────────────────────────────────────────────────────────────┤
│  ✗ 线性业务（经验不值钱）                                                │
│   → 做得再多，也只是重复，收费上不去                                      │
│   → 修盘子、送外卖、搬砖                                                  │
│   → 修10000个盘子 ≠ 修1个盘子 × 10000                                   │
└─────────────────────────────────────────────────────────────────────────┘

判断标准：
□ 这个业务需要"判断力"还是"执行力"？
□ 客户会为"经验"付更多钱吗？
□ 新人需要多久才能达到你的水平？
```

## 三、杠杆分析 - 回答"如何放大"

```
四种杠杆类型：

┌──────────────┬──────────────┬──────────────┬──────────────┐
│   代码杠杆    │   媒体杠杆    │   人力杠杆    │   资本杠杆    │
├──────────────┼──────────────┼──────────────┼──────────────┤
│   技能/Skill  │   内容/品牌   │   团队/合伙  │   投资/资金  │
├──────────────┼──────────────┼──────────────┼──────────────┤
│  ★ 边际成本0  │  ★ 一次产出  │  需要分钱     │  需要承担风险 │
│              │  多次分发     │  管理成本     │  杠杆+双刃剑 │
├──────────────┼──────────────┼──────────────┼──────────────┤
│  你的"子弹"   │  你的影响力   │  你的放大器   │  你的加速器   │
└──────────────┴──────────────┴──────────────┴──────────────┘

最优策略：优先用"边际成本为0"的杠杆
```

### 四、子弹剥离分析 - 回答"你能抽身吗"

```
子弹剥离三阶段：

阶段1：子弹在身体里（1.0模式）
├── 靠时间和体力赚钱
├── 停下来 = 收入停止
└── 天花板明显

阶段2：部分剥离（2.0模式）
├── 建立系统，找人帮忙
├── 但核心还是自己做
└── 可以同步做1-2件事

阶段3：完全剥离（3.0模式）
├── 系统自动运转
├── 主要靠声誉和框架
└── 你的存在 = 资产

你的子弹是什么？能否被标准化？
```

## 八条核心问题

```
⚠️ 在分析之前，先用「项目筛选标准」筛一遍。不匹配的项目，不进入深度分析。

在决定之前，必须回答这8个问题：

□ 0. 项目通过筛选标准了吗？
   → 决策周期？复购？客户群体？可视性？专业门槛？客单价？

□ 1. 这个机会的本质是什么？
   → 不是表面看起来的那样

□ 2. 我的定位是什么？
   → 招商负责人？销售？合伙人？

□ 3. 我能提供的独特价值是什么？
   → 技术背书？信息差？谈判能力？

□ 4. 我能用什么杠杆放大价值？
   → 代码？媒体？人力？资本？

□ 5. 子弹能否剥离？
   → 哪些可以标准化？哪些必须我做？

□ 6. 关键决策点是什么？
   → 需要和对方明确什么？

□ 7. 风险是什么？
   → 资金？声誉？时间？关系？

□ 8. 退出机制是什么？
   → 如何保护自己？
```

## 项目筛选标准（加盟流量引擎模式）

在做任何项目分析前，先用这套标准筛一遍。**选对项目比做对方法重要十倍。**

```
加盟流量引擎模式适合的项目特征：

✅ 客户决策快（几周内能成交）
   → 不是月级别的工业设备采购
   → 面向小B商家或个人创业者

✅ 有复购（耗材、服务、持续需求）
   → 不是一锤子买卖
   → 设备+耗材、设备+服务、设备+系统皆可

✅ 客户群体大（不是只有特定类型工厂）
   → 广泛的小B商家或个人
   → 一个城市有足够多的潜在客户

✅ 视觉可展示（视频能拍出效果差距）
   → 效果可见、可对比
   → 不需要专业背景就能看懂

✅ 不需要加盟商有专业背景
   → 操作简单，普通人能上手
   → 不需要行业经验或技术资质

✅ 客单价适中（几千-几万的加盟费门槛）
   → 10万以内，决策阻力小
   → 回本周期可计算且合理
```

### 反例：不适合加盟流量引擎的项目

```
❌ 非标准件喷涂设备 → 工厂客户、月级成交、一锤子买卖、需技术背景
❌ 大型生产线设备 → 客单价百万级、成交半年起、客户极少
❌ 纯技术服务（如SAAS定制）→ 不可视化、交付重、难标准化
```

### 如果项目不匹配

两种选择：
1. **换项目** — 基金池子里筛一个匹配的，不动模式
2. **换模式** — 走销售代理拿佣金（适合大设备、长周期、高客单），不做加盟系统

## 决策框架

```
                    高收益
                      ↑
                      │
         ┌────────────┼────────────┐
         │    ★ 推荐  │    高风险   │
         │   高杠杆   │   高回报   │
         │            │            │
─────────┼────────────┼────────────┼─────────→  高风险
         │            │            │
         │    低收益  │   ★ 远离   │
         │   低杠杆   │   高风险   │
         │   低回报   │   必亏     │
         └────────────┼────────────┘
                      │
                      ↓
                    低收益

推荐区间：低风险高收益 > 低风险中收益 > 中风险中收益
远离区间：高风险低收益 > 高风险中收益
```

## 路线图模板

### 阶段1：定位验证（第1-2周）

```
目标：回答3个问题
├── 1. 我是谁？（定位）
├── 2. 我能提供什么价值？（产品/服务）
└── 3. 谁会为此买单？（客户）

任务：
□ 盘点你的特定知识
□ 找到你的"甜蜜区"
□ 定义你的客户画像
□ 设计你的MVP

里程碑：定位文档 + 客户画像 + MVP设计
```

### 阶段2：能力建设（第3-6周）

```
目标：打造你的"子弹"

任务：
□ 建立你的内容资产（Skill/工具/模板）
□ 设计你的内容矩阵
□ 搭建分发渠道
□ 打磨转化能力（一对一话术/对比表）
□ 建立背书（案例/评价/认证）

里程碑：30条内容储备 + 转化话术Ready
```

### 阶段3：MVP测试（第7-12周）

```
目标：用最小成本验证商业模式

核心原则：快速试错，低成本验证

任务：
□ 设定验证指标
□ 启动内容获客
□ 进行客户沟通
□ 迭代优化
□ 建立飞轮

里程碑：
├── 10个有效客户咨询
├── 3个付费客户成交
├── 转化率验证通过
└── 标准化交付流程确定
```

### 阶段4：规模放大（第13周+）

```
目标：从1到100

路径选择：
├── A. 深度深耕（提高客单价）
├── B. 团队复制（招人做执行）
├── C. 产品化（降低边际成本）
└── D. 平台化（建立品牌）

里程碑：
├── 月收入目标达成
├── 被动收入占比 > 50%
└── 子弹完全脱离身体
```

## 常见坑和避坑指南

```
坑1：定位模糊
   → 症状：什么都想做，什么都不精
   → 解决：先窄后宽，找到切入点

坑2：内容无效
   → 症状：发了很多没人看
   → 解决：先研究平台规则，再研究用户需求

坑3：转化断层
   → 症状：有人咨询但成交少
   → 解决：打磨话术，降低成交阻力

坑4：交付过度
   → 症状：服务客户太累，没时间获客
   → 解决：标准化交付，控制服务客户数量

坑5：现金断流
   → 症状：收入不稳定，焦虑
   → 解决：保持低成本结构，验证期不投入大资金
```

## 使用示例

**用户说**：
> 朋友是基金管理者，有AI机器人、AI培训、智慧电网三个项目，想让我帮他招商。我擅长规划、信息收集、一对一谈判，不擅长一对多教育。有Skill能出内容。应该怎么做？

**AI响应**：
1. 读取SKILL.md
2. 按"输出格式"生成分析报告
3. 重点关注：定位矩阵、杠杆类型、子弹剥离
4. 生成定制化路线图
5. 更新到索引（如果需要）
